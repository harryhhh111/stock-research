# HD Hyundai Electric（KRX: 267260）研究

> 初稿整理：2026-09-15 ｜财务/订单数据截至：2026Q2（2026-07-28 披露）｜股价数据截至：2026-09-14
>
> 本文只把已披露的订单、设备和工厂节点放入证据链；不从营收、合同金额、厂商产能或市场份额反推数据中心已上线 GW。

## 结论先行

1. **它是比 Hitachi Energy 更适合继续做“订单—设备—园区”反查的上市公司。** 业务较聚焦于电力变压器、GIS、断路器、配电设备及旋转设备，且拥有 Alabama 本地变压器工厂。[公司产品与北美网络][2]
2. **数据中心订单证据更硬，但仍非 GW 证据。** 2026-07，公司披露与一名未具名全球 Big Tech 签订面向北美在建数据中心的长期框架协议：最高 KRW1.1212tn，按项目进度分批供货至 2028。实际 PO 仍会分批下达，未披露园区、设备型号、MVA 或调试日期。[公司公告][3] [交易所公告][4]
3. **景气与盈利已在财报出现。** 2026Q2 收入 KRW1.1418tn、营业利润 KRW287.0bn、营业利润率 25.1%，在手订单 $8.49bn；但订单中数据中心所占比例没有公开，因此不能拿 backlog 的某个比例估算数据中心电力。
4. **2027 的可核对催化剂是 Alabama 二厂。** 该厂计划 2027-04 完工，预计将美国超高压变压器产能增加约 50%，新增 765kV 级制造/试验能力。它增强未来供给，不是某座数据中心已经投运的证据。[公司新闻稿转发][5]

## 1. 公司概览与业务地图

HD Hyundai Electric 是韩国上市的电力设备公司，不是 Hyundai Motor。其产品可分为：

```text
电网/发电侧
  大型电力变压器、并联电抗器、GIS、断路器
                    ↓
园区/工业配电侧
  配电变压器、MV/LV 开关柜、MV/LV 断路器
                    ↓
其他
  高低压电机、发电机、海洋电气、BESS、能源管理软件
```

其美国实体 HD Hyundai Power Transformers USA 位于 Montgomery, Alabama；公司列示该厂的变压器能力范围为 **60–750MVA、最高 500kV**。这说明其具备美国本地高压变压器制造能力，但该范围是产品能力，不能视为单个数据中心项目的设备清单。[公司北美网络][2]

## 3. 数据中心订单：目前最有价值、也最易被误读的一条证据

### 3.1 已披露事实

| 项目 | 事实 | 研究处理 |
|---|---|---|
| 客户 | “全球 Big Tech”，未披名 | 不猜测 Microsoft、Meta、Google、Amazon 或 Oracle |
| 地点 | 北美、客户正在建设的数据中心 | 未披露州/园区，无法同 utility 项目去重 |
| 合同类型 | 长期**基本/框架协议**；后续按项目进度分批下 PO | 不把 KRW1.1212tn 当成已确认收入或一次性积压订单 |
| 产品 | 配电设备 KRW553.9bn + 电力设备 KRW567.3bn | 未给变压器/GIS/开关柜的金额、型号或 MVA |
| 最大金额 | **KRW1.1212tn**（公告按 $721.294m、USD/KRW=1,554.40 折算） | 金额不能换算 MW 或 GW |
| 交付窗口 | 至 2028 年分批供货 | 未披露 2027 交付份额、FAT、到场/SAT 或园区上线日期 |

公司公告的价值在于：它把 HD Hyundai Electric 与“北美在建数据中心”的**实际商业关系**连接起来，且同时包括配电与电力设备。其局限也同样明确：实际 PO 分批、合同条款可能调整、没有物理容量和园区定位。因此目前在 `数据中心/电力系统/2027新增数据中心电力上游台账.md` 中只能记为“供应链验证线索”，**计入 2027 Active IT = 0GW**。[公司公告][3] [交易所公告][4]

### 3.2 下一步怎样把它变成可计算证据

1. 追踪公司后续关于单个 PO 的交易所披露，记录设备类型、合同额、交付日期；金额仍不是 MVA。
2. 用客户北美建设计划、州级许可、utility interconnection 和 Alabama 发货/到场信息缩小可能园区。
3. 只有公开得到“某园区专供设备 MVA + 到场/SAT/投运”时，才用上游台账的 1.3–1.6GVA/GW IT 工程先验做**园区电力上限**；然后仍须与机房/IT 上架取最小值。

## 4. 北美产能与供给约束

| 节点 | 公开事实 | 对 2027 模型的含义 |
|---|---|---|
| Alabama 既有工厂 | 2011 年投产，后续多次扩建；公司在当地生产高压变压器 | 是北美本地供给基础，不代表专供数据中心 |
| Alabama 二厂 | 2026-03 破土；投资约 $200m；目标 2027-04 完工 | 是明确的 2027 供给节点，但尚不是“2027 已交付项目” |
| 二厂能力 | 美国超高压变压器产能约 +50%，新增 765kV 级制造/试验；预期年收入增量约 KRW200bn | 没有公开 MVA/台数、良率或满产时间，不能换算可供给 GW |
| Ulsan | 公司称当前扩产计划在 2026-09 完成 | 可能与美国工厂形成出口/工程协同；仍需逐项核对对应产品与产能 |
| 765kV 美国订单 | 公司历史页记录 2026-05 获得 KRW173bn 订单 | 客户、项目、MVA 与是否数据中心均未披露，不纳入 DC 台账 |

**我的推演：** HD Hyundai 的优势是“韩国制造 + Alabama 本地制造 + 高压/配电组合包”。这使它有机会受益于美国供电升级和数据中心园区建设；但也使客户、项目和变压器产能混在一起。要判断定价权与供给瓶颈，不能只看其收入增速，而要追踪超高压变压器的交期、订单转换、工厂爬坡、GOES 与运输。

## 5. 客户、竞争与风险

### 客户与竞争

- 公开可见客户包括美国/欧洲公用事业、工业/半导体项目、海事客户与匿名北美 Big Tech；公司历史页列有 AEP、National Grid、Xcel 等过往公用事业订单，但这些历史案例不能外推为当前数据中心订单。[公司历史][6]
- 高压变压器/变电站主战场的可比公司是 Hitachi Energy、Siemens Energy、GE Vernova/Prolec、Hyosung Heavy、Mitsubishi Electric；在园区中低压层又与 Eaton、Schneider、部分 GEV/Siemens 产品重叠。
- HD Hyundai 更适合做“北美进口/本地供给的补充者”研究，不宜在尚无可复算数据中心 LPT 市占率时宣称其份额或排名。

### 主要风险

1. 框架协议转 PO 的节奏、金额和产品结构低于最大合同额；客户建设项目延期或取消。
2. 美国扩产延迟、试验/质量爬坡不顺，或原材料、运输、贸易政策上升。
3. 高利润率随竞争对手扩产、产品组合变化或低价订单而回落。
4. 北美收入和订单占比高，电网投资周期、汇率、关税和公用事业采购都将放大波动。
5. 把供货合同、园区规划容量、设备 MVA 和 Active IT 混用，导致对 2027 新增电力的高估。

## 6. 估值与后续研究

本轮不写目标价或估值结论。虽然已记录 2026-09-14 股价，但尚未核对总股本、净现金/债务、估值倍数、卖方一致预期及利润率正常化假设；不能因为数据中心框架协议就给出估值判断。

优先补齐：

1. 2026Q3 及后续业绩中的订单、backlog、订单目标和利润率变化；
2. Big Tech 框架协议的分批 PO，及任何 MVA/设备类别/园区披露；
3. Alabama 二厂在 2027-04 后的实际投产、认证、产能爬坡与新增订单；
4. 与 [Hitachi Energy](../HITACHI/Hitachi%20Energy.md)、Hyosung Heavy、Siemens Energy 的同口径比较；
5. 通过北美 utility 的 interconnection/变电站台账反查具体园区，纳入上游电力模型。
