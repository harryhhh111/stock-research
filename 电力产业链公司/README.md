## 使用纪律

1. 厂商收入、订单金额、总产能与市占率只用于理解景气、约束和受益，**不能直接推算年度新增 Active IT GW**。
2. 进入项目级台账须有园区/utility/EPC/厂商的可去重事实：项目专属的设备 MVA、到场、SAT 或投运时间；之后还需与机房机电和已上架 IT 取最小值。
3. 同一园区的主变、配电变、UPS 等是同一功率流的不同层，禁止相加。

方法与项目台账见：[2027 新增 AI 数据中心电力：上游设备反推台账](../数据中心/电力系统/2027新增数据中心电力上游台账.md)。
