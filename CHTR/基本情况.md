你说的 **CHTR** 是 **Charter Communications**，消费者更熟悉它的品牌 **Spectrum**。它是美国最大的有线宽带运营商之一，主要提供家庭互联网、手机、电视和固定电话服务。

## 先给结论

CHTR 现在不是普通意义上的“低估值优质成长股”，而更像一只：

> **高负债、强现金流、核心业务承压、依靠回购和并购放大股东收益的有线宽带公司。**

截至 **2026 年 8 月 6 日**，股价约 **155.28 美元**，市值约 **188 亿美元**，表面市盈率只有约 **4 倍**。但公司同时有约 **938 亿美元债务**，所以不能只看市值或市盈率；它更接近一种“高杠杆股权”：企业价值的大部分属于债权人，留给普通股股东的部分较小，经营表现稍有变化，股价波动就会非常大。([Charter Communications Inc.][1])

---

# 一、CHTR 到底做什么

Charter 通过 Spectrum 品牌，在美国 41 个州向接近 5900 万户家庭和企业提供服务。截至 2026 年第二季度，公司拥有：

| 业务     |   客户规模 |
| ------ | -----: |
| 互联网客户  | 2940 万 |
| 手机线路   | 1250 万 |
| 电视客户   | 1250 万 |
| 固定电话客户 |  570 万 |

核心业务不是电视，而是**家庭宽带互联网**。电视和固定电话都在长期衰退，手机业务则是当前增长最快的部分。([corporate.charter.com][2])

## 1. 宽带互联网

Charter 利用原来的有线电视同轴电缆网络，为家庭提供高速互联网。

这是公司最重要的业务，因为：

* 每月重复收费；
* 客户更换运营商有一定麻烦；
* 宽带毛利率和现金流通常较好；
* 网络已经建成后，新增客户的边际成本相对有限。

2026 年第二季度互联网收入约 **57.76 亿美元**，占总收入约 43%。但同比下降 **3.2%**，互联网客户净减少 **17.2 万户**，这是当前最大的风险。([Charter Communications Inc.][1])

## 2. Spectrum Mobile

手机业务是 Charter 用来防守宽带客户的重要工具。

它不是完全自建的全国手机网络，而是以 **MVNO** 模式使用 Verizon 的移动网络，同时尽可能把流量导向 Spectrum Wi-Fi 网络。因此 Charter 可以用低价手机套餐和家庭宽带进行捆绑。([Charter Communications Inc.][3])

截至 2026 年第二季度：

* 手机线路达到 **1250 万条**；
* 过去一年增加约 **170 万条**；
* 当季新增 **40.6 万条**；
* 手机服务收入同比增长 **18.9%**。

这部分增长很快，但手机目前更多是**宽带留客和获客工具**，还不能简单理解成第二个 Verizon 或 T-Mobile。([Charter Communications Inc.][1])

## 3. 电视业务

传统有线电视长期受到 Netflix、YouTube TV 等流媒体服务冲击。

不过 Charter 最近改变了策略：把 Disney+、Hulu、HBO Max、Paramount+、Peacock 等流媒体应用打包进电视套餐，希望把传统电视套餐变成“流媒体聚合套餐”。

2026 年第二季度电视客户只减少 **2.1 万户**，相比上年同期减少 8 万户明显改善；但电视收入仍同比下降 **9.7%**。这说明用户流失暂时放缓，但收入压力依然存在。([Charter Communications Inc.][1])

## 4. 企业业务

Charter 也向中小企业和大型企业提供：

* 商业宽带；
* 光纤连接；
* 电话；
* 托管网络；
* 云和 IT 服务。

2026 年第二季度商业收入约 **18.65 亿美元**，同比增长 **1.5%**。这部分相对稳定，但增长速度并不高。([Charter Communications Inc.][1])

# 二、最近三年财务表现

单位：亿美元。

| 指标         |  2023 |  2024 |  2025 |
| ---------- | ----: | ----: | ----: |
| 营业收入       | 546.1 | 551.0 | 548.0 |
| 调整后 EBITDA | 218.9 | 226.0 | 227.0 |
| 净利润        |  45.6 |  51.0 |  50.0 |
| 经营现金流      | 144.3 | 144.0 | 161.0 |
| 资本开支       | 111.2 | 113.0 | 117.0 |
| 自由现金流      |  34.9 |  43.0 |  50.0 |

可以看出：

* 收入已经基本停止增长；
* EBITDA 仍然比较稳定；
* 自由现金流从 2023 年的 34.9 亿美元恢复到 2025 年的 50 亿美元；
* 资本开支一直非常高，每年超过 110 亿美元。

2023 年自由现金流较低，主要因为公司加大了农村网络扩张和网络升级投入；2024—2025 年现金流有所恢复。([Charter Communications Inc.][4])

## 最新季度：2026 年第二季度

| 指标         |    Q2 2026 |        同比 |
| ---------- | ---------: | --------: |
| 营业收入       | 135.26 亿美元 |     -1.7% |
| 调整后 EBITDA |  54.49 亿美元 |     -4.3% |

2026 年上半年收入下降 **1.4%**，调整后 EBITDA 下降 **3.2%**，自由现金流为 **23.41 亿美元**，低于上年同期的 26.10 亿美元。整体来看，公司仍然赚钱，但经营趋势在恶化。([Charter Communications Inc.][1])

# 三、为什么净利润稳定，但 EPS 还在增长

2026 年第二季度净利润与去年接近，但每股收益从 **9.41 美元**增长到 **10.76 美元**。

主要原因不是利润增长，而是 Charter 大量回购股票：

* Q2 回购约 400 万股；
* 花费约 8.38 亿美元；
* 基本加权平均股数同比减少 **13.1%**。

也就是说，公司把自由现金流用于回购，分母不断下降，所以即使总利润不增长，每股利润也能增长。([Charter Communications Inc.][1])

这是 Charter 长期资本配置模式的核心：

> 维持高负债 → 产生自由现金流 → 回购股票 → 减少股数 → 提高每股现金流和 EPS。

这个模式在业务稳定时非常有效，但如果宽带客户和 EBITDA 持续下降，高负债会反过来放大风险。

按照约 155.28 美元股价计算：

| 指标             |       粗略数值 |
| -------------- | ---------: |
| 市值             |  约 188 亿美元 |
| 2025 净利润       |   约 50 亿美元 |
| 表面市盈率          |      约 4 倍 |
| 2025 自由现金流     |   约 50 亿美元 |
| 表面自由现金流收益率     |    约 26.6% |
| 债务             |  约 938 亿美元 |
| 现金             |    约 5 亿美元 |
| 企业价值 EV        | 约 1121 亿美元 |
| EV/2025 EBITDA |    约 4.9 倍 |
| 净债务/EBITDA     |    约 4.1 倍 |

股权自由现金流收益率看起来非常夸张，但真正有参考价值的是 **EV/EBITDA 和债务偿付能力**，而不是单纯的 P/E。

CHTR 2026 年上半年利息费用约 **25.32 亿美元**，一年大约可能超过 50 亿美元。也就是说，公司很大一部分经营利润必须先用来支付利息。([Charter Communications Inc.][1])

因此，市场不是在认为 Charter 马上破产，而是在担心：

> 现在的 50 亿美元自由现金流能否长期维持，以及这些现金最终有多少真正属于现有股东。

# 五、为什么股价这么低

## 1. 宽带用户开始减少

这是最重要的问题。

以前市场认为有线宽带基本是地区性垄断：用户即使取消有线电视，也仍然需要宽带。因此电视业务衰退并不可怕，只要宽带用户继续增长即可。

但现在宽带也面临竞争：

* T-Mobile 和 Verizon 的固定无线接入；
* AT&T、Verizon 等公司的光纤网络；
* 地方光纤运营商；
* Starlink 等卫星互联网；
* 新建住宅市场放缓。

2026 年第二季度 Charter 宽带客户净减少 17.2 万户，比上年同期减少 11.6 万户更差。互联网收入也同比下降 3.2%。([Charter Communications Inc.][1])

如果宽带客户只是暂时下降，估值可能非常便宜；如果这是一种长期结构性衰退，当前自由现金流就不能直接外推。

## 2. 负债过高

截至 2026 年 6 月底，公司债务本金约 **938 亿美元**，现金只有约 **5.09 亿美元**。([Charter Communications Inc.][1])

高负债带来三个问题：

* 利率上升后，再融资成本提高；
* 经营下滑时没有太多缓冲空间；
* 即使企业价值变化不大，股权价值也可能大幅变化。

例如，企业价值约 1120 亿美元，其中约 930 亿美元是净债务，股权只有不到 190 亿美元。企业价值下降 10%，股权理论上可能损失一半以上。

## 3. Cox 并购增加复杂性

Charter 正准备与 Cox Communications 合并。交易企业价值约 **345 亿美元**，Charter 将承接大约 **126 亿美元的 Cox 净债务和其他义务**；Cox 股东也会取得合并后公司约 23%的股份。

公司预计交易完成后三年内实现约 **5 亿美元年度成本协同**。但同时也会出现：

* 股份稀释；
* 债务和利息增加；
* 整合成本；
* Cox 网络升级投入；
* 管理层注意力分散。

截至 2026 年 8 月 6 日，交易尚未正式完成，市场预计可能在 8 月中下旬完成，仍取决于最后的监管程序。([Reuters][5])

所以当前 4 倍 P/E 并不能完全代表合并后的股权结构。

## 4. 手机业务的增长质量还需观察

Spectrum Mobile 增长很好，但其全国蜂窝网络主要依赖 Verizon。

这意味着：

* Charter 不需要承担建设全国移动网络的巨额资本开支；
* 但也要向 Verizon 支付批发网络费用；
* 手机利润率受到批发协议影响；
* 低价手机套餐可能是在牺牲短期利润换取宽带留存。

因此不能仅凭手机线路增长 15%—20%，就认定它能完全弥补宽带业务下降。

# 六、CHTR 的潜在优势

## 1. 网络仍有较强的本地规模优势

Charter 已经把网络铺设到接近 5900 万户家庭和企业。即使光纤技术更先进，竞争对手重新铺设全国范围的最后一公里网络也需要大量资本和时间。([corporate.charter.com][2])

## 2. 宽带和手机捆绑具有竞争力

Charter 可以通过：

* 家庭宽带；
* 家庭 Wi-Fi；
* 手机套餐；
* 电视和流媒体；

形成一个综合套餐。

这比只销售家庭宽带更有粘性，也是 Charter 对抗 T-Mobile、Verizon 和 AT&T 的主要战略。

## 3. 网络升级接近后半段

Charter 正在升级网络，使其支持对称和多千兆宽带，计划在 **2027 年完成**主要网络演进计划。公司预计 2026 年资本开支约 **114 亿美元**。([Charter Communications Inc.][1])

假设 2027 年以后：

* 网络升级资本开支下降；
* 农村建设投入逐渐减少；
* EBITDA 不再下滑；

自由现金流可能明显增加。这是多头最核心的逻辑。

## 4. 回购对每股价值非常有力

2025 年 Charter 花费约 **54 亿美元**回购股票，甚至超过当年的 50 亿美元自由现金流。2026 年第二季度又回购 8.38 亿美元。([corporate.charter.com][6])

如果公司能在低价持续回购，并且业务最终稳定，每股价值可能增长得很快。

# 七、我认为最值得关注的五个指标

以后看 CHTR 财报，不必过度关注普通 EPS，重点看：

1. **互联网客户净增减**：最好先从负 17 万改善到接近零。
2. **互联网收入和每户收入**：客户下降能否被价格和套餐结构抵消。
3. **调整后 EBITDA 增速**：目前已经下降 4.3%。
4. **资本开支和自由现金流**：2027 年后资本开支是否真的下降。
5. **净债务/EBITDA**：Cox 合并后能否稳定在公司计划的 3.5—4.0 倍范围。

# 我的初步判断

**CHTR 确实便宜，但不是简单的“4 倍市盈率捡漏”。**

多头逻辑是：

> 宽带用户流失只是阶段性的，移动捆绑最终能稳定客户；2027 年网络升级完成后资本开支下降；Cox 带来规模和协同；公司在低价持续回购，推动每股现金流快速增长。

空头逻辑则是：

> 有线宽带已经进入结构性衰退；移动业务只是低利润补贴；Cox 增加债务和稀释；自由现金流最终用于利息、升级和整合，无法维持当前水平。

以目前的数据，我会把它定义为一只**赔率可能很高、但判断难度和资产负债表风险也很高的深度价值股**。真正的买点不是“P/E 只有 4 倍”，而是你是否相信宽带客户流失会停止、EBITDA 能稳定，以及 2027 年后自由现金流会恢复增长。
