这里要先区分两个概念：

* **有息债务**：公司借来的钱，需要还本金并支付利息。
* **会计总负债**：除了借款，还包括应付账款、递延税款、租赁负债等。

我前面说 CHTR 负债过高，主要指的是它的**有息债务约 938 亿美元**，不是单纯指资产负债表上的所有负债。

## 一、CHTR 的 938 亿美元具体是什么

截至 **2026 年 6 月 30 日**，Charter 的有息债务本金为 **938.45 亿美元**。可以按债务性质拆成下面三类：

| 债务类型               |             金额 |    占有息债务 |
| ------------------ | -------------: | -------: |
| 经营公司层面的有担保债券       |     546.58 亿美元 |    58.2% |
| 银行循环贷款和定期贷款        |     124.53 亿美元 |    13.3% |
| CCO Holdings 无担保债券 |     267.34 亿美元 |    28.5% |
| **合计**             | **938.45 亿美元** | **100%** |

也可以按发行债务的法律实体拆分：

| 借款主体                             |             金额 |
| -------------------------------- | -------------: |
| CCO Holdings                     |     267.34 亿美元 |
| Charter Communications Operating |     562.20 亿美元 |
| 原 Time Warner Cable              |      98.91 亿美元 |
| 原 Time Warner Cable Enterprises  |      10.00 亿美元 |
| **合计**                           | **938.45 亿美元** |

这些债务并不是普通的供应商欠款，而主要是公司发行的几十年期公司债和从银行取得的定期贷款。([Charter Communications Inc.][1])

### 1. 546.58 亿美元有担保债券

这部分主要由 Charter Operating、原 Time Warner Cable 和相关经营子公司发行。

所谓“有担保”，意味着债权人的地位相对较高。这些债券和贷款由 Charter 的大部分经营子公司担保，并以 Charter Operating 及其大部分子公司的资产和子公司股权作为抵押。理论上如果发生严重违约，债权人对这些资产的索偿顺序会优先于股东。([美国证券交易委员会][2])

其中包括大量长期债券，例如：

* 2028 年到期的 3.75%、4.20%债券；
* 2034 年到期的 6.55%、6.65%债券；
* 2045 年到期的 6.484%债券；
* 2050—2063 年到期的一系列长期债券。

原 Time Warner Cable 仍保留约 **108.91 亿美元**债务，其中一些债券最早在 1993—2012 年发行，最晚到 2042 年才到期。([Charter Communications Inc.][1])

### 2. 124.53 亿美元银行贷款

主要包括：

| 银行贷款          |             余额 |
| ------------- | -------------: |
| Term Loan A-6 |       4.00 亿美元 |
| Term Loan A-7 |      41.99 亿美元 |
| Term Loan B-3 |       7.26 亿美元 |
| Term Loan B-4 |      19.50 亿美元 |
| Term Loan B-5 |      24.62 亿美元 |
| 已使用循环信贷额度     |      27.16 亿美元 |
| **合计**        | **124.53 亿美元** |

这部分大多是**浮动利率债务**，利率通常是：

> SOFR 基准利率 + 1.25%至2.25%

因此，市场利率越高，这部分贷款的利息成本越高。目前 Charter 总债务中大约 13%是浮动利率，约 87%是固定利率。([Charter Communications Inc.][1])

### 3. 267.34 亿美元无担保债券

这些债务主要由上层控股公司 **CCO Holdings** 发行，利率大约在 **4.25%—7.375%**之间，到期时间集中在 2027—2036 年。

“无担保”意味着这部分债权人没有像经营公司债权人那样直接取得主要经营资产的第一顺位抵押，因此：

* 风险比经营公司有担保债券更高；
* 信用评级更低；
* 通常利率也更高。

截至 2026 年第二季度，这一层的企业信用评级大致处于 **BB+/Ba2/BB+**，属于非投资级，也就是通常所说的高收益债。([Charter Communications Inc.][1])

# 二、为什么 CHTR 会欠这么多钱

## 1. 2016 年的大型并购留下了高债务基础

2016 年，Charter 完成了对：

* Time Warner Cable；
* Bright House Networks；

的合并和收购，规模由此大幅扩大。交易完成时，Charter 也继承了原 Time Warner Cable 的大量债务。直到现在，公司债务表里仍有约 **109 亿美元**以 TWC 和 TWCE 名义存在。([美国证券交易委员会][3])

但这只能解释一部分。Charter 后来并没有积极降低杠杆，而是主动维持高负债。

## 2. 管理层故意维持约4倍杠杆

Charter 长期的资本配置策略并不是“尽快还清债务”，而是把净债务维持在 EBITDA 的大约 **4—4.5 倍**。

截至 2026 年第二季度：

* 总债务：938.45 亿美元；
* 现金：约5.09亿美元；
* 过去12个月调整后 EBITDA：约223.38亿美元；
* 净债务/EBITDA：约 **4.18倍**。

这意味着假设公司把全部 EBITDA 都用于还债，且不支付利息、税费、资本开支和运营费用，理论上也需要超过4年；实际当然不可能这样还。([Charter Communications Inc.][1])

对比来看：

* 公用事业、通信、有线网络公司确实可以承受比普通制造业更高的杠杆；
* 但4倍以上仍属于明显偏高；
* 一旦 EBITDA 开始持续下降，杠杆率就会自动上升。

Charter 自己也明确表示，公司会根据目标杠杆率增加或减少债务，而不是以消灭债务为目标。([美国证券交易委员会][2])

## 3. 大量现金被用于回购股票，而不是还债

这是债务一直降不下来的关键原因。

从2016年9月至2026年6月，Charter 累计花费约 **806亿美元**回购股票和合伙权益，累计回购量相当于2016年稀释后股份的约59.8%。平均回购价格约 **429美元**。([Charter Communications Inc.][4])

也就是说，过去十年公司大致做了这样的事情：

> 产生自由现金流 → 保持高负债 → 用现金回购股票，而不是偿还债务。

2025年公司自由现金流约50亿美元，却花了约50亿美元回购普通股。2026年第二季度又花：

* 8.38亿美元回购股票；
* 10亿美元回购面值12亿美元的债券。

这说明管理层最近才开始同时回购低价债券，但股权回购仍在继续。([美国证券交易委员会][5])

## 4. 公司每年资本开支非常高

Charter 需要持续投入资金建设和升级：

* 宽带网络；
* 用户路由器和机顶盒；
* 农村宽带；
* 光纤和同轴网络；
* 多千兆和对称速率升级；
* 移动业务基础设施。

2025年资本开支约117亿美元，过去12个月截至2026年第二季度约121亿美元，2026年预计仍要投入约114亿美元。高资本开支本身未必直接增加债务，但会减少可以用来还债的自由现金流。([Charter Communications Inc.][4])

# 三、为什么说这个债务水平危险

## 1. 利息支出非常高

2025年 Charter 的净利息支出约 **50.42亿美元**，几乎和当年：

* 归属于 Charter 股东的净利润约49.87亿美元；
* 自由现金流约50亿美元；

处于同一水平。([美国证券交易委员会][2])

2026年上半年，公司实际支付现金利息约 **25.06亿美元**。([PR Newswire][6])

可以粗略理解为：

> Charter 每赚出约100亿美元可用于利息和股东的现金，其中接近一半先交给债权人。

因此自由现金流收益率虽然看起来很高，但股东并不是公司现金流的第一受益人，债权人排在前面。

## 2. 股权只是企业价值中很薄的一层

截至2026年6月底，公司债务约938亿美元，而按当时股价计算的股权市值只有约170亿—190亿美元。([Charter Communications Inc.][1])

可以简化成：

| 资金来源      |    大致金额 |
| --------- | ------: |
| 债权人资金     |  938亿美元 |
| 股东资金的市场价值 | 约180亿美元 |

因此企业价值每发生一点变化，股权价值的变化都会被放大。

例如，仅作数学示意：

* 企业价值约1118亿美元；
* 如果经营恶化导致企业价值下降10%，减少约112亿美元；
* 债务本金不会同步减少；
* 这112亿美元的价值损失主要由约180亿美元的股权层承担。

理论上股权可能因此损失超过一半。这就是所谓的**财务杠杆放大效应**。

# 四、是不是马上就有偿债危机

目前还不能这样判断。

Charter 的债务虽然高，但期限结构其实不差：

* 加权平均债务成本约 **5.2%**；
* 加权平均剩余期限约 **11.7年**；
* 87%为固定利率；
* 93%的债务在2028年以后到期。([Charter Communications Inc.][1])

短期到期债务大致是：

| 到期年份      |        金额 |
| --------- | --------: |
| 2026年剩余时间 |   1.52亿美元 |
| 2027年     |  13.05亿美元 |
| 2028年     |  53.92亿美元 |
| 2029年     |  72.79亿美元 |
| 2030年     | 145.25亿美元 |
| 2031年     |  88.44亿美元 |

真正明显的再融资压力集中在 **2029—2031年**，并不是2026年立刻需要拿出938亿美元。

因此，CHTR 当前更准确的描述是：

> **不是短期现金流断裂风险，而是长期高杠杆叠加业务下滑风险。**

# 五、除了938亿美元借款，还有哪些“会计负债”

截至2026年6月底，Charter 资产负债表上的总负债约为 **1337.17亿美元**：

| 负债项目           |             金额 |
| -------------- | -------------: |
| 应付账款、应计费用等流动负债 |      127.79亿美元 |
| 一年内到期的长期债务     |        9.99亿美元 |
| 长期债务           |      929.60亿美元 |
| 手机设备分期融资       |       15.96亿美元 |
| 递延所得税负债        |      202.37亿美元 |
| 其他长期负债         |       51.46亿美元 |
| **总负债**        | **1337.17亿美元** |

([PR Newswire][6])

这里面需要特别区分：

* **递延所得税负债202亿美元**：主要是会计和税务确认时间不同产生的，不等于马上要向税务机关支付202亿美元。
* **手机设备分期融资约16亿美元**：Charter 把客户购买手机形成的分期应收款用于融资，与普通公司债有所不同。
* **应付账款和应计费用128亿美元**：包括欠供应商、节目内容商、员工薪酬、资本开支应付款等日常经营负债。
* 真正影响估值和偿债风险最大的，仍然是约 **938亿美元有息债务**。

## 核心判断

CHTR 的债务不是因为公司持续经营亏损而被迫借出来的，更多是管理层主动采取的资本结构：

> 大型并购建立高债务基础，再长期维持约4倍杠杆，把大部分自由现金流用于回购股票。

这种策略在宽带客户稳定、EBITDA持续增长时，可以快速提高每股收益；但现在宽带客户和 EBITDA 开始下降，原本用来放大股东回报的杠杆，就开始变成放大股东风险的杠杆。
