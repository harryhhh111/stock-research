对，CHTR 的 ROE 看起来非常漂亮，但**它的高 ROE 很大程度上是高杠杆 + 大规模回购造成的，并不是经营效率特别高**。

以 2025 年为例，CHTR 归属于普通股股东的净利润约 **49.87 亿美元**；2024 年末归属于 Charter 股东的账面权益约 **155.87 亿美元**，2025 年末约 **160.54 亿美元**。因此用平均股东权益计算：

[
ROE \approx \frac{49.87}{(155.87+160.54)/2}=31.5%
]

所以它确实有 **30%+ ROE**。([美国证券交易委员会][1])

但把这个 31.5% 拆开，你就会发现问题。

## 1. CHTR 有 1554 亿美元资产，真正属于股东的只有约160亿美元

2025 年末：

| 项目           |            金额 |
| ------------ | ------------: |
| 总资产          |  **1542 亿美元** |
| Charter 股东权益 | **160.5 亿美元** |
| 总有息债务        | 约 **946 亿美元** |
| 净利润          |  **49.9 亿美元** |

到了 2026 Q2，总资产进一步达到 **1556 亿美元**，但 controlling interest 股东权益只有 **169.5 亿美元**。([Charter Communications Inc.][2])

换句话说：

> CHTR 用约 **160 亿美元股东账面资本**，控制着超过 **1500 亿美元资产**。

资产/股东权益大约接近 **9～10倍**。

这就是 ROE 高的第一个来源：**财务杠杆极高。**

---

## 2. 用杜邦分析拆一下，就非常明显

ROE 可以拆成：

**ROE = 净利率 × 资产周转率 × 权益乘数**

2025 年 CHTR 大致是：

| 杜邦因素  |       CHTR |
| ----- | ---------: |
| 净利率   |      ~9.1% |
| 资产周转率 |     ~0.36× |
| 权益乘数  |  **~9.6×** |
| ROE   | **~31.5%** |

其中真正异常的不是净利率，也不是资产周转率，而是：

> **权益乘数约9.6倍。**

也就是说，CHTR 的资产经营本身并没有产生特别夸张的回报，真正把 ROE 从普通水平推到30%以上的是杠杆。

你甚至可以看 ROA：

[
ROA \approx \frac{49.9亿}{约1520亿平均资产}
\approx 3.3%
]

**ROA 只有大约3%。**

然后通过接近10倍的资产/权益杠杆，把3%左右的资产回报放大成30%左右的股东权益回报。2025 年公司净利润49.87亿美元、总资产约1542亿美元，支持这一判断。([美国证券交易委员会][1])

---

# 3. 为什么股东权益只有160亿美元？

这里才是 CHTR 最有意思的地方。

并不是因为公司历史上只投入了160亿美元。

恰恰相反，CHTR **长期疯狂回购股票，把账面股东权益不断消掉了。**

例如2025年：

* 回购约 **1654万股**；
* 现金支出约 **51.32亿美元**；
* 其中真正的公开市场/Liberty股票回购约 **50.33亿美元**。

2025 年公司净利润才49.87亿美元。

也就是说：

> **一年赚约50亿美元，然后差不多把整整50亿美元拿去回购股票。**

会计上，股票回购会减少股东权益。([美国证券交易委员会][1])

所以会发生一种很有意思的现象。

假设年初：

> 股东权益 = 160亿美元

一年赚：

> +50亿美元利润

理论上权益应该变成：

> 210亿美元

但公司随后：

> -50亿美元回购股票

最后权益又差不多变回：

> 160亿美元。

于是下一年又拿50亿美元利润除以160亿美元权益：

> ROE ≈ 31%

所以 CHTR 可以长期维持非常高的 ROE。

---

# 4. 而且这个回购已经持续很多年

看实际流通股数量非常夸张：

| 年末   | Charter Class A 股数 |
| ---- | -----------------: |
| 2022 |             1.527亿 |
| 2023 |             1.452亿 |
| 2024 |             1.419亿 |
| 2025 |         **1.266亿** |

仅2025年一年，就减少了大约 **11%**。

2016年以来，公司更是进行了极其庞大的股票回购。([美国证券交易委员会][1])

所以你会看到两个东西同时发生：

**股数越来越少**

→ EPS越来越容易增长。

**账面股东权益越来越小**

→ ROE越来越容易维持高位。

---

# 5. 更极端的是：CHTR 曾经有巨额累计亏损

2025年底股东权益构成很有意思：

| 项目                         |          2025 |
| -------------------------- | ------------: |
| Additional Paid-in Capital |     214.47亿美元 |
| Accumulated Deficit        | **-53.93亿美元** |
| Charter股东权益                | **160.54亿美元** |

也就是说，它甚至还有 **53.9亿美元累计赤字**。([美国证券交易委员会][1])

这里的 accumulated deficit 并不意味着最近一直亏钱。

一个重要原因就是**股票回购并注销**。

Charter 在注销库存股时，会把回购成本分配到：

* Additional Paid-in Capital；
* Accumulated Deficit。

因此长期高价回购股票，会把账面权益大量削减。Charter 的10-K明确说明了这种会计处理。([美国证券交易委员会][1])

# 6. 所以 CHTR 和 Adobe 的高 ROE，其实有一点类似

你之前研究 Adobe 时，我们也碰到过类似问题。

有些公司的高 ROE 是：

> 净利润很高
>
> * 轻资产
>   → 真正经营能力优秀

但还有一种是：

> 高债务
>
> * 大规模股票回购
>   → 股东权益非常低
>   → ROE数学上变得很高

CHTR **明显更偏第二种**。

而且它比普通回购型公司更加极端，因为它同时拥有约 **940亿美元债务**。截至2025年底 Charter 本身也表示其杠杆率约 **4.15× Adjusted EBITDA**。([美国证券交易委员会][3])

# 7. 一个极简模型，你马上就能理解

假设有两家公司，业务完全一样：

### 公司A

资产1000亿
债务0
股东权益1000亿
利润50亿

那么：

**ROE = 50 / 1000 = 5%**

### 公司B

资产1000亿
债务850亿
股东权益150亿
利润50亿

那么：

**ROE = 50 / 150 = 33%**

你看到：

> 业务没有任何变化。

利润都是50亿。

但是因为公司B大量借债、减少股权资本：

**ROE从5%直接变成33%。**

CHTR 就非常接近这种情况。

# 所以研究 CHTR，我不会特别看重 ROE

CHTR 的：

> **ROE ≈ 30%+**

单独看会让人感觉这是一家资本回报极高的优秀公司。

但实际上：

> **ROA大约只有3%**

然后通过：

> **约4倍净债务/EBITDA + 大量回购压低账面权益**

把 ROE 放大到了30%以上。

因此研究 CHTR，我认为比 ROE 更重要的是：

**ROIC、FCF/EV、FCF/股、净债务/EBITDA，以及宽带用户数量。**

尤其是 **ROIC**。因为 ROIC 把债权人和股东提供的资本一起考虑进去，不会像 ROE 一样因为公司借了900多亿美元债务就变得异常漂亮。

事实上，**下一步我们最好直接算一下 CHTR 最近3年的 ROIC**。这个数字会比 ROE 更真实地告诉我们：**Charter 这门生意本身，到底是不是一门高回报的生意。**
