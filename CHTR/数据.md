# 3. 负债趋势

这个数据很有意思。

| 时间          |     有息债务本金 |
| ----------- | ---------: |
| **2023 年底** | **976亿美元** |
| **2024 年底** | **938亿美元** |
| **2025 年底** | **946亿美元** |
| **2026 Q2** | **938亿美元** |

Charter 的债务其实**没有继续快速增加**，反而比2023年底少了约38亿美元。([Charter Communications Inc.][1])

所以 CHTR 的问题不能简单理解成：

> “公司每年都在疯狂新增债务。”

实际上最近几年是：

> **债务一直维持在940亿美元上下。**

真正的问题是 **940亿美元本身已经非常大**。

截至2026年6月底：

* 债务本金：**938亿美元**
* 现金：仅 **5.09亿美元**
* 净债务：约 **933亿美元**
* 可用额外信贷流动性：约 **37亿美元**

([Charter Communications Inc.][3])

也就是说，现金几乎可以忽略：

> **Net Debt ≈ Debt ≈ 930+亿美元。**

而 Charter 最近12个月 EBITDA 大约只有220多亿美元，所以净债务/EBITDA仍然约 **4倍出头**。2026 Q1官方披露为 **4.15×**；公司长期目标本身就是维持约4.0–4.5×杠杆。([Charter Communications Inc.][4])

# 5. 这里最关键的不是电视，而是互联网客户

电视客户从1410万掉到1250万，我反而不会特别害怕。

因为有线电视本来就是结构性衰退业务，Charter 也在通过流媒体套餐等方式逐步适应。

**真正决定 CHTR 投资价值的是 Internet：**

> 30.6m → 30.1m → 29.7m → **29.4m**

这个趋势如果继续，就比较危险。([Charter Communications Inc.][1])

因为 Mobile 的逻辑其实很大程度建立在宽带之上：

**Spectrum Internet**

↓

给家庭卖低价 Spectrum Mobile

↓

提高客户粘性

↓

减少宽带流失

所以现在公司最重要的问题其实是：

> **Mobile 从780万涨到1250万，为什么宽带客户还是在下降？**

如果手机高速增长最终能够让宽带客户稳定，那么现在的估值可能真的很低。

但如果：

> Mobile +60%
> 宽带仍然持续流失
> EBITDA开始下降
> 同时还有930亿美元净债务

那 CHTR 的投资逻辑就会明显恶化。

所以现在研究 CHTR，我认为**最重要的数据已经不是 PE，也不是 ROE，而是未来4–6个季度的 Internet net adds 和 EBITDA**。
