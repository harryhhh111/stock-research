AMD **现在基本上是一家纯芯片设计公司（fabless）**，自己不拥有先进晶圆厂来制造 CPU、GPU 芯片。AMD 负责芯片架构和设计，然后把制造交给晶圆代工厂。AMD 2026 年最新披露也明确说，其所有产品的硅晶圆都使用第三方晶圆厂制造。([Advanced Micro Devices, Inc.][1])

最核心的分工可以理解成：

**AMD：设计芯片 → TSMC / GlobalFoundries：制造芯片 → 封装测试厂：封装测试 → AMD/合作伙伴销售产品**

其中现在最重要的是 **TSMC（台积电）**。AMD 的 Ryzen、EPYC CPU 和 Radeon、Instinct GPU 等使用 **7nm 及以下先进制程的晶圆全部依赖 TSMC**。较老的、7nm 以上制程产品则主要由 **GlobalFoundries（格芯）**生产。([Advanced Micro Devices, Inc.][2])

这也是理解 AMD 和 Intel 最大区别之一：

| 公司         | 芯片设计             | 自己制造先进芯片       |
| ---------- | ---------------- | -------------- |
| **AMD**    | ✅                | ❌              |
| **NVIDIA** | ✅                | ❌              |
| **Apple**  | ✅                | ❌              |
| **Intel**  | ✅                | ✅，同时也找 TSMC 代工 |
| **TSMC**   | 通常不设计自己的 CPU/GPU | ✅              |

AMD 以前其实**是自己造芯片的**。2009 年左右 AMD 把自己的晶圆制造业务拆出去，这家公司后来就是 **GlobalFoundries**。从此 AMD 转向了 Fabless 模式。

这件事情对分析 AMD 非常重要：**AMD 真正的核心资产不是工厂，而是 CPU/GPU 架构、芯片设计能力、软件生态和产品路线图。**

所以如果你是在比较 **AMD、Intel、TSMC** 的投资逻辑，可以粗略理解：

**AMD = 芯片设计公司**
**TSMC = 芯片制造公司**
**Intel = 芯片设计 + 芯片制造公司**

而这恰好解释了为什么 AMD 在过去十几年能够追上 Intel：**AMD 不需要承担先进晶圆厂巨额资本开支，并且可以直接使用 TSMC 最先进的制造工艺。**这部分如果继续往下拆，会直接涉及 AMD 为什么能从濒临破产一路逆袭 Intel。
