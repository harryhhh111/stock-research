# 行业调研与知识库建设方案

日期 2026-11-19。行业分类、目录入口与工作流已更新，首份行业研究待试点。

## 1. 背景与目标

公司研究先有行业参照，才能解释公司在产业链的位置、和谁可比、异常来自行业还是公司。现有行业材料已积累不少，例如[数据中心产业地图](../../数据中心/行业背景/产业地图.md)、[Hyperscale 五家对比](../../数据中心/Hyperscale五家对比.md)和[SSD 价格口径调研](../../SSD/2026-09-11-SSD价格多口径调研.md)。这些材料分散在不同研究项目，后续研究需要重复寻找适用结论及其时点。

目标是让每个已建档行业有一个 HTML 卡片首页和可独立更新的模块页。研究员能快速找到行业边界、赚钱方式、比较基准和未解问题，再顺着证据去做公司研究。本方案细化[公司研究 SOP 重构方案](2026-11-19-公司研究SOP重点导向重构方案.md)中的行业环节。两份方案均按各自范围审阅。

## 2. 范围与非目标

- 首期选一个有明确公司研究需求的细分行业，完成大卡片首页、必要的行业模块和来源记录，再用一家公司验证复用效果。
- 新建的行业概览集中放在仓库根目录的 `行业研究/` 下。每个细分行业是一个研究项目，沿用现有 HTML 报告管理工具和唯一索引。证据随行业项目保存，现有资料按原路径引用。
- 首期范围限于库内调研工作流。全市场分类、批量迁移历史资料、数据库、向量检索、自动采集、网站「行业研究」页面及专用 Skill 可按实际使用需求另行评估。

## 3. 现状分析

现有[项目规范](../../研究流程/standards/研究库项目规范.md)已区分公司和主题身份，[HTML 命名与索引规范](../../研究流程/standards/HTML报告命名与索引规范.md)已支持 `topic` 报告。[内部网站接入](../../研究流程/standards/HTML报告内部网站接入.md)的公司列表按 `company:` 聚合。行业概览可作为独立主题登记，首期用库内索引与公司主报告交叉链接访问，网站入口另行核对。

当前缺的是行业调研优先查哪些材料、怎样判定口径可比、结论什么时候刷新，以及公司报告怎么引用。已有材料要按日期、范围和原始依据筛选。适合继续使用的内容可以接入，资料过时或口径有争议时保留其历史属性。

## 4. 调研方案

| 步骤 | 怎么做 | 交付前问什么 |
|---|---|---|
| 1. 划行业边界 | 先写研究目的，再限定地区、产品或服务、主要客户及上下游。说明易混淆的相邻行业和分类差异 | 同一组数字与公司是否真正可比？ |
| 2. 用机构研报搭框架 | 优先选两到三份日期合适、方法能追溯、视角互补的材料。可用券商、评级机构、行业协会、研究咨询机构的材料。记录作者、发布日期、覆盖范围及核心假设 | 每份材料提供了哪些资料和假设？多份转引同一来源时算同一证据链 |
| 3. 核关键事实 | 用政府统计、行业协会调查、监管披露、代表性公司报告或原始交易披露交叉核实。区分已发生事实、机构预测、公司指引和我们的推演 | 关键数字回得去哪里？冲突能否由地区、期间、分母或分类解释？ |
| 4. 得出公司要验证的问题 | 画简明产业链，解释谁购买、谁收费、哪里有议价权。列出少量可比指标、适用同业，并指出影响回报的主要变量和反证 | 公司研究拿到这页后，知道该读哪张表、该问哪两个问题吗？ |

第一轮调研做到能建立公司研究参照。若机构结论只有付费摘要或二手转述，记录实际可见部分及限制。材料的分析可以摘要引用，原始数据按可访问范围保存。对缺乏可比数据的环节列替代指标、未解问题和影响，避免把预测补成实绩。

## 5. 知识库结构与数据约定

行业研究和公司研究在目录上各有入口。行业资料集中在 `行业研究/`，下设细分行业子目录，每个行业维护一个卡片首页和若干模块页。公司目录继续维护各自的报告、公司专属分析和证据，并直接链接到适用的行业模块。例如：

```text
行业研究/
└── 美国专业建材分销/
    ├── reports/
    │   ├── us-building-products-distribution.html  # 首页，大卡片进入模块
    │   ├── value-chain.html                       # 行业边界、产业链与盈利模式
    │   ├── demand-metrics.html                   # 市场需求与指标
    │   └── competition.html                      # 竞争格局与研究问题
    └── factcheck/
        └── data/                  # 实际用到且适合保留的行业证据或数据
```

首页和模块按 `report_type=topic` 登记到现有 `html-index.json`，共享稳定 `entity_id=topic:industry-us-building-products-distribution`，各用独立 `report_id`。`topic:industry-` 前缀区分行业与其他主题，首页 `report_id` 约定用 `-overview` 后缀供行业列表识别。首期用现有字段与 `reports.py` 流程，通过相对链接和稳定章节锚点在首页与模块页之间导航。证据文件按已有资源授权和登记规则处理。已有的 `数据中心/`、`SSD/` 等历史资料先按原路径引用，核验后的长期结论沉淀到相应模块。

**行业首页直接展示大卡片。**

- **首页**显示行业名称、范围、最近核对日及一句话判断。卡片直接呈现模块名、它回答的问题和一条发现，点击进入对应页面。首个试点先做「产业链与赚钱方式」「市场需求与指标」「竞争格局与可比公司」三张卡，去公司研究的链接放在竞争模块。
- **模块页**放本模块的详细指标、图表、机构分歧、来源及更新记录。每个常用指标注明地区、产品范围、期间、单位和分母，并明确可比限制。可用结构化表格供程序读取。原始文件按需放 `factcheck/data/`，每段行业正文只在所属模块维护。

建议每条重要事实或数据保留「指标或判断、值或结论、事实类型、地区与口径、数据期间、来源日期、原文页码或表格、核对日期」。口径不同的数字分列。对行业规模、增速或利润率等争议保留各自假设，必要时给可解释的区间。首期在 HTML 表格中维护这些信息，确有复算需求时复用相应数据文件。

## 6. 公司复用、更新与实现步骤

1. **试点建档。** 推荐从美国专业建材分销开始，限定专业分销与相关客户，屋面材料等按数据可比性划子范围。调研优先回答：客户为什么用专业分销、同业收入增长如何区分并购和有机变化、规模如何影响库存周转和经营现金。
2. **先做概览再进入公司。** 为 QXO 列可比对象、公司要验证的假设及需要的原始资料。公司唯一 HTML 主报告简述对判断有影响的行业结论，引用概览的 `report_id` 或稳定章节链接，并记录所用数据期间。行业通用定义和同业底表在行业页维护。
3. **遇到新证据先回查适用性。** 公司发现的行业事实核验后回写行业页，并标明哪些行业判断及引用公司的假设受影响。行业页保留最近核查日和指标期间，按重要披露、口径重述或供需变化更新。公司报告重用前先确认其指标仍适用于当前时点。
4. **通过后验证跨公司复用。** 第二个候选为 AI 算力云，优先复用 `数据中心/` 已有资料，用 CoreWeave 与 Nebius 验证一个行业概览能否帮助比较交付、定价、资本投入和回款。出现代表性重复工作后，再决定是否开发行业 Skill 或增加自动更新。

计划执行时只需新增行业 SOP 或模板中的最小规则、首个卡片首页及模块和必要证据，并用现有工具登记。行业流程的定位与公司 SOP 重构一起确认，避免在两处重复维护详细条款。

## 7. 风险与处理

- **行业太宽。** 以公司真实业务为边界，从可比较的子行业做起。多业务公司可引用不同主题，每次注明使用的是哪块业务。
- **同一预测被误当多源事实。** 追溯机构的数据依赖，区分转载、机构估算和原始披露，同时保留被核对后仍存在的分歧。
- **行业库堆满旧新闻。** 正文保留能复用的持续结论。事件材料只在改变供需、竞争、口径或判断时更新相应章节和记录。
- **公司引用过时或偷换口径。** 每次引用核对日期、地域和适用业务。对高频指标明确截至哪一期，必要时重新取数。

## 8. 验证方式

| 核验 | 首期通过条件 |
|---|---|
| 阅读 | 打开首屏能看懂行业范围和当前主要问题，并从大卡片直达想看的内容。模块页能返回首页，链接在离线情况下也能打开 |
| 证据 | 抽查影响判断的数字可追到原文；预测、实绩、不同口径能区分，未解决差异有明确说明 |
| 复用 | 用该页能直接列出 QXO 的可比对象及至少两个待验证的问题。公司报告引用稳定位置，避免重新整理整份行业背景 |
| 更新 | 能独立替换某模块的过时数据，查到来源、旧值和口径变化。首页摘要及其他模块仅在受影响时同步 |
| 技术 | 行业 HTML 离线可读，表格、来源和锚点有效，现有报告索引检查通过 |

## 9. 回滚方案

试点按独立项目提交。若行业页复用效果不足，停止复制到新行业并回退新增的流程挂接。已登记 `report_id` 按现有规范归档或保留兼容入口，原始证据、历史资料及已核公司报告继续保留。

首轮已验证现有索引可登记独立行业首页和模块，验证材料为临时样本。美国专业建材分销的行业正文按上述证据与复用条件单独验收。
