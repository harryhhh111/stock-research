# Amazon项目术语

整理日期：2026-11-04。跨项目通用财务术语沿用[根术语表](../术语.md)。

| 词 | 含义与本项目边界 |
|---|---|
| AWS | Amazon Web Services，企业计算、存储等云服务分部；不是全部收入都来自AI |
| Prime | 会员配送、内容等权益体系；订阅收入不全等于Prime会员费 |
| FBA | Fulfillment by Amazon，卖家使用Amazon仓储履约服务；费用计入第三方卖家服务，不是卖家全部商品销售额 |
| EC2 / S3 | AWS弹性计算与对象存储服务，客户通常按使用资源付费 |
| Bedrock | AWS提供模型访问及应用开发服务的平台；所售模型不必由Amazon自己训练 |
| Trainium / Graviton | AWS自研训练/推理加速芯片及CPU体系；相关实例服务已含AWS收入，不另加芯片业务运行率 |
| RPO（本报告用法） | 一年以上合同尚未确认的履约承诺，主要来自AWS；不等于已收现金或年度固定收入 |
| paid units / seller unit mix | 付费商品件数、其中第三方卖家件数占比；不是GMV或收入占比，披露口径不含Whole Foods |
| AI/芯片年化运行率 | 管理层将时点业务规模外推一年，非全年实际收入，两者可能交叉 |

AWS基础设施术语（相关研究见[AWS专题](AWS.md)；跨项目工程词沿用[数据中心术语](../数据中心/行业背景/术语.md)）：

| 词 | 含义与边界 |
|---|---|
| Trn3 UltraServer | AWS由最多144颗Trainium3组成的集成系统；产品规格不是全球已部署机柜数量 |
| landed | 公司描述芯片已交付落地；不能单独证明全部设备满载运行或某园区全部接电 |
| Core / AI | AWS管理层讨论中的基础云与AI业务；未披露完整互斥的收入利润拆分，不据运行率相减制造精确结构 |
