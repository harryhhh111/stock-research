# 字节跳动项目术语

> 整理日期：2026-10-05。跨项目通用会计/财务词请参见根目录术语；本页只解释产品、主体与本项目特有边界。

| 词 | 含义与研究边界 |
|---|---|
| TikTok USDS JV | 美国数据安全合资主体，负责数据/算法安全和内容治理；持股比例不直接等于全部美国商业权益 |
| 美国商业实体 | TikTok全球体系负责美国广告、电商等商业活动的实体，与USDS职责不同 |
| 抖音来客 | 本地生活商家经营入口；支付团购与到店核销不能混用 |
| 货架场景 | 商城、搜索、商品卡等主动购物场景，与直播/短视频发现成交分开 |
| 店播 | 商家自己直播；达人播由创作者带货，成本与分配不同 |
| Seed | 字节模型研发/模型品牌体系，不是单独已披露财务分部 |
| 豆包 | 消费者应用及相关模型品牌；应用用户和外部模型客户不是同一概念 |
| Seedance / Seedream | 视频/图像模型体系；生成效果与商业盈利分开 |
| 火山引擎 / 火山方舟 | 企业云与模型服务入口；内部调用需从集团外部收入剔除 |
| BytePlus | 海外企业技术服务品牌/主体；与海外TikTok广告收入不同 |
| 飞书 / Lark | 企业协作产品与品牌；ARR、席位、已确认收入应分开 |
| GMV Max | TikTok广告产品；营销消耗不是平台交易佣金 |
| CapCut / 剪映 | 创作工具；创作者在平台获得的销售额不是工具收入 |
