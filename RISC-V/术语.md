# RISC-V专题术语

整理日期：2026-11-11。跨项目财务词见根目录[术语](../术语.md)，此处只收架构与本专题技术用语。

| 词 | 意义与实际例子 |
|---|---|
| ISA／指令集 | 软件能要求处理器执行的指令规则；RISC-V开放的是这套规则，不是每家完整设计 |
| CPU IP／处理器核设计 | 可供芯片商集成的硬件设计；晶心或SiFive向设计客户授权 |
| 核心／core | 芯片内部的计算单元；一颗SoC可有多个核心，不等于多颗芯片 |
| SoC | 集成处理器、接口及其他功能的系统级芯片；可同时含不同ISA核心 |
| 扩展／extension | 在基础ISA上增加某类能力，例如向量计算；旧芯片一般不会靠软件获得缺失电路 |
| Profile | 规定一类系统应支持的标准能力组合，帮助软件兼容；不等于单一核的具体实现 |
| 微架构 | 实现ISA的具体电路组织，同样指令集可有不同性能、面积和功耗 |
| 向量／矩阵 | 一条指令处理一组数据或矩阵运算；适合部分AI和数值工作负载 |
| 主CPU／管理核 | 主CPU运行主要系统任务，管理核可能只控制电源或安全；两者商业价值不同 |
| 流片／tape-out | 芯片设计交付制造，不等于验证成功、量产或已收到版税 |
| Fabless | 无晶圆厂芯片设计模式，制造封测外包；仍承担库存、委外成本与交付风险 |
| DDIC／TCON | 显示驱动芯片／时序控制器，分别驱动像素与组织显示时序 |
| 工具链 | 编译、调试等配套工具，把软件转成处理器可执行的程序并排查问题 |
