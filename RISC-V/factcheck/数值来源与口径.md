# 数值输入来源与复算口径

核对日期：2026-11-11。financial-inputs.json 为人工从原始主表/附注转录的计算输入，不是原始下载文件。原始PDF不改，哈希见sources.json；第三方转载快照见web-sources.json。

| 输入组 | 来源与定位 | 期间/说明 |
|---|---|---|
| Andes年度主表 | 2023/2024/2025合并年报资产负债、损益、现金流表；收入附注、权益变动表 | 2023—2025，2022仅取2023报告比较列作为同比/平均权益基数 |
| Andes季度 | 2026Q1/H1 PDF第4—8页及收入、无形资产附注；2025Q3第6/8页 | Q2由H1−Q1；2025Q4由FY25−9M25；EPS不差分 |
| Andes 26Q3 | 11月9日公告的ahan.net第三方转载 | 只有9M收入/毛利/经营/净利润和总权益；原件现金流等缺失，毛利异常保留 |
| Andes财务结构 | 各年报债券、租赁附注，H1附注10及金融工具 | 债券用负债账面，现金等价物与按摊销成本金融资产分列 |
| ESWIN年度/Q1 | 9月28日招股书PDF第17—22、341—349页 | 金额均为合并非母公司单体；第344—345页是母公司，不能混入 |
| ESWIN CapEx字段 | 招股书PDF第349页 | ppe_cash存“固定＋无形合计”，intangibles_cash=0表示已包含，不能解释为无形支出为零 |
| 现金其他非流动资产 | Andes现金流及附注6(7) | 主FCF不包含，另计算宽口径敏感性；不把资产转列重复当现金 |
| 估值 | 11月10日交易所STOCK_DAY JSON收盘与10月29日增资公告二手转载 | 226元官方已核实、股数含680万缴款凭证；Yahoo价格冲突以官方为准 |

金额输入：千本币；输出：M本币，1 M=100万；同比和利润率/ROE为百分数。毛利/经营/净利率=同口径利润÷收入；年度ROE=归属股东净利润÷期初期末平均权益；FCF=CFO−现金固定及无形购置；宽口径额外扣除其他非流动资产现金。TTM=上个完整年＋本年累计−上年同累计；各组按可取得的实际最新报告期，不能用H1现金流冒称Q3。负净利润不机械算正常增长率，直接看金额变化。

运行：`python factcheck/verify.py`（从RISC-V目录）或在任意目录用脚本路径。脚本仅读本目录输入并写复算结果，不调用行情接口。PDF文本重建用extract_pdf.py，需安装PyMuPDF；抓取网页用collect_sources.py，需requests，原始快照不覆盖。来源网页可变，复算财务依靠已保存PDF和输入，不承诺重新抓取页面完全一致。

2026-11-11异常纠错补充：Andes原始损益表新增转录销售、管理、信用减值项目（正数扣减，利益为负），与研发共同构造毛利至经营利润桥。verify.py另输出anomaly-review.json，区分勾稽残差和未解决成因；Q3隐含成本为−160千元，不因算术可复现就认定冲回。详见两家公司第3节的成因与限制。
