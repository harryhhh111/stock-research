# 2. Nebius 自己公开的“卖算力价格”

这其实比机柜数量更有价值。

2026 Q2：

**核心 AI Cloud 中期合同**

> **$20–25M / MW / 年**

期限通常：

**1–3年。**

公司还说此前 2026 年的基础水平大约只有：

**$12M/MW/年**

说明价格涨得非常快。

所以直接换算：

|     算力容量 |    $20M/MW |    $25M/MW |
| -------: | ---------: | ---------: |
|    10 MW |    $200M/年 |    $250M/年 |
|    50 MW |      $1B/年 |   $1.25B/年 |
|   100 MW |      $2B/年 |    $2.5B/年 |
|   500 MW |     $10B/年 |   $12.5B/年 |
| **1 GW** | **$20B/年** | **$25B/年** |

所以我们前面说：

> **1GW 满负荷按当前中期合同价格出租，对应约 $20–25B 年化合同收入。**

这个不是凭空估出来的，基础数据就是 Nebius 自己的 **$20–25M/MW**。

# 7. Nebius 已经建了多少？

这是另一个特别容易搞混的地方。

Nebius自己把电力分成三个概念：

**Contracted power**

→ 已经锁定土地、电力供应。

**Connected power**

→ 数据中心基本已经建好并接上电。

**Active power**

→ GPU等IT设备已经装好并且实际工作，可以开始产生收入。

所以：

# **5GW contracted ≠ 5GW GPU已经在跑。**

2025年底：

**Active power ≈170MW。** ([Nebius][1])

2026年底目标：

**Connected power = 800MW–1GW。** ([The Motley Fool][2])

2026年底最新目标：

**Contracted power = 5GW。** 

然后：

**2027年开始计划每年部署 >1GW。** 

这三个数字一定要分开。

## 最后，把目前真正缺失的数据列出来

Nebius到现在**没有公开**：

* Microsoft准确MW
* Microsoft GPU型号和GPU数量
* Microsoft机柜数
* Meta准确MW
* Meta Rubin GPU数量
* 每个客户的机柜数
* 每个客户项目CapEx
* Microsoft/Meta具体 $/GPU-hour
* 1GW具体包含多少NVL72
* 5GW contracted power中多少最终会成为IT active power

所以这些暂时不要硬猜。

但我们现在已经知道足够多，可以搭出一个非常实用的模型：

**5GW contracted → 每年部署>1GW → 1GW满载理论收入$20–25B → 当前项目22个月回本 → 客户预付款承担50–60% CapEx。**

这条链才是研究 NBIS 最重要的东西。

而且从这里已经可以进一步看出一个很值得追的问题：**如果Nebius 2026全年只花$20–25B CapEx，却计划未来每年部署>1GW，那么我们之前估的“1GW=$50B”显然不能直接套到Nebius身上。** 下一步应该专门用 Nebius 已披露的 CapEx、MW和合同回报，反推它真正的 **$/MW 建设成本**。
