# 千问（Qwen）：模型、产品与商业化

> 整理与核对日期：2026-09-24。财务数据截至 FY2027Q1（2026-06-30 止季度，2026-08-20 发布）；产品资料截至整理日。金额均为人民币亿元。本文把公司披露值、第三方测评值与研究推断分开。

## 一、先把三个“千问”分开

| 层次 | 是什么 | 谁使用、如何变现 | 财报位置与边界 |
|---|---|---|---|
| **千问模型家族** | 文字、代码、视觉、音频、视频等模型及开放权重版本 | 开发者可自行部署部分模型；模型能力也支撑阿里产品 | 模型研发在“AI 实验室与应用”；模型下载不是收入 |
| **百炼 / Model Studio** | 托管千问及第三方模型的 API、知识库等云服务 | 企业/开发者调用模型，通常按 Token 等使用量付费 | 商业化服务属于云产品范畴；未披露千问 API 单独收入，也未披露其在“AI 相关产品收入”中的金额 |
| **千问 App / 千问办公** | 面向消费者的 AI 助手；面向个人和企业的工作智能体 | App 以使用与电商服务连接为主；办公平台公布订阅加积分的定价方式 | 属于“AI 实验室与应用”分部；不披露两款产品各自营收或利润 |

依据：[FY2027Q1 财报及分部定义](https://www.sec.gov/Archives/edgar/data/1577552/000110465926099220/tm2623667d1_ex99-1.htm)、[Model Studio 产品和计费说明](https://www.alibabacloud.com/help/en/model-studio/what-is-model-studio)、[千问办公发布说明](https://www.alibabagroup.com/zh-HK/document-2021039099929952256)。**同一模型可以被下载、自行部署、云端调用或用于阿里自有 App；这些使用方式不能累加为一个收入数。**

## 二、模型到底强在哪里，证据有多硬

**产品能力**：千问不是单个版本，而是一组通用、代码与多模态模型。2025 年发布的 Qwen3 同时提供稠密和混合专家（MoE）型号，支持思考/非思考模式；2026 年的 Qwen3.5 强化文本、图像、视频理解。2026 年 8 月发布的旗舰 Qwen3.8-Max，阿里称总参数 2.4 万亿、每次推理激活约 950 亿，并提供最长约 100 万 Token 上下文；参数规模本身**不能**证明真实任务质量或单位推理成本。[Qwen3 发布说明](https://www.alibabagroup.com/en-US/document-1853940226976645120)、[Qwen3.5 发布说明](https://home.alibabagroup.com/en-US/document-1960233590314762240)、[Qwen3.8-Max 发布说明](https://www.alibabagroup.com/en-US/document-2021044032125272064)。

**开放权重的准确含义**：千问团队已在 Hugging Face 发布 [Qwen3.8-2.4T-A95B 权重](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)，模型卡称托管版 Qwen3.8-Max 基于它，但增加视觉输入、默认约 100 万上下文和内置工具等功能。因此，能下载基础权重**不等于**拿到了与官方托管 API 完全相同的产品。该大模型页面标注 `qwen3.8-max` 专用许可；不能把所有千问型号都概括为 Apache 2.0。[官方模型卡](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B)。

**能力验证**：阿里 2026-08-03 发布说明称当时 Qwen3.8-Max 在 Text Arena 第五、Vision Arena 第二；排名随时间和测试口径变化，属**公司引用的榜单位置**。[阿里发布说明](https://www.alibabagroup.com/en-US/document-2021044032125272064)。第三方 [Artificial Analysis 对 2026-09-02 API 版本的测试](https://artificialanalysis.ai/models/qwen3-8-max)给出 Intelligence Index **45**，同价位比较组中位数 **25**；同时测得输出约 **39 Token/秒**、比较组中位数约 **74 Token/秒**，且完成测试所用 Token 较多。这是**特定 API 版本和测试方法**的测评，不等于所有千问版本都同样快或慢。可支持“有竞争力的能力”，不能直接证明阿里有持久定价权。

## 三、产品在解决什么任务

- **千问 App**：公司将它定位为生活和消费 AI 助手；通过淘宝、淘宝闪购、支付宝、飞猪、高德完成找商品、下单、付款、旅行规划等任务。2026 年 1 月公布的这些功能当时处于公测；“能调用阿里生态服务”是它区别于一般问答助手的核心产品假设。[公司产品说明](https://www.alibabagroup.com/en-US/document-1948497434959151104)。
- **千问办公（QwenWork）**：2026-08-03 推出公测，提供网页和桌面端，整合桌面、云端及企业协作智能体，计划接入钉钉；公司公布订阅制加积分机制，分个人版与企业版。[公司发布说明](https://www.alibabagroup.com/zh-HK/document-2021039099929952256)。公测发布和钉钉潜在分发渠道，尚不等于已形成大规模付费订阅。
- **百炼 / Model Studio**：让开发者购买托管的千问和第三方模型调用。模型按 Token 等计费，客户不必自己购买和运维大模型算力。[阿里云产品文档](https://www.alibabacloud.com/help/en/model-studio/what-is-model-studio)。这是比 App 用户数更直接的模型商业化渠道，但千问自身 API 收入未单独披露。

## 四、使用规模与财务回报不能混为一谈

### 用户量：数字有，但统计范围不同

| 日期、来源 | 数字 | 准确口径 |
|---|---:|---|
| 2026-01-15，阿里公司披露 | **超过 1 亿月活** | 千问 App 公测两个月内的月活；[公司产品说明](https://www.alibabagroup.com/en-US/document-1948497434959151104) |
| 2026-02，阿里公司披露（2026-03-19 发布） | **超过 3 亿月活** | 千问消费者应用**全平台**月活；[公司业绩说明](https://www.alibabagroup.com/en-US/document-1971445322303406080) |
| 2026-06，QuestMobile 原始报告（2026-07-14 发布） | **1.67 亿月活** | QuestMobile 的**AI 原生 App**活跃用户统计；同报告豆包 3.82 亿、DeepSeek 1.29 亿；[QuestMobile 半年报](https://www.questmobile.com.cn/research/report/2076954943839809537/) |

**不能把 3 亿减去 1.67 亿，断言千问流失了 1.33 亿月活**：前者是公司“全平台”口径，后者是第三方“AI 原生 App”口径，且月份不同。需要阿里连续披露同口径全平台 MAU，或 QuestMobile 给出连续的同口径 App 序列，才能判断留存趋势。2026-08 发布的 FY2027Q1 财报没有更新千问 App 的 MAU。[公司季度财报](https://www.sec.gov/Archives/edgar/data/1577552/000110465926099220/tm2623667d1_ex99-1.htm)。

### 收入：尚无“千问单独营收”

阿里没有分别公布千问 App、千问办公、千问 API 的实际收入，也没有披露千问付费用户数或收入占整个 AI 分部的比例。能看到的最接近数据如下；其中**没有一个数字可以直接当作千问营收**。

| 指标 | 可确认的含义 | 不能推出什么 |
|---|---|---|
| 千问模型下载、衍生模型 | 开发者生态和分发广度；部分版本可自行部署 | **不能等同付费客户、API 收入或毛利**；自部署甚至可能绕开阿里云 |
| **2.5 亿用户**体验 AI 购物（公司披露，截至 2026-08 财报发布） | 自千问 App 上线以来的累计首次购物体验用户，显示触达规模 | 不是付费用户、月活、成交买家、订单或 GMV；不能据此推算佣金。[FY2027Q1 财报](https://www.sec.gov/Archives/edgar/data/1577552/000110465926099220/tm2623667d1_ex99-1.htm) |
| **123.76 亿**季度 AI 相关云产品收入（公司披露） | 整个云分部的 AI 产品合计 | 不等于千问 API 收入；训练算力、平台等也可能在内，产品拆分未披露。[同上](https://www.sec.gov/Archives/edgar/data/1577552/000110465926099220/tm2623667d1_ex99-1.htm) |
| **33.38 亿**收入、**-138.61 亿**经调整 EBITA（公司披露） | FY2027Q1 整个“AI 实验室与应用”分部；亏损扩大主要与 AI 投入及千问 App 推理成本上升有关 | 不等于千问 App 单独收入或亏损，也不是千问模型的完整集团利润。[同上](https://www.sec.gov/Archives/edgar/data/1577552/000110465926099220/tm2623667d1_ex99-1.htm) |

管理层 2026 年 5 月曾**预计**模型与应用服务（含百炼）年化经常性收入在 6 月季度超过 **100 亿元**、到 2026 年底达 **300 亿元**。[当时公司说明](https://www.alibabagroup.com/en-US/document-1991364841188622336)。这是**预期及年化口径**，而且模型平台还提供第三方模型；2026-08 的 FY2027Q1 正式业绩公告没有单独给出该指标的实际达成值，不能把预测写成已实现的千问收入，也不能把它与 123.76 亿云 AI 产品季度收入相加。

## 五、研究判断与后续验证

**目前较可信的判断**：千问已具备有竞争力的模型能力、广泛的开发者分发，以及阿里电商和支付场景的产品入口。真正的投资问题是：这些优势能否转化为**外部客户持续付费和单位经济改善**。现有财报显示云 AI 产品收入增长，但实验室与应用分部仍大额亏损；无法给“千问业务”单独估值或宣称已盈利。

重点跟踪四项证据：① 百炼/千问 API 的实际收入、付费客户及留存；② App 的活跃用户、付费率、由 AI 导致的**增量**交易和转化，而非仅累计体验；③ 办公产品付费席位与续费；④ 模型推理成本、云分部利润率和实验室亏损是否同步改善。竞争上应分别比较模型质量与价格、开发者服务、消费者入口和企业工作流，不能用一张模型榜单代替商业竞争分析。
