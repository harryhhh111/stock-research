对，这样就清楚了。后面我们讨论“海尔”，默认都指 **海尔智家（600690.SH / 6690.HK）**，除非特别说明海尔集团。

海尔智家本质上不是一家单纯的“中国海尔牌家电公司”，而是一家**全球化的综合家电集团**。公司目前拥有 **海尔、卡萨帝、Leader、GE Appliances、Candy、Fisher & Paykel、AQUA** 等品牌，业务覆盖全球 200 多个国家和地区。([海尔智慧家居][1])

我建议我们先把它理解成下面这个结构：

| 核心业务         | 主要产品       | 你可以简单理解为                    |
| ------------ | ---------- | --------------------------- |
| **冰箱/冷柜**    | 冰箱、冷柜、酒柜   | 海尔最传统、最强的业务之一               |
| **洗衣设备**     | 洗衣机、干衣机    | 全球优势业务                      |
| **空调**       | 家用空调、中央空调等 | 目前非常值得重点研究                  |
| **厨电**       | 灶具、烤箱、洗碗机等 | GE Appliances、Candy、F&P 很重要 |
| **水家电**      | 热水器、净水等    | 国内优势明显                      |
| **其他智慧家庭业务** | 智能家居、场景方案等 | 相对次要，但属于战略延伸                |

公司自己的披露也是按照冰箱/冷柜、厨电、空调、洗衣设备、水家电及其他智慧家庭业务来描述主营业务。([海尔智慧家居][2])

但研究海尔智家时，还有一个维度甚至比“产品”更重要：

**地区。**

因为今天的海尔已经不能只看中国市场。

大致可以画成：

**海尔智家**

→ **中国**

* 海尔
* 卡萨帝
* Leader

→ **北美**

* GE Appliances

→ **欧洲**

* Haier

→ **澳大利亚 / 新西兰**

* Fisher & Paykel

→ **东南亚、南亚、中东、非洲等新兴市场**

* 主要以 Haier 品牌扩张

这也是海尔和格力、美的研究方法有点不一样的地方。**海尔海外不是简单的“中国制造 → 出口”。**很多地区实际上已经形成了本土品牌、本土研发、本土工厂、本土渠道的一整套体系。官方披露的全球品牌组合也明确包括 GE Appliances、Candy、Fisher & Paykel、AQUA 等。([海尔智慧家居][3])

所以如果最终目的是理解**海尔智家的业绩和股价**，我认为真正应该盯的是四件事：

**① 中国家电基本盘还能不能增长**

**② 海外业务还能不能持续增长**

**③ 空调能不能成为新的增长引擎**

**④ 高端化和运营效率能不能让利润增速长期高于收入增速**

尤其第 ④ 点很重要。海尔已经是一个年收入超过 **3000 亿元** 的庞然大物，单纯研究“能不能多卖几台冰箱”意义没那么大。对于股价而言，**收入增长几个百分点 + 利润率提高多少**，往往比单纯的销量增长更加重要。2025 年海尔智家收入已经达到约 **3023.5 亿元**。([海尔智慧家居][4])

所以我们可以沿用之前研究美的的办法，但我建议稍微调整：

**第一步先拆产品业务。**

冰箱 → 洗衣机 → 空调 → 厨电 → 水家电。

把每块**收入规模、市场地位、增速、利润特点**搞明白。

然后第二步再把海尔最特殊的一层拆开：

**中国 → 北美 → 欧洲 → 澳新 → 日本 → 新兴市场。**

这样最后我们才能回答真正有投资意义的问题：

> **未来两三年，到底是哪一块业务在拉海尔智家的收入，哪一块业务在拉利润。**

我们下一步可以直接从海尔智家最大的业务开始，我先把 **2025 年各业务收入占比**排出来，这样马上就能知道应该重点研究哪几个。
