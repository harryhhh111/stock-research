## 1. 公司概览

一句话：

> **希捷最核心的生意，就是给云数据中心卖超大容量 HDD 机械硬盘（Nearline HDD）。**

- NASDAQ: STX，全球 HDD 三寡头之一（另两家：Western Digital、Toshiba）。
- 已经不是"电脑里装一块机械硬盘"的老故事：核心客户和增长来源集中在 **AWS、Microsoft、Google、Meta、Oracle 等超大规模数据中心**。
- FY2026 营收 **$12.20B**，其中 Data Center 占约 **80%**；出货约 **789 EB**，Nearline 占 88%。

与之前研究的铠侠（NAND/SSD）是完全不同的一类存储公司，见 2.3。

## 2. 业务模块

（本章只解释业务是什么、卖给谁、怎么赚钱；经营数据见第 5 章营收。）

### 2.1 Data Center（核心，约 80% 收入）

- 产品：高容量 **Nearline HDD**、企业级 HDD、存储系统。
- Nearline HDD 定义：数据中心里存放"大量、需长期保存、但不要求像 GPU 显存/NVMe SSD 那么快"的数据的超大容量硬盘——训练数据集、模型 checkpoint、日志、图片/视频、数据湖、归档。
- 客户真正关心的不是"一块硬盘多少钱"，而是 **存 1EB 数据需要多少机架、多少盘、多少电、多少机房面积** → 即 $/TB、W/TB、机架/TB、整体 TCO。盘从 20TB 提到 40TB，同样 1EB 所需盘数理论上减半。

### 2.2 Edge IoT（约 20%）

NAS、监控、消费级硬盘、PC HDD、部分 SSD。占比持续下降，非投资主线。

### 2.3 HDD vs NAND：和铠侠不是一回事

| | HDD（希捷） | NAND/SSD（铠侠） |
|---|---|---|
| 速度/延迟 | 慢/高 | 快/低 |
| $/TB | **低** | 高 |
| 大规模冷/温数据、归档 | **核心市场** | 贵、部分 |
| GPU 本地高速存储 | 不适合 | **适合** |
| 技术核心 | 磁记录 | NAND 半导体 |

存储分层：**GPU → HBM → 高速 NVMe SSD → HDD 大容量存储 → 归档/冷数据**。希捷自己也承认 SSD 会在部分高性能 workload 与 Nearline 竞争，但 HDD 在大容量领域有明显成本优势。([FY2026 10-Q](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000088/stx-20260403.htm))

### 2.4 HAMR：目前最大的技术故事

HAMR = Heat-Assisted Magnetic Recording，热辅助磁记录。磁记录密度逼近物理极限后，用激光瞬间加热盘面极小区域再写入，把面密度继续往上推：10 盘片 × 2TB/盘片 = 20TB → ×4TB = 40TB → 路线图指向 ×10TB = **100TB**。

- **Mozaic 4+ HAMR 平台已做到最高约 44TB，已通过两家大型 hyperscaler 认证并进入量产**。([Seagate IR](https://investors.seagate.com/news/news-details/2026/Seagate-Delivers-Industrys-Highest-Capacity-Hard-Drives-with-Next-Generation-Mozaic-4/default.aspx))
- 对比 WDC：WDC 目前主力仍是 ePMR/UltraSMR（40TB 在 qualification），HAMR 刚进入客户测试。**HAMR 量产进度上希捷领先 WDC 半个身位**——这是两家未来 $/TB 成本曲线分叉的关键变量。

### 2.5 制造体系：垂直整合，比半导体设计公司重得多

不是 fabless，也不是整机外包富士康。模式是：**核心技术/核心部件垂直整合自制 + 部分标准零件外购 + 自有工厂完成大量制造与装配**。([FY2026 10-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000159/stx-20260703.htm))

| HDD 部件 | 希捷 |
|---|---|
| 磁记录介质 media | **核心自制** |
| 读写磁头 head | **核心自制** |
| HAMR 激光/光子部件 | **核心技术自研/自制** |
| 磁盘基板 substrate | 自制 + 外购 |
| 主轴马达 / ASIC / DRAM / NAND | 外购 |
| PCB / PCBA | 大量外包 |
| 最终装配 | 大量自有工厂 + 部分合同制造 |

全球 7 个主要制造基地（截至 2026-07-03）：北爱尔兰 Springtown（磁头）、美国 Minnesota（磁头+研发）、中国无锡（HDD+子组件）、马来西亚 Johor（基板）、新加坡 Woodlands（磁记录介质）、泰国 Korat（HDD+子组件，最大）、泰国 Teparuk（子组件）。流水线：马来西亚基板 → 新加坡介质 → 美国/北爱尔兰磁头 → 泰国/中国总装。

## 3. 行业供需框架（强周期核心章）

**判定：HDD 适用强周期变体**——产品商品化、供给由三寡头产能与 TB/drive 路线图决定、经营杠杆极大。

### 3.1 需求测算框架（可复算）

```
希捷营收 ≈ HDD EB 出货 × Revenue/EB
其中 EB ≈ HDD 数量 × 平均 TB/盘
需求 ≈ 全球新增数据量 × 需长期保存比例 × HDD 占比
```

AI 同时提高数据生成量与保留量。终极模型：**AI 数据中心 GW → GPU 数量 → 数据产生 → 分层 → Nearline HDD EB → Seagate 营收**。

### 3.2 供给：三寡头 + 供给纪律

HDD 行业经历残酷整合后只剩 Seagate / WDC / Toshiba（对比 NAND 还有 Samsung、SK Hynix、Kioxia、SanDisk、Micron 多个玩家）。厂商少 + 高容量 HDD 制造越来越难 → **行业供给纪律**发生结构性变化：过去是产能过剩、价格战、ASP 阴跌；现在三家都没有恶性扩产动机。

### 3.3 周期机制：销量 × ASP × 产能利用率的三重周期

```
上行：需求↑ → 产能紧张 → 客户提前锁单 → ASP/$/TB 改善 → 利用率↑ → 毛利率暴涨
下行：客户买多 → 库存积压 → 砍单 → 出货↓ → 利用率↓ → 降价 → 毛利率暴跌
```

FY2023 就是教科书案例：Mass Capacity 与 Legacy 需求同降 + 疫情后库存调整 + 价格下降 + 工厂利用率不足，仅低利用率相关费用就约 **$250M**，净利润从 +$1.65B 转为 -$0.53B。([FY2023 10-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778923000049/stx-20230630.htm))

### 3.4 本轮的新变量：HAMR 带来的"资本高效 EB 增长"

希捷当前策略**不是**"需求 +25% → 多建厂多买机器"，而是管理层明说的：**靠 areal density（面密度）提升满足 mid-20% 的 Nearline EB 增长，不增加 HDD unit 产量**。([Q2'26 电话会](https://www.fool.com/earnings/call-transcripts/2026/01/28/seagate-stx-q2-2026-earnings-call-transcript/))

直观例子：一条体系年产 4,000 万块盘，平均 20TB → 800EB；换 HAMR 后平均 25TB，**单位数量不变，EB 产能 +25%**。这就是管理层说的 **capital-efficient exabyte growth**。

推论（重要）：

> **物理 HDD 单位产能 ≈ 基本稳定；EB 产能 ≈ 每年 +20%–25%（靠 TB/盘提升）。**

FY2026 实际出货 789 EB ≈ 0.79 ZB/年；若 FY2027 Nearline 按 mid-20% 增长（695EB × 1.25 ≈ 869EB + 约 90EB 非 Nearline），**FY2027 潜在出货约 0.95–1.0 ZB**（我的估算，非公司指引）。

这也意味着希捷模式比 NAND 更不容易自我毁灭：NAND 扩产 = 建 Fab → bit supply 暴增 → 价格崩；HDD 这轮是"单位产能受控 + EB 靠技术爬坡"，供给弹性天然更小。

### 3.5 当前供给状态：严重供不应求

| 时间 | 希捷披露的订单能见度 |
|---|---|
| 2025 Q4 | Nearline 产能基本订到 2026 年中 |
| 2026 Q2 | **2026 全年产能完全分配**，长约看到 2027 |
| 2026 Q3 | 产能基本分配到 **2027 年底**；CEO：wafer fab is relatively full |
| **2026 Q4** | **绝大多数 Nearline EB 已分配到 calendar 2028**，客户开始讨论 2029+ |

([Q2'26 实录 PDF](https://s24.q4cdn.com/101481333/files/doc_financials/2026/q2/CORRECTED-TRANSCRIPT_-Seagate-Technology-Holdings-Plc-STX-US-Q2-2026-Earnings-Call-27-January-2026-5_00-PM-ET.pdf))([Q3'26 电话会](https://www.fool.com/earnings/call-transcripts/2026/04/28/seagate-stx-q3-2026-earnings-transcript//))([Q4'26 电话会](https://earningscalls.dev/transcripts/seagate-technology-holdings-plc_stx_earnings_call_transcript_2026-07-28))

**当前真正瓶颈不是总装厂，而是 Heads + Media（磁头+介质）**：FY2026 HDD 单位数基本 flat，但每块盘内 disk+head 数量增长约 15%–20%，磁头 wafer fab 已比较满，新增投资主要投向这些环节。

## 4. 周期位置判断

### 4.1 五阶段复盘

| 阶段 | FY | 发生了什么 |
|---|---|---|
| 上轮高点 | FY22 | 631 EB，营收 $11.66B，GM 29.7%（Mass Capacity 541EB，+30%） |
| **崩盘** | **FY23** | EB -30%，营收 -37%，GM 18.3%，净亏 $0.53B |
| **触底** | FY24 | EB 继续降到 398EB（真正出货谷底），但控产+提价使 GM 回升至 23.4% |
| **量复苏** | **FY25** | EB +49%，营收 +39%，GM 35.2% |
| **供不应求** | **FY26** | EB ≈789（+33%），GM **45.6%**（Q4 单季 52.3%），产能锁到 2028 |

### 4.2 核心异常：营收只比上轮顶部高 5%，利润率完全变了

| | FY2022（上轮顶） | FY2026（本轮） |
|---|---:|---:|
| 出货 | 631 EB | ≈789 EB |
| 营收 | $11.66B | $12.20B（**+4.6%**） |
| 毛利率 | 29.7% | **45.6%** |
| 净利润 | $1.65B | $3.18B（**+93%**） |

**营收几乎持平上轮顶部，净利润翻倍——这轮上涨不能简单解释成"又一个普通 HDD 周期"。** 公司自己的解释：pricing actions + 产品组合向更高容量迁移。([FY2026 10-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000159/stx-20260703.htm)) 叠加第 3 章的机制，本轮出现过去 HDD 周期没有的组合：

> **需求很强 + 单位产能受控 + 客户提前锁定供给 + HAMR 提高 EB/drive + $/TB 未同比例下降。**

### 4.3 两种互斥解释（与 WDC 笔记同一框架）

- **解释 A（结构性）**：寡头供给纪律 + HAMR 资本高效增长 + 长约锁产能到 2028 → GM 45%+ 是新常态。
- **解释 B（周期顶）**：hyperscaler 补库存 + AI 资本开支狂潮 → 供给恢复后 GM 回落到 ~30%，当前 $3.18B 净利润是周期高点利润。

**判断标准很清晰：盯毛利率 45.6% 能否维持。** 若未来营收维持 $12B 而 GM 回到 30%，净利润大约只有现在的三分之一到一半。

当前状态：FY2027 Q1 指引营收 $4.1B±$0.1B（同比继续大增），尚无拐头信号；但估值已把解释 A 定价得比 WDC 更满（见第 11 章）。

## 8. 订单与客户承诺（LTA / BTO）（可选模块：启用——判断解释 A vs B 的关键）

### 8.1 两层合同结构

希捷披露的与 CoreWeave 式"某客户 $10B×5 年"完全不同，是两层：

1. **长期供货协议（LTA / master purchase agreements）**：锁定未来几年客户要多少 EB、希捷预留多少产能；**部分合同带取消费用（cancellation charges）**。
2. **Build-to-order（BTO）合同**：临近交付期再确定具体型号、容量、交期、**价格**。

([FY2026 10-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000159/stx-20260703.htm)) Q3'26 管理层确认：已与**几乎所有主要 cloud/hyperscale 客户**签有 EB-scale supply agreements，当时正敲定截至 FY2027 的 BTO（定义具体配置和价格）。([Q3'26 电话会](https://www.fool.com/earnings/call-transcripts/2026/04/28/seagate-stx-q3-2026-earnings-transcript//))

**关键理解：LTA ≠ 三年价格锁死。** 模式是"先锁 EB 需求和产能，临近交付再锁价"——如果市场持续缺货，希捷不用把三年后的售价现在就锁死，**对它更有利**。

### 8.2 披露缺口

- **没有 backlog / RPO 金额**（10-K 不披露 backlog 指标）；
- 不知道锁定产能对应多少钱、多少 EB、客户是谁。

我们知道的是"产能锁到 2028"，不知道"锁了多少亿美元"。这是希捷披露的最大缺口，也是后续可自己估算的方向（见第 14 章）。

### 8.3 为什么这个结构可能改变 HDD 周期

传统 HDD 周期的杀伤链：客户突然砍单 → 厂商库存爆炸 → ASP 崩 → 毛利率崩（FY2023 就是这么发生的）。现在变成 **LTA + BTO + cancellation charge**，等于把一部分库存风险从 Seagate 转移给 hyperscaler。**这件事可能比"AI 带来多少需求"更重要**——它有机会钝化 HDD 过去那种暴力库存周期。

⚠️ 别混淆：希捷自己也签了大量**供应商**长期采购合同——截至 2026-07-03 unconditional purchase obligations 约 **$2.1B**（$1.6B 一年内支付）。这是希捷向供应商买零件的义务，不是客户订单，方向相反。([FY2026 10-K](https://www.sec.gov/Archives/edgar/data/1137789/000113778926000159/stx-20260703.htm))

## 11. 估值与资金效率

### 11.1 市场定价（库口径，2026-08-26）

- 收盘价 **$846.37**，市值 **$191.8B**，**PE TTM 60.9（真实口径，无一次性损益失真）**，股本约 218M 股（Q2'26 末）。
- 对照 WDC：市值 $169.1B、真实 PE 约 46x——**市场给希捷的溢价比 WDC 更高**，定价的是 HAMR 领先 + 干净利润表 + 更抗跌的谷底表现。

### 11.2 Reverse DCF 先行：当前价格隐含了什么？

以 FY2026 FCF $3.11B 为基数（**假设**：贴现率 10%、5 年显性期、永续增长 3%）：

| 假设 FCF 5 年 CAGR | 隐含估值 |
|---|---:|
| 20% | ≈$90B |
| 25% | ≈$110B |
| 30% | ≈$132B |
| 35% | ≈$157B |
| **≈40%** | **≈$192B（当前市值）** |

- 市值 / FY2026 FCF ≈ **61.7x**，FCF yield ≈ **1.6%**。
- **当前市值隐含 FCF 在创纪录的 $3.1B 基数上以约 40% CAGR 连涨 5 年（涨到约 $17B/年）**——比 WDC 隐含的 ~33% 还要激进。管理层自己的 Nearline EB 目标只是 mid-20% 增长，40% FCF CAGR 意味着还要叠加利润率在 45.6% 毛利率基础上继续大幅扩张。

### 11.3 ±30% 偏离规则

按解释 A 乐观情形（FCF CAGR 20–25%）自估 **$90–110B**，对市价 $191.8B 偏离 **-43% ~ -53%**，大幅触发 ⚠️ **caution**。分歧来源与 WDC 相同（更低贴现率、更长显性增长期、把供给纪律当确定性），但 STX 的偏离幅度比 WDC（-27%~-41%）更深——**两家都贵，STX 更贵**。

### 11.4 资金效率小结

- FCF margin FY2026 = 25.5%（Q4 更高）；谷底年份 FCF 仍为正——现金制造机属性贯穿周期；
- CapEx 收入占比 3–4%，长期 4–6%；
- 负债率从 119% 修复到 78%，净资产转正；
- 回报以分红（小额）+ 债务退役为主，回购节奏放缓（Q2'26 回购仅 $29M）。

## 12. 我的看法（【我的推演】，整篇主观，待事实纠正）

1. **研究框架**：希捷 = "Nearline EB 量价 × 寡头供给纪律 × HAMR 成本曲线"，Edge IoT 可忽略。与 WDC 共用同一框架，两家合看即为全球大容量 HDD 行业的大头。
2. **周期判断**：与 WDC 一致，倾向"**A 与 B 之间、偏 A**"，且 STX 侧的证据更强：HAMR 已量产（对手还在测试）、产能锁到 2028 的能见度、LTA+BTO+cancellation charge 把库存风险转移给客户。**但锁定的是 EB 产能，不是价格**——BTO 临近交付才定价，下行期价格照样会跌，长约钝化周期而非免疫周期。
3. **估值判断**：$191.8B 隐含 ~40% FCF CAGR，比 WDC 还贵，偏离我的乐观估值 -43%~-53%。**HAMR 领先是事实，但市场已经为这个事实付了双份钱（利润率新高 + 高倍数）**。赔率比 WDC 更差。
4. **相对结论**：如果一定要在两家里选，STX 是更好的公司（HAMR 领先、谷底 FCF 为正、利润表干净），WDC 是更便宜的价格（隐含 33% vs 40%）。**"更好的公司"和"更好的股票"在当前价位是分离的。**
5. **跟踪信号**（与 WDC 笔记共用一套）：季度 Nearline EB 环比与产能分配年份是否继续后延（2028→2029 是景气延续信号，停止后延是拐点信号）；BTO 定价方向；GM 45% 防线；HAMR ramp 的 heads/media 瓶颈进展；hyperscaler 资本开支指引。
