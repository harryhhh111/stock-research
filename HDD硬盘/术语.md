# HDD 行业术语

> 整理日期：2026-10-05。用于本文件夹三家公司研究。

| 术语 | 含义 | 研究时注意 |
|---|---|---|
| Nearline HDD / 近线硬盘 | 面向数据中心的大容量硬盘 | 客户端 HDD、近线 HDD 的需求不能混为一谈 |
| EB / Exabyte | 十进制 10¹⁸ 字节；1EB = 1,000,000TB | 出货容量与出货块数是不同指标 |
| CMR | 传统磁道排列，磁道不采用 SMR 的重叠方式 | 不是“完全没有辅助磁记录技术” |
| SMR | 叠瓦式磁记录，通过磁道重叠提高容量 | 需匹配写入负载和数据管理方式 |
| Host-managed SMR | 主机管理的 SMR | 主机负责数据放置和重写，不能默认即插即用替代 CMR |
| MAMR | 微波辅助磁记录 | 辅助磁记录路线，可结合 CMR 或 SMR |
| FC-MAMR | 东芝的磁通控制微波辅助磁记录技术 | 与东芝产品系列/技术阶段一起看 |
| HAMR | 热辅助磁记录 | 演示、送样、认证、量产不能混用 |
| ePMR / UltraSMR | WDC 的辅助垂直磁记录路线 / 增强 SMR 技术 | 两个维度，不能只用容量比较成本 |
| TB/drive | 单块硬盘的容量 | 平均出货容量不同于最高规格容量 |
| $/TB | 每 TB 的售价或成本 | 必须说明售价/成本、合同/零售，以及容量和负载口径 |
| W/TB | 每 TB 对应的功耗 | 不等同整个存储集群 TCO |
| Qualification | 客户认证 | 产品公告不是客户认证完成证据 |
| Ramp | 产能或产品的生产交付爬坡 | 首次出货不代表满产 |

技术定义来源：[东芝 MG11/MA11 公告（2024-09-10）](https://toshiba.semicon-storage.com/us/company/news/2024/09/storage-20240910-1.html)、[东芝 M12 公告（2026-03-31）](https://toshiba.semicon-storage.com/kr/company/news/news-topics/2026/03/storage-20260331-1.html)、[东芝 HAMR 演示（2024-05-14）](https://storage.toshiba.com/news/pr/toshiba-successfully-demonstrates-nearline-hdds-with-massive-capacity-of-over-30-terabytes)、[WDC 技术路线（2026-02-03）](https://www.westerndigital.com/in-id/company/newsroom/press-releases/2026/2026-02-03-western-digital-accelerates-storage-innovation-for-ai-era)。
