# 行业研究

每个细分行业单独建项目。项目内 `reports/` 维护卡片首页和独立模块，`factcheck/data/` 按需保存原始证据。公司报告引用行业模块中适用的结论和数据口径，结合自身业务进一步分析。

按 [行业与竞争规则](../研究流程/standards/modules/行业与竞争.md) 开工。在 [唯一 HTML 索引](../研究流程/index/html-index.json) 中查找 `topic:industry-` 主体，`-overview` 结尾的报告 ID 指向该行业的首页。建档和登记按 [命名与索引规范](../研究流程/standards/HTML报告命名与索引规范.md) 执行。
