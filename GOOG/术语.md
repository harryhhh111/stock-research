# Google研究术语

整理日期：2026-10-29。

| 术语 | 含义与边界 |
|---|---|
| TPU | Google自研张量处理器，可供自用、云服务或系统销售；三者不能重复算收入 |
| GCP | Google Cloud Platform，计算、存储、数据及AI平台；Cloud分部还包括Workspace等 |
| TAC | Traffic Acquisition Costs，流量获取成本，包括分发伙伴及广告网络伙伴款项；不是全部广告成本 |
| AI Overviews / AI Mode | 搜索中的AI摘要/交互形式；使用次数不是独立营收 |
| Other Bets | Alphabet非Google业务的合并分部口径，不等于股权投资组合 |

通用财务术语见[工作区术语](../术语.md)，定义来源见[主文档](GOOG.md)。
