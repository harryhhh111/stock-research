## 核心判断

**怎样赚钱：搜索和视频广告仍是现金发动机，云和 AI 基础设施成为新增收入的重要来源；但集团已从高现金回报的平台，进入资本密集、需要外部融资的扩张阶段。**

【我的推演】本轮判断是“经营竞争力强，股东现金回报需要重新验证”，暂不把低表观 PE 当作买入依据。三个投资问题：

1. AI 增加搜索次数之后，商业查询变现和推理成本能否共同改善？查询增长不能单独证明搜索经济性改善。
2. 云收入翻倍，多少来自可重复的算力消费，多少来自 TPU 系统交付？后者收入确认、库存和回款节奏不同。
3. CapEx、外购算力、收购和模型投资之后，普通股股东最终能拿到多少现金，新增收益是否覆盖融资及稀释？

正面证据是搜索收入仍增长、云分部利润率提升；反面证据是 FCF 连续两季为负、普通股融资与优先股融资并存。若未来云订单转收入和现金持续匹配、集团 FCF 恢复且稀释放缓，判断可以改善；若云收入上升但应收、库存、采购承诺及融资更快增加，应下调增长质量评价。

## 1. 公司、业务与并表边界

| 业务 | 谁付钱、为何付钱及收费机制 | 进入财报与利润边界 |
|---|---|---|
| Search & other | 商家购买高购买意图的流量，例如本地牙医竞价“附近牙科”；按点击等广告事件计费，竞价与转化效果影响单价 | Services；不是用户每次搜索付费。未独立披露搜索利润 |
| YouTube | 广告主买曝光/转化；个人购买 Premium、Music、TV 等订阅 | 广告收入单列，订阅在订阅/平台/设备中，不能把 YouTube 广告当全部 YouTube 收入；需支付内容分成和版权成本 |
| Network | 第三方网站和应用通过广告工具变现，广告主付费，Google 向合作伙伴分成 | 广告营收与流量获取成本 TAC 分列，收入规模不代表全部归 Google |
| 订阅、平台与设备 | Google One、Gemini 相关套餐、YouTube 订阅按期收费；Play 按应用交易收服务费；Pixel/Nest 等出售硬件 | 混合业务，硬件与订阅毛利不同，未披露独立利润；不能直接当 AI 订阅收入 |
| Google Cloud | 企业为 GCP 计算、存储、数据库、AI 模型调用按量/承诺用量付费；Workspace 按席位订阅；本季也包含 TPU 系统销售 | 服务按履约确认，设备销售按相应控制权转移确认；云总收入不是 AI 收入 |
| Other Bets | Waymo 自动驾驶出行、互联网等早期业务，乘客等付费 | 包括并表但有外部股东的实体；不等于全部损益都由普通股股东经济承担 |

【原始披露】主要分部是 Services、Cloud、Other Bets；共享前沿 AI 研发费用在 Alphabet 层列示。Google DeepMind、Gemini、TPU 不是可以在分部收入之上再相加的独立上市资产。YouTube、Android、Chrome、Play 已在集团内；Waymo 并表，外部融资不等于集团营业收入。Anthropic 等少数股权投资不把被投公司的全部营收并入 Alphabet；其投资估值收益、对外云销售、客户采购承诺必须分开。[S1][S2][S3]

## 5. 客户、竞争对手与行业景气

【原始披露】2023—2025 无单一客户或关联客户组占集团收入超过 10%。这证明集团层面的客户分散，并不能证明 Cloud 没有大客户集中。广告主是付费方，搜索用户和创作者分别是流量/内容参与者；Apple 等分发伙伴属于渠道，不应当作广告收入客户。[S1]

| 市场 | 真实对手与比较维度 | 判断与边界 |
|---|---|---|
| 搜索和商业意图广告 | Bing、Amazon 站内购物广告；ChatGPT、Perplexity 改变信息入口 | 竞争的是商业流量、广告转化和每次服务成本；查询数与搜索收入一起看，不能用模型榜单推导市场份额 |
| 视频广告与订阅 | Meta、TikTok 争夺注意力；Netflix 等竞争客厅观看与订阅预算 | YouTube 用户与创作者双边生态强，但广告价格受宏观/内容结构影响，长短视频及版权成本不同 |
| Cloud | AWS、Azure、Oracle 及专门算力云 | 比较总拥有成本、可用容量、模型/芯片兼容、数据迁移、安全与企业销售；不把 Azure 增速与整个 Microsoft 收入混比 |
| Workspace/AI 助手 | Microsoft 365/Copilot、OpenAI、Anthropic | 按付费席位、续费、调用成本与工作流粘性比较，活跃用户不能替代收入 |
| TPU | Nvidia GPU 平台、云厂自研芯片 | 潜在优势是软硬协同和大规模利用率；跨客户可移植性、供应链和资本占用会限制优势兑现 |

### 2026-10-29补充：是否错杀

【我的推演】约290美元有错杀的可能，但尚不足以判断“明显过低”。前面的TTM PE约15倍受到投资收益抬高分母影响，应补充经营盈利代理；同时当前FCF被扩张投入压低，不能把全部增长CapEx永久化后就认定公司昂贵。

【行情核对】[StockAnalysis](https://stockanalysis.com/stocks/goog/)显示2026-10-28美东19:59盘后GOOG 290.50；这不是10月29日常规收盘。[财报原件](factcheck/data/2026-q3.pdf)与全年底表推得TTM经营利润156,976。为排除巨额投资估值收益，假设长期税率20%，再扣约19,000优先股清算本金×6.25%的年股息1,187.5，得到普通股经营盈利代理124,393，即每股10.12美元。以290.50计算约28.7倍。✅ 脚本复算一致；**这不是公司调整后净利润**：未纳净利息/其他非经营损益、未来转换稀释及税务差异。

若该代理盈利未来一年增长20%/30%，当前价格对应约23.9/22.1倍未来盈利；这是需要兑现的假设而非预测。以当前盈利代理套20/25/30倍，价格敏感性约202/253/304美元，倍数为研究员自设，无历史分位或同业数据背书，不构成目标价。当前价格需要较高倍数或持续增长支持，并无单凭静态盈利即可确认的显著安全边际。

错杀逻辑：市场可能过度惩罚季度投资损失和建设期现金流，而搜索/云主营仍增长。合理重估逻辑：新增算力资本回报、融资与每股稀释存在真实风险。更强的低估证据应是资本回报改善、每股主营盈利维持增长、订单带来可收回现金，或价格已能在保守增长假设下提供回报。当前结论为“值得跟踪的成长估值，尚非已证实错杀”。复算见[脚本](factcheck/valuation_normalized.py)、[结果](factcheck/2026-10-29-经营利润估值.json)。
