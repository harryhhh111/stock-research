# 长鑫科技项目术语

> 整理日期：2026-09-15。只收录本项目高频的 DRAM/产品术语；跨项目通用概念仍以根目录《术语.md》为准。

| 术语 | 含义 | 在长鑫研究中的作用 |
|---|---|---|
| DRAM | Dynamic Random Access Memory，动态随机存取存储器；需要周期性刷新，断电后数据不保留。 | 长鑫主营的内存芯片类别；区别于 NAND Flash。 |
| DDR5 | 第五代双倍速率同步 DRAM 接口/产品代际。 | 面向服务器、PC 等高性能场景，是公司 DDR 产品升级重点。 |
| LPDDR | Low Power DDR，低功耗 DRAM。 | 主要用于手机、笔记本、AIoT、汽车等；长鑫已有 LPDDR4X、LPDDR5/5X，LPDDR6 在客户验证。 |
| IDM | Integrated Device Manufacturer，垂直整合制造。 | 公司覆盖研发、制造等关键环节；好处是协同与控制力，代价是高资本开支和折旧。 |
| DRAM die | 从晶圆切割得到、尚需封装测试的单体芯片（裸片）。 | DRAM 芯片是公司出货和销售的主要产品类型；模组不是唯一收入来源。 |
| RDIMM / MRDIMM | 寄存式 DIMM / 多路复用 Rank DIMM，均为服务器内存模组形态。 | 公司 DDR5 模组产品，服务高可靠性或高带宽的服务器内存需求。 |
| ASP | Average Selling Price，平均销售单价。 | 存储器收入和毛利率的核心周期变量；公司未披露 ASP，不能从收入增速直接反推。 |
| bit 出货 | DRAM 按存储容量计量的出货量。 | 与 ASP 相乘决定产品收入；长鑫目前未公开定量 bit 出货数据。 |
| WSPM / wafer starts | Wafer Starts Per Month，每月投入生产线的晶圆数量，通常以 12 英寸等效片计。 | 是衡量晶圆厂名义投片规模的口径；不能直接等同于可销售 DRAM 颗粒、bit 出货或营业收入。 |
| G5 平台 | 长鑫第五代 DRAM 工艺技术平台；公司于 2026-09 宣布量产。 | 公司称按 8Gb 基准每片晶圆的裸片数较第四代至少提升 50%；这反映密度提升，不能等同于良率提升。 |
| 4F² DRAM 架构 | 以最小特征尺寸 F 表示的 DRAM 存储单元面积为 4F² 的架构；常被用于讨论相较 6F² 单元的缩放潜力。 | 长鑫管理层在 2026-10-10 行业会议上介绍相关进展并称拟用于新一代 DDR5 RDIMM；现阶段应视为会议口径/产品目标，不是已披露的量产与收入。 |
| 良率 | 合格芯片数量占投入产出的比例。 | 决定先进产品的单位成本、可销售产量及规模量产能力。 |
| 绿鞋 | 超额配售选择权。 | 长鑫 IPO 中已全额行使，影响最终发行股数和募资金额，不直接代表经营增长。 |

术语及产品定义以[长鑫科技 2026 年半年报](https://static.cninfo.com.cn/finalpage/2026-08-29/1225529543.PDF)为准。
