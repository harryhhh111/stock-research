# HTML 报告与财务可视化规范

维护日期：2026-11-17。本文件是[研究方式](../研究方式.md)的展示附件，不另设研究内容标准。结构见[主文档模板](公司研究主文档模板.md)，验收见[执行清单](研究更新与交付检查清单.md)。

## 1. 适用范围与阅读顺序

后续公司/主题研究的新建、更新与纠错只维护和交付 HTML 报告，放在对应项目目录，名称清晰且主报告路径稳定。不新建或同步维护 Markdown 报告、机器正文底稿，已有 Markdown 停更保留为历史资料，不批量转换；局部更新可仅建立对应范围的 HTML 并明确覆盖边界。内部 SOP 与证据笔记仍可使用 Markdown。HTML 是报告文件，不要求部署网站、配置服务或接入实时行情。

阅读顺序：标题与一句话判断 → 副标题下日期标签与关键指标 → 简短摘要/核心矛盾 → 目录 → 九个阅读章节（覆盖十一项研究问题） → 风险 → 跟踪指标 → 待验证问题 → 核验、口径说明与来源。使用语义标题和稳定章节 id；历史解释迁移时保留数据旁摘要与定位。

顶部标签明确文档更新日、最新财报季度/半年及实际期末日；估值报告另标行情截止日。前文不单设冗长日期模块，主体/财年/TTM/股本时点、历史研究日期及引用细节放文末。表图旁的期间、单位、主体及实际/指引标识仍就近保留。

摘要可放少量关键指标，例如收入、经营利润率、FCF和净债务，每项同时显示期间、单位、可比变化及来源定位。卡片不混淆年度/TTM/期末，不替代完整底表；关键缺失明确显示，不能用零填充。

## 2. 表格是精确数据层

- 表前注明主体、币种、单位、期间性质和口径；年度、单季、累计、TTM分别成表，资产负债标期末。三完整财年及当年已披露季度的最低覆盖要求不变。
- 通常行放业务/指标、列放期间，按时间先后排列；最新季度同比与季度环比分组清晰。宽表保留完整数据，可横向滚动并固定首列/表头；不能为适配窄屏删除季度。
- 营收每格分行显示“金额、同比、占比”并明确标签，数字右对齐，同行精度一致。金额、股数、EPS、比率不同量纲不误套统一单位。利润率变化写百分点。
- 缺失用“未披露/未取得/不可比/不适用”并解释；零值、负值、估计、管理层指引和复算拆季各自标明。负值与跨零优先给金额变化。
- 每行或指标组有可定位来源；共用来源可放表注并用编号定位。来源、拆季公式、口径差异、重述及异常说明在表附近，不能只藏在悬停里。
- 关键精确表格默认展开；补充底表可折叠但打印应展开。筛选或切换不能成为获取必需期间的唯一方式。排序不破坏季度先后和财务桥顺序。

## 3. 图表按要回答的问题选择

| 问题 | 默认图形 | 必须保留的限制 |
|---|---|---|
| 三年/逐季收入、利润变化 | 分组柱状图或折线图 | 年度与季度分开；完整时间轴，缺失不连成连续实绩 |
| 各业务贡献多少收入 | 堆叠柱状图 | 分部互斥、含抵销解释；负抵销单列，不藏进其他 |
| 结构占比怎样变化 | 100%堆叠柱状图 | 分母一致，真实构成可加总，保留金额表 |
| 单期支出用途、客户/地域分布 | 横向柱状图优先，合格时环形图 | 金额可比；构成图须满足第4节条件 |
| 收入来源与利润形成、现金来源与用途 | 桑基图优先，无法可靠表达时瀑布图兜底 | 收入与现金分图；节点或变化桥可勾稽；真实负值不绝对化 |
| 利润、现金余额为何变化 | 瀑布图/变化桥 | 起终点、加减方向、残差和公式可复算 |
| CFO、现金CapEx、FCF关系 | 分组柱状图 | CapEx支出方向说明，FCF不是与前两者可加总的第三种用途 |
| 毛利率、经营/净利率变化 | 单独折线图 | 同口径百分比，不与金额混为同一轴 |
| 债务何时到期 | 到期年度柱状图 | 最新期末、债务类型及租赁边界明确 |
| 估值随增长/利润率怎样变化 | 敏感性表，可辅以热力图 | 行列假设、公式、单位、行情日明确，标【我的推演】 |

图表只围绕重要判断配置，不机械把每张表画一次。颜色在整份报告中固定对应业务/指标；事实与指引采用明确文字和线型区分，不能只靠颜色。

柱状图金额轴从零开始；负值真实穿过零线，不取绝对值伪装为正值。折线轴若非零起点必须明确刻度且不夸大变化。默认不用双轴，金额与比率分图；不用3D、面积失真、截断刻度或用不同比例的小图制造比较错觉。

### 3.1 十一项研究模块选图指引

先明确图要回答的一个重要问题，再核对披露、期间与可比性。定量图表达可复算关系，表格保存精确值，文字说明成因证据与判断。下表编号对应十一项研究问题，不是阅读章号；业务/营收连续组织、资本分配归第2/3节、订单归客户章、核心矛盾归摘要、治理文化独立，具体九章顺序见主模板。下表是选图指引，不是每模块至少一图的硬要求；一个问题已解释清楚时交叉定位，不复制主图。资料可取得时应继续核验，不能以“未披露”代替未做的工作。

| 模块 | 读者要回答的问题 | 首选图形与必要替代 | 适用边界 |
|---|---|---|---|
| 1 公司与业务 | 谁付款、买什么、谁承担成本？哪些资产并表？ | 付费/交付泳道图；公司股权与并表关系图 | 资金、服务、股权用不同文字及线型，未披露金额等宽示意。持股不自动等于控制或并表；真实案例与机制例子分开 |
| 2 营收结构 | 哪块大、哪块贡献增长？ | 构成/趋势柱状图＋收入桑基；量、价、组合、汇率/并购增长贡献瀑布图 | 量价存在交互项时保留拆解顺序与公式，不把无法解释的残差归于涨价 |
| 3 盈利、负债与现金流 | 赚到利润为何没留下现金？何时需要还钱？ | 收入利润与现金桑基/瀑布；利润到CFO调节桥；债务到期柱图；金额/利润率分图 | 非现金加回不等于无经济成本；债务面值/账面值及租赁分开 |
| 4 客户 | 谁在使用、处于什么阶段、是否过度集中？ | 已披露客户占比横向条图；客户×产品×阶段矩阵；有原始数据时留存队列热力图 | 匿名不猜名，案例不当排名；没有占比不做客户饼图，缺失留存不填零 |
| 5 竞争对手 | 同一市场上优势体现在哪？ | 同口径市场份额趋势；价格/成本/性能对照条图；可比企业散点图 | 份额分母、地区和时点一致；散点只画量化数据，不画研究者任意给的“技术力分数”，相关不当因果 |
| 6 估值与资金效率 | 当前价格要求什么经营结果？ | 增长×利润率/终值倍数敏感性热力表；历史估值区间；ROIC与适用资本成本对照 | 明确股价日期、财务期间、模型公式和税率；区间非保证，资本成本属推演，不拿高点盈利做稳定基准 |
| 7 行业景气 | 需求、产能、价格、库存处在哪一阶段？ | 供需分别画趋势，兼容时同单位比较；产能→有效产量转换示意；库存天数与价格分图 | 名义/有效、存量/增量、产品口径分开；多图保持时间对齐，禁用双轴制造因果或把采购额转为未经验证产能 |
| 8 分红与资本分配 | 钱投到哪，何时形成回报？回购是否减少股数？ | 现金桑基/瀑布；项目建设—投产—爬坡时间线；期初股数→回购/增发/SBC归属→期末股数瀑布 | 现金已有，其余项目状态区别实绩与指引；股数桥用实际股数，SBC费用不能直接当增发股数。未起租承诺不算本期付款 |
| 9 核心矛盾（摘要）与治理文化（独立章） | 哪些变量影响收入、成本和估值？谁控制、如何激励？ | 关键变量影响路径图；股权投票权关系图；有披露权重时薪酬指标构成图；重大事件时间线 | 推断箭头标【我的推演】，处罚发生/计提/支付分开；持股权与投票权不同，不凭箭头证明因果 |
| 10 订单与客户承诺 | 大合同何时转收入、是否必须兑现？ | RPO/积压订单预计转收入的期限柱图；期初订单＋新增－确认收入±取消/汇率＝期末订单瀑布 | 只有预计期限时只画期限，不假设直线转收入；仅在公司口径可勾稽时作桥，订单与收入范围不一致不可强扣；不把承诺当现金 |
| 11 护城河 | 优势是否转化为持续超额回报、在扩大还是收缩？ | 留存、客单价、利润率、ROIC、份额的证据趋势小图；业务×壁垒来源×证据矩阵 | 按证据选图，不机械画全部指标；不用主观雷达图将复杂判断伪装精确，也不把毛利率跨模式直接对标 |

### 3.1.1 微软试阅确认的布局与选图规则

- **业务与营收连起来读**：用初中生能理解的语言解释付费方、购买理由及计费方式，重要产品紧邻营收量级与分类说明；机制关系没有金额时只用等宽箭头，不造业务收款。
- **最新实绩与指引前置**：在营收章节前部用对照表及适用图形呈现；实绩/预测分列，标发布日期、各自期间、区间、汇率及同比基数。区间常驻显示，中点只作有标识的复算示意；不把未来指引接成历史实绩线，也不替代三年和完整年内单季。
- **收入图下紧接现金投入与股东分配图**：分开会计收入与现金图，可用“CFO→现金CapEx/FCF→分红/回购/差额”桑基图；已知同期间金额可勾稽时不只用数字卡片。差额不是期末余额或现金增加，尚含其他投资/融资/汇率影响；旁注公式并链接完整现金桥，不暗示资金逐笔追踪或所有CapEx都是AI。
- **增长贡献只比较增量**：有负贡献用发散单根堆叠条或紧凑瀑布图，标净增额、正负贡献及公式；不把期初/期末收入存量混入贡献占比，不把负贡献绝对化画饼。
- **结构问题可用更简单的图**：单期非负互斥且有可靠分母时，可用饼图/环形图或单根100%堆叠条，少类别优先直接标金额与比例；预计订单确认比例显著标预计。饼图不用于净利润到CFO等含负数的调节过程，非负也须先判断是否真正构成关系。
- **变化桥要紧凑可读**：缩短相邻柱的空隙和连接线，金额与项目名贴近对应柱，防止浮动柱与图底标签隔得过远；必要时换行或横向滚动。起终点、正负方向与金额比例保持真实，不能用截轴、增粗小值等办法改善外观。离线和窄屏检查标签碰撞与打印缩放。
- **订单与客户同章**：客户案例、需求/集中度之后接RPO/backlog、确认期限和兑现风险；自身采购/租赁付款承诺归资本分配。核心矛盾在摘要，治理与文化用独立证据章节。

### 3.2 摘要、风险、跟踪与证据

| 位置 | 可视化 | 限制 |
|---|---|---|
| 摘要与我的判断 | 1—3个投资问题对应的证据卡片，附迷你趋势与反证条件 | 卡片仍注明期间/单位，不能替代主表；不自动生成买入/卖出信号 |
| 主要风险 | 风险事件→经营指标→现金/估值传导图；有支持的情景敏感性表 | 不臆造概率做风险热力评分；未知概率用“未知” |
| 跟踪指标 | 当前值、历史趋势、触发复核条件的紧凑看板 | 阈值需有依据，否则用定性事实；绿灯不是自动建议交易 |
| 时间与证据覆盖 | 财年/季度来源覆盖矩阵及研究更新时间线 | 状态缺口分未披露、未完成、不可比、不适用；不与研究观点评分混合 |
| 历史新闻与行情 | 统一基准的价格/总回报图＋事件标记 | 注明复权/分红、起点和基准；事件相关不证明因果，不用相似走势当交易有效性证据 |

### 3.3 优先评估的六项图形

1. **业务付费/交付链路图**：先看懂谁向谁付钱，再读财务科目。
2. **收入/利润驱动瀑布图**：从“涨了多少”转向“由什么贡献”。
3. **利润→CFO→FCF解释**：相邻独立桥或清晰分阶段图，避免将FCF混作额外现金用途。
4. **投入→建设→交付→收入→收款时间线**：对应重资产、AI和长周期业务的核心研究问题，预计与已发生区分。
5. **估值反推敏感性**：回答当前价格要求什么，而不仅陈列PE。同时用情景表展示“隐含业务/产品→商业化节点→具体目标财年→所需收入/利润/FCF→折现现值与现价差异”，按研究方式第七节检验兑现延迟和倍数收缩。可配兑现时间线、增长/利润率或兑现年份敏感性图，预测与事实明确区分；精确假设及结果常驻表格，不只藏在悬停中。
6. **订单转收入与净股数桥**：分别验证商业兑现和股东回报。

这六项是默认评估是否适用的研究问题，不是每份报告强制新增六张图。已由一图清楚解释的模块直接交叉定位；数据不足记录原因，继续核验可取得证据，不以“未披露”代替未做的工作。

图形特有核验：量价拆解明确交互项及顺序；股数桥用实际股数而非SBC费用；订单桥先确认期初/新增/取消/收入确认属于同一口径；时间线分别记录发生日、公开日、预计窗口及状态。供需图不混名义/有效、存量/增量，不用双轴暗示因果。

不默认使用主观护城河雷达图或无依据风险概率评分。图中的关系箭头、事件标记及相关性不证明因果；股权、付款、交付、合作和推断须区分。金融、周期制造、亏损成长与协议等按经济性质选图，不强套相同利润/现金模型。

## 4. 支出到底流向哪里

### 4.1 先分清三套问题

1. **利润表费用**：营业成本、研发、销售、管理等，用费用表及收入利润桑基图，无法可靠表达时用毛利→经营利润瀑布图；说明资本化、折旧和SBC。回答利润如何形成，不把它称为现金用途分布。
2. **投资与股东分配的现金用途**：现金CapEx、现金并购、股权投资、分红、回购等，在同期间按互斥定义列金额及来源，用横向柱状图比较。标题明确是“已列现金用途”，不声称覆盖所有经营付款。资本化支出按报表分类去重，净额并购付款注明是否扣取得现金。
3. **完整现金来源与去向**：优先使用现金来源用途桑基图，无法可靠表达时用现金流量表瀑布图兜底；期初现金＋CFO＋投资现金流净额＋融资现金流净额＋汇率及其他调节＝期末现金。现金范围（现金等价物、受限现金等）与原表一致；各大项展开时不重复加总父项和子项。融资项可拆借款/偿债、分红/回购，投资项可拆CapEx/证券买卖/并购，并保留剩余项。

CFO已经扣除经营现金支出，不能在CFO起点的资金桥中再扣研发或工资；折旧、非现金租赁、资产增加、回购授权和未来承诺不作为本期已付现金。若原表未拆经营付款，就写无法完整展示供应商/员工等现金去向，不用利润表费用估造。

### 4.2 饼图/环形图的使用门槛

仅用于同一主体、同一期间、同一币种、同一现金/会计口径的非负、互斥且覆盖明确分母的分类；建议不超过6类，多类别优先横向柱状图。中心或标题显示总额及分母名称，每类金额和占比可见，另附精确表格。

存在负值、净流入、抵销或重复分类时改用柱状图/瀑布图；不以绝对值强行凑饼。未拆余额仅在总额和已知分类均可靠且同口径时复算为“未拆分”，展示公式；它不代表零，也不任意分配。披露不全且无可靠总额时仅展示已知金额，不画覆盖全公司的构成图。占比合计的舍入误差说明，不能修改原数凑100%。

例如【纯示意，非公司实绩】：现金CapEx 60、并购20、回购15、分红5，定义互斥后可画“本表四项现金用途合计100”的环形图；研发费用30不能加入这一分母。还本、证券投资等若未纳入，必须说明该图不是全部现金支出。

### 4.3 桑基图优先、瀑布图兜底

适用于收入来源→集团收入→成本/毛利→费用/经营利润，以及现金来源→汇总→用途/留存。默认优先桑基图；负利润、负CFO、净流入、抵销、冲回或复杂关系无法清楚且可靠地表达时，使用带真实符号的瀑布图，说明替代原因。趋势、占比、债务到期、估值等问题继续按第3节选图，不强行改成资金流图。

**未采用桑基图的说明是必填项。** 对收入/利润、现金两条链路分别执行，包括改用瀑布图、构成图、仅列底表或完全未配图的情况：

1. **就地说明原因**：写在对应图、表或章节旁，不只在聊天、生成脚本或文末笼统说明。指出具体期间、链路及受限环节；数据不足须给已查来源和缺少科目，负值或抵销须指出其如何妨碍守恒或经济含义，不能只写“亏损”“负现金流”“结构复杂”或“为简洁”。
2. **说明替代与覆盖**：列采用的替代图及其回答的问题；未配图则说明理由和保留的底表。指出尚未表达的来源、成本费用、用途或终点及其影响；另一章节已有同一链路图时给准确锚点，不重复绘制。
3. **检查是否仅局部受限**：净亏损不必然妨碍收入→成本/毛利→费用/经营利润的前段表达；负CFO也应先评估能否按经济方向作为现金净用途表达。可以可靠展示的部分仍应展示，再用独立瀑布图处理受限环节，不因一个负终点跳过整条链路。小额利润用标签补充，不放大流量。
4. **判定理由是否成立**：仅有收入构成条图不能替代收入到利润形成的流向，不能以“第三章解释了利润”代替实际图形或准确定位。数据已足够而绘图遗漏，须补图；文字承认遗漏不算验收通过。确实不适用时说明经济性质及证据，不强套图形。

可用说明格式：“本段未采用桑基图：〔具体受限环节与原因/证据〕；改用〔替代图或底表〕，覆盖〔关系〕；〔未覆盖内容、原因及影响，或另一处图的链接〕。”占位符须替换为实际内容。说明的存在与理由的有效性分别核验，不能仅搜索到“未采用”就判通过。

- 一图同主体、同期间、同币种、同单位、同会计口径。收入利润与现金分别成图，不将产品收入直接连到CapEx/分红；集团数据不能冒充分部数据。
- 每条边有来源或可复算公式；同图带宽按金额统一比例。中间节点入流等于出流；源和终端按定义核对。容差依据原始精度说明，不改数凑守恒。
- 负值不得取绝对值伪装分配。能按经济方向表示的净流入单列并勾稽，否则用瀑布图。数据不足时只展示已知桥段和明确缺口，不凭空构造完整终点。
- 残差仅在可靠总额与同口径已知项存在时计算，注明公式及“其他净额/未拆分”。合并小类保留明细；不隐藏关键业务。小流量用标签及引导线补充，不人为增加带宽。
- 公共节点之后的路径不证明逐笔资金或产品级成本归属，不按收入比例虚构产品利润。行业特殊口径先定义节点，不能将本金、代币发行、收入、费用和权益分配混接。
- 现金图显著标总额/净额；期初余额不是当期收入，期末余额不是费用，汇率不是付款。父子项不重复计入，CFO已扣的经营付款不再扣；非现金资产、折旧、SBC、未来承诺及回购授权不算本期付款。
- 名称、金额常驻；标题明确主体、期间、单位和口径，来源及限制就近可读，占比标分母。节点颜色固定，经济性质同时用文字区分；悬停高亮只作增强。
- 离线静态图、精确表与来源默认完整；期间选择仅限已取得数据，不用交互隐藏必需期间。单期桑基图不能替代三年及年内连续季度底表；历史结构图标历史和选用原因，并保留最新季度。
- 图表、数字、占比、底表及正文从同源数据生成；HTML为唯一维护的研究正文，不另行生成或同步Markdown机器正文底稿，不指定必须使用某个图形库。
