# 现金流核验输入

JSON 放公司 `factcheck/` 或本次临时核验目录。先从已核数据准备输入，再对照最终 HTML。金额使用同一币种和单位，保留来源精度。表格金额格直接填金额，可使用千位分隔和括号负数。同比、环比和注释放独立列或表旁。

| 字段 | 填写约定 |
|---|---|
| `entity`、`unit` | 主体名、表格和核验输入共用的单位，如 `M美元` |
| `latest_annual`、`latest_period` | 开工时按财报确定的最新完整财年和最新单季或半年，如 `2025`、`2026Q3` |
| `annual_count` | 默认 3，需扩展历史时填写实际年数 |
| `annual`、`interim` | 年度、当年单季或半年分别配置，支持最新财年起前后实际期间 |
| `bridge` | 最近披露现金桥的期间、现金范围、位置及逐项金额 |

`annual` 和 `interim` 都包含以下字段：

- `table` 使用 `{"id":"annual-cash-flow"}` 选择表格。已有报告也可用 `{"heading":"实际标题","header_prefix":["指标"]}` 匹配前置标题和首行前缀，必须匹配唯一表格。
- `rows` 把 `cfo`、`cash_capex`、`fcf` 映射到表格第一列的实际指标名。各表首行由指标列和期间列组成，期间使用 `FY2025`、`2026 Q1` 等写法。
- `source` 填年度或单季的原始披露位置和实际核验数据路径，注明拆季依据。`capex_basis` 填 `cash_paid` 表明原始数据是已付现金。资产新增或承诺不得标为现金支付。
- `values` 按 `2025`、`2026Q1` 等期间放 `{"cfo":10,"cash_capex":15,"fcf":-5}`。公司调整后 FCF 另列，核验输入的 `fcf` 采用同期间 CFO 减现金 CapEx。

`bridge` 包含 `table`、`period`、`cash_scope`、`source` 和 `items`。每个 `items` 元素填写 `role`、`label`、`expected`。使用 `opening`、`cfo`、`investing`、`financing`、`closing`，有汇率或其他披露变动时加入 `fx` 或 `other` 并列入 `required_roles`。来源用途分栏时，`label_column` 填项目名所在的零起始列，下一列应为数值。源报告把用途写作正值时设置 `sign: -1`，`expected` 始终按现金影响带符号填列。一个类别可分多个项目，期初和期末各只列一项。合计行不进入桥计算，避免重复相加。

单格差额按显示精度的一半检查，FCF 和现金桥按公式涉及显示项的舍入上限检查。输入保持相同单位和口径，来源版本差异需要单独核实。脚本输出预期和已通过期间、桥接分类金额、差额、错误及文件哈希，报错时返回非零退出码。
