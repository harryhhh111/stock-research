# HTML 研究报告内部网站接入

维护日期 2026-11-20。hl-trader 读取已审核的同版本快照，沿用现有登录授权，以 iframe 展示登记的原始 HTML。

## 1. 从索引发现报告

从发布根目录读取 [研究流程/index/html-index.json](../index/html-index.json)。字段以 [JSON Schema](../index/html-index.schema.json) 和[命名与索引规范](HTML报告命名与索引规范.md)为准。按 `report_id` 查页面，按 `entity_id` 聚合主体。索引快照同时包含入口、已授权模块和 `assets`。历史 `research.yaml` 仅用于 Markdown 定位及主体关联。

| 列表或状态 | 展示规则 |
|---|---|
| 公司研究 | 登录后筛选已授权的 `company:` 主体及 `draft`、`ready` 报告，排除演示和归档。公司列表打开唯一非归档 `company_research` 首页；模块、专题、更新从页面链接进入。仅有 Markdown 的公司不进入列表，已有 HTML 专题但缺首页的主体可列内部待整理区 |
| 行业研究 | 同一索引中筛选 `topic:industry-` 主体和 ID 以 `-overview` 结尾的非归档首页，其他模块由卡片进入 |
| 交付与验收 | 草稿在列表和阅读页标记。分别显示交付状态、内容核验状态、数据截止和正文记录的缺口。未知日期显示「未记录」 |
| 未发布来源 | `unpublished_links` 记录来源链接和不可访问原因。外层显示提示，或在保留版本的展示副本中禁用相应链接。页面图片、样式和绘图数据仍须登记并可访问 |

快照来自获准 Git 提交或审核过的文件清单。工作树预览使用单独版本并标记 dirty。保留仓库的相对目录结构并核对跨模块、跨公司或行业链接的访问权限；目录与身份从索引解析。

## 2. 后端路由

路径由网站按现有约定命名。建议提供以下能力。

| 能力 | 示例 | 返回 |
|---|---|---|
| 列表 | `GET /api/research-reports` | 授权范围内的主体、报告 ID、标题、类型、日期、状态和版本 |
| 阅读入口 | `GET /api/research-reports/{id}` | 元数据、服务端生成的 `content_url`、`download_url` 及资源缺口 |
| 正文及资源 | `GET /research-content/{snapshot}/{registered_path}` | 同版本的 HTML 或已批准资源。逐请求授权 |
| 下载 | `GET /api/research-reports/{id}/download` | 单文件 HTML 或含获准相对依赖的压缩包，标明附件范围 |

- 发布根目录由部署配置指定。服务端验证规范化路径落在该快照根目录并命中白名单，兼容页通过 `redirects` 关联目标 ID。拒绝越界、外部符号链接、双重编码绕过和任意路径读取。正文、图片、数据与下载执行相同授权。
- 保留入口及资源相对路径，使普通链接和章节锚点原样解析。HTML 按 `text/html; charset=utf-8` 返回源字节，其余资源按 MIME 类型处理。获准的核验脚本仅作文本或下载。无需注入 `<base>`。
- 内容路由先于 SPA 兜底路由。未登记、缺失或无权资源返回对应错误。内部内容默认私有缓存策略，敏感内容用 `private, no-store`。私有缓存按用户和版本隔离，并处理权限撤销。

## 3. 阅读与隔离

- 以带标题的独立 iframe 加载授权 URL，默认 `sandbox=""`、`referrerpolicy="no-referrer"`，报告自行滚动。URL 按路径段编码中文、空格和特殊字符。外层显示报告状态、截止日、版本、缺口、返回与获准下载。
- 优先使用独立内容来源，避免主应用会话 Cookie 覆盖该来源。检验跨来源鉴权。同源托管仅用于明确登记的静态报告。CSP 同时约束 iframe 与直接访问内容 URL，静态模式禁脚本和远程取数，只开放报告所需样式、图和获准资源。
- 内容响应设置 `frame-ancestors` 允许网站来源并启用 `nosniff`，站点 `frame-src` 允许内容来源。检查 X-Frame-Options 与嵌入方式兼容。敏感 URL 不发送到第三方日志。
- 打印、目录高亮或交互图表确需脚本时先审阅，以独立来源和 CSP 哈希或 nonce 控制执行。仅按需授予 `allow-scripts` 或打印所需 `allow-modals`，避免同时授予脚本和同源能力。优先内嵌展示数据；校验 sandbox 对弹窗、下载、脚本和资源读取的限制。

## 4. 联调与验收

1. 用[估值反推演示](../../估值反推Skill/演示报告.html)验证登录后的 UTF-8 正文、精确表、图形、桌面、窄屏和打印。演示标合成数据，与公司列表隔离。
2. 用[微软主报告](../../MSFT/MSFT.html)核对目录锚点、专题、离线可读性、折叠区及静态/增强模式的打印差异。逐项核查 `src`、`href`、CSS 链接、脚本取数和获准证据。发布副本的链接处理保留原因和版本。
3. 验证匿名、未获授权、直接访问正文和附件、异常路径与缺失资源；确认权限及错误响应生效。
4. 从同一快照读取索引及文件，验证切换和回滚后版本一致。分别显示实质更新日、财报/行情截止日及来源版本。
