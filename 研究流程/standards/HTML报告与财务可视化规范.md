# HTML 报告与财务可视化规范

维护日期 2026-11-20。页面结构按[主文档模板](公司研究主文档模板.md)，路径与登记按[命名规范](HTML报告命名与索引规范.md)，内容与期间按[对应模块细则](../../研究方式.md#二报告交付与模块入口)。

## 1. 阅读顺序

- HTML 是唯一维护的报告正文。首页展示判断和模块卡片，模块页有稳定章节锚点和返回链接。卡片可整体点击，桌面、窄屏与键盘顺序一致。
- 顶部明列文档更新日、财报季度或半年及实际期末日，估值另标行情截止日。详细财年、TTM、股本与并表口径放文末，数据表和图旁仍写主体、期间、单位及口径。
- 摘要仅保留影响判断的事实。指标卡显示可比变化、期间、单位及来源，缺失显式标注。

## 2. 精确数据表

- 期间、分表、营收单元格及实绩与指引对照按[财务细则](modules/财务与估值细则.md#表格期间单位与展示约定)。宽表可横向滚动，数据列完整保留。
- 可比数字右对齐、精度一致。金额、股数、EPS、比率用各自单位，利润率变化写百分点，负值或跨零优先比较金额。
- 每个指标或指标组给可定位来源。异常解释、拆季算式和重述口径紧邻表格。零、负数、实际、估计、指引与缺失分别标识。缺失说明原因。
- 必需底表常驻可读，必要折叠内容在打印时展开。

## 3. 按研究问题选图

| 要回答的问题 | 图形及口径 |
|---|---|
| 行业现在在哪一段，谁领先？ | 周期阶段可用示意图标出当前判断及证据日期。供需、价格、库存和份额趋势按口径对齐，区分名义产能、有效产量和出货 |
| 谁付款、怎样交付、哪些资产并表？ | 真实案例与机制示意分开，付款、交付、股权和推断用文字及线型区分。缺金额用等宽示意 |
| 客户、订单和护城河有没有兑现？ | 客户案例矩阵、披露集中度、同口径留存与份额趋势。订单期限标预计，订单桥勾稽新增、确认、取消及汇率 |
| 收入、利润或现金流怎样变化？ | 分组柱状图或折线图，年度和季度分开，金额与利润率分图。CFO、现金 CapEx、FCF 可并列比较，FCF 与前两项有计算关系 |
| 哪些业务贡献收入和增长？ | 同分母构成用堆叠柱，结构变化可用 100% 堆叠柱。量价组合及汇率等用增量瀑布图或发散条，列拆解顺序、交互项和残差，负抵销单列 |
| 钱投到哪，何时回收？ | 现金来源用途按下节。项目用建设、投产、爬坡、交付、收入至收款时间线，区分发生日、公开日和预计窗口 |
| 什么时候还钱，股东份额怎样变化？ | 最新期末债务到期柱图区分债务、租赁及面值/账面值。期初至期末股数桥用实际股数，单列回购、增发和激励影响 |
| 谁控制公司，激励怎样兑现？ | 投票权关系、已披露薪酬权重或事件时间线，区分持股与投票权、处罚发生与计提和付款 |
| 现价要求什么结果，什么会改变判断？ | 情景和敏感性表，可辅以热力图。假设、具体兑现财年、单位、公式和行情日常驻，标【我的推演】。风险与跟踪图使用有证据的触发条件；历史行情注明基准与复权 |

每图回答一个重要问题。已解释清楚的内容用链接定位主图。柱状图金额轴从零开始，保留负值方向。折线非零起点须显式标刻度。避免双轴、3D、截断、面积失真及无依据评分。变化桥保留起终点、增减、残差与公式，柱和标签紧凑可读。并列趋势使用可比较坐标，事件与关联证据分开解释。事实与预测用文字和线型区分，颜色对应的指标保持一致。

## 4. 支出到底流向哪里

### 4.1 先分清三套问题

| 问题 | 数据与表达 |
|---|---|
| 利润如何形成？ | 用收入到成本、毛利、费用和经营利润的图表，说明资本化、折旧与 SBC |
| 本期实际付了什么？ | 同口径列现金 CapEx、净现金并购、投资、分红、回购等，以横向柱状图比较。标题写明覆盖范围 |
| 期初到期末现金为何变化？ | 以现金流量表口径勾稽期初现金＋CFO＋投资净流量＋融资净流量＋汇率及其他＝期末现金，注明现金等价物及受限现金范围 |

收入利润与现金分图。**现金用途图紧接在收入主图之后。** 现金图位于另一模块时，收入主图后紧接现金用途摘要及直达该图和完整现金桥的链接。摘要可列 CFO→现金 CapEx/FCF→分红/回购及差额，注明公式与未计项目。差额与期末余额、净现金变动分别标示。CFO 已含经营现金收付，桥上避免重复扣除工资、研发等付款。父项与子项去重，非现金资产、折旧、SBC、未履行承诺及回购授权与本期现金付款分开。经营付款未拆分时标明缺口，避免拿利润表费用填补。

### 4.2 饼图/环形图的使用门槛

分类须同主体、同期、同币种、同口径、非负且互斥，并覆盖可靠分母。图上给总额、分母名称、各类金额和占比，附精确表。项目多或含负数、净流入、抵销时用横向条图或瀑布图。仅能用可靠总额减同口径已知项复算未拆分余额，注明算式和舍入；总额不可核时只列已知金额。

### 4.3 桑基图优先、瀑布图兜底

收入来源与利润形成、现金来源与用途**分别优先桑基图**。确实受限时用带真实符号的瀑布图。可可靠表达的前段继续画，负利润或负 CFO 先判断能否按经济方向展示。小流量补标签，带宽仍按同图金额统一比例。

- 每条边可追溯或复算，中间节点守恒、起终点与底表勾稽，舍入容差按原始精度解释。残差仅用可靠总额复算，合并项保留明细。
- 图与表统一范围及口径。集团现金、费用和分部归属分别标明，公共节点之后的分流只表达已核实关系。图旁有主体、期间、单位、来源、金额及占比分母。
- 两条链路分别检查替代理由。对应图表旁写明具体受限环节、查过的证据、替代方式、覆盖关系及剩余影响，或链接已绘制的准确位置。仅列构成或数据表须说明仍缺哪段；数据可用却漏画时补图。验收需判断理由和表达是否成立。
- 历史结构图标明期间及选用原因，同时保留最新已披露季度底表。

## 5. 数据、离线与打印

- 图、表、占比和正文数字使用同一份已核数据。源文件放 `factcheck/data/`，保留来源、期间、单位、精度、口径、公式及缺失状态。脚本相对自身位置解析路径，记录可重复更新方式。
- 正文、来源、精确表和静态图支持本地离线及无脚本阅读，交互用于增强。核心内容可直接看见，不依赖悬停、外链字体、CDN 或联网取数。本地用相对资源路径；`file://` 下避免依赖异步读文件。图形有文本摘要或替代说明，交互具备文字图例和键盘支持。
- 打印保留关键列、图、图例、来源和解释，展开所需折叠区并去掉遮挡的导航。交付前按[检查清单](研究更新与交付检查清单.md)验收，生成的截图和打印预览遵循[验收产物目录](2026-10-08-Git管理说明.md#验收产物目录)。改数后联动图表、摘要、模型和跟踪项，复算变化桥并记录检查范围。
