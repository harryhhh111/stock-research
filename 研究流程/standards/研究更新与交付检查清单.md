# 研究更新与交付检查清单

维护日期 2026-11-20。完整研究逐模块验收，分轮和更新覆盖当前问题与联动影响。开工与研究顺序见[研究 SOP](../../研究方式.md)。

## 1. 开工时确认范围

- 记录主体、证券、业务边界、唯一首页、本轮主问题、反证与交付范围。首次一般性研究先选行业问题。确认用户展示要求和需保留的重要解释。
- 核对最新应有披露、已取得文件及期间。获取失败记未完成，公司未披露列已查资料。控制权变化、转型或重大并购追踪资金、权利和每股结果。

## 2. 新财报联动检查

核对首页判断和假设、订单兑现、营收与利润、滚动现金流、期末债务与期后事项、资本配置、股本与估值、跟踪及缺口。核对最新值、指引、来源、日期和入口。历史数保留在明确标注的比较中。每项记录「已更新 / 核查后不受影响 / 未完成 / 不适用」、理由及位置。

### 季度完整性硬检查

逐公司及承担经营跟踪的业务页，在取数前与交付前核对同一矩阵。集团与分部口径分别核对。

| 指标组与主体 | 预期季度 | 实际季度 | 同比/环比基期及来源 | 缺口和结果 |
|---|---|---|---|---|
| 收入、利润及适用的现金流底表 | 按[期间要求](modules/财务与估值细则.md#1-时间长度与可比性)填写 | 逐期记录 | 上年同期、上季及来源 | 分类、影响及通过状态 |

按[财务细则](modules/财务与估值细则.md#四历史财务与指标的最低标准)检查单季与累计勾稽、利润率及拆季依据。关键缺季影响完整交付，记录已查来源及影响。

## 3. 重构的信息保留检查

开工盘点用户追问、异常成因、重要事实、推导和旧锚点。交付记录原位置、新位置和核验结论。数据旁保留直接回答、金额、口径、证据定位。

## 4. 交付验收

- [ ] 使用[命名与索引规范](HTML报告命名与索引规范.md)规定的路径。索引中的路径、状态、截止日、资源和正文哈希与报告一致，报告工具 check 通过。
- [ ] 首页回答主问题并定位证据、反证和未决项。按[模块表](../../研究方式.md#二报告交付与模块入口)和细则验收适用模块，记录证据与缺口。
- [ ] 分轮交付给判断、来源、反证和下一步追问。首页只链接有内容的模块，区分待研究模块和本轮未决项。
- [ ] 首页在桌面、窄屏、键盘导航中均按[模板顺序](公司研究主文档模板.md#唯一主入口)排列。
- [ ] 行业按[行业与竞争](modules/行业与竞争.md)验收边界、可比口径、结论和来源。唯一首页可往返模块，并支持公司提出可核的问题。
- [ ] 行业首轮指出利润变量。周期行业核对周期位置、新需求、有效供给及向公司量价、成本、现金流和估值的传导。
- [ ] 核对年度和近期底表实际覆盖[开工确定的期间](#季度完整性硬检查)，注明例外依据。
- [ ] 按[营收 Skill](../skills/revenue-analysis/SKILL.md)对照覆盖矩阵，核对集团和分部的期间、同比、占比、来源及缺项影响。
- [ ] 完整研究或主报告迁移对最终营收页运行覆盖脚本，记录结果。失败项修复复验，适用例外写明依据和影响。
- [ ] 完整研究、迁移或现金底表更新对最终页面运行[现金流 Skill](../skills/cash-flow-analysis/SKILL.md)复算，核现金 CapEx、期间、现金桥与图表，记录结果及缺口。
- [ ] 按[底表口径](modules/财务与估值细则.md#表格期间单位与展示约定)复核分表、同比与环比基期、季节性及移期解释。
- [ ] 表前单位、B/M换算、特殊量纲、百分比与百分点无歧义。
- [ ] 主动检查越界比率、负成本、高毛利/经营亏损、收入利润背离及利润/CFO/FCF背离；原始主体/单位/期间/重述与拆季已核。
- [ ] 高毛利/经营亏损已有毛利至经营利润费用桥及科目分类解释；主要变化贡献可勾稽，资本化/摊销与现金不重复。
- [ ] 毛利率>100%已算隐含成本；小分母与舍入已量化；冲回、补偿等有原始证据才写成事实。
- [ ] 每项异常就近说明金额、成因证据、现金/税效、持续性及判断影响；可能原因不冒充结论，原因未确认不得标原因核验通过或用于正常化模型。
- [ ] 异常结果有就近解释，重要追问的信息保留映射已验收；发现一项已检查本轮同类异常并联动摘要/模型/跟踪。
- [ ] 核对最新TTM、期末及已付/待付状态；正文、摘要、估值、跟踪和缺口没有互相冲突。
- [ ] 经营与投资收益、税前税后、现金与非现金分清；必要变化桥已复算。
- [ ] 资本配置说明用途、资金来源、股东回报及风险；资产增加/现金付款/承诺不混用。
- [ ] 价格和估值注明真实截止日；历史快照不称当前，无法取得则明确未完成。
- [ ] 当前估值已回答隐含业务/产品预期与具体兑现财年；公开叙事有来源，实绩、指引和研究者反推分开。
- [ ] 核查[估值 Skill](modules/财务与估值细则.md#估值条件反推-skill)适用性。适用且假设确认时复算并与正文核对。待确认或不适用时记录原因、影响和替代分析。
- [ ] 支撑现价的所需收入、增长、利润/FCF及业务驱动已实际反推；输入/公式可追溯，求解变量与固定假设明确，并与现实基数及可核验空间比较。
- [ ] 当前价值与未来业绩桥可复算，折现/回报率、终值、期间现金流、净债务、股数稀释口径一致；没有将未来估值直接当现值，适用时列终值现值占比。
- [ ] 对照延续、兑现、延迟或不及预期及终值敏感性，列年份、每股现值、相对股价差异、预期计入程度和证伪条件。
- [ ] 未将反推当全市场唯一预期、未将残差无依据归给某概念或虚构成功概率；关键模型缺口如实标未通过，并联动摘要、风险与跟踪。
- [ ] 各项缺口分类准确，授权范围内可核验的工作实际完成；关键未完成项不能标整篇完成。
- [ ] B2B 查实名客户案例，列产品、用途、阶段和日期。核对实际客户身份与披露边界。
- [ ] 来源及必要脚本/输入可追溯，链接和入口位置有效。

改数后按影响范围复算并联动结论。

### HTML 与图表交付检查

按[展示规范](HTML报告与财务可视化规范.md)核对实际交付的 HTML。

- [ ] 入口、目录、交叉引用及新旧锚点有效，内容和核验证据可定位。
- [ ] 顶部日期标文档更新、财报实际期末和行情时点，详细口径放文末，必要期间及单位留表图旁。
- [ ] 业务用易懂语言讲清谁付钱、为何买、怎么收费。产品与营收量级就近关联，真实案例有证据。
- [ ] 按[财务细则](modules/财务与估值细则.md#表格期间单位与展示约定)核对实绩、指引及营收底表顺序。
- [ ] 按[收入和现金图位置规则](HTML报告与财务可视化规范.md#41-先分清三套问题)检查相邻展示及链接，复算现金用途与差额。
- [ ] 客户案例、集中度与订单期限位于业务页，自身承诺归现金页，治理有行为证据或缺口。
- [ ] 图表与精确表同源，核对期间、金额、分母、符号、舍入、缺失及更新联动。
- [ ] 按[选图规则](HTML报告与财务可视化规范.md#3-按研究问题选图)核对量纲、坐标、负值和预测标识。
- [ ] 构成图分类互斥，饼图及环形图覆盖可靠分母，各项非负。未披露余额有依据，费用、现金、非现金资产与承诺各按口径。
- [ ] 按[桑基与瀑布规则](HTML报告与财务可视化规范.md#43-桑基图优先瀑布图兜底)验图形选择和资金归属。
- [ ] 两条链路分别按[桑基规则](HTML报告与财务可视化规范.md#43-桑基图优先瀑布图兜底)就地核对原因、替代、覆盖和缺口，已有图时给准确锚点。
- [ ] 核验替代原因是否成立，能表达的链路仍须画。数据足够却漏画时补图后复验。
- [ ] 桑基边按金额定带宽，节点守恒，起终点勾稽，残差和舍入有依据。保留符号及合并项明细。
- [ ] 资金来源用途及瀑布图起点、终点、符号、残差均可勾稽；没有把CFO中已扣的经营支出再扣一次。
- [ ] 新增收入贡献图保留负贡献及净增公式，不混存量；净利润到CFO含负调节项不用饼图，紧凑瀑布图的标签贴近柱形、连接线短且不碰撞，金额比例真实。
- [ ] 实际离线验桌面、窄屏和打印，核心图表无需联网或悬停，必要内容完整，资源路径相对。受阻明确未完成。
- [ ] 交互存在时检查切换/图例/键盘操作和无脚本降级；来源链接与本地资源有效；对比标签、颜色和文本可读。
- [ ] HTML、图表、数据同版本，HTML 为唯一正文。旧 Markdown 入口限制如实记录。

### 全模块选图的补充验收

检查本轮实际采用的图形，其余注明不适用的原因。

- [ ] 每图对应重要研究问题，同一问题未重复堆图；图旁可读精确数据、来源、异常解释及判断边界。
- [ ] 业务图区分付款、交付、股权和推断；真实客户及合作阶段有证据，金额/占比/留存缺失不填零或造数。
- [ ] 增长贡献桥的量价交互、公式、拆解顺序和残差明确；利润到CFO到FCF分别勾稽，非现金经济成本未被忽略。
- [ ] 项目时间线区分已发生/预计，发生日/公开日及阶段清楚；名义产能与有效供给、投入额与产量未混用。
- [ ] 股数桥按实际股数，不以SBC费用代替发行数量；订单桥确认范围、取消/汇率和收入确认口径匹配，期限预测不是实绩。
- [ ] 竞争份额、价格/成本、回报率等可比边界明确；估值反推公式、行情日与假设完整，不把模型情景当共识或预测。
- [ ] 护城河和风险以事实趋势或证据矩阵支撑，不主观打分伪装精度；路径箭头、相关与事件标记不冒充已证实因果。
- [ ] 分别记录财务、来源、结构与视觉验收结果。受阻明确未通过。
