# Git 管理说明

维护日期 2026-11-20。跟踪规则以仓库 [.gitignore](../../.gitignore) 为准。

## 纳入 Git

保留研究 HTML、规则、核验记录、脚本、可复算的小型证据和必要图表或附件。原始证据按用途和大小判断，保留路径、来源、口径和精度。大型行情及派生数组使用独立归档；缓存、虚拟环境、运行数据库和凭据留在本地。不设全局 CSV、JSON、PDF 或 `factcheck/data/` 豁免。

| 常见本地数据 | 保留方式 |
|---|---|
| 数字资产批量行情、标准化分钟数组、请求分页和 ZIP | 原始及清洗数据留本地或独立归档，Git 留获取方法、运行窗口和小型结果 |
| HYPE 逐笔、旧分钟行情、资金费率缓存和净值曲线 | 保留同步脚本、交易明细、汇总和缺口核验。完整复算需要恢复相应输入 |
| 密钥、环境文件与运行缓存 | 由忽略规则排除，示例配置只能含公开占位值 |

## 验收产物目录

浏览器验收截图和打印预览统一写入所属项目的 `factcheck/visual/`。固定使用 `desktop.png`、`mobile.png`、`print.pdf` 等名称，多页验收可用模块名区分。复验覆盖同名产物，验收日期写入记录。Git 忽略整个产物目录。核验脚本与结果记录留在 `factcheck/`，正文依赖的展示资源按报告规范登记。

## 提交与推送

- 提交前审核实际暂存差异、文件大小和凭据，保留并行编辑以及大文件的本地原件。
- 仅推送经审阅的正常分支。Codex 本地检查点可能包含生成数据，应保留在本机，避免镜像推送。单独取得授权后再清理检查点、原始数据或重写历史。
