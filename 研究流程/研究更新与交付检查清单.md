# 研究更新与交付检查清单

维护日期：2026-11-04。本文是[研究方式](../研究方式.md)的执行附件，不另设研究内容标准。[主文档模板](公司研究主文档模板.md)提供结构。完整研究逐项执行，专题/重构限定影响范围并说明；不要求每轮新闻重做全部报告。

## 1. 开工时确认范围

- 是首次完整研究、财报更新、专题追问，还是纯结构调整？本轮允许称为完成的范围是什么？
- 唯一主文档、证券和业务边界是什么？是否存在适用的用户展示偏好？
- 最新应有披露是什么、取得哪些原始文件、日期和报告期是什么？获取失败与未披露分开。
- 用户此前明确追问过哪些重要解释？重构前列出位置及拟迁移位置，不能凭记忆删减。

## 2. 新财报联动检查

每项填写“已更新 / 核查后不受影响 / 未完成 / 不适用”，并给原因和定位。不得为了打勾而假造数据。

| 检查对象 | 至少核对的内容 |
|---|---|
| 摘要、判断、关键假设 | 新证据是否改变支持/反对证据；数据是否仍用旧期 |
| 营收 | 年内单季序列、分部/产品、同比和占比；累计及指引分别展示 |
| 盈利 | 单季同比/环比、最新异常解释、投资及一次性损益、税效 |
| 现金流 | 最新季度/累计与滚动TTM、毛净CapEx、FCF、营运资本和SBC |
| 资产负债及融资 | 最新期末现金/债务/租赁、利息、到期和期后事项；已发生融资不再作为未来事项重复相加 |
| 资本配置 | 最新投入用途、股权投资/并购、分红回购实绩/授权、股数变化、资金缺口 |
| 订单/客户承诺 | 最新RPO/backlog、期限及转收入；历史数不能冒充最新值 |
| 估值 | 股价时段、股本、最新TTM及期末净债务、倍数与情景；注明跨时点限制 |
| 跟踪、风险、缺口 | 观察值和正文一致；已完成事项从“待核验”移除，缺口分类正确 |
| 入口、来源与记录 | research.yaml定位、文件路径、日期、计算证据与更新记录 |

### 季度完整性硬检查

在取数前和交付前使用同一矩阵，逐组记录“指标组及主体口径、预期季度、实际季度、同比/环比基期、来源、缺口类型、结果”。公司主文档与经营类子文档分别验收，子文档就地展示本业务连续季度。经营表拆分或迁移不能以结构整理为由豁免。

- Qn已披露时，Q1至Qn逐季无遗漏；年度、单季、累计、TTM分表。
- 收入/主要分部、利润/利润率、CFO/现金CapEx/FCF逐组核对；SBC等按适用性补充。集团投入不冒充分部投入。
- 同比基期、Q1对上年Q4环比、正负值处理、累计拆季证据与EPS不得差分均核实。
- 单季之和与H1/9M/全年相勾稽，利润率重新计算；来源重述差异需解释。
- 未通过项如实分类；关键季度缺失不标完整交付。用户审阅前由研究者完成，不把重复验收负担交给用户。

## 3. 重构的信息保留检查

| 必须保留的内容 | 原位置 | 新位置 | 数据旁解释/交叉定位 | 验收 |
|---|---|---|---|---|
| 用户明确追问、重要异常解释、关键证据及推导 | 开工时填 | 完成后填 | 读者能否直接找到 | 通过/未通过 |

重复内容可以合并，但关键事实、机制、金额、税前税后及证据不能在压缩中丢失。不要把重要解释搬到远处只留“见后文”，数据旁至少保留直接回答与明确章节定位。

## 4. 交付验收

- [ ] 结构符合十一项模板，业务拆分不替代研究模块；摘要前置。
- [ ] 三完整财年齐备；当年已披露单季序列完整或例外有解释。
- [ ] 年度、单季、累计、TTM分表；同比/环比基期正确；季节性与移期解释明确。
- [ ] 表前单位、B/M换算、特殊量纲、百分比与百分点无歧义。
- [ ] 主动检查越界比率、负成本、高毛利/经营亏损、收入利润背离及利润/CFO/FCF背离；原始主体/单位/期间/重述与拆季已核。
- [ ] 高毛利/经营亏损已有毛利至经营利润费用桥及科目分类解释；主要变化贡献可勾稽，资本化/摊销与现金不重复。
- [ ] 毛利率>100%已算隐含成本；小分母与舍入已量化；冲回、补偿等有原始证据才写成事实。
- [ ] 每项异常就近说明金额、成因证据、现金/税效、持续性及判断影响；可能原因不冒充结论，原因未确认不得标原因核验通过或用于正常化模型。
- [ ] 异常结果有就近解释，重要追问的信息保留映射已验收；发现一项已检查本轮同类异常并联动摘要/模型/跟踪。
- [ ] 核对最新TTM、期末及已付/待付状态；正文、摘要、估值、跟踪和缺口没有互相冲突。
- [ ] 经营与投资收益、税前税后、现金与非现金分清；必要变化桥已复算。
- [ ] 资本配置说明用途、资金来源、股东回报及风险；资产增加/现金付款/承诺不混用。
- [ ] 价格和估值注明真实截止日；历史快照不称当前，无法取得则明确未完成。
- [ ] 各项缺口分类准确，授权范围内可核验的工作实际完成；关键未完成项不能标整篇完成。
- [ ] B2B客户已查公开实名案例并列产品/用途、阶段与证据日期；匿名大客户不猜名，客户/投资者/伙伴/终端用户分开；未披露金额不被当作省略身份的理由。
- [ ] 来源及必要脚本/输入可追溯，链接和入口位置有效。

按本轮范围进行计算勾稽：分部/产品加总、单季/累计对账、TTM滚动、利润/现金桥、债务及承诺去重。改数后重算相关结论；纯排版改动不必重复无关计算。Markdown标题、链接与入口校验只验结构，不能代替阅读和事实核验。
