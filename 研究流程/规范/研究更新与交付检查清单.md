# 研究更新与交付检查清单

维护日期：2026-11-17。本文是[研究方式](../../研究方式.md)的执行附件，不另设研究内容标准。[主文档模板](公司研究主文档模板.md)提供结构。完整研究逐项执行，专题/重构限定影响范围并说明；不要求每轮新闻重做全部报告。

## 1. 开工时确认范围

- 是首次完整研究、财报更新、专题追问，还是纯结构调整？本轮允许称为完成的范围是什么？
- 唯一主文档、证券和业务边界是什么？是否存在适用的用户展示偏好？
- 最新应有披露是什么、取得哪些原始文件、日期和报告期是什么？获取失败与未披露分开。
- 用户此前明确追问过哪些重要解释？重构前列出位置及拟迁移位置，不能凭记忆删减。

## 2. 新财报联动检查

每项填写“已更新 / 核查后不受影响 / 未完成 / 不适用”，并给原因和定位。不得为了打勾而假造数据。

| 检查对象 | 至少核对的内容 |
|---|---|
| 摘要、判断、关键假设 | 新证据是否改变支持/反对证据；数据是否仍用旧期 |
| 营收 | 年内单季序列、分部/产品、同比和占比；累计及指引分别展示 |
| 盈利 | 单季同比/环比、最新异常解释、投资及一次性损益、税效 |
| 现金流 | 最新季度/累计与滚动TTM、毛净CapEx、FCF、营运资本和SBC |
| 资产负债及融资 | 最新期末现金/债务/租赁、利息、到期和期后事项；已发生融资不再作为未来事项重复相加 |
| 资本配置 | 最新投入用途、股权投资/并购、分红回购实绩/授权、股数变化、资金缺口 |
| 订单/客户承诺 | 最新RPO/backlog、期限及转收入；历史数不能冒充最新值 |
| 估值 | 股价时段、股本、最新TTM及期末净债务、倍数与情景；注明跨时点限制 |
| 跟踪、风险、缺口 | 观察值和正文一致；已完成事项从“待核验”移除，缺口分类正确 |
| 入口、来源与记录 | research.yaml定位、文件路径、日期、计算证据与更新记录 |

### 季度完整性硬检查

在取数前和交付前使用同一矩阵，逐组记录“指标组及主体口径、预期季度、实际季度、同比/环比基期、来源、缺口类型、结果”。公司主文档与经营类子文档分别验收，子文档就地展示本业务连续季度。经营表拆分或迁移不能以结构整理为由豁免。

- Qn已披露时，Q1至Qn逐季无遗漏；年度、单季、累计、TTM分表。
- 收入/主要分部、利润/利润率、CFO/现金CapEx/FCF逐组核对；SBC等按适用性补充。集团投入不冒充分部投入。
- 同比基期、Q1对上年Q4环比、正负值处理、累计拆季证据与EPS不得差分均核实。
- 单季之和与H1/9M/全年相勾稽，利润率重新计算；来源重述差异需解释。
- 未通过项如实分类；关键季度缺失不标完整交付。用户审阅前由研究者完成，不把重复验收负担交给用户。

## 3. 重构的信息保留检查

| 必须保留的内容 | 原位置 | 新位置 | 数据旁解释/交叉定位 | 验收 |
|---|---|---|---|---|
| 用户明确追问、重要异常解释、关键证据及推导 | 开工时填 | 完成后填 | 读者能否直接找到 | 通过/未通过 |

重复内容可以合并，但关键事实、机制、金额、税前税后及证据不能在压缩中丢失。不要把重要解释搬到远处只留“见后文”，数据旁至少保留直接回答与明确章节定位。

## 4. 交付验收

- [ ] 按 [命名与索引规范](HTML报告命名与索引规范.md) 使用标准路径或已登记legacy入口；唯一索引中的路径、状态、截止日、资源及正文哈希与本次报告一致，报告工具check通过，未登记/过时兼容项已处理。

- [ ] 结构按九个阅读章节组织，十一项研究问题覆盖可定位；业务/营收连续，资本分配归第2/3节，订单与客户同章，核心矛盾前置，治理文化独立。
- [ ] 三完整财年齐备；当年已披露单季序列完整或例外有解释。
- [ ] 年度、单季、累计、TTM分表；同比/环比基期正确；季节性与移期解释明确。
- [ ] 表前单位、B/M换算、特殊量纲、百分比与百分点无歧义。
- [ ] 主动检查越界比率、负成本、高毛利/经营亏损、收入利润背离及利润/CFO/FCF背离；原始主体/单位/期间/重述与拆季已核。
- [ ] 高毛利/经营亏损已有毛利至经营利润费用桥及科目分类解释；主要变化贡献可勾稽，资本化/摊销与现金不重复。
- [ ] 毛利率>100%已算隐含成本；小分母与舍入已量化；冲回、补偿等有原始证据才写成事实。
- [ ] 每项异常就近说明金额、成因证据、现金/税效、持续性及判断影响；可能原因不冒充结论，原因未确认不得标原因核验通过或用于正常化模型。
- [ ] 异常结果有就近解释，重要追问的信息保留映射已验收；发现一项已检查本轮同类异常并联动摘要/模型/跟踪。
- [ ] 核对最新TTM、期末及已付/待付状态；正文、摘要、估值、跟踪和缺口没有互相冲突。
- [ ] 经营与投资收益、税前税后、现金与非现金分清；必要变化桥已复算。
- [ ] 资本配置说明用途、资金来源、股东回报及风险；资产增加/现金付款/承诺不混用。
- [ ] 价格和估值注明真实截止日；历史快照不称当前，无法取得则明确未完成。
- [ ] 当前估值已回答隐含业务/产品预期与具体兑现财年；公开叙事有来源，实绩、指引和研究者反推分开。
- [ ] 支撑现价的所需收入、增长、利润/FCF及业务驱动已实际反推；输入/公式可追溯，求解变量与固定假设明确，并与现实基数及可核验空间比较。
- [ ] 当前价值与未来业绩桥可复算，折现/回报率、终值、期间现金流、净债务、股数稀释口径一致；没有将未来估值直接当现值，适用时列终值现值占比。
- [ ] 已比较既有业务延续、新业务兑现、延迟/不及预期路径及终值倍数敏感性；各情景列具体年份、现值/每股价值及相对现价差异，说明预期已计入程度和超预期/证伪条件。
- [ ] 未将反推当全市场唯一预期、未将残差无依据归给某概念或虚构成功概率；关键模型缺口如实标未通过，并联动摘要、风险与跟踪。
- [ ] 各项缺口分类准确，授权范围内可核验的工作实际完成；关键未完成项不能标整篇完成。
- [ ] B2B客户已查公开实名案例并列产品/用途、阶段与证据日期；匿名大客户不猜名，客户/投资者/伙伴/终端用户分开；未披露金额不被当作省略身份的理由。
- [ ] 来源及必要脚本/输入可追溯，链接和入口位置有效。

按本轮范围进行计算勾稽：分部/产品加总、单季/累计对账、TTM滚动、利润/现金桥、债务及承诺去重。改数后重算相关结论；纯排版改动不必重复无关计算。Markdown标题、链接与入口校验只验结构，不能代替阅读和事实核验。

### HTML 与图表交付检查

按 [HTML 展示规范](HTML报告与财务可视化规范.md) 执行；后续局部更新同样交付对应范围的 HTML；历史 Markdown 停更保留，不要求全篇迁移。

- [ ] HTML 阅读入口、目录与章节锚点有效；十一项内容、重要解释、来源与核验记录完整；合并后旧锚点有效且编号/交叉引用同步。
- [ ] 副标题下标签明确文档更新日、最新财报季度/半年和实际截止日，行情另标真实时点；冗长期间/口径与引用移到文末，表图旁仍有必要期间和单位。
- [ ] 业务用初中生能理解的语言说明谁付钱、为何买、怎么收费，重要产品与营收量级相邻，机制例子不冒充真实案例。
- [ ] 最新实绩/指引在营收章节前部表图中分列，预测期间/发布日/区间/同比及汇率边界清楚；中点标复算，不冒充精确指引；未省略三年或年内季度。
- [ ] 收入主图后紧接独立现金用途图；CFO、现金CapEx、FCF、分红/回购与差额勾稽，残差非期末现金，包含范围/未计项目及完整现金桥链接明确；不造业务资金归属。
- [ ] 客户案例、集中度与订单/RPO及期限同章；订单不是当期收入或现金，自身采购/租赁付款承诺另归资本分配；治理与文化有可核验行为证据或明确缺口。
- [ ] 表格与图表来自同一已核验数据；逐项核对系列、期间、金额、占比、分母、符号、舍入和缺失状态；最新更新已联动所有图表。
- [ ] 年度/单季/累计/TTM分开；金额/比率/百分点分清；柱状图零基线、负值和预测标识正确，无误导双轴或3D。
- [ ] 构成图类别互斥；饼图/环形图非负且覆盖完整分母，单期结构可用单根100%堆叠条；未披露余额不猜测，研发费用/现金CapEx/资产新增/承诺不混加。
- [ ] 来源与分配优先桑基图；无法可靠表达时瀑布图兜底并说明原因。收入/费用与现金分图，没有猜测产品级资金或费用分摊。
- [ ] 收入/利润、现金两条链路分别核对：未采用桑基图（含仅放构成图/表格或完全不配图）时，已在对应位置说明具体受限环节、证据、替代方式、覆盖关系和剩余缺口/影响；其他章节已有图则给准确锚点。不能只在聊天或文末概括解释。
- [ ] 未画桑基图的理由已实质核验：负净利润、负CFO或“结构复杂”不自动豁免可表达的前段/其他环节；构成图没有冒充利润或资金流向。数据足够却遗漏绘图须补图，未说明或理由不成立则该项不通过，不能以文字说明存在或算术/视觉检查通过代替。
- [ ] 桑基边与底表同源、带宽同比例、中间节点守恒，合并小类有明细、残差及舍入有依据；负值/抵销/净流入未绝对化。数据不足不伪造完整终点。
- [ ] 资金来源用途及瀑布图起点、终点、符号、残差均可勾稽；没有把CFO中已扣的经营支出再扣一次。
- [ ] 新增收入贡献图保留负贡献及净增公式，不混存量；净利润到CFO含负调节项不用饼图，紧凑瀑布图的标签贴近柱形、连接线短且不碰撞，金额比例真实。
- [ ] 本地离线打开并视觉检查桌面、窄屏和打印；受阻则标明未完成，不以用户认可单张图代替全部验收；正文、表格、核心图表不依赖网络及悬停，打印不截断关键数据；无本机绝对路径。
- [ ] 交互存在时检查切换/图例/键盘操作和无脚本降级；来源链接与本地资源有效；对比标签、颜色和文本可读。
- [ ] HTML/图表/数据版本一致；未新建或同步更新 Markdown 报告及机器正文底稿，历史入口停更及 HTML 未接入限制如实记录；结构校验与财务内容验收分别说明。

### 全模块选图的补充验收

按本轮实际使用的图形逐项检查；未使用者标不适用及原因，不为打勾强制配图。

- [ ] 每图对应重要研究问题，同一问题未重复堆图；图旁有精确表、来源、异常解释及判断边界，三年和完整年内季度不被交互替代。
- [ ] 业务图区分付款、交付、股权和推断；真实客户及合作阶段有证据，金额/占比/留存缺失不填零或造数。
- [ ] 增长贡献桥的量价交互、公式、拆解顺序和残差明确；利润到CFO到FCF分别勾稽，非现金经济成本未被忽略。
- [ ] 项目时间线区分已发生/预计，发生日/公开日及阶段清楚；名义产能与有效供给、投入额与产量未混用。
- [ ] 股数桥按实际股数，不以SBC费用代替发行数量；订单桥确认范围、取消/汇率和收入确认口径匹配，期限预测不是实绩。
- [ ] 竞争份额、价格/成本、回报率等可比边界明确；估值反推公式、行情日与假设完整，不把模型情景当共识或预测。
- [ ] 护城河和风险以事实趋势或证据矩阵支撑，不主观打分伪装精度；路径箭头、相关与事件标记不冒充已证实因果。
- [ ] 财务计算、来源核验、链接结构与桌面/窄屏/打印视觉检查分开记录；受阻项目如实标未通过，不把用户认可单图当作全部验收。
