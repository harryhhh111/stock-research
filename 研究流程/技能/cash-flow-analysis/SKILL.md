# 现金流与资本开支

从研究仓库根目录读取《研究方式》第四节及资本分配相关要求，按报告索引定位公司唯一 HTML 主报告。开工确定用户要求的研究范围和最新披露期间。完整研究与主报告迁移沿用最近三完整财年和本财年全部已披露单季的范围。

1. **核原表和口径。** 以公司现金流量表及附注核对 CFO、购建资产的现金支付、期初期末现金和分类净流量。拆季保留原累计数、差分和精度。对资产新增、租赁和采购承诺另行分类。若现金含受限现金，期初、期末和净变动使用同一范围。
2. **写回主报告。** 年度和单季分别列 CFO、现金 CapEx 和 FCF，现金支出用正数，FCF 按 CFO 减现金 CapEx 复算。公司调整后 FCF 单列口径和差额。以最近披露且同口径的期间建立现金桥，列期初、经营/投资/融资变动、适用的汇率及其他项目、期末。可用来源与用途分栏表示同一组变动。
3. **检查最终 HTML。** 根据 [核验输入约定](references/input.md) 用已核资料准备 JSON。完整研究与主报告迁移，及改动这些底表的更新，交付前运行 `scripts/check_cash_flow.py <主报告.html> --input <核验输入.json>`。程序对照集团期间、金额、FCF 公式和现金桥，输出版本哈希、差额与缺项。修正后按同一范围重跑。确有不可比、未披露或获取受阻的，保留缺项和来源限制。
4. **验收证据和联动。** 核对脚本输入确实来自原表现金支付栏，说明现金桥边界和现金变化原因。比对同源图表的数值以及摘要、风险、估值和跟踪指标。记录来源、脚本结果、图表核对及未通过项，沿用主报告核验区。脚本能发现标明的口径错误和金额差异，具体资产是否已付款须回到披露核实。

本 Skill 的输入和输出范围限于上述现金流检查。完整资本配置、利润异常、债务和稀释按 SOP 相应章节继续验收。
