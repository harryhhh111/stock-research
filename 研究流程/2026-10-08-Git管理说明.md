## 适合纳入版本管理的内容

| 类型 | 例子 | 保留理由 |
|---|---|---|
| 正文与规范 | 公司主文档、专题、术语、研究方式、AGENTS、研究流程分析 | 核心研究资产，适合版本比较与网站索引 |
| 计算与下载脚本 | factcheck/*.py、数字资产行情同步脚本 | 记录获取方法、假设和复算逻辑 |
| 小型原始证据 | BURRY 的价格 CSV、ORCL/Nebius 财报 HTM/JSON、腾讯年报 PDF | 支持原文追溯和复算，不笼统忽略全部 data/CSV/JSON/PDF |
| 小型结果与清单 | HYPE 的交易明细、汇总结果、数字资产 runs/ 与核对 JSON | 保存结论依据、窗口、参数、数据覆盖与缺口 |
| 必要图表及附件 | 报告引用的 PNG、PDF、XLSX | 使文档完整可读；有引用的附件不只因能重新生成就一概排除 |

当前保留的候选文件约 543 个、69.13 MiB（新增本说明前的工作树快照，不含参考嵌套仓库和 `.git`），不代表已暂存或已提交。最大候选文件为约 6.56 MiB 的 ORCL 年报 HTM，没有超过 100 MiB 的候选文件。

不因本次修订删除旧附件或历史版本。后续新建附件应按日期/主题命名，避免无用途的重复下载。
