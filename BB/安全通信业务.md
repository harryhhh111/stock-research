# 安全通信业务（Secure Communications）研究笔记

> 合并自：安全通信业务.md（业务介绍）、安全通信业务怎么收钱.md（商业模式）、安全通信业务营收.md（5年营收分析）。
> 金额单位：美元。财年于 2 月底结束。

## 1. 业务是什么

出售Cylance终端安全业务后，黑莓的"安全通信"业务已全面聚焦于一个高价值、高壁垒的赛道：**为全球政府、军队和关键基础设施提供"主权级"的安全通信与危机管理解决方案**。

### 🎯 市场定位：为什么需要"主权级"安全？

黑莓安全通信业务的核心逻辑，建立在政府和军队对**通信主权**的刚性需求之上。

*   **痛点**：普通加密应用（如WhatsApp、Signal）在国家级威胁面前存在两大软肋：一是元数据（谁、何时、何地与谁通信）易被获取；二是其商业属性可能导致数据被第三方利用。
*   **方案**：黑莓提供一套**独立于电信运营商或卫星网络之上的加密层**。其对通信数据进行**容器化隔离**，并严格管控元数据和验证身份，确保通信的机密性、完整性和主权。

### 🛡️ 核心产品矩阵

安全通信业务由三大核心产品构成：

*   **BlackBerry SecuSUITE**：**军事级加密通信**的核心。提供防窃听、防身份伪造的安全语音、消息和文件共享服务，覆盖手机、笔记本等全平台。它拥有**北约（NATO）机密级**、**德国BSI**及**美国NIAP**等全球顶级安全认证。
*   **BlackBerry AtHoc**：**关键事件管理与危机沟通**平台。用于在自然灾害、网络攻击等紧急情况下，进行安全通知、人员问责和多部门协同响应。
*   **BlackBerry UEM**：**统一终端管理**平台。对所有接入政府网络的设备进行统一的安全策略管理。

### 🌍 客户版图与市场地位

其客户均为对安全要求最高的机构，市场地位极其稳固：

*   **政府与军队**：客户包括**所有七国集团（G7）政府**、**20国集团（G20）中18个成员国**政府。其AtHoc平台被**80%的美国联邦政府机构**采用。
*   **关键基础设施**：服务对象包括执法部门、应急服务等，以及**全球前十大银行中的8家**。
*   **重大国际活动**：其系统被用于保障**东盟峰会**等全球重大活动的通信安全。

### 🚀 增长战略：三大前瞻布局

1.  **拥抱后量子密码学（PQC）**：黑莓承诺在**一年内将全线产品升级为量子安全架构**，以应对未来量子计算机对现有加密体系的威胁。
2.  **深耕亚太市场**：自2023年底与**马来西亚政府**签约后，黑莓将亚太总部迁至当地，并设立**网络安全卓越中心**，已为东盟各国培训**超9000名**专业人员。
3.  **拓展产品平台**：将**SecuSUITE扩展至Windows设备**，并升级AtHoc平台功能。

## 2. 商业模式：怎么收钱

黑莓安全通信业务的赚钱模式，与QNX的"按量收费"截然不同。它的核心是 **"企业级订阅制"**，即为政府等机构提供标准化软件平台的年度或多年期使用权，从而获得**年度经常性收入（ARR）**。

具体到各个核心产品，收费方式略有不同：

### 🔐 SecuSUITE：按"用户席位"订阅 + 政府大单

*   **模式**：主要为**按用户数量**收取年度订阅费。这是一种**"销售主导"**的商业模式，没有公开定价，需直接联系黑莓销售获取报价。
*   **逻辑**：客户为每个需要加密通信的员工（如政府官员）购买一个"席位"。
*   **特点**：政府大单的软件 license 常在签约时点**一次性确认收入**（见第 3 节），因此这块收入波动性明显大于标准 SaaS。

### 📱 UEM（统一终端管理）：按"设备"订阅

*   **模式**：通常也按**管理的设备数量**收取订阅费。
*   **逻辑**：客户为每一台接入政府网络的手机、电脑等设备支付管理费。

### 🚨 AtHoc（危机管理）：灵活的混合订阅

*   **模式**：更灵活，可能结合了**固定平台费**和**按用户数的可变费**。同样是**销售主导**模式。
*   **逻辑**：客户支付平台基本费，再根据需要使用系统的员工数量支付额外费用。

### 💰 模式的财务特征

*   **高比例经常性收入**：ARR 稳定在 **2.2亿美元** 左右（FY27 Q1 为 $220M），构成收入基本盘。
*   **高毛利**：调整后毛利率约 **72%**。
*   **客户粘性指标要客观看**：DBNRR（美元净留存率）为 **92%**——注意，**低于 100% 意味着老客户年消费在缩水约 8%**（UEM 流失拖累所致，见第 3 节），而不是"客户越买越多"。这是评估这块业务时必须盯住的指标。

## 3. 营收情况

先把口径问题讲清楚：**真正按今天的 Secure Communications（UEM + SecuSUITE/Secusmart + AtHoc）口径重列的数据，公司只追溯到了 FY2023。** FY2022 披露的是整个 Cybersecurity 分部（含后来卖掉的 Cylance），不能直接比较。BlackBerry 出售 Cylance 后将其列为 discontinued operations，并将剩余三项业务重新定义为 Secure Communications。([FY2026 10-K][1])

### 五年营收序列

| 财年        | Secure Communications 营收 |         同比 |
| --------- | -----------------------: | ---------: |
| FY2022    |               **$477M*** |        不可比 |
| FY2023    |              **$288.2M** |          — |
| FY2024    |              **$283.8M** |      -1.5% |
| FY2025    |              **$272.6M** |      -3.9% |
| FY2026    |              **$258.9M** |      -5.0% |
| FY2027 Q1 |               **$73.6M** | **+23.7%** |

\* FY2022 的 $477M 是当年 **Cybersecurity** 总营收（含 Cylance），不能视为今天 SC 口径的数字。([FY2022 10-K][2])

真正同口径的数据是 **FY2023 $288.2M → FY2026 $258.9M**：过去三年**连续下滑**，累计下降约 **10%**，年化约 **-3.5%**。([FY2025 10-K][3])

### 为什么一直下降？拆开看是三个性质不同的业务

FY2025（$283.8M → $272.6M，-$11.2M）：([FY2025 10-K][3])

* 马来西亚政府长期合同前期确认收入减少 **$34.9M**
* **UEM -$19.1M**
* Secusmart / SecuSUITE **+$32.1M**
* Professional Services **+$7.9M**
* AtHoc **+$2.7M**

FY2026（$272.6M → $258.9M，-$13.7M）：([FY2026 10-K][1])

* Secusmart / SecuSUITE **-$11.8M**
* UEM **-$5.2M**
* AtHoc **+$3.5M**

结论：当年的下降有很大一部分是**政府大合同收入确认时点**造成的，但 UEM 本身也确实在持续衰退。三个子业务的真实面目：

*   **UEM：慢慢萎缩**
*   **SecuSUITE：政府大客户为主，订单质量不错，但季度/年度收入非常波动**
*   **AtHoc：相对稳定的小规模增长业务**

### 关键现象：收入下降，ARR 却在增长

*   FY2024 Q4：**$202M**
*   FY2025 Q4：**$208M**（[FY2025 10-K][3]）
*   FY2026 Q4：**$218M**（[FY2026 10-K][1]）
*   FY2027 Q1：**$220M**（[FY2027 Q1 财报][4]）

> Revenue：**$288M → $259M，下降**；ARR：**$202M → $218M，增长**

这并不矛盾。主要原因是 SecuSUITE 里不少政府合同和软件 license 是**某时点一次确认收入**，不是标准 SaaS 那样每年均匀确认。某一年拿到一笔马来西亚政府合同，收入可能突然多几千万；下一年即使客户还在，收入也会明显回落。**所以这块业务不能只看 Revenue。**

### 最新季度 +24% 怎么解读？

FY27 Q1：收入 **$59.5M → $73.6M（+23.7%）**，分部 EBITDA **$9.6M → $20.2M（+110%）**，确实是非常好的季度。([FY2027 Q1 财报][4])

但同期 ARR 仅从 $209M 增至 $220M（约 +5%），DBNRR 持平于 92%。所以：

> **+24% 不能理解成整个 SC 经常性业务突然进入 24% 增长。** 它仍然受 SecuSUITE 政府大单和收入确认时点影响。

公司 FY2027 全年 SC 指引 **$270–280M**，相比 FY2026 的 $258.9M 约 **+4%～+8%**（若达成将是六年来首次全年增长），而不是 +24%。([FY2027 Q1 财报][4])

### 与 QNX 对比：增长资产 vs 现金流资产

|              | QNX           | Secure Communications |
| ------------ | ------------- | --------------------- |
| FY23–FY26 营收 | **持续增长**      | **持续下降**              |
| 当前增长动力       | royalty + 新项目 | SecuSUITE 政府项目         |
| 老客户趋势        | 较健康           | **UEM 有流失**（DBNRR 92%） |
| 收入可预测性       | 较高            | SecuSUITE 大单导致波动       |
| FY27 指引      | **+10%～16%**  | **+4%～8%**            |

**QNX 是 BlackBerry 的增长资产，Secure Communications 更像现金流资产**——五年营收数据已经把这一点显示得比较清楚。

## 4. 后续研究方向

最值得继续拆的是 **UEM、SecuSUITE、AtHoc 到底各自有多大**。现在整个 SC 的表面数字掩盖了一个事实：**UEM 很可能仍在萎缩，而 SecuSUITE 正在把这个下降补回来。** 这决定了这块业务究竟应该给"衰退软件业务"的估值，还是"稳定政府安全业务"的估值。
