# QNX 业务研究笔记

> 合并自：QNX.md（业务介绍）、QNX 怎么收钱.md（商业模式）、QNX 的营收情况.md（5年营收与客户深度分析）、QNX 与汽车行业.md（汽车业务占比）。
> 金额单位：美元。财年于 2 月底结束。

## 1. QNX 是什么

QNX是黑莓公司旗下的一款**硬实时操作系统（RTOS）**，它诞生于1980年，至今已有超过45年的发展历史。你可以把它看作是专门为那些"不容许出错"的高端设备打造的"**数字神经系统**"。

### 📜 发展历程：从"手机配件"到"汽车大脑"

QNX最初的设想并非为汽车服务，而是为更广泛的嵌入式市场而生。它的关键历程如下：

*   **1980年**：诞生于加拿大，最初名为QUNIX（意为"快速UNIX"）。
*   **2004年**：被音响巨头哈曼国际（Harman）收购。
*   **2010年**：被正处转型期的黑莓以**2亿美元**收购。虽然黑莓曾想用它重振手机业务未果，但却为日后转型埋下了伏笔。
*   **现在**：QNX已成为黑莓最核心的业务。2025年初，黑莓更是将原"物联网（IoT）"部门直接更名为**QNX**，以凸显其核心地位。

### ⚙️ 核心技术：为何QNX如此可靠？

QNX强大的秘密，主要在于它与众不同的**微内核（Microkernel）架构**。

为了帮你更直观地理解，可以将它和主流的**宏内核（Monolithic Kernel）** 做个对比：

| 特性 | **宏内核（如Linux）** | **微内核（如QNX）** |
| :--- | :--- | :--- |
| **核心思想** | **大管家**：内核庞大，包含几乎所有服务。 | **小核心+专业团队**：内核极小（仅负责基础调度），其他服务是独立的外部进程。 |
| **稳定性** | **牵一发而动全身**：一个驱动崩溃，可能导致整个系统蓝屏或死机。 | **故障隔离**：一个部件（如音乐播放器）崩溃，可以**自动重启**，完全不影响核心系统（如刹车）。 |
| **实时性** | 非原生RTOS，需打补丁，响应时间存在不确定性。 | **硬实时（Hard Real-time）**：原生设计，任务响应时间**确定、可预测、极低延迟**。 |
| **可扩展性** | 修改和增减功能相对困难，常需重新编译内核。 | **模块化**：可按需灵活增删功能模块，轻松适配从2核到64核的各种芯片。 |

简单来说，QNX的**微内核**就像是只负责指挥调度的"总指挥部"，而**文件系统、网络协议、硬件驱动**等所有其他服务，都是独立在外、各司其职的"专业团队"。即便某个"团队"出问题，"总指挥部"和其他团队依然能稳定运行。

### 🎯 主要应用：它藏在我们身边的哪里？

凭借其高可靠性和实时性，QNX被广泛应用于对安全要求极高的领域：

*   **智能汽车（核心市场）**：它是**全球超过2.75亿辆汽车**的软件基石（FY2026 10-K 口径），被广泛应用于：
    *   **数字仪表盘**：确保车速、电量等关键信息稳定显示。
    *   **高级驾驶辅助系统（ADAS）**：处理摄像头、雷达等传感器数据，支持自动紧急刹车等功能。
    *   **信息娱乐系统**：管理中控大屏，并将不安全的娱乐系统与安全的驾驶系统隔离。
    *   其客户几乎囊括所有主流车企，如宝马、奔驰、大众、丰田、本田等。
*   **工业与机器人**：用于工业控制系统和机器人，确保生产线的精准与安全。
*   **医疗设备**：被**强生**等公司用于新型AI心脏泵等关键医疗设备。
*   **航空航天与国防**：用于航空电子、无人机控制等系统。

此外，QNX还提供**QNX Hypervisor**（虚拟机）技术，允许在同一个芯片上**同时、安全地运行QNX、Linux和Android**等多个系统。

### 🚀 最新进展：拥抱AI与未来

QNX并没有停下脚步，正积极布局未来：

*   **发布全新版本**：推出了新一代**QNX软件开发平台8.0（SDP 8.0）**，性能大幅提升，能更好地发挥从2核到64核等各种芯片的性能。
*   **拥抱AI**：扩大与**英伟达（NVIDIA）** 的合作，将其系统集成到NVIDIA的IGX Thor平台上，为下一代边缘AI和自动驾驶系统提供安全可靠的软件基础。
*   **深耕中国市场**：与**零跑、地平线、芯驰科技**等众多中国车企和科技公司建立了广泛合作。

## 2. 商业模式：QNX 怎么收钱

QNX的核心商业模式就是**收取授权费**，但它的收费方式并非简单的一次性买卖，而是一个精心设计的、能带来持续性收入的**"两步走"模式**。

简单来说，QNX的收费可以分为**研发阶段**和**量产阶段**两个部分。

### 💰 第一步：研发阶段（Development Licensing）

在汽车或设备研发阶段，厂商需要向黑莓支付一笔**一次性的开发授权费**。

*   **目的**：这笔费用让客户获得**QNX软件开发平台**的使用权，以便在其硬件上进行系统开发、测试和优化。
*   **意义**：这是QNX收入的**早期信号**。因为开发授权通常在车型投产**数年前**就已售出，所以它的增长预示着未来会有更多的量产项目，是衡量未来"版税"收入的**关键前瞻指标**。例如，在最近一个季度，QNX的开发授权收入就达到了**八个季度以来的最高水平**。

### 📈 第二步：量产阶段（Production Royalties）

当搭载QNX系统的汽车或设备开始大规模量产后，真正的"印钞机"模式才启动。黑莓会按照**每卖出一台设备（每辆车）** 收取一笔**版税（Royalty）**。

*   **模式**：这是一种**长尾的、按单位计量的持续性收入**。只要车辆在销售，这笔收入就会持续产生。
*   **关键指标**：这引出了QNX业务最核心的两个概念：
    *   **Design Wins（设计订单）**：指汽车厂商决定在下一代车型中使用QNX的协议。每一个"设计订单"都可能转化为未来数年的版税收入流。
    *   **Royalty Backlog（版税积压订单）**：指所有已签约"设计订单"在未来预期产生的版税收入总和。这是衡量QNX未来收入的**关键指标**。

## 3. 营收情况（最近 5 年）

先把一个口径问题讲清楚：**BlackBerry 现在披露的"QNX segment revenue"并不等于纯 QNX OS 收入**。FY2026 的 QNX 分部包含 **QNX 软件 + BlackBerry Radar + Certicom + 其他 QNX 应用**；FY2022–FY2023 当时叫 IoT segment，范围非常接近，但还包括 IVY。因此我们能得到的是一条高度可比的"QNX/原 IoT 业务"收入序列，而不是纯 RTOS 收入。([FY2026 10-K][1])

| 财年        |  QNX/IoT 营收 |         同比 |
| --------- | ----------: | ---------: |
| FY2022    |   **$178M** |          — |
| FY2023    |   **$206M** | **+15.7%** |
| FY2024    | **$215.4M** |  **+4.6%** |
| FY2025    | **$236.0M** |  **+9.6%** |
| FY2026    | **$268.0M** | **+13.6%** |
| FY2027 Q1 |  **$72.3M** | **+25.7%** |

FY2022–FY2024 的原 IoT 分部数据分别为 $178M、$206M 和约 $215M；BlackBerry 后来按新的 QNX 分部口径把 FY2024 精确重列为 $215.4M，FY2025 和 FY2026 分别为 $236M、$268M。([FY2024 10-K][2]) 最新 FY2027 Q1 则达到 $72.3M，同比增长 26%。([FY2027 Q1 财报][3])

所以五年下来：

**$178M → $268M**，复合增长率大约 **10.8%/年**。

这个增长其实挺稳定的，只是 FY2024 因汽车行业和项目节奏等因素增速明显放缓，然后 FY2025、FY2026 又重新加速。

## 4. 客户深度：比营收数字更有意思

BlackBerry **没有每年披露"QNX 有多少个付费客户"**，所以不能严谨地说"FY2022 有 100 个客户 → FY2026 有 200 个客户"。但它给了三个非常有价值的替代指标：**① 覆盖多少汽车厂；② 已经进入多少辆汽车；③ royalty backlog 有多少。** 把这三个指标放在一起，反而更容易看清 QNX 到底怎么增长。

### 4.1 汽车厂客户：其实五年前就已经接近饱和

FY2022 BlackBerry 就已经宣布：QNX 获得全球前 25 大 EV 厂商中的 **24 家** design wins（从此前的 23/25 → 24/25）。([FY2022 10-K][4])

到了 FY2026，公司披露：与 **45+ 家汽车制造商**合作；包括全球 **Top 10 OEM**；仍然是 **Top 25 EV OEM 中的 24 家**；与**所有主要 Tier 1 汽车供应商**合作。([FY2026 10-K][1])

所以这里出现一个很重要的结论：

> **过去 5 年 QNX 的增长，不能主要解释成"以前没有客户，现在终于拿到很多车厂客户"。** 因为 2022 年客户覆盖面已经非常高了。BMW、Mercedes-Benz、Toyota、Honda 等这类车企早就是 QNX客户。([PR Newswire][5])

这其实把研究方向限定得很清楚：**增长主要应该来自老客户价值增加，而不是新增 Logo。**

### 4.2 进入汽车的数量：195M → 275M+

*   FY2022：**195M+** 辆汽车使用 QNX。([FY2022 10-K][4])
*   2022 年中：**215M+**
*   FY2024：**235M+**
*   FY2025 附近：约 **255M+**
*   FY2026：**275M+** —— 最新 10-K 明确说同比增加约 **2000 万辆**，相比 2020 年增加约 **1 亿辆**。([FY2026 10-K][1])

五年大致是 **195M → 215M → 235M → 255M → 275M**，一个非常稳定的节奏：**每年新增大约 2000 万辆搭载 QNX 的汽车。**

但这里必须注意：**这是 installed base，不等于每年新增客户。** 比如 Toyota 本来就是客户，今年 Toyota 新生产了几百万辆搭载 QNX 的车，这会让"QNX 车辆数"增加，但客户数量仍然是一个 Toyota。

### 4.3 真正值得看的指标：Royalty Backlog

这个数据比"275M 辆车"对投资研究更重要。QNX royalty backlog 是公司根据已经拿下的项目、royalty rate 和未来预计车型销量估算出来的**未来 royalty 收入池**。

| 时间     | QNX Royalty Backlog |
| ------ | ------------------: |
| FY2023 |           **$640M** |
| FY2024 |           **$815M** |
| FY2025 |           **$865M** |
| FY2026 |           **$950M** |

FY2023 → FY2024 一口气增加 **$175M**，之后继续增长到 $950M。([FY2024 10-K][2])

再往前看，FY2022 Q1 时这个数字只有约 **$490M**；FY2023 Q1 已经变成 $560M。([FY2023 Q1 10-Q][6])

大致就是：**$490M → $640M → $815M → $865M → $950M**

补充几个要点：

*   **增速在加快**：年增速从 FY2025 的约 +6% 提升至 FY2026 的约 +10%；管理层强调，**新增设计订单为积压订单贡献的金额，远超同期确认为收入的金额**。FY2027 Q1 公司口径为"接近 10 亿美元"（未更新精确数字）。
*   **约 4 年翻倍**：从 FY2022 的约 $4.9 亿到 FY2027 Q1 接近 $10 亿。
*   **多年收入可见性**：近 10 亿美元的积压订单为 QNX 未来多年的 royalty 收入提供了高度确定性。

### 4.4 近期重要设计订单（Design Wins）

积压订单的增长源于持续获得的新设计订单。近期披露的重要订单包括：

*   **汽车领域**：
    *   与**一家北美前五大汽车制造商**在数字座舱项目上合作
    *   与**一家欧洲前五大汽车制造商**在高通平台上的 ADAS 安全系统合作
    *   与**中国领先电动汽车制造商**签订 QNX Sound 合约
    *   与**宝马（BMW）** 及**高通（Qualcomm）** 的战略合作
    *   即将与一家欧洲汽车制造商达成 **Alloy Kore 平台**的重大设计订单

*   **非汽车领域**（目前约占 QNX 营收 20%）：
    *   **医疗设备**：**强生（Johnson & Johnson）** 等
    *   **工业自动化**：与 GEDP 的合作
    *   **半导体设备**：获得一家领先半导体设备制造商的版税承诺

这些新增设计订单是积压订单持续增长、未来收入可见性不断提升的直接驱动力。

### 4.5 佐证：FY2026 营收增长来自哪里

FY2026 QNX：**$236M → $268M，增加 $32M。** 公司把增量明确拆出来了：([FY2026 10-K][1])

*   **Royalty +$18.0M**
*   **Development seats +$9.1M**
*   Radar +$5.9M
*   Professional services **-$1.3M**

**Royalty 增长**代表以前拿到的项目进入量产、汽车出货；**Development seat 增长**代表车厂/Tier 1 正在开发下一代项目。所以：**老项目正在量产赚钱，同时新项目开发活动还在增加。** 这比单纯"客户数量上涨"要健康得多。

### 4.6 对 QNX 客户变化的理解【我的推演】

如果只看客户 logo，**变化其实不大**——五年前 QNX 就已经覆盖几乎所有主要汽车厂了。但如果看**客户深度**，变化很明显：

> QNX 搭载车辆：**195M → 275M+**
> royalty backlog：**约 $490M → $950M**
> 收入：**$178M → $268M**

所以 QNX 过去五年的增长模型不是"找新车厂 → 找新车厂"，而更接近：

> **已经进入绝大部分车厂** → **拿更多车型 design wins** → **从 infotainment 向 cluster / ADAS / domain controller / hypervisor 等更多位置扩展** → **项目量产** → **royalty 增加**

## 5. 与汽车行业：汽车业务的营收占比

QNX汽车业务的营收占比在过去10年间，从微不足道的**约2%** 飙升到了今天的**约39%**，已成为黑莓的绝对核心业务。

| 对比维度 | **约10年前 (2016年)** | **最新数据 (2026财年)** |
| :--- | :--- | :--- |
| **QNX总营收** | 未单独披露，占公司总营收**约2%** | **2.68亿美元** |
| **汽车业务营收占比** | 占QNX业务本身**绝大部分**（近乎100%） | 占QNX业务**约80%** |
| **汽车业务占公司总营收** | **约2%** | **约39%** (2.68亿 × 80% / 5.49亿) |

**2016年**：当时QNX业务规模极小，据IHS分析师估算，QNX整体仅占黑莓总营收的**约2%**。由于当时QNX几乎全部收入来自汽车领域，因此汽车业务占公司总营收也约为**2%**。

**2026财年**（截至2026年2月）：

*   黑莓全年总营收**5.49亿美元**
*   QNX全年营收**2.68亿美元**，占公司总营收**48.8%**
*   根据黑莓2026财年10-K文件披露，QNX业务中约**20%** 来自非汽车市场（如医疗设备、工业机器人等），因此汽车业务约占QNX的**80%**
*   计算得出汽车业务营收约**2.14亿美元**（2.68亿 × 80%），占公司总营收约**39%**

10年间，QNX汽车业务营收占比从**约2%** 增长至**约39%**，实现了近**20倍**的飞跃。这背后是汽车行业"软件定义汽车"趋势的爆发，以及黑莓战略转型的成功——从一家濒临消亡的手机公司，蜕变为智能汽车操作系统的核心供应商。

## 6. 后续研究方向

**最关键的问题：一辆汽车里面，QNX 到底能卖几份东西？** 如果 QNX 从过去一辆车只赚一份 infotainment royalty，变成未来 cockpit + ADAS + Hypervisor + Sound 等多份软件收入，那么即使全球汽车销量完全不增长，**QNX 的单车收入也仍然可以增长**。这是需要继续深挖的地方（Alloy Kore 平台对单车 ASP 的提升是核心线索）。
