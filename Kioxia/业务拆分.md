可以。先把铠侠的业务结构定下来。

需要先注意一个细节：**铠侠财报实际上只有一个报告分部——Memory。** 公司下面的 **SSD & Storage、Smart Devices、Other** 严格来说是按“产品最终用途”披露收入，而不是三个独立经营分部。FY2025（截至 2026 年 3 月）总营收 2.338 万亿日元。([基昂西亚控股][1])

| 业务                |       FY2025营收 |        占比 |     同比 |
| ----------------- | -------------: | --------: | -----: |
| **SSD & Storage** |     1.363 万亿日元 | **58.3%** | +37.5% |
| **Smart Devices** |       7600 亿日元 | **32.5%** | +51.6% |
| **Other**         |       2150 亿日元 |  **9.2%** |  +0.4% |
| 合计                | **2.338 万亿日元** |      100% |        |



但如果我们是为了**研究股票**，这个三分法还不够。我会进一步拆成下面 **6 块**。

### 1. 数据中心 / Enterprise SSD

这是现在最值得研究的一块。

卖的是服务器里面的 NVMe SSD，包括：

**数据中心 SSD**

* 给 hyperscaler / 云数据中心使用
* 大容量、低功耗、强调单位 TB 成本
* XD 系列等

**Enterprise SSD**

* 企业服务器、企业存储阵列、数据库
* 更强调可靠性、寿命、掉电保护、性能稳定性
* CM、PM、LC 系列等

铠侠现在还进一步针对 AI 推理开发了：

* 超大容量 LC 系列，已经做到约 **245.76TB**
* CM 系列高带宽 SSD
* Super High IOPS SSD

公司明确提出，要把 **Data Center + Enterprise 占销售组合提高到 60%以上**。([基昂西亚控股][2])

这块和普通 NAND 最大的区别是：

> **不是单纯卖 NAND 颗粒，而是“自己的 NAND + Controller + Firmware + SSD”。**

所以产品附加值、认证壁垒和客户粘性都明显高一些。

而且 AI 给它创造了新的使用场景，例如 KV Cache、RAG 数据库和 GPU memory extension。铠侠已经在围绕 NVIDIA CMX / Storage-Next 这样的架构开发产品。

**这是未来增长核心。**

---

### 2. PC / Client SSD

这一块其实也被财报塞在 **SSD & Storage** 里面。

就是我们电脑里的：

**M.2 NVMe SSD。**

比如笔记本厂商采购铠侠 SSD，直接装进 Dell、HP、Lenovo 等 OEM 电脑里。

它和数据中心 SSD 的区别很大：

PC SSD 更在乎：

**价格、容量、功耗、体积。**

而服务器 SSD 更在乎：

**IOPS、持续性能、可靠性、寿命、掉电保护、故障率。**

铠侠官方的 SSD 产品线本身就明确分成：

**Client SSD / Data Center SSD / Enterprise SSD。** ([Kioxia Singapore Pte. Ltd.][3])

所以财报里的：

> **SSD & Storage = 数据中心 SSD + Enterprise SSD + Client SSD + 一部分直接销售的 NAND Memory**

而不是单纯的“服务器业务”。财报也明确说这一分类包括用于 **PC、Data Center 和 Enterprise** 的 SSD 和 Memory Products。([基昂西亚控股][1])

这点以后看 AI 增长的时候一定要注意：

**58% 的 SSD & Storage ≠ 58% 都是 AI。**

---

### 3. NAND Memory / 裸颗粒

这是很容易被忽略的一块。

铠侠并不是所有 NAND 都自己做成 SSD。

它也会直接卖：

**BiCS FLASH 3D NAND 芯片 / NAND package**

给其他厂商。

客户拿过去以后可以自己：

* 配 controller
* 做 SSD
* 做嵌入式存储
* 做其他存储设备

所以铠侠本质上同时是：

> **NAND 原材料厂 + SSD 成品厂。**

铠侠官方产品体系也区分了 **raw NAND flash** 和带 controller 的 managed memory。([KIOXIA America, Inc.][4])

这一部分相对更接近大宗商品：

**NAND ASP 涨 → 赚钱非常快；
NAND ASP 跌 → 利润很容易崩。**

所以以后我们分析铠侠利润周期，这部分非常关键。

---

# 第二大块：Smart Devices

财报定义非常明确：

> Smart Devices 是带控制功能的嵌入式 Memory Products，用于 smartphone、tablet、TV，以及汽车和工业设备。([基昂西亚控股][1])

我会把它再拆成两部分。

### 4. 手机 / 消费电子嵌入式存储

最主要就是：

**UFS、eMMC。**

比如一部手机写着：

> 256GB storage

里面并不是插了一块 PC SSD。

手机一般使用的是一颗非常小的封装：

**NAND + Controller → UFS**

焊在手机主板上。

铠侠目前已经有 UFS 4.1、UFS 5.0 等产品。([KIOXIA America, Inc.][5])

这块非常重要，因为铠侠有一个超级大客户：

**Apple。**

FY2025 对 Apple Group 的销售达到 **4760 亿日元**，占铠侠总收入约 **20%**；Apple 是唯一被单独披露、超过总营收 10% 的客户。

所以：

> **iPhone 的 NAND 容量升级，本身就是铠侠的重要增长变量。**

例如消费者从：

128GB → 256GB → 512GB

即使手机销量不增长，单机 NAND bit consumption 也会增长。

这跟我们以后分析手机市场的时候非常重要。

---

### 5. 汽车 / Industrial Embedded Memory

Smart Devices 里面还有一块：

**汽车 NAND + 工业设备 NAND。**

例如：

* 车载信息娱乐系统
* ADAS
* 数字仪表
* 地图
* 行车数据
* OTA 软件
* 工业控制设备

这些东西同样需要长期保存数据。

汽车存储和手机相比，更强调：

**耐高温、寿命、可靠性、长期供应。**

铠侠有专门面向 automotive 的 UFS、NAND 产品。([鎧俠亞洲有限公司][6])

不过公司**没有披露 Smart Devices 里面手机和汽车各占多少收入**。

所以这里千万不能自己编一个比例。

---

# 最后一块：Other

这一块其实有点特殊。

### 6. Retail + Sandisk JV

Other 包括两个性质完全不同的东西：

**A. 消费零售产品**

例如：

* SD 卡
* microSD
* USB U盘
* 消费级 SSD

这就是普通消费者可以买到的 KIOXIA 品牌产品。

但这不是最重要的。

**B. 向 Sandisk 的销售**

这是 Other 里面非常特殊的一部分。

铠侠与 Sandisk 在日本有三个 NAND 制造 JV，共同投资工厂，然后双方按照协议分别取得 NAND 产出。因此向 Sandisk JV 体系相关销售，也会进入 **Other**。公司财报明确把这部分与 SD 卡、USB flash drive 一起归入 Other。([基昂西亚控股][1])

因此：

> **Other 不能理解成“消费电子小业务”。**

里面混着 Sandisk JV 的特殊交易。

这也是为什么 FY2025：

Other 只有 **2150 亿日元，同比增长不到 1%**，并不像另外两个业务跟着 NAND 行情一起暴涨。

---

## 所以我建议我们真正用这个模型理解铠侠

不是简单的三个财报科目：

**铠侠**
→ NAND 制造

然后 NAND 最终流向六个地方：

1. **AI / Data Center SSD** ← 未来最重要
2. **Enterprise SSD**
3. **PC Client SSD**
4. **手机 UFS / eMMC** ← 现在仍然非常重要
5. **汽车 / Industrial**
6. **裸 NAND + Retail + Sandisk**

其中前 **1～3 + 一部分裸 NAND** 被装进财报的 **SSD & Storage 58%**；

第 **4～5** 被装进 **Smart Devices 32.5%**；

第 **6 的 Retail/Sandisk 部分**进入 **Other 9.2%**。([基昂西亚控股][1])

这里有一个很重要的结论：

> **铠侠现在并不是一家“AI SSD 公司”。它现在仍然是手机 + PC + 数据中心三条腿的 NAND 公司，只不过数据中心正在迅速变成最重要的一条腿。**

下一步我们就应该**先拆第一块 Data Center / Enterprise SSD**。因为这里最复杂，也直接决定市场为什么现在愿意重新给铠侠估值。我们可以具体看：**它到底卖给谁、一台 AI 服务器到底需要多少 NAND、为什么不用 HDD、三星/海力士/美光跟它谁更强。**
