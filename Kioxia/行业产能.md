可以。把全球几家 NAND 大厂全部放到一起之后，周期位置就比只看铠侠清楚很多。

先给结论：

> **2026～2027 我暂时看不到明显的“全球 NAND 产能爆炸”。真正危险的时间窗口更像是 2028 下半年～2029。**
>
> 原因是铠侠 K2 已经在爬坡、YMTC 正在明显扩产，但 Micron 的新加坡 NAND 新厂要到 **2028 H2** 才开始产出，SK hynix 的 M17 更要到 **2029 H1**；三星目前也没有一个明确在 2027 前大规模释放的全新 NAND fab。([美光科技投资者关系][1])

而需求端，TechInsights 当前预测全球 NAND bit demand：

| 年份           |     全球 NAND需求 |
| ------------ | ------------: |
| 2025         |    **997 EB** |
| 2026E        | **约1,216 EB** |
| 2027E        | **约1,484 EB** |
| 2028E        |  **1,807 EB** |
| 2025→28 CAGR |      **约22%** |

其中数据中心 NAND 从 **295 EB → 909 EB**，增速明显高于整个市场。Kioxia 引用的这套预测甚至认为 NAND 供需在 **整个 CY2027 仍偏紧**。

**bit density ~1.5×**

Gen8 → Gen10：

**~1.6×**

而铠侠目标到 FY2026 年底：

**Gen8 占生产 GB 超过80%。**

FY2026～28 CapEx：

**平均约4700亿日元/年**

相比 FY2025：

**+66%。**

所以 Kioxia 真正的 supply growth 是：

> **K2新增 wafer capacity**
>
> ×
>
> **Gen8/Gen10 每片晶圆更多 bits**

而不是简单多盖一间厂。

### 它需要增长多少？

如果到 2028 年 Kioxia + SanDisk 仍然维持现在约 **25%** bit share：

全球：

**1,807 EB × 25% ≈ 452 EB**

现在对应约：

**304 EB**

所以：

> **2026 → 2028 需要增加约148 EB**
>
> 即 **+49%左右。**

这实际上没有我们刚才想象得那么恐怖。

因为整个 NAND 市场同期：

**1,216 → 1,807 EB**

也是：

**+49%。**

换句话说：

> **Kioxia + Sandisk 只要供给跟着整个市场增长，就可以维持现在的份额。**

K2 + Gen8 + Gen10 完全可能承担相当一部分这个增长。

因此我目前不会把 **K2 本身**视为导致下一次 NAND 崩盘的核心风险。

**Memory supply受到capacity constraints限制，AI server、enterprise SSD需求强，H2市场仍预计供不应求。**([Samsung Global Newsroom][3])

预计：

这对 2027 NAND 价格其实是一个好消息。

# 所以现在我对铠侠周期的位置会这样定

之前我们只是说：

**“利润率70%，好像很顶部。”**

现在把全球 capacity 全拉出来，我反而会稍微修正这个判断。

### 利润率

确实已经处在：

**极端景气。**

但：

### 物理供给周期

可能还没有到顶。

因为：

> **真正的大规模新 wafer capacity，很多是在 2028～2029 才出来。**

所以非常可能发生一种情况：

**2026**
ASP继续很高

→

**2027**
供应依然紧，铠侠继续赚超额利润

→

**2028**
供给明显改善，ASP涨幅停止甚至下降

→

**2029**
如果多个新厂同时成熟，正式进入下一轮下行周期。

这和简单说：

> “2023谷底 + 四年 = 2027见顶”

相比，我觉得现在这个判断**有扎实得多的产业依据**。

而且现在我们已经知道**真正最该盯哪家公司了：不是铠侠，而是 YMTC。**

三星、SK、Micron的新厂时间大体明确；**YMTC 后续两个 100k/月 fab 什么时候上、多少拿来做 NAND**，可能是决定 2028～29 会不会供给过剩的最大变量。([Reuters][8])
