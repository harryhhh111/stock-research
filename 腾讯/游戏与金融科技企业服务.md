# 腾讯业务补充：游戏与金融科技及企业服务

> 整理／核对日期：2026-10-07。财务截至2026-06-30；游戏榜单截至2026年8月，用户数据逐项注明期间。金额默认人民币亿元。【公司披露】、【第三方估计】、【自己复算】及【研究判断】分别标注。

## 1. 增值服务不等于游戏

【公司披露】2026Q2集团收入2,047.85亿元，增值服务984.14亿元，包括游戏659.51亿元、社交网络324.63亿元。[A]

【自己复算】✅ 属实：游戏占集团32.20%（659.51÷2,047.85），占增值服务67.01%（659.51÷984.14）。社交网络占集团15.85%，包括视频、音乐会员、直播及其他增值收入，分类不能直接等同于某一个App的全部收入。金融科技及企业服务602.86亿元，占集团29.44%。

因此，按财报分部，增值服务最大；拆出游戏后，游戏规模仅略高于金融科技及企业服务。腾讯是一家同时经营游戏、广告、支付与企业服务的平台公司。

### 谁研发、谁取得收入

- **内部工作室研发运营**：例如天美的王者荣耀、光子的和平精英。取得游戏相关收入，同时承担研发、运营、推广及渠道成本。
- **并表游戏子公司**：Riot、Supercell等经营游戏；公司被纳入集团报表，不只是腾讯收取股息。子公司其他股东享有的利润份额不属于腾讯归母利润。
- **外部IP授权／合作发行**：腾讯与外部开发商及版权方合作，承担部分发行运营工作；收入确认、分成及IP权利因合同不同，不能把玩家全部付费当成腾讯利润。
- **非并表股权投资**：单纯持有某游戏公司股份，不等于将其全部游戏收入并入腾讯。不能仅按股权关系推算业务金额；鸣潮的库洛已有多数股权收购报道，不能将其直接作为普通少数股权投资的例子。

产品组合以持续运营游戏为重要基础，靠赛季、角色、皮肤、玩法、赛事等更新吸引玩家继续参与与付费；也有内容付费及广告变现等形式。游戏流水要按履约与道具性质等确认收入，广告变现还可能计入营销服务。不能把免费游戏下载量当成收入。

### 当前最值得研究的经营问题

【研究判断】腾讯游戏的关键是“老产品能否保持用户关系，新产品能否从首发成功变为多年经营”。老产品已积累好友组队、熟练度、IP和运营经验，存在网络效应与迁移成本；新产品可以提供增量，但首月日活不能证明三年后仍能赚钱。射击产品组合扩大也可能分流自身玩家，不能将各游戏日活相加。

最新国内增长已有公司披露支持，但海外从2025年的33%增长降到2026Q2固定汇率4%，反映产品周期和基数波动。分析需要分别看国内／海外，不宜笼统说游戏都保持高速增长。

**盈利披露边界：** 公司披露增值服务分部毛利，但其中还有音乐、视频、直播等；所核资料未提供国内游戏、国际游戏、各款游戏完整经营利润与FCF。因此不能用增值服务64%的Q2毛利率称作游戏净利率，也不能精确测算单款游戏投资回报。

后续观察：老游戏平均活跃与流水是否稳定、新游戏半年及一年留存、付费增长来自人数还是单人支出、海外按固定汇率表现、内部研发与外部授权组合，以及版号／未成年人保护和竞争对长期回报的影响。单款收入、留存、付费率等未公开的指标明确留空，不用排行榜反推。

【研究判断】王者、和平是既有大体量产品；三角洲、无畏契约系列及洛克提供新增量。腾讯2026Q2国内游戏收入同比增长17%，公司明确指出主要驱动为后三者[A、G]。不能把增长全部归因于王者荣耀，也不能根据某款游戏流水涨幅推算其确认收入占比。

**鸣潮与腾讯的关系（2026-10-08核对）：** 鸣潮由库洛游戏研发、发行和运营；库洛官网明确将其列为自有产品。Game Developer在2024年12月报道腾讯成为库洛多数股东，因此可称为腾讯控股公司旗下游戏，但不宜称为腾讯内部工作室直接研发的游戏。腾讯2025年度及2026Q2业绩将鸣潮列为游戏收入增长贡献项。[库洛公司介绍](https://www.kurogames.com/introduction)、[多数股权收购报道，2024年12月，媒体转述](https://www.gamedeveloper.com/business/tencent-grabs-majority-stake-in-chinese-studio-kuro-games)。本稿没有用公开工商比例替代最新统一口径的集团控制权核验，不给未经核对的2026年持股比例。

国际业务还包括PUBG Mobile、Riot的英雄联盟系列、Supercell的部落冲突／皇室战争等。2025年海外收入增长33%，但2026Q2人民币收入下降0.8%、固定汇率增长4%：鸣潮及无畏契约PC的增长被部分Supercell游戏下降抵消[A、B、G]。腾讯拥有、发行、代理或持股的游戏需要分别识别，不能把所有被投游戏的全额流水归给腾讯。

## 3. 市场份额能精确到多少

- **单款游戏的完整2026年市场份额：⚠️ 无法复算。** 现有公开资料没有统一口径的全渠道单款收入及行业分母。排名能证明头部地位，不能推出占比。
- **历史行业估计：** Morningstar在2024-10-18研究中估计腾讯国内游戏份额约40%[H]。这是研究机构估计、并非腾讯披露；只能作历史参照，不能标成2026年份额。
- **榜单局限：** Sensor Tower全球手游榜通常覆盖App Store与Google Play，排除第三方安卓商店；中国大陆仅iOS，因此不覆盖完整中国手游市场，也不覆盖PC／主机[D、F]。
- **流水不等于营收；玩家也不能直接相加。** 流水是消费者付费估计，确认收入受递延、渠道及合同处理影响；同一人可能玩多款游戏。峰值日活、平均日活、月活和累计下载不可互换。

腾讯并未公开每款游戏2026年收入、平均日活、付费率及付费用户平均支出的完整表。研究判断应结合多款长线产品、新游戏续航及整体国内／海外增长，避免依赖单一榜单。

## 4. 金融科技及企业服务具体卖什么

| 子业务 | 产品／场景 | 谁付钱、腾讯取得什么收入 |
|---|---|---|
| 商业支付 | 微信支付、财付通；线上购物、线下收款、部分跨境支付 | 商户等按协议支付处理与相关服务费用；交易总额不等于腾讯收入 |
| 财富管理 | 理财通；基金等持牌机构产品分销 | 按产品与合作协议获得销售／服务相关收入；客户购买的基金本金不属于腾讯营收 |
| 消费贷款相关服务 | 与持牌金融机构合作的贷款分销等；微粒贷是微众银行产品 | 腾讯取得适用合作协议的服务收入；不能把微众银行全部贷款利息收入并入腾讯收入 |
| 保险服务 | 微保等保险服务平台 | 保险分销／相关服务业务；不能把保费全部计成腾讯营收；未单独披露当期规模 |
| 云基础设施 | 腾讯云计算、存储、数据库、网络及安全服务 | 企业购买容量、资源使用及技术服务 |
| 音视频与行业解决方案 | 直播、实时音视频、媒体处理；零售、金融等行业方案 | 企业购买技术能力或项目服务；与腾讯视频会员业务区分 |
| 企业软件 | 腾讯会议、企业微信、腾讯文档等 | 付费版本、功能及企业服务；免费用户数不等于付费客户数 |
| 云与企业AI | GPU租赁、模型服务、WorkBuddy、CodeBuddy | 算力、模型调用及软件付费；没有单独披露完整AI营收 |
| 电商技术服务 | 微信小店等交易技术支持 | 相关技术服务费；商家商品销售额不等于腾讯收入。平台广告费归营销服务 |

来源：2026Q2业绩[A、G]、2025年业绩[B]、公司金融及企业产品说明[I、J]。历史产品说明仅用于识别产品和收费模式，不作为2026年业务规模证据。

**哪些贡献最大？** 财报只披露金融科技及企业服务的合计，未给出支付、理财、贷款、云各自完整收入表。2025Q4公司说明，财富管理是金融科技收入的第二大贡献项[B，第22页]；结合商业支付的业务披露，支付是主要基础业务，但无法据此复算2026Q2各自收入占比。

**最近增长来自哪里？** 2026Q2分部收入602.86亿元，同比+8.55%（602.86÷555.36−1，✅ 自己复算）；公司指出支付、财富管理及消费贷款服务收入增加，云收入同比增速加快至20%出头，受AI需求、国际扩张及通用云需求推动[G]。云增长较快不意味着整个602.86亿元都来自云，或都属于AI收入。

## 金融科技及企业服务：怎么理解这门生意（2026-10-08补充）

**它包含两类客户与收费方式：金融科技连接消费者、商户和金融机构；企业服务向企业出售技术与软件。** 按财报分部规模仅次于增值服务，不等于“腾讯云收入”。

|---|---:|---:|
| 2023全年 | 2,037.63 | +15.08% |
| 2024全年 | 2,119.56 | +4.02% |
| 2025全年 | 2,294.35 | +8.25% |
| 2026H1 | 1,201.71 | +8.81% |

金额【公司披露】，同比【自己复算】✅ 属实，来源及复算见主报告营收章节。最新Q2收入602.86亿元、毛利314.22亿元，公司取整毛利率52%。毛利未扣完整研发、销售及总部等费用，不能当成净利率。[2026中报，2026-08-12](https://www.tencent.com/wp-content/uploads/2026/08/E700_IR.pdf)

### 金融科技：支付提供基础，理财和贷款服务扩展收入

**商业支付。** 商户通过微信支付接受线下扫码、线上订单等付款，按合同承担处理及相关服务费用。收入依赖交易笔数、平均金额和实际收费；同时有银行通道、清算、风控及系统成本。红包／个人转账不应一律当作商户付费交易，也不能把账户里的客户资金当作腾讯自有现金。2026Q2公司称交易笔数增加、单笔金额同比降幅收窄。[G]

**财富管理。** 理财通分销基金等持牌金融机构产品，腾讯通过适用合同获得佣金及服务收入。财富管理规模提高、客户数量增加、产品组合变化会影响收入；买入基金本金与客户赚到的投资收益都不属于腾讯营业收入。公司2025Q4明确称财富管理为金融科技收入第二大贡献项，但未列精确金额。[B，第22页] 当前腾讯产品页称服务超2亿用户，但未提供统一统计时点和活跃定义，不将其当成2026月活。[理财通官网，2026-10-08查阅](https://www.tencent.com/products/licaitong/)

**消费贷款相关服务。** 公司最新披露收入增长，历史材料解释微粒贷是微众银行产品、腾讯取得分销费用。微众银行是关联银行，不因微信入口就将银行全部利息并成腾讯营收。其他贷款合作安排与风险承担须按产品核对，不能把微粒贷历史“不承担信用风险”的描述推广到全部金融业务。[I、G]

**保险。** 微保等平台提供保险分销与相关服务；腾讯并非因此承担所有产品的保险承保。保费不等于其营业收入，当前集团财报未列单独业务金额。历史产品清单列佣金模式，不用旧用户规模描述现状。[腾讯产品清单，2021Q2，历史收费模式](https://www.tencent.com/attachments/toolkit/2021/Q2/ProductListofTencent2Q21.pdf)

### 企业服务：算力之外，还有技术能力、软件和交易服务

**云基础设施**：企业租用计算、GPU、存储、网络及数据库，按资源／使用量等付费；**音视频与安全等技术服务**：直播、会议、游戏客户购买实时音视频、内容处理、防护等能力；**企业软件**：腾讯会议、企业微信、腾讯文档等免费基础能力之外的付费版本、功能及服务；**AI服务**：模型调用、GPU租赁以及CodeBuddy／WorkBuddy付费；**电商技术服务**：小店相关技术支持收费。

同一个商家可能同时买广告、付支付费和技术服务费。广告计入营销服务，支付与相关电商技术服务计入本分部。各项都不能按商家的商品销售额直接计收入，也不能把免费企业工具用户等同于付费客户。

2026Q2公司披露云收入同比增长20%出头，来自AI需求、国际拓展及通用云需求，但仍受算力供给约束；未给云收入和AI收入完整金额。[G，第20页]

### 规模、增长与盈利怎么看

【研究判断】支付较依赖消费交易及频次，财富管理依赖客户资产与产品结构；贷款相关收入要关注风控与合作条款；云／AI有需求空间，但重资产采购、折旧、价格竞争及算力利用率影响回报。企业软件可能提高客户黏性，不过免费覆盖不能证明商业回报。整个分部2024仅增长4%，2025恢复到8%，不能将云约20%的最新增速直接套给整个分部。

公司没有披露支付、理财、消费贷款、云等各自完整收入与经营利润。可确认理财是金融科技第二大收入贡献项，但无法复算它占合并分部多少，也无法准确排序每项利润贡献。当前52%是合并毛利率，不意味着每笔微信支付能赚52%，更不意味着云和金融科技各自都达到52%。

核心观察项：**商业支付金额与频次、财富管理客户资产、金融业务风险／收费变化、云AI需求能否转成利润与现金，以及资本开支与利用率。**
