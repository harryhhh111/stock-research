# 腾讯营销服务：收入来源与增长空间

> 整理／核对日期：2026-10-07。财务截止2026-06-30。金额默认人民币亿元。区分【公司披露】、【自己复算】与【研究判断】。本报告不预测具体未来增速。

## 具体卖什么

营销服务主要是向广告主提供广告展示、用户获取及转化服务。广告主包括电商、互联网服务、游戏、当地生活服务等企业，不是微信用户为聊天付费。2024Q3起，腾讯将原“网络广告”分部更名为“营销服务”，用于体现广告及配套营销技术服务的范围；更名不代表突然增加同等规模的新业务。[A]

| 收入场景 | 具体产品与付费动机 |
|---|---|
| 微信内容与社交广告 | 视频号、朋友圈、公众号：品牌推广、引导进店／购买或获取客户 |
| 微信搜一搜 | 用户搜索产品及服务时展示相关推广，广告主获取有购买意向的用户 |
| 小程序广告 | 小游戏、短剧等中的广告，包括观看广告获得奖励；开发者提供展示场景，广告主购买用户与转化 |
| 内容平台广告 | 腾讯视频、音乐、新闻等内容平台的广告及相关营销服务；与会员费分别归类 |
| 移动广告联盟 | 第三方App开发者接入腾讯广告能力；广告收入与合作伙伴分成，不能把广告主全部预算认成腾讯利润 |

来源：公司2026-06-17投资者演示[B]。实际收费可因产品及协议按曝光、点击或转化等目标设计；不能把某一种报价方式视为全部收入模式。

**例子：商家投放视频号广告→用户进入微信小店→微信支付成交。** 腾讯可能取得广告收入、小店技术服务费及支付服务收入。广告归营销服务，后两者归金融科技及企业服务；商品销售额主要归商家，直播打赏和视频会员也不算广告收入。

第三方确实统计小程序用户、应用活跃、时长与广告触达等，但公开报告与商业数据库的覆盖程度不同。视频号／朋友圈属于微信内部功能，不能简单拿独立App榜单替代；要检查功能识别、样本及统计范围。微信与WeChat合并全球月活也不能与第三方中国境内监测用户直接做渗透率计算。各场景用户重叠，不能相加得腾讯总用户。

【研究判断】目前更强的证据是微信整体用户增长较慢，但视频号使用时长和商业化改善支撑广告增长；并非腾讯营销收入主要依赖新增微信用户。广告收入还取决于使用频次、展示量、广告负载及单位展示收入。缺少场景收入和统一活跃数据，不计算视频号等场景的广告收入／用户指标。网上将2025小程序日活推算为7.64亿的部分统计页，注明用了线性回归预测，不能当成腾讯披露或实际测量值。

## 为什么增长

公司最新披露可归为三条线[C、D、E]：

1. **展示量增加。** 视频号用户观看与广告展示增长；小游戏、短剧等内容增加了小程序广告需求。2026Q2视频号总使用时长同比增长超过20%。
2. **每次展示更有价值。** 公司披露Q2每千次展示收入与展示量均提高；AI推荐帮助匹配用户和广告，提高转化。不能据此认定所有广告主收益都改善。
3. **投放至成交的路径更顺畅。** AIM+自动投放工具结合素材生成、选择及竞价，在微信小店、小游戏等场景里连接投放与转化。公司披露2026Q1 AIM+承载约30%的广告主营销服务支出；它是广告工具渗透率，不是单独新增30%收入。

2025年度公司还指出搜一搜商业查询量与变现改善，收入增长受价格及展示增长共同支持[F]。场景越来越多，但公司并未量化每个驱动各贡献多少收入增长。

## 会成为未来增长点吗

**【研究判断】是，且已成为现实增长引擎；增长能否持续，要看商业效果与用户体验，而非单纯增加广告数量。**

| 增长空间 | 为什么有机会 | 约束／待验证 |
|---|---|---|
| 视频号变现 | 使用时长、视频观看及广告展示增加，公司称广告负载仍低于行业 | 负载是公司判断，未给可完整对照的统一行业数据；加广告会影响体验 |
| 搜索商业化 | 用户明确搜索产品／服务，有助广告转化 | 搜索流量能否转成持续商业需求，受到其他搜索与AI服务竞争 |
| 小程序与小店 | 更多内容、商家及交易支持站内广告需求 | 交易与开发者收益需要健康增长，不能依靠过度买量维持 |
| AI投放 | 改善匹配、素材和自动竞价，帮助广告主扩大可盈利投放 | 算力、折旧及运营成本上升，收入增长不一定提高利润率 |
| 广告联盟 | 第三方App扩大覆盖面，激励广告提高变现 | 分成、流量质量及第三方平台规则影响净收益 |

【公司披露】2026Q2营销服务毛利249.69亿元，毛利率公司取整为57%，去年同期58%；公司解释更高收入基本抵消了AI基础设施扩张带来的折旧及运营成本[C]。因此这是有增长、有毛利贡献的业务，但不能直接称为“AI使利润率持续上升”；集团没有单独披露这一分部完整经营利润或自由现金流。

宏观消费与广告预算、抖音／快手等平台的竞争、广告负载和隐私规则都会影响增长；连续数年约20%增长不等于未来每年都能维持20%。后续重点看：**收入增速、分部毛利率、视频号观看／广告负载、广告转化效果，以及小店／小程序交易生态。**
