好，最后一个是 **智慧物流 / 安得智联**。这一块其实比前面的新能源、医疗更容易判断，因为安得正在申请独立上市，所以财务和客户数据披露得很清楚。

## 7. 智慧物流——安得智联

安得智联不是美的后来收购来的公司，而是**从美的自身供应链体系中孵化出来的物流公司**。它目前做的是一体化供应链物流，而不是我们通常理解的单纯“快递”。美的把它概括成“1+3”模式：一个端到端物流底盘，加上**生产物流、一盘货统仓统配、最后一公里送装一体**三类核心解决方案。([美的][1])

简单来说，它想管的是：

> 原材料进工厂 → 工厂内部物流 → 成品入库 → 仓储 → 经销渠道 → 消费者家里 → 安装

这与顺丰、京东物流有重叠，但并不只是做最后一公里配送。

### 财务数据

安得智联最新招股资料已经把2025年数据完整披露出来：

| 安得智联     |       2024 |       2025 |         变化 |
| -------- | ---------: | ---------: | ---------: |
| **营业收入** | **186.6亿** | **214.5亿** | **+14.9%** |
| 净利润      |  **3.80亿** |  **4.49亿** |      约+18% |
| 净利率      |      约2.0% |  **约2.1%** |       小幅提升 |
| 毛利率      |      约7.3% |  **约7.1%** |         略降 |

2023—2025年，安得收入从162.2亿元增长到214.5亿元，净利润从2.88亿元增长到4.49亿元。([证券时报][2])

这里马上能看到一个很明显的特点：

> **它规模不小，但利润率非常低。**

214亿收入只赚4.5亿元左右，净利率大约2%。这其实是物流商业模式决定的，和美的家电30%左右的毛利率完全不是一种生意。2025年安得整体毛利率约7.1%。([凤凰财经][3])

所以以后研究它，肯定要完全按照一家**物流公司**的框架看，不能按照制造企业的方式看。

# 最有价值的数据：它到底有多依赖美的？

这个问题现在终于可以直接用数据回答了。

安得智联来自美的集团的收入占比：

|      | 来自美的集团收入占比 |
| ---- | ---------: |
| 2023 |  **36.6%** |
| 2024 |  **41.1%** |
| 2025 |  **39.6%** |

所以2025年大约：

**美的集团内部/关联客户：85亿元**

**美的之外第三方客户：约130亿元，占60.4%。** ([观察者网][4])

这个数据非常关键。

它说明我们之前对安得的判断可以进一步修正：

> **它已经是一家真正对外经营的物流公司，但还没有完全摆脱对美的母体的依赖。**

不是“美的内部物流部门”，因为现在**六成收入来自集团外部**。

但也不能把它当完全独立公司，因为**四成收入仍然来自最大客户美的**，客户集中度相当高。安得的招股资料也把关联交易和客户集中度列为风险因素。([新浪财经][5])
