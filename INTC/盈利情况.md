如果你指的是 **Intel 整家公司**，现在的情况可以概括成一句话：

> **主营经营已经明显恢复盈利，但 Foundry 仍然巨亏；负债不低，不过目前还谈不上危险。**

### 盈利情况

先看过去三年 GAAP 净利润：

| 财年   |     营收 |  Intel 归母净利润 |
| ---- | -----: | -----------: |
| 2023 | $54.2B |  **+$1.69B** |
| 2024 | $53.1B | **-$18.76B** |
| 2025 | $52.9B |  **-$0.27B** |

所以 2024 年是一个巨大的亏损低谷，2025 年已经基本回到盈亏平衡。([英特尔][1])

真正值得看的是 **2026 Q2**：

| Q2 2026      |           数据 |
| ------------ | -----------: |
| 营收           |  **$16.13B** |
| 毛利率          |    **40.4%** |
| 营业利润         |   **$1.80B** |
| 营业利润率        |    **11.1%** |
| GAAP 归母净利润   | **-$11.03B** |
| Non-GAAP 净利润 |  **+$2.20B** |

这里千万不要被 **-$110 亿净亏损**吓到。

Intel Q2 实际经营已经赚钱了，营业利润 **+$18 亿**。GAAP 巨亏主要因为美国政府托管股份相关衍生负债产生了约 **$12.53B 非现金市值重估损失**；剔除这些特殊项目，Intel non-GAAP 净利润是 **+$2.20B**。([英特尔][2])

而且内部结构非常清楚：

> **CCPG 营业利润：+$2.34B**
> **DCAI：+$2.47B**
> **Intel Products 合计：+$4.82B**
>
> 但是
>
> **Foundry：-$2.09B**

所以现在 Intel 的情况实际上是：

> **芯片设计/销售业务已经非常赚钱，尤其 DCAI；Foundry 继续吃掉大量利润。** ([美国证券交易委员会][3])

这也是研究 Intel 时最重要的矛盾。

---

## 负债情况

截至 **2026 Q2**：

| 项目        |            金额 |
| --------- | ------------: |
| 现金        |   **$12.87B** |
| 短期投资      |   **$16.85B** |
| 现金 + 短期投资 |   **$29.73B** |
| 短期债务      |    **$1.99B** |
| 长期债务      |   **$48.55B** |
| **总债务**   |   **$50.54B** |
| **净债务**   | **约 $20.81B** |

Intel 年底 2025 总债务还是 **$46.59B**，半年后增加到了 **$50.54B**。其中一个重要原因是 Intel 为回购 Ireland SCIP 少数股权支付约 **$14.2B**，其中使用了一笔 **$6.5B term loan**。([美国证券交易委员会][3])

但 Intel 目前流动性并不紧张：

> Current assets：**$57.2B**
> Current liabilities：**$35.7B**

同时公司总资产约 **$202.4B**，Intel 自身股东权益约 **$87.5B**。([美国证券交易委员会][3])

所以我不会把 Intel 定义成类似 CHTR 那种**高度杠杆、债务本身决定生死**的公司。

Intel 真正的问题是：

> **它有约 $505 亿债务，同时还要继续承担极其昂贵的 Fab / 18A / 14A 资本开支。**

因此它的风险不是“明天还不起债”，而是：

> **如果 Foundry 长期每年亏几十亿美元，同时还必须继续投入几十亿美元甚至上百亿美元资本开支，那么 DCAI 和 CCPG 赚出来的钱会持续被 Foundry 吸走。**

反过来，如果 Foundry 亏损快速收窄，那么 Intel 的利润会有非常大的释放空间。

所以我现在看 Intel 盈利，**最值得盯的并不是 GAAP 净利润，而是两个数字：Intel Products 营业利润和 Foundry 营业亏损。**

目前最新季度两者分别是：

> **Intel Products：+$48.2 亿**
> **Intel Foundry：-$20.9 亿**

这两个数字之间的变化，可能比 Intel 总净利润更能说明这家公司的真实经营拐点。
