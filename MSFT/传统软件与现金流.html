01 / 先把业务边界画清楚

第一层关注Windows、Office与服务器数据库等成熟业务。它们的客户、收费和财报归属不同；传统授权、按期订阅、SaaS和Azure服务不能混成一类。

PC厂商→Windows OEM→预装操作系统许可
企业IT部门→Windows / SQL Server→本地部署授权
企业与个人→Office / M365→本地许可或订阅服务

等宽箭头仅表示交易关系，不表示金额；传统软件独立现金收款未披露。

产品钱从谁来、为何支付披露归属研究分类
Windows OEMPC厂商支付预装许可费设备与消费者传统许可
Windows商业本地许可企业采购桌面系统使用权代理与基础设施／生产力及服务器许可传统许可
Windows Server / SQL Server企业采购本地服务器或数据库使用权代理与基础设施／生产力及服务器许可传统许可；按期付费也不自动是SaaS
M365 / Office企业或个人采购订阅、升级或本地许可云服务与本地许可按合同区分应用服务与本地许可分开
Azure托管数据库客户为托管平台及资源使用付费Azure云平台服务，不属于本地数据库许可
披露边界：微软未单列这组“传统软件业务”的完整现金收入、经营付款和FCF。不能画出“SQL Server现金流入→AI建设”的精确资金流。集团资金统一调配，现金具有可替代性。

【我的推演】经营现金流上升，而FCF连续下降，说明现金投入增速更快。它提出了资本回报问题，却不能证明传统软件业务本身衰退，也不能证明全部投入都是AI。

06 / 第一层接下来真正要验证什么

  • 收入来源：传统Windows、Office及服务器数据库许可各自规模与增速；新旧分类重述后再比较。
  • 经营质量：续费、升级、定价权、费用与利润证据；不把订阅增长自动解释为提价。
  • 现金转化：合同确认与收款时点、递延收入和应收变化；利润和现金分开。
  • 向AI过渡：传统许可被云订阅替代的影响，以及每用户收入是否覆盖新增推理成本。

本页是HTML展示测试，非第一层完整研究验收；尚未填入可独立归属于传统软件的现金总额。最新季度及分部详情继续见AI专题底稿和集团研究。本页年度图不冒充最新季度或当前行情。
