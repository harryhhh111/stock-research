研究摘要与我的判断

结构试阅版 · 2026-11-14：按用户反馈重排与简化展示，未更新财报或行情。本轮报告结构已同步到SOP；财报与行情未刷新，skill尚未创建。

微软通过企业软件订阅、云资源消耗和软件许可赚钱，Windows、游戏与广告提供补充。最有价值的组合是：用Office、身份、安全、开发工具建立企业关系，再将数据、应用和AI工作负载转化为订阅升级及Azure消耗。

【我的推演】经营质量强，资本回报进入重新验证期；目前更适合持续跟踪，不能仅凭AI增长认定股价便宜。 三个投资问题：①Copilot能否带来扣除推理成本后的真实增量利润；②Azure增长能否转化为足以覆盖设备更新和租赁的现金；③对模型公司的投资、采购与客户合同是否增加共同融资风险。

正面证据是企业软件盈利能力、Azure最新季度增长和客户合同储备；反面证据是现金投入加速、FCF下降以及表外未起租承诺扩大。按11月13日本轮核对采用的11月11日行情快照，滚动GAAP PE约27.21倍，剔除OpenAI投资影响约28.89倍，但FCF收益率仅1.55%。利润估值与现金估值给出不同信号，关键在未来投入强度能否下降，而非只看PE。

核心矛盾：增长能否变成现金回报

【我的推演】核心矛盾是成熟软件的高现金回报模式与AI基础设施重投入模式并存：微软可以通过企业分发变现AI，也可能把软件利润不断投入折旧更快、竞争更激烈的算力。模型厂商既是伙伴、投资对象又可能争夺应用入口，使采购、投资和客户关系不能分别乐观相加。

1. 微软怎样赚钱

把微软想成一家卖“工作工具”和“计算能力”的公司。 它既卖软件使用权，也持续提供办公、云和AI服务，还靠游戏、广告和设备赚钱。下面先讲每笔钱为什么有人愿意付，再看这笔钱在财报里有多大。[S1][S2][S3]

卖什么谁付钱，为什么付，怎么收费收入有多大（各期分开）
Office / M365公司要让员工写文档、算表格、开会、共享文件，所以替员工买办公工具。企业通常按用户订阅，更多功能或AI另行升级；本地Office许可另算。FY2026商业M365产品与云服务101.997 B美元，占集团30.74%；这是许可与云的合计，不是Copilot收入。
Azure云服务企业需要计算、存储、数据库等能力，可以租用微软的资源，而不全部自己建机房。客户按用量、预留资源或合同付钱；微软负责运行基础设施。FY2027 Q1独立Azure收入33.165 B美元，占集团35.94%。包含传统云，不能全部算AI。
SQL Server / Windows Server企业需要管理订单和库存的软件，也需要运行服务器的操作系统。买微软软件的使用权后，可以自己安装和维护；改用微软托管服务则是另一笔云服务交易。FY2027 Q1生产力及服务器许可8.407 B美元，占9.11%；还含其他软件，未单列SQL Server收入。
Windows与电脑设备电脑厂商给新电脑预装Windows，向微软付授权费；企业还会购买商业授权。微软也卖Surface等设备。预装许可、企业授权和设备是不同交易。FY2027 Q1 Windows OEM及设备3.551 B美元，占3.85%；不能当作所有Windows收入。
GitHub、Dynamics与行业软件程序员购买代码协作、安全和AI工具；销售、财务和医院等部门购买管理业务的软件。收费包括订阅和实际用量。FY2027 Q1行业解决方案5.337 B美元，占5.78%；GitHub云归入M365商业云，不能再加一次。
LinkedIn招聘公司为找人付钱，广告主为展示广告付钱，销售人员和会员为更多功能付钱。免费用户和真正付钱的人不完全相同。FY2026收入19.817 B美元，占5.97%。FY2027起招聘/销售与广告/会员拆入不同项目。
Xbox与游戏玩家买游戏、道具和会员，第三方游戏也通过平台销售。收入还包括游戏机，但硬件与内容的成本和利润不同。FY2026 Xbox收入21.790 B美元，占6.57%。
搜索广告用户免费搜索和浏览，广告主付钱获得曝光或点击；微软也会为从其他平台带来的流量付费。FY2026搜索广告15.176 B美元，占4.57%；新口径搜索及广告另含LinkedIn部分业务。

例如，一家制造企业为员工购买M365，另外为Azure上的业务数据库、AI检索及模型调用付费。这是同一客户的不同履约内容，不能把Copilot、M365、Microsoft Cloud及集团收入相加。[S1][S2]

LinkedIn、GitHub、Nuance、Activision Blizzard等业务属于并表范围；OpenAI和Anthropic属于投资及商业合作对象，不能把其全部营收并入微软。微软既可能投资模型公司，又向其销售云资源或采购模型服务；投资损益与云经营收入分别分析。[S1][S3][S5]

FY2026旧分部中，生产力与业务流程经营利润83.879、智能云56.972、更多个人计算14.386；各占集团经营利润54.03%、36.70%、9.27%【复算✅】。Azure、Copilot各自独立经营利润没有在这些分部表中披露，智能云利润不能冒充Azure利润。
