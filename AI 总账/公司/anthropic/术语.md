# Anthropic 研究术语

整理日期：2026-10-29。通用现金流、估值与资金效率定义见[根术语](../../../术语.md)。

|术语|本公司具体口径与例子|
|---|---|
|NRR|净收入留存；同一批合格客户今年对应季度收入/去年对应季度收入。排除Pro/Max，900%即约9倍收入、增长800%，不是人数留存率|
|Run-Rate Revenue|用量收入按过去28天、订阅按一个月年化；与全年收入、TTM和Q3乘4不同|
|Token、缓存|模型处理的计量单元；重复前缀可按条件复用计算，缓存读取价与有效期、命中率不同，token也不是跨模型统一任务量|
|Consumption-based|按实际使用付费，可由个人或企业购买，不能直接等同B端|
|CSP|云服务供应商；可同时是渠道、算力供应商、股东和竞争者，不能当作同一终端客户|
|RPO|剩余履约义务：不可取消承诺中未确认收入；非全部未来需求，也非已收现金|
|True-up / take-or-pay|保底补足/照付不议；使用不足也可能付款，须看违约、交付与取消条款|
|Ready for service|设备达到可服务条件，可能触发租金；并不保证客户用量和收入已出现|
|SAFE / rollover note|未来股权安排/受持股限制暂不能转换而续存的票据；账面公允值、现金本金和转换股数不同|
|VIE|可变利益实体；是否并表取决于控制等会计判断，不因项目法律上独立即自动出表|
|LTBT / Class T / Class F|长期利益信托及治理股类；Class T主导多数董事任免，Class F控制一般股东事项，两者无经济权利|
|RSU|限制性股票单位；满足服务和上市等条件后可能确认费用并交付股票，未确认总额不等于当季全部费用|

来源：[Anthropic 2026-10-26 S-1](https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm)，以主报告口径说明为准。
