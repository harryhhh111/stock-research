# SK 海力士（SK hynix，000660.KS）研究主报告

> 整理日期：2026-09-11  
> 财务数据截止：2026-06-30（2026 年 Q2 业绩公告）；行情截止：2026-09-10 收盘。  
> 口径：除特别说明外，金额均为万亿韩元（KRW T），财务数据为合并 K-IFRS。本报告将**公司披露、第三方估计和本人复算**分开标注；不构成投资建议。

## 先给结论

**SK 海力士是当前 AI 内存景气中产品结构最优、HBM 商业化最领先的 DRAM 厂商之一；但它也不是“脱离周期的 AI 软件公司”。** 其 2026 年的超高盈利同时来自 HBM/服务器 DRAM 产品组合、普通 DRAM 与 NAND 的急剧涨价，以及供给约束。投资判断的关键不是 HBM 技术本身，而是：

1. HBM4 能否在 2026 下半年至 2027 年顺利放量、保持良率和 ASP 优势；
2. HBM 龙头优势能否转化为可持续的客户份额，而不是在 Samsung、Micron 追赶后被稀释；
3. 2027 年后 Yongin、M15X 与同行扩产投放时，DRAM 价格和资本回报是否仍能支撑今天的利润率。

截至 Q2 2026，公司经营利润率已达 **76%**。这证明产品与周期处在极强位置，也意味着不能用当季利润简单年化估值。

## 1. 公司概览与业务拆解

### 1.1 公司是什么

SK 海力士是韩国存储芯片制造商，主营 **DRAM** 与 **NAND Flash**；普通股在韩国交易所交易（000660），美国 ADR 于 2026 年 7 月开始在 Nasdaq 交易。最大股东为 SK Square，持股 **20.5%**（2026-05-06），国民年金与 BlackRock Fund Advisors 分别持股 8.1% 和 5.1%（公司 IR 披露）。[股权结构（公司 IR）](https://www.skhynix.com/ir/UI-FR-IR04/)

### 1.2 先分清财报口径：有产品收入拆分，但没有产品营业利润拆分

公司在经营分部层面只报告一个“半导体”分部；但合并中期财报的收入附注**实际披露了 DRAM、NAND Flash 和 Others 的产品收入**。相反，公司并不披露 HBM、通用 DRAM、NAND/Solidigm 各自的营业利润、毛利或客户收入。因此，研究上应：

- 将 DRAM 与 NAND 的收入采用公司附注的实际数；
- 将 HBM 作为 **DRAM 内部**的高端产品线，而非第三个会计分部；
- 对“各业务利润率”使用券商重建口径，并明确它不是公司审计披露。

截至 2026 H1，DRAM 是 **74.0%** 的收入，NAND Flash 为 **25.4%**，Others 为 0.5%。这说明海力士本质上仍是一家以 DRAM 为核心的存储厂，HBM 是 DRAM 组合升级，不是独立于 DRAM 周期之外的第三门生意。产品收入来自公司中期财报附注。[产品收入附注（中期报告镜像）](https://financialfilings.com/filings/sk-hynix-inc/interim-quarterly-report/2026/56530973/)

|---|---|---:|---|

### 1.3 DRAM：真正的利润池，内部还要再拆三层

#### A. HBM：给 AI 加速器用的“带宽层”

| 维度 | 业务拆解 |
|---|---|
| 产品 | 当前商业化重心是 HBM3E 与 HBM4；Q2 2026 已开始 HBM4 量产出货，HBM4E 仍处样品/客户验证阶段。 |
| 客户场景 | GPU、AI ASIC 与高性能计算系统。它贴近加速器封装，主要缓解模型权重、KV Cache 等工作负载的带宽瓶颈；并不取代服务器主内存或 SSD。 |
| 收入公式 | **加速器出货量 × 每颗加速器的 HBM 堆栈数 × 每堆栈容量/规格 × 实现 ASP**。因此“AI 服务器台数”不是充分指标：同一服务器可搭载不同数量和代际的加速器。 |
| 成本/供给上限 | DRAM wafer、先进制程良率、TSV 堆叠、逻辑/基础 die、封装、测试及散热。HBM 消耗的 wafer 与后段资源显著高于同容量普通 DRAM。 |
| 定价本质 | 不是纯现货商品。产品必须进入客户平台并完成系统认证；在供给紧张时，按期交付和良率可带来高溢价，但客户多元采购或下一代认证变化也会很快改变份额。 |

公司披露的 HBM4 使用 2,048 I/O、速度超过 10Gbps，并采用 Advanced MR-MUF 与 1bnm DRAM；这些是公司产品口径，并非跨厂商的独立性能排名。[HBM4 开发与量产准备公告](https://news.skhynix.com/en/sk-hynix-completes-worlds-first-hbm4-development-and-readies-mass-production/) Q2 2026 业绩公告进一步确认，HBM4 已在当季开始量产出货，计划下半年提升产量；HBM4E 当时仍只是已送样的下一代产品。[Q2 2026 业绩公告](https://news.skhynix.com/en/q2-2026-business-results/)

**研究上不应只问“HBM 市占多少”，还应问：**

- HBM3E→HBM4 的代际转换会不会带来认证空窗、良率爬坡或 ASP 下滑；
- 每颗 GPU/ASIC 的堆栈数、单堆栈层数和容量是否继续增加；
- HBM 占用更多 DRAM 产能后，是否反过来推高普通服务器 DRAM 的价格；
- 封装是否成为交付瓶颈，从而令 wafer 产能扩张不能即时转成收入。

#### B. AI/服务器 DRAM：容量层，不是 HBM 的替代品

该层包括 DDR5 RDIMM、3DS RDIMM、MRDIMM、SOCAMM2、CMM-DDR5（CXL 内存模块）等。它们分别服务 CPU 服务器的容量扩展、更高带宽模块、AI 服务器的低功耗/紧凑形态，以及 CXL 架构下的内存扩展和池化。

公司展示的具体产品包括 256GB 3DS RDIMM、64GB 1c 制程 RDIMM、96GB MRDIMM、192GB SOCAMM2 与 CMM-DDR5。产品展示证明组合方向，但不披露每项的销售额或利润。[2026 Dell Technologies World 产品组合](https://news.skhynix.com/en/dtw-2026/)

这块业务的收入公式更接近：**服务器出货量 × 每台服务器 CPU 插槽/内存通道 × 每通道容量 × DRAM ASP**。AI 服务器会增加总内存需求，但 HBM、DDR5/SOCAMM 和 CXL 处理的是不同层级的数据：

```text
GPU/ASIC 旁的极高带宽热数据       → HBM
CPU/服务器工作内存与大容量内存    → DDR5 / MRDIMM / SOCAMM / CXL
数据集、检查点、推理持久化数据    → 企业 SSD / NAND
```

对海力士而言，服务器 DRAM 是 HBM 最重要的协同业务：当大量 DRAM wafer 优先转向 HBM，高容量服务器 DRAM 的可供给量会收缩，普通 DRAM ASP 也可能上升；反过来，一旦 HBM 需求低于预期，释放出的资源会加剧普通 DRAM 的供给压力。

##### 服务器 DRAM 入门：先用四个问题把名称拆开

“DDR5 RDIMM”“256GB 3DS RDIMM”“MRDIMM”“CXL 内存”“HBM”听起来像五种芯片，实际上是把不同维度混在一起命名。理解它们只需依次问四件事：它接在谁旁边、以什么接口连接、模块怎样缓冲信号、容量如何做大。

##### 从硅晶圆到 DRAM：芯片是怎样被“做”出来的

这里的“晶圆”要先分清：硅料经拉制单晶锭、切片、研磨和抛光后，得到的是一张几乎空白的 300mm **硅晶圆**；进入 DRAM fab 后，才在这张底板上逐层做出数十亿个存储单元。每个典型 DRAM cell 是 **1T1C**：一个晶体管（transistor）负责选通，一个电容（capacitor）储存电荷；有电/无电对应 bit 状态。电容会漏电，故 DRAM 必须定期 refresh。

```text
高纯硅 → 单晶硅锭 → 切片/抛光的裸晶圆
   → 反复沉积薄膜、光刻、刻蚀、离子注入与退火
   → 制作 1T1C 单元、字线/位线/感测放大器
   → 金属互连层、通孔与 CMP 平坦化
   → 晶圆电性测试（wafer sort）→ 切割成 die
   → 封装与成品测试 → DRAM 颗粒
   → 多颗颗粒贴装在 PCB 上，加 RCD/PMIC/SPD 等 → RDIMM 等内存条
```

最容易误解的是中间一段：不是把“晶体管做完、再一次性做电容”那么线性，而是在不同结构层上，反复进行 **沉积 → 光刻曝光显影 → 刻蚀 → 去胶/清洗 → 掺杂与热处理 → 平坦化**。这些循环决定了图形尺寸、绝缘性、导电性和良率；一个先进 DRAM 制程会有大量这类工序。电容的高深宽比结构、介电层和电极决定单元能存多少电荷，字线控制一整行 cell，位线把信号送到感测放大器读写。

晶圆测试会筛掉不能工作的 die；因此可卖产出不是“每片晶圆能切多少颗”，而是 **每片晶圆理论 die 数 × 前段良率 × 封装测试良率**。这也是制程从 1b 到 1c 的意义：若在相近晶圆面积上放入更多合格 bit，成本/bit 才会下降。普通 DDR DRAM 到这里通常封成单颗 BGA 后再组成 DIMM；HBM 则还要把超薄 die 用 TSV 垂直堆叠，并和 GPU/ASIC 做先进封装，后段难度明显更高。

| 维度 | 常见答案 | 它解决什么问题 | 例子 |
|---|---|---|---|
| **接在谁旁边** | CPU 直连 / 加速器直连 / 经 CXL 扩展 | 决定最基本的延迟、带宽与软件可见性 | CPU 的 RDIMM；GPU/ASIC 旁的 HBM；PCIe/CXL 卡上的 CXL memory |
| **DRAM 接口代际** | DDR4、DDR5、LPDDR5X、HBM3E/HBM4 | 决定每 pin 传输速率、功耗与生态 | “DDR5”是接口/芯片家族，不等于某一种模块 |
| **模块的电气架构** | UDIMM、RDIMM、LRDIMM、MRDIMM | 在速度、信号完整性、容量、成本间取舍 | “RDIMM”说明模块上有寄存器，不是在说 DRAM die 本身 |
| **容量/封装办法** | 标准 die、3DS 堆叠 die、多 rank | 在同一插槽塞进更多 GB | “3DS RDIMM” = 3DS 高密度 DRAM die 做成的 RDIMM |

所以一个产品全名可读作：**DDR5 + 3DS + RDIMM + 256GB**。它仍是 CPU 直连的服务器主内存；“3DS”讲容量，“RDIMM”讲模块信号，“DDR5”讲接口。相反，HBM 虽也是 DRAM，却不是 DIMM，通常焊在 GPU/AI ASIC 的封装旁。

##### 服务器里真正有哪几层内存

```text
CPU 核心
  └─ CPU 直连 DDR5 DIMM：通用主内存，追求容量、可靠性、可扩展性
       ├─ RDIMM：主流标准配置
       ├─ LRDIMM / 3DS RDIMM：优先追求超大容量
       └─ MRDIMM：优先追求更高带宽，需特定平台支持

GPU / AI ASIC
  └─ HBM：封装内极高带宽的近端内存，放模型权重和热数据

CXL 插槽 / CXL 交换机
  └─ CXL Memory Expander：额外的 DRAM 容量池，延迟/带宽通常不如 CPU 直连 DIMM

NVMe 企业 SSD
  └─ NAND Flash：持久化数据、检查点、数据集；不是 DRAM，断电后仍保存
```

这四层不是简单的替代关系。举例：一个 AI 推理服务器可以同时有 CPU 的 DDR5 RDIMM（操作系统、CPU 端数据）、GPU 的 HBM（模型计算）、CXL DRAM（较冷的数据/扩容）和 eSSD（持久化 KV cache 或数据集）。把其中任意一层加大，都不意味着可以删掉其他三层。

##### CPU 直连主内存：RDIMM、LRDIMM、3DS RDIMM、MRDIMM 到底差在哪

| 类型 | 一句话理解 | 优先优化什么 | 主要代价/限制 | 典型场景 |
|---|---|---|---|---|
| **UDIMM** | 无缓冲模块 | 成本、略低延迟 | 能挂的 DIMM 数和容量有限；不是大型服务器主流 | 台式机、部分工作站 |
| **RDIMM** | 在 DRAM 与 CPU 内存控制器之间加寄存器，先缓冲地址/命令信号 | 信号完整性、稳定性、可插更多条内存 | 有极小的附加延迟；必须由服务器平台支持 | 云、通用企业服务器的主力 |
| **LRDIMM** | 比 RDIMM 多用数据缓冲器，进一步减轻内存控制器的电气负担 | 多 rank、超大容量配置 | 成本/功耗/延迟通常更高；通常不能与 RDIMM 混插 | 大型数据库、内存数据库、虚拟化密度优先 |
| **3DS RDIMM / 3DS LRDIMM** | 在每颗 DRAM 封装内部垂直堆多层 die；外面仍可做成 RDIMM/LRDIMM | 在有限插槽中把单条容量做大 | 良率、散热和成本更难；不是新的 CPU 接口 | 128GB、256GB 及更高容量服务器 |
| **MRDIMM** | 用模块上的逻辑把多个 rank 的数据路径复用/汇聚，提高有效数据率 | 每通道带宽、AI 推理和 HPC 性能 | 对 CPU 代际和主板支持要求高；第一代产品与平台绑定较强 | 高核数 CPU、带宽受限型数据库/HPC |

RDIMM 是最应先理解的基准：寄存器缓冲地址/命令，降低 CPU 内存控制器面对多颗 DRAM、多个插槽时的电气负担，因此可获得更高容量和稳定性；它并非单纯为了跑得更快。[Samsung 对 RDIMM 的说明](https://semiconductor.samsung.com/emea/dram/module/rdimm/m392b5270dh0-ck0/)  LRDIMM 的额外数据缓冲则把“多插槽、高 rank 的容量扩展”再往前推一步；两者的电气架构不同，很多服务器不能混插，必须以 CPU/主板认证列表为准。[Samsung 兼容性说明](https://semiconductor.samsung.com/dram/ddr/)

MRDIMM 的误解最多。它不是 HBM 的平替，也不是单纯“更高频的 RDIMM”，而是 DDR5 DIMM 路线继续提高**每个 CPU 内存通道**带宽的办法。当前第一代产品可达到约 8,800 MT/s，Micron 给出的对比是相对其 DDR5 RDIMM 带宽提升约 39%；但首代主要对应特定 Intel Xeon 6 平台，开放的 JEDEC 后续规范仍在演进。因此研究上应把 MRDIMM 看成**高端服务器 DDR 的 ASP/bit 升级机会**，而不能把所有服务器 DDR5 出货都假设会立刻迁移过去。[Micron MRDIMM 说明](https://www.micron.com/products/memory/dram-modules/mrdimm) [AMD 的平台兼容性说明](https://www.amd.com/en/products/processors/server/epyc/memory.html)

##### 两个容易混淆的技术词：channel 与 rank

- **Channel（内存通道）**：CPU 到内存的一条并行高速道路。服务器 CPU 常有很多通道；通道数越多，能并行访问的 DIMM 越多，总带宽越高。
- **Rank（逻辑 rank）**：一条 DIMM 上可被独立选通的一组 DRAM 芯片，可以把它想成同一条内存上的“班组”。更多 rank 有利于做大容量和并行调度，但电气负载也更难控制，正是 RDIMM/LRDIMM/MRDIMM 出现的原因。

带宽可粗略理解为：**每通道传输速率（MT/s）× 64 bit ÷ 8 × 通道数**。例如 DDR5-6400 的一个 64-bit 通道理论峰值约 51.2GB/s；12 个通道约 614GB/s，实际应用会因读写比例、NUMA、内存填充方式和软件访问模式而低得多。这里的 MT/s 是“每秒传输次数”，不是简单等同于 MHz；DDR5-6400 的基础时钟约为 3200MHz，但每周期进行双倍数据传输。

##### HBM、SOCAMM2、CXL：为什么它们也被归到“服务器 DRAM”

| 名称 | 本质 | 为什么出现 | 与 RDIMM 的关系 |
|---|---|---|---|
| **HBM** | 多层 DRAM die 通过 TSV 堆叠、紧贴 GPU/ASIC 封装的高带宽内存 | AI 训练/推理对带宽的需求远高于普通 CPU 主内存 | 补充而非替代：HBM 服务加速器，RDIMM 服务 CPU 主内存 |
| **SOCAMM2 / LPDDR 模块** | 把低功耗 LPDDR 类 DRAM 做成可维护的紧凑模块；SOCAMM 是形态而非新的 DRAM 物理规律 | AI 服务器希望在空间、功耗、带宽、可维修性之间折中 | 仅适配专门设计的平台，不能插入普通 RDIMM 插槽 |
| **CXL Memory Module / CMM-D** | 卡上仍是 DRAM，但通过 CXL/PCIe 链路连接 CPU | 解决 CPU DIMM 插槽不足、内存池化和按需扩容 | 是“较远一层”的 DRAM：容量弹性更好，通常延迟/带宽不及 CPU 直连 DDR5 |

CXL 是互连协议，不是内存芯片。它让 CPU 以缓存一致的方式访问挂在外部设备上的内存，可用于内存扩展和池化；CXL Type 3 是典型的内存扩展设备。其价值是提高数据中心 DRAM 利用率、把较冷的数据放在更便宜或可共享的一层，而不是让所有访问速度与本地 RDIMM 相同。[CXL Consortium 概览](https://computeexpresslink.org/about-cxl/) [CXL DRAM 扩展说明](https://computeexpresslink.org/blog/dram-resource-scalability-enabled-by-cxl-1071/)

##### 这对研究 SK 海力士意味着什么

1. **先看层级，再看“服务器 DRAM 增长”这个大词。** HBM 增长和 RDIMM 增长都会计入 DRAM，但前者主要受加速器、封装和认证制约，后者更多受 CPU 平台、内存通道数、每通道容量与服务器出货驱动。
2. **高容量和高带宽都会抬高每台服务器的 DRAM 含量。** 3DS RDIMM 抬高 GB/服务器；MRDIMM 抬高 GB/s/通道；HBM 抬高 GB/s/加速器；CXL 则抬高可配置总容量。
3. **它们争夺同一部分 DRAM 制造资源，但利润弹性不同。** HBM 的供给还卡在 TSV/封装/良率；RDIMM/MRDIMM 主要受先进 DDR die、模块接口芯片和 CPU 平台认证影响；CXL 模组另受控制器、PCIe/CXL 生态和软件内存分层能力制约。
4. **追踪指标不能混用。** HBM 看 stack 数、每 stack 容量、加速器平台认证；RDIMM 看服务器 CPU 出货、通道填充率和 GB/通道；CXL 看平台支持和实际内存池化部署；NAND/eSSD 则看 TB、QLC 渗透和数据中心存储架构。

#### C. 移动、PC、显卡和汽车 DRAM：规模大，但弹性更强

这部分包括 LPDDR、LPCAMM、GDDR 和车规 DRAM 等，面向智能手机、PC、显卡、汽车及各类边缘设备。它提供广泛的 bit 需求和客户基础，但通常更容易受消费电子出货、库存调整与现货价格影响，产品差异化及合同能见度一般低于 HBM。公司 2026 年公开展示同时覆盖 LPDDR6、LPCAMM2、GDDR7 及车规 LPDDR/NAND，说明其并非只押注数据中心。[MWC 2026 产品组合](https://news.skhynix.com/en/mwc-2026/)

### 1.4 NAND、SSD 与 Solidigm：从卖“bit”走向卖数据中心解决方案

公司 2021 年完成 Intel NAND/SSD 业务第一阶段收购，并成立美国子公司 Solidigm；交易总价为 90 亿美元（第一阶段 70 亿美元，后续 20 亿美元）。公司当时明确的组合逻辑是：SK 海力士的移动 NAND 与 Solidigm 的企业 SSD 互补。[收购说明（公司披露）](https://news.skhynix.com/en/sk-hynix-completes-the-first-phase-of-intel-nand-and-ssd-business-acquisition/)

这使公司不只是卖 NAND die，也有更高附加值的 eSSD 渠道、控制器/固件和企业客户产品能力。业务链条可以拆为：

| 环节 | 海力士/Solidigm 的产品与角色 | 收入、毛利与风险 |
|---|---|---|
| NAND die | 176/238 层 NAND、321 层 2Tb QLC 等 | bit 供给和 ASP 决定周期底色；层数/密度提高一面降成本，一面扩大行业 bit 供给 |
| Client SSD / 移动存储 | cSSD、手机 UFS 等 | 规模化但更受 PC/手机销量、渠道库存与价格竞争影响 |
| Enterprise SSD | PCIe 企业 SSD、QLC eSSD、高容量产品 | 面向云与数据中心，产品认证、固件、可靠性和控制器能力提高附加值；AI 推理数据层是核心增量 |
| AI-NAND 新架构 | AIN P/B/D、HBF 等 | 仍属早期布局，取决于客户系统是否导入；不可按当前收入估值 |

321 层 2Tb QLC NAND 是该策略的代表：公司称其 2025 年开始量产、通过客户验证后商业化；以 32 个 die 同封装的方式瞄准超大容量 eSSD。公司产品展示已覆盖 245TB eSSD。[321 层 QLC 公告](https://news.skhynix.com/en/sk-hynix-begins-mass-production-of-321-layer-qlc-nand-flash/) [SC25 产品展示](https://news.skhynix.com/en/sk-hynix-showcases-advanced-ai-memory-at-sc25/)

这块业务的基本收入公式是 **NAND bit 出货 × 每 bit 实现 ASP**；若卖的是 eSSD，还叠加控制器、固件、产品形态和企业级可靠性带来的结构差异。QLC 的单位 bit 售价通常低于 TLC，但可在相同 wafer 上承载更多 bit，并适合大容量、成本敏感的数据中心层。不能只看“出货 bit 增加”：若 ASP 下跌快于 bit 增加，收入和利润仍可下降。

Solidigm 是这一业务的战略接口：它补足了海力士在企业 SSD 的产品与客户能力，使集团能将 NAND 供应、SSD 产品定义和云客户认证结合起来。第三方报道称其 Q2 2026 的服务器需求带动 Solidigm bit 出货环比增长 40%；这只是行业媒体转述的 Counterpoint 数据，不能替代公司分部业绩。[第三方市场跟踪](https://www.tomshardware.com/tech-industry/ymtc-breaks-into-the-top-three-nand-makers-for-the-first-time)

### 1.5 “Full-stack AI memory”是产品战略，不是第四个利润分部

公司把 HBM、AI-DRAM 与 AI-NAND 统称为 Full-Stack AI Memory，并将 CXL、PIM、HBF、定制 HBM 等列为中长期方向。[2026 股东大会表述](https://news.skhynix.com/en/78th-annual-general-meeting/) 这对研究很重要，但目前不应拆出一个“新业务估值”：

- **CXL 内存**：扩展/池化服务器内存，本质仍以 DRAM 模组为基础；
- **PIM**：让部分计算靠近内存，技术期权高于现阶段可确认收入；
- **HBF（High Bandwidth Flash）**：希望填补 HBM 和大容量 NAND 之间的数据层，仍需观察客户架构是否采用；
- **定制 HBM（cHBM）**：可能提高客户黏性和 ASP，但也提高共同开发、验证与单客户依赖风险。

换言之，“full-stack”更准确的理解是以同一客户的 AI 系统为单位交叉销售不同存储层，而不是公司突然拥有一项不受存储周期影响的软件服务收入。

#### NAND 增长桥：**主要由 ASP，bit 增长为辅**

公司未在中期财报中披露 NAND 的 H1 总 bit/ASP 同比数，因而不能将 H1 的 +321.5% 收入精确拆成两个百分点。但 Q2 电话会给出了足够明确的季度证据：

| 2026 Q2 NAND（含 Solidigm） | 环比变化 | 对收入的含义 |
|---|---:|---|
| 产品收入（公司中期财报） | **+89.7%** | 11.574 → 21.960 |
| bit 出货 | **+15% 左右**（管理层称 mid-teens） | 有助于收入，但不是主因；来自 Q1 低出货基数和 eSSD 销量扩张 |
| ASP | **+55% 左右**（管理层称 mid-50%） | 是主要增量；全产品线价格走强 |
| eSSD 收入 | **约翻倍** | 产品结构进一步放大了价格/收入弹性 |
| Solidigm 的 ≥30TB eSSD 收入 | **超过三倍** | 高容量企业 SSD 是重要的结构性增量，但公司未给出绝对金额 |

本人按中值复算：若 bit +15%、ASP +55%，仅这两个变量的收入乘数为 **1.15 × 1.55 = 1.7825**，即约 **+78.3%**；实际产品收入为 +89.7%。差额大致来自高容量 eSSD 产品结构、具体产品组合、汇率及四舍五入，而不是 bit 本身。也就是说，Q2 大约六成的收入增幅可直接归于 ASP 上涨，bit 与结构共同贡献其余部分。

因此，对问题的简答是：**NAND Flash 增长更快，首先是价格驱动，其次才是 bit 销量增长；而 eSSD/QLC 的产品结构把二者放大。** 这也解释了为什么 NAND 收入占比在 H1 从 20.0% 升至 25.4%：不仅卖得更多，更是以显著更高的实现价格销售。数据来自 [Q2 2026 电话会实录](https://www.investing.com/news/transcripts/earnings-call-transcript-sk-hynix-posts-record-q2-2026-results-as-shares-fall-93CH-4818480)；其中“mid-teens”“mid-50%”为管理层区间表述，复算仅用于量级判断。

### 2.5 必须避免的误读：Q2/H1 报表 EPS 不能直接拿来估值

Q2 净利润 93.923 高于营收 79.319、也显著高于营业利润 60.543。中期财报附注说明，2026 H1 的税前利润 174.325 中，净融资收益为 **76.251**，其中金融工具公允价值变动收益 **63.179**；H1 所得税为 40.057。这意味着 H1 归母 EPS 189,546 韩元中含有大额非经营性投资估值收益。[2026 H1 中期财报](https://financialfilings.com/filings/sk-hynix-inc/interim-quarterly-report/2026/56530973/)

#### 什么是“非经营性投资估值收益”

它不是“卖出更多 HBM/DRAM 的利润”，而是公司持有的一项金融资产在期末被**重新按市场或估值模型计价**后，账面价值上涨所形成的收益。K-IFRS/IFRS 9 下，若该资产被归为“以公允价值计入当期损益”（FVTPL），即使公司没有把它卖掉，价值上升也会直接进入当期损益表；若后续价格或估值下降，同一机制也会产生损失。[IFRS 9 分类说明](https://www.ifrs.org/issued-standards/list-of-standards/ifrs-9-financial-instruments/)

可以把它和卖芯片作一个区分：

| 项目 | 发生了什么 | 进入哪里 | 本期是否必然有现金流 | 能否作为存储业务的经常性盈利 |
|---|---|---|---|---|
| 卖 DRAM/NAND | 出货、确认收入，扣制造/销售费用 | 营业利润 | 通常会形成应收账款，后续转现金 | **可以**，但仍受存储周期影响 |
| 金融资产公允价值上涨 | 持有资产在报表日“更值钱” | 融资/金融收益、税前利润 | **不必然**；未出售时通常只是账面重估 | **不可以**，除非能证明可持续、可实现 |
| 处置金融资产的收益 | 已经卖掉资产，成交价高于账面价值 | 融资/金融收益 | 通常会有出售现金流 | 有现金，但仍不是芯片经营利润 |

海力士 H1 的数字非常极端：

| 2026 H1，万亿韩元 | 数值 | 含义 |
|---|---:|---|
| 营业利润 | 98.153 | 存储芯片业务本身的经营结果 |
| 金融工具**估值**收益 | **63.179** | 账面重估；占 H1 净利润 134.269 的约 **47%** |
| 已处置金融工具收益 | 0.182 | 与 63.179 相比很小，说明不能把大头视为已变现的出售收益 |
| 利息收入 / 股息收入 / 汇兑收益 | 0.493 / 13.980 / 5.080 | 也属于金融收益，但性质与估值收益不同 |
| 净融资收益 | 76.251 | 上述收益扣除利息、汇兑、衍生品等融资费用后的净额 |

财报的现金流量表把这笔 **63.179** 从净利润中反向扣除，以调节到经营现金流，正是它在 H1 不是经营现金流入的直接证据。公司披露的“金融资产处置收益”只有 0.182，而“估值收益”为 63.179；因此研究中应把两者严格分开。[融资收益附注与现金流调节](https://financialfilings.com/filings/sk-hynix-inc/interim-quarterly-report/2026/56530973/)

这笔收益并不是“公司拿闲置现金买债券”那么简单，**核心资产是对日本 NAND 厂商 Kioxia 的间接投资**。公司在中期财报的承诺事项附注中明确披露：集团通过 BCPE Pangea Cayman2 Limited 持有 Kioxia 相关权益；并因持股比例及董事提名权受限，不能对 Kioxia 的经营管理施加重大影响。[2026 H1 财报：Kioxia 投资附注](https://financialfilings.com/filings/sk-hynix-inc/interim-quarterly-report/2026/56530973/)

公司在 2026 年 7 月的正式披露还说明了这项投资的原始结构：2018 年参与 Bain 财团，向 SPC 1 投资 2.637 万亿韩元，并购买 SPC 2 发行的、可转换为 SPC 2 约 15% 权益的可转债 1.279 万亿韩元；公司将它们分类为 **FVTPL（以公允价值计入当期损益）**。该披露同时给出 2026Q1 末 SPC 1 / SPC 2 的账面价值分别为 6.616 / 13.609 万亿韩元。[公司 2026-07-10 正式披露](https://kind.krx.co.kr/external/2026/07/10/000103/20260710000123/10601.htm)

需要区分“公司一手披露”与“媒体对韩国语半年度报告的转述”：英文中期财报把 H1 的 **63.179 万亿韩元**按“金融工具估值收益”合并列报，并没有在同一张表中逐项列出每个标的的收益；但媒体依据韩国语半年度报告转述，其中 BCPE Pangea Cayman2 的估值收益为 **59.331 万亿韩元**，约占合并估值收益的 94%。因此，**Kioxia/SPC 2 是这笔异常收益的主要来源**这一判断为 🟡 基本属实；59.331 万亿这一逐项数值目前是二手转述，不应误写成英文财报逐行披露。[韩国媒体转述（2026-08-19）](https://v.daum.net/v/20260819084601278)

- **经营质量应优先看营业利润 98.153 与 74.4% 营业利润率**；
- H1 报表 EPS 可以用于核对会计利润，但不能直接年化为“经常性 EPS”或前瞻 P/E；
- 估值要使用对未来 DRAM/NAND 价格、HBM 组合、产量与税率的正常化 EPS 假设，而不是把这一笔公允价值收益当作存储芯片利润。

这不是对经营表现的否定：仅营业利润本身已创历史高位；而是为了防止将非经营性收益误判为芯片毛利。

### 2.6 资产负债与现金

公司披露，2026-06-30 现金及现金等价物为 **88.0**，总债务为 **18.6**，净现金为 **69.4**；均较 Q1 明显改善。[Q2 2026 业绩公告](https://news.skhynix.com/en/q2-2026-business-results/)

结论：公司短期并不受融资约束，真正的财务问题是资本开支后能否在下一轮价格下行时维持自由现金流，而不是偿债能力。

### LTA 到底披露了什么、没有披露什么

| 项目 | 公司已披露 | 没有披露，因而不能推算 |

| NVIDIA | 公司确认多年合作、先进内存供货和 HBM 共同开发，故可列为已确认的核心 AI 内存客户/合作方。 | 收入占比、采购量、合同金额、是否为客户 A/B、是否独家。 |

### 研究含义

长约提高短期排产与收入能见度，但不能把“约 10 家 LTA”直接翻译为“未来三年收入已锁定”。它不能消除两类风险：一是客户平台认证改变，二是客户 AI 资本开支放缓。后续最重要的验证不是新闻中的“合作”，而是 HBM4 实际出货、单客户/平台份额、应收账款回款与管理层是否开始量化 LTA 覆盖量。

## 4. 行业格局与竞争对手

### 4.1 DRAM / HBM

不能把“内存市占率”理解成一张可相加的总表：DRAM 与 NAND 是两个不同市场，而 HBM 是 DRAM 的子集。以下是截至 2026 Q2 可取得的最新第三方统计；DRAM、HBM 均为**营收份额**，NAND 同时给出营收与 bit 出货两个口径。

| 全球 DRAM 营收份额（2026 Q2） | 份额 | 备注 |
|---|---:|---|
| Samsung | 39.4% | 营收 609.8 亿美元 |
| SK 海力士 | 24.9% | 营收 385.9 亿美元 |
| Micron | 23.3% | 营收 360.0 亿美元 |
| 其余厂商合计 | 12.4% | 主要含 CXMT、Nanya、Winbond、PSMC 等 |

三巨头合计 **87.6%**，所以普通 DRAM 的边际供给、ASP 和利润几乎完全由 Samsung、SK 海力士、Micron 的产能/制程选择决定。TrendForce 同期统计的行业 DRAM 营收为 1,547.3 亿美元；价格上升是营收增长的主因、bit 出货仅温和增加。[TrendForce：Q2 2026 DRAM 营收排名](https://www.trendforce.com/presscenter/news/20260907-13219.html)

| 全球 HBM 营收份额（2026 Q2；DRAM 子集） | 份额 | Q1 2026 → Q2 2026 |
|---|---:|---|
| SK 海力士 | 50% | 58% → 50% |
| Samsung | 33% | 21% → 33% |
| Micron | 18% | 21% → 18% |

HBM 是更极端的三家市场。SK 海力士仍是第一，但不是“垄断”：其份额已从 2025 Q2 的 64% 降至 50%，而 Samsung 的 HBM4 出货使份额显著追近；这里不能把 HBM 的 50% 再加到 DRAM 的 24.9% 上。[Counterpoint：Q2 2026 HBM 份额](https://korea.counterpointresearch.com/global-hbm-market-share-q2-2026/)

#### 把 DRAM 拆开后，才是实际竞争格局

| DRAM 子市场 | 主要产品 | 谁决定采购 | 竞争的真正门槛 | 对 SK 海力士的意义 |
|---|---|---|---|---|
| HBM | HBM3E、HBM4 | GPU/AI ASIC 设计商与云厂商共同定义平台 | die 良率、TSV/堆叠、先进封装、功耗和客户平台认证 | 价值量和技术溢价最高；份额从 64% 降至 50% 是估值最敏感的变化 |
| 通用服务器 DRAM | DDR5 RDIMM、3DS RDIMM、MRDIMM | CSP、服务器 OEM、CPU 平台 | 大容量模组良率、DDR5/平台认证、稳定的长期交付 | 规模远大于单纯的 HBM；AI 服务器除 HBM 外也需要大量 CPU 内存 |
| 移动 DRAM | LPDDR5X、LPDDR6 | 手机 OEM / SoC 平台 | 低功耗、封装尺寸、手机客户认证 | 容量大但议价力低于数据中心，容易受手机销量和库存影响 |
| PC / 消费 DRAM | DDR4、DDR5、SODIMM | PC OEM、模组厂、渠道 | 成本、供货和合约价 | 更像周期品；当三巨头把晶圆让给服务器/HBM 时反而会出现被动紧缺 |
| 图形/汽车/工业 | GDDR、车规 LPDDR/DDR | GPU 厂、Tier-1、工业客户 | 可靠性、生命周期、认证 | 量较小，但汽车/工业认证使供给切换不如 PC 灵活 |

2026 年 DRAM 最重要的结构变化是数据中心需求已超过消费端。按 Counterpoint 的追踪口径，**服务器 DRAM 占全球 DRAM bit 出货约 48%，HBM 再占约 9%**，即数据中心/AI 合计约 57%；因单价更高，两者占行业营收约 65%。这里的 9% 是 HBM 的 bit 份额，不是营收份额，恰好说明 HBM 是“小 bit、大价值”的产品。[Counterpoint 数据的二手转述与口径](https://www.techtimes.com/articles/319284/20260701/more-half-dram-now-goes-data-centers-counterpoint-says.htm)

因此，2026 Q2 的 24.9% DRAM 营收份额不能被误读为“海力士只占全球晶圆的四分之一”。它是 **bit 出货 × ASP × 产品组合** 的结果。Counterpoint 另一套营收追踪显示，SK 海力士虽然 Q2 收入同比仍增 214%，份额却从上年同期 39% 降至 26%，原因是 Samsung 与 Micron 在当季的普通 DRAM/服务器 DRAM ASP 上涨与出货增长更快。[Counterpoint：Q2 2026 DRAM 份额变化](https://counterpointresearch.com/en/insights/ai-demand-reshapes-dram-rankings-in-q2-2026) TrendForce 的同口径数据也显示，行业收入大涨主要来自 ASP，bit 出货仅温和增长；所以本轮市场份额波动首先是**价格和产品组合的波动**，其次才是物理产能份额的变化。[TrendForce：Q2 2026 DRAM](https://www.trendforce.com/presscenter/news/20260907-13219.html)

#### 供给为何只由少数厂商决定

一片先进 DRAM 晶圆不是可以无成本地在 HBM、RDIMM、LPDDR 和 PC DDR 之间瞬时切换：前段制程、die 设计与良率要适配，HBM 还需要 TSV、减薄、堆叠、封装和测试。因而“某厂扩大 HBM”会同时发生两件事：一是提升每片晶圆的价值；二是挤占可供普通 DRAM 的有效供给。2026 Q2 的服务器 DRAM 数据显示，DDR5 已超过服务器 DRAM 出货的 90%，而 HBM 的产能分流继续限制 RDIMM 增长，供给紧缺与涨价预期延续到 2027。[TrendForce：服务器 DRAM Q2 2026](https://www.trendforce.com/research/download/RP260907MR)

三巨头短期增加 bit 的主渠道也不是立即新建大量晶圆厂，而是先进节点迁移、提高良率、改造洁净室和在产品间重新分配空间；这使供给弹性远小于价格上涨给人的直觉。Samsung 的规模与全产品线最强，Micron 聚焦高价值服务器 DRAM，SK 海力士则把更多产品结构压在 HBM 上。公司管理层也明确表示会按客户需求和中长期战略在 HBM 与普通 DRAM 之间分配销售组合；这正是海力士 ASP、出货与“市占”会季度性波动的原因。[SK 海力士 Q2 2026 电话会](https://stockanalysis.com/quote/krx/000660/transcripts/653208-q2-2026/)

#### 对海力士估值应看的三张成绩单

1. **HBM：** 守住多少收入份额、HBM4 的良率/认证和单位堆栈价值；这是利润质量与估值溢价的来源。
2. **服务器 DRAM：** 能否在为 HBM 分配晶圆后仍拿到高容量 DDR5 RDIMM/3DS RDIMM 的订单；这是利润规模的底座。
3. **普通 DRAM：** 当 PC/手机供给被压缩时价格能否维持；这会决定周期高点的利润是否被市场过度年化。

所以对股票最有用的结论不是“海力士的 DRAM 份额是 25% 还是 26%”，而是：**它在总 DRAM 中是第二大厂、在 HBM 中仍是第一；但其高估值依赖于 HBM 份额不继续向 Samsung/Micron 回落，同时服务器 DRAM 的紧缺足以覆盖普通 DRAM 周期回落。**

| 对手 | 相对位置 | 对海力士的含义 |
|---|---|---|
| Samsung | DRAM 龙头、制造规模和资本开支实力极强 | HBM4 客户认证、良率与价格竞争是直接压力；若份额加速上升，海力士的高端溢价会被压缩 |
| Micron | HBM 与先进 DRAM 的主要追赶者 | 在高端 AI 内存提升供货，会同时影响 HBM 价格和客户多元化采购 |
| CXMT 等中国厂商 | 以通用 DRAM 追赶为主 | 短期不是 HBM4 同等替代品，但会影响中低端 DRAM 的供需和价格底部 |
| Kioxia/SanDisk、Samsung、Micron、YMTC | NAND/eSSD 竞争者 | eSSD 与 QLC 可受 AI 推动，但 NAND 供给扩张及中国厂商份额变化会显著影响盈利 |

### 4.2 NAND：AI 利好，但比 HBM 更接近传统周期品

NAND 要特别区分“卖出多少 bit”与“赚到多少收入”：企业级 SSD 的单位价值高，因此两种排名会不同。

| 全球 NAND 营收份额（2026 Q2，TrendForce） | 营收 | 份额 |
|---|---:|---:|
| Samsung | 230.6 亿美元 | 29.3%（原始披露） |
| SK 海力士集团（含 Solidigm） | 142.7 亿美元以上 | 约 18.1% 以上（复算下限） |

### 5.1B 电力会不会卡住扩产：近端不是 M15X，Y1 初期已安排，远期电网是实质风险

**结论先行：截至 2026-09，电力不是 M15X 正在爬坡的已证实瓶颈，也不是 Y1 2027 年初开洁净室的基准情景瓶颈；但它是 Yongin 四座 fab 全部扩张时、尤其 2031 年以后最实际的执行风险之一。**

| 时间/对象 | 已落实事实 | 风险判断 |
|---|---|---|
| M15X（清州，当前爬坡） | 位于既有清州生产基地；公司已经在 2026 Q1 投片。公司未披露其 MW 负荷或电力受限信息。 | **未发现电力限制量产的证据**；跟踪重点仍是设备、先进 DRAM 良率与 HBM 后段。 |

### 5.1A 当前 HBM 的短板判断：先进 DRAM 晶圆/die 良率优先于自家封装测试

这是基于公开项目时间表和管理层表述的**研究判断**，不是公司披露了各段产能后的精确测量。对 2026 H2 能新增的 HBM 供给而言，最短板应先看 **先进 DRAM wafer 与合格 die 产出**：公司为提高近期 HBM/DRAM 供给响应而提前 M15X 量产，Q2 电话会又把 HBM4 的“规模化稳定良率、品质与产能爬坡”列为当前重点。每个 HBM stack 要同时凑齐多颗合格 die，因此前段良率的损失会被堆叠要求放大；增加先进 wafer input 才是近期可量化的扩产抓手。[Q2 电话会：M15X 与 HBM4 爬坡](https://stockanalysis.com/quote/krx/000660/transcripts/653208-q2-2026/)

封装/测试当然也是必要条件，但现有公开材料**不足以证明它是 2026 当下的绑定瓶颈**：P&T7 在建、目标 2027 年末完成，随后还要装机爬坡，因而不可能解释或解决 2026 H2 的即时增量；它证明的是公司在为 2028 后的 HBM 后段能力预留产能，而不是证明现有封测线此刻已经把 HBM4 卡死。公司也没有披露 wafer starts、HBM stack/月、封测利用率或各段良率，故不能把“未来需要建 P&T7”偷换为“现在封装已是最短板”。

还应把 SK 的 HBM stack 封装与 GPU/ASIC 的系统级封装（如 CoWoS）分开：后者可能限制加速器整机出货和客户拉货节奏，但不等同于 SK 海力士自身 HBM 的制造瓶颈。若后续出现 M15X 增投后 HBM stack 出货仍不增、或公司披露 P&T 交付/测试排队异常，才应把判断转向封装测试；在此之前，模型应优先跟踪 M15X 的先进 wafer 投入、1b/1c die 良率与 HBM4 合格 stack 产出。

### 5.4 2027 年供给会增加多少：区分晶圆、bit 与可售产品

“产能扩张”不能只用一个百分比回答。晶圆投片（wafer starts）增加后，先进制程/更高层数会继续增加每片的 bit；反过来，HBM 每 bit 消耗的晶圆显著高于通用 DRAM。因此，下表的 **bit 供给** 才更接近 ASP 与盈利的实际变量。

| 范围 | 2027 年可量化的增量 | 对供需的正确解读 |
|---|---|---|
| 全球 DRAM（含 HBM） | **bit 供给约 +24% YoY**（TrendForce 预测） | 不是“供给过剩”。新厂的有效产出主要在 2027 H2 后、更多在 2028；且 HBM 投片占全 DRAM 约 **30%**，高于 2026 年的 22%，继续挤占通用 DRAM wafer。HBM bit 占比约 13%，说明大量 wafer 并不等比例转换为更多通用 DRAM bit。|
| 全球 NAND | 免费公开资料**未给出可核验的单一 bit 增速百分比** | TrendForce 的判断是：高层数迁移、既有厂房填充与新厂逐步爬坡令 2027 bit 供给增速显著高于 2026，供需平衡在 **2027 H2 转正**。这比一个未经核验的“扩产 x%”更有投资意义。|
| SK 海力士 DRAM | 券商估计其 2026–2027 合计**净** wafer 产能约 **+9 万片/月（+18%）** | M15X 是主要近端来源。不同第三方对其 2027 满载口径为约 9 万片/月（净扩产锚）至 10–12 万片/月（M15X gross run-rate），不能混为一个精确值；Yongin Y1 在 2027 年初开放洁净室、装机/认证/爬坡按阶段进行，不能把未来满载产能一次性计入 2027 出货。|
| SK 海力士 NAND | **没有公司披露的 2027 新增 wpm 或 bit 指引** | 公司下一座专门 NAND 厂 M17 的洁净室目标为 2028 年末；2027 的增量主要只能来自 Dalian/Solidigm 既有厂利用率、制程与层数升级，而非 M17 新厂。因此海力士自身的 NAND 新晶圆扩张低于行业中中国厂商和其他新厂带来的边际供给。|

全球 DRAM bit +24% 来自 [TrendForce 2027 研究摘要](https://www.trendforce.com/research/download/RP260728GY)；HBM 投片/bit 占比来自 [TrendForce HBM 2027 预测](https://www.trendforce.cn/presscenter/news/20260602-13073.html)。NAND 的 2027 H2 转松判断来自 [TrendForce NAND 更新](https://www.trendforce.com/presscenter/news/20260721-13148.html) 与其[DRAM/NAND 分化展望](https://www.trendforce.com/presscenter/news/20260730-13158.html)。海力士 +9 万片/月为 [未来资产证券的第三方估计](https://securities.miraeasset.com/newir/view/pc/en/investor/researchReportsView.jsp?messageId=2338588)；M15X 2026 约 4 万片/月、2027 接近 10–12 万片/月为 [Samsung Securities](https://www.bondweb.co.kr/Data/20261/28/menu01/2026012820.pdf) 与 [LS Securities](https://consensus.hankyung.com/analysis/downpdf?report_idx=647122) 的第三方产能跟踪。公司仅确认 M15X 已在 2026 Q1 投片、将逐步爬坡，并未公开 WSPM 指引。[公司 SEC 文件](https://www.sec.gov/Archives/edgar/data/2120882/000119312526299963/d32785d424b4.htm)

**投资含义**：2027 年真正要警惕的是 NAND，不是因为它必然马上过剩，而是它最先出现“供给增长快于需求”的结构变化；DRAM 虽也增产，但 HBM 的 wafer 挤占和新厂爬坡滞后使其在 2027 年仍紧。若实际发生在 2027 H1 而非 H2，或中国 NAND 新增产能超预期，NAND ASP 与海力士 NAND 利润率会先承压；若 DRAM 的 24% bit 增长仍低于 AI 服务器需求，DRAM/HBM 的高 ASP 将延续更久。

### 5.4A 2027 海力士 DRAM 产能模型（底向上初版，2026-09-16）

**先给结论。** 在不把 Yongin Y1 的未来满产提前计入、且只把已投片的 M15X 纳入的基准情景下，模型得到：

- **2027 全年平均前段 DRAM wafer capacity：约 +9% YoY**；合理区间约 **+8% 至 +12%**。
- **2027 年末 run-rate 前段 capacity：约 +9% YoY**；合理区间约 **+7% 至 +15%**。
- 经 1c 制程迁移、良率爬坡和 HBM 对有效 bit 的挤占后，**可售总 DRAM bit capacity 的研究区间为约 +10% 至 +21%，基准约 +15%**。这不是收入或出货指引。

#### 先定“现在”的基数：约 55–60 万片/月 DRAM wafer starts，而非单一的 HBM 产能

海力士不公开按厂/产品的月投片表。按可追溯的第三方口径，2025 年 DRAM wafer capacity 约 **54.5 万片/月**，2026 年约 **60 万片/月**；另一份近期产业报道给出的较保守口径是，既有 DRAM 约 **50 万片/月**、加上刚爬坡的 M15X 后约 **55 万片/月**。因此截至 2026 年 9 月，最稳妥的表述是：**海力士 DRAM 的当前 run-rate 约为 55–60 万片 12 英寸晶圆/月**，即约 660–720 万片/年的物理投片能力。

这不是可直接出售的 DRAM bit，更不是 HBM stack/月：同一片 wafer 投向 HBM、服务器 RDIMM、移动/PC DRAM，会产生完全不同的 bit 数、良率和单位价值。公司只确认 M15X 于 2026 Q1 开始投片并逐步爬坡，并未给出 HBM 的投片份额或 stack 产能；行业资料把 2026 年海力士 HBM 投片估在约 **20 万片/月**，但该数字只能作为第三方情景锚，不能视为公司指引。[2025/26 DRAM 产能估计](https://files.futurememorystorage.com/proceedings/2025/20250805_BMKT-101-1_Avril-Wu.pdf) [55 万片/月的保守口径](https://en.sedaily.com/finance/2025/12/25/sk-hynix-to-launch-m15x-fab-in-may-2026-cementing-global-ai) [M15X 公司法定披露](https://www.sec.gov/Archives/edgar/data/2120882/000119312526299963/d32785d424b4.htm)

NAND 不应和上述 DRAM wafer starts 相加。公司也未披露集团 NAND 的当前总 WSPM；能核验的是大连一期约 **10 万片/月**，二期拟新增约 **5 万片/月**、目标 2027 H1 量产，因而这 5 万片不属于“现在”的产能。清州既有 NAND 厂的产能未有可靠的公开拆分，故报告不伪造合计数。[大连扩产的二手报道](https://www.tomshardware.com/pc-components/ssds/sk-hynix-to-expand-production-capacity-in-china-as-it-mulls-solidigm-ipo-report-claims-second-phase-of-fab-could-boost-local-production-by-50-percent)

#### A. 晶圆层：只计算已证实的近期增量

未来资产的“+9 万片/月、+18%”反推出海力士扩产前的标准化 DRAM 基数约 **50 万片/月**（90 ÷ 18%=500）；这只是为了使券商口径可复算，不是公司披露的实际 WSPM。Samsung Securities 估计 M15X 在 2026 年新增约 4 万片/月，LS Securities 估计 M15X 在 2027 年可接近 10–12 万片/月满载。假设 2026 年 M15X 从 0 线性爬至 4 万片/月，则 2026 全年平均总产能为 500 + 4/2 = **52 万片/月**。2027 的计算如下：

| 情景 | 2027 年末 M15X run-rate（千片/月） | 2027 平均总 WSPM（千片/月） | 对 2026 平均 WSPM 的增长 | 2027 年末对 2026 年末的增长 | 假设 |
|---|---:|---:|---:|---:|---|
| 保守 | 80 | 560 | **+7.7%** | **+7.4%** | M15X 慢于券商满载预期；Y1 不贡献 |
| 基准 | 90 | 565 | **+8.7%** | **+9.3%** | 采用未来资产的净扩产锚；Y1 不贡献 |
| 乐观 | 120 | 580 | **+11.5%** | **+14.8%** | M15X 接近 LS 的满载上沿；Y1 仍只作试产、不计全年平均 |

公式为：2027 平均 WSPM = 500 + (2026 年末 M15X 40 + 2027 年末 M15X run-rate)/2；2026 平均 WSPM = 500 + 40/2。这里刻意不把 Y1 的“2027 Q1 开洁净室”当作晶圆产出：洁净室开放后仍有设备安装、工艺认证和良率爬坡，提前计入会系统性高估 2027 年供给。

#### B. bit 层：制程升级不会等于 WSPM 的同比增速

1c 在 2027 Q1 预计会超过 1b 成为海力士最大 DRAM 制程，增加每片 wafer 的可用 bit 与成本竞争力；但公司没有披露 1c 相对 1b 的 die 面积、良率或各节点投片份额，因此不能把“1c 更先进”机械地写成某个确定百分比。[1c 成为主制程的行业跟踪](https://www.trendforce.com/news/2026/09/07/news-sk-hynix-1c-dram-reportedly-to-overtake-1b-as-main-process-in-1q27-as-it-prepares-for-hbm4e/) 为避免把不公开的工程参数伪装成事实，bit 预测显式采用如下**研究假设**：

| 情景 | 晶圆平均产能增长（上表） | 1c 渗透/良率带来的有效 bit 增量（假设） | HBM mix 提升对总 bit 的拖累（假设） | 可售总 DRAM bit capacity（模型输出） |
|---|---:|---:|---:|---:|
| 保守 | +7.7% | +4.0% | -2.0% | **约 +10%** |
| 基准 | +8.7% | +8.0% | -2.0% | **约 +15%** |
| 乐观 | +11.5% | +12.0% | -2.5% | **约 +21%** |

这里的“HBM mix 拖累”不是说 HBM 不计入 DRAM bit，而是指在相同前段 wafer 下，HBM 的较大 die、合格 die 筛选和堆叠损耗使可售 bit 的转换效率低于通用 DRAM。故上述 **+10% / +15% / +21%** 是透明的保守/基准/乐观估算，不是管理层指引；一旦取得 1c die size、M15X 实际投片或 HBM wafer allocation，应该直接替换这三个假设而非继续沿用。

#### C. HBM：可预测 bit，不能可靠预测 stack 数

HBM 的公司级 stack/月产能没有公开。公开的可靠行业锚是：三大厂 HBM wafer input 占全部 DRAM wafer input 的比例，预计从 2026 年的 **22%** 提高到 2027 年的 **30%**。[TrendForce](https://www.trendforce.com/presscenter/news/20260602-13074.html) 这意味着即使总 WSPM 只增约 9%，投向 HBM 的 wafer 仍可显著增加；但海力士自身的起始 HBM 投片份额、HBM4/4E 每 stack 的 die 配置、die/stack 良率和封测能力均未披露。因此本模型**不编造 HBM stack 增速**，而是将它作为需要用季度 HBM4 出货、M15X 投片和客户平台装机来验证的输出变量。

#### D. 把产能翻译成机柜：能算单柜需求，不能反推海力士能交付多少柜

以 NVIDIA 已公布的 **Vera Rubin NVL72** 为例：NVIDIA 披露 Rubin GPU 最高配置为 **288GB HBM4**、采用 12-Hi stack；海力士已展示的 12-Hi HBM4 为 **36GB**。若采用该 36GB 规格，则是 **8 个 stack/GPU**（288 ÷ 36），一个 72-GPU rack 对应 **576 个 HBM stack、20.736TB HBM**（作者复算）。这只是把公开规格换算成物理需求，不是 NVIDIA 对任一型号的正式 BOM。[NVIDIA Rubin 规格](https://developer.nvidia.com/blog/inside-nvidia-rubin-gpu-architecture-powering-the-era-of-agentic-ai/) [SK 海力士 36GB HBM4](https://news.skhynix.com/en/sk-hynix-showcases-next-generation-ai-memory-innovations-at-ces-2026/)

| 机柜层的量纲 | 计算 | 结论 |
|---|---|---|
| 1 个 Rubin NVL72 等价 HBM 需求 | 72 GPU × 288GB | **20.736TB HBM/rack** |
| 1 个 rack 等价 stack 数 | 72 GPU × (288GB ÷ 36GB/stack) | **576 stack/rack** |
| 10,000 个此类 rack | 576 × 10,000 | **576 万个 stack、207.36PB HBM** |
| 海力士可交付 rack 数 | 海力士实际合格 HBM stack ÷ 576 | **无法从公开资料计算** |

最后一行正是投资判断的边界：M15X 的 WSPM 不能直接除以 576。中间还缺少并且公司未披露的 **HBM 投片分配、每片可用 die、12-Hi die/stack 良率、封装良率、以及其中分给 NVIDIA/ASIC 客户的比例**。因此说“海力士 2027 能覆盖 x 万个机柜”会是编造精度。

但方向可以明确判断：全球供给难以满足所有数据中心想建的机柜。TrendForce 预计 2027 年三大厂 HBM 投片占 DRAM 投片约 **30%**、HBM bit 仅占总 DRAM bit 约 **13%**；同时 Rubin Ultra 和 AI ASIC 会继续抬升每颗加速器的 HBM 容量与出货需求。该机构判断 2027 年 DRAM 需求增长仍快于供给，新增 fab 的实质产出大多要到 2027 H2 以后、更多在 2028 年体现。[TrendForce：HBM 投片与需求](https://www.trendforce.cn/presscenter/news/20260602-13073.html) [TrendForce：2027 DRAM 供需](https://www.trendforce.com/presscenter/news/20260730-13158.html)

所以本报告的基准结论是：**海力士 2027 年总 DRAM 可售 bit 增加约 10%–21%、基准约 15%，但其新增 HBM 能力只能让优先/长约客户多拿到机柜配额，不能让行业整体“想建多少 Rubin/ASIC 机柜就建多少”。** 对单一客户能否满足，公开资料无法验证；对行业整体，答案是 **不能完全满足**，这也是 HBM 与服务器 DRAM 仍维持紧缺和高 ASP 的逻辑，而不是供给失效。

#### 这个模型会如何被证伪

1. M15X 在 2026 Q4 / 2027 Q1 的实际投片或设备导入慢于 4 万片/月锚，基准 WSPM 应下修；
2. Y1 若在 2027 H2 就有规模化 wafer output，基准没有计入的供给会上修；
3. 1c 良率低于预期，bit 增速会更接近晶圆增速而非 +15%；
4. HBM4/4E 合格 stack 低于客户需求，即使总 DRAM bit 如期增长，HBM 收入与利润也不会同步兑现。

### 5.4B M15X 的经济回收期：高 CapEx 不等于低回报

M15X 的长期总投资为**超过 20 万亿韩元**，且是分期进行的厂房、洁净室、设备投资；P&T7 的约 19 万亿是另一项先进封装/测试项目，不能粗暴相加后再除以 M15X 的 wafer 产能。[M15X 公司公告](https://news.skhynix.com/en/sk-hynix-to-produce-dram-from-m15x-in-cheongju/) [P&T7 公司说明](https://news.skhynix.co.kr/fact-02/) 以下测算只问一个问题：**若 M15X 约 9 万片/月的基准满产能力兑现，它靠自身新增 DRAM 经营利润多久能覆盖其 20 万亿投资？**

#### A. 单位经济的可复算锚

公司 2026 H1 披露 DRAM 收入 97.641 万亿韩元，机械年化为 195.283 万亿。把上一节由券商“9 万片/月 = +18%”反推的 50 万片/月标准化基数作为分母，得到当期的**混合 DRAM 收入强度**约为 3,255 万韩元/wafer（195.283 万亿 ÷ 600 万片/年）；它含全公司 HBM、服务器与通用 DRAM 的组合，**不是 M15X 的实际结算价**。M15X 9 万片/月满产则对应约 108 万片/年。公司没有披露 DRAM 分部营业利润，因此不能把公司 H1 74.4% 合并营业利润率冒充为 M15X 的真实利润率。

| 情景（研究假设） | 收入强度相对 2026 H1 | M15X 年收入（万亿韩元） | 假设营业利润率 | 税后经营利润 NOPAT（万亿韩元，按 25% 税率简化） | 20 万亿投资的静态回收期 |
|---|---:|---:|---:|---:|---:|
| 周期高位延续 | 100% | 35.2 | 70% | 18.5 | **约 1.1 年** |
| 正常化 | 50% | 17.6 | 40% | 5.3 | **约 3.8 年** |
| 下行周期 | 25% | 8.8 | 20% | 1.3 | **约 15.2 年** |

计算为：年收入 = 1.08 百万片 × 3,255 万韩元/片 × 收入强度；NOPAT = 年收入 × 假设营业利润率 × (1 - 25%)；回收期 = 20 万亿 ÷ NOPAT。25% 是韩国 2026 年大额应税所得的法定企业所得税最高边际税率的简化取值，未逐项模拟地方税、税收抵免、折旧、维持性 CapEx 和营运资本，因此该表是**项目经济性敏感度**，不是会计现金流预测。[韩国税率](https://taxsummaries.pwc.com/republic-of-korea/corporate/taxes-on-corporate-income)

#### B. 怎样解读这个看似夸张的结果

这解释了为什么存储厂会在景气高点花 20 万亿、却仍可能有极高回报：HBM/高端服务器 DRAM 的单位晶圆价值很高，而 fab 的固定成本在满产后被摊薄。若当前价格与产品结构维持，M15X **满产后的**静态回本可以接近一年；这不是说从 2024 年开工起一年就回本，因为资本支出和产能均是逐年投放、2026 才开始投片、2027 才接近满载。

按本模型的 M15X 爬坡假设（2026 平均 2 万片/月、2027 基准平均 6.5 万片/月），若周期高位延续，2026–2027 累计 NOPAT 约 17.4 万亿，约在 **2028 年初**覆盖 20 万亿；若回到“正常化”情景，累计回收则延至约 **2030 年**。这就是该投资真正的风险：不是晶圆厂永远回不了本，而是公司在价格/利润率高位建设的资产，若在满产时正好遇到 ASP 回落，回收期会从约 1–4 年拉长到十年以上。

#### C. 对估值的含义

高投资不应自动视为利空，也不能自动视为护城河。应追问的是：

1. M15X 的新增 wafer 是否继续投向 HBM/高容量服务器 DRAM，而非在下行期投向低价通用 DRAM；
2. 2027–2028 的 ASP 与产品组合更接近上表哪一行；
3. P&T7、Y1 等后续投资能否产生额外的高价值 HBM 出货，而不是仅把全行业供给推高。

## 6. 行业景气：短期紧，远期开始分化

### 当前（2026）

TrendForce 在 2026-07 的观点是：AI 服务器和大规模数据中心仍让 DRAM 供给极紧；但消费电子需求转弱、涨价速度较此前高基数阶段放缓。该机构预计 Q3 仍上调 DRAM/NAND 合约价，但幅度趋缓。[TrendForce 2026 Q3 展望](https://www.trendforce.com/presscenter/news/20260703-13134.html)

这与海力士 Q2 的经营现实一致：既有 HBM 的结构性高 ASP，也有普通 DRAM/NAND 的价格上行。因此当前利润并非只由 HBM 决定。

### 2027 以后

TrendForce 预计 NAND 到 2027 年供给增长会跑赢需求、供给约束在 2027 年下半年缓解。[TrendForce NAND 展望](https://www.globenewswire.com/news-release/2026/07/21/3330544/0/en/NAND-Flash-Supply-Growth-to-Outpace-Demand-in-2027-Easing-Supply-Constraints-in-2H27-Says-TrendForce.html)

对于 DRAM/HBM，公司的新增洁净室与同行扩产较晚，短期不会立即形成 wafer 供给冲击；但 2027–2029 是必须警惕的区间。供给风险还来自“相同 wafer 制造更多 bit”的节点迁移，而不仅是新厂。

## 7. 估值：先看 P/E，再用经营利润校验（只作情景，不给目标价）

韩国股票当然看 P/E；SK 海力士在韩国市场通常也会同时看 trailing P/E、forward P/E 和 P/B。只是存储行业盈利波动很大，**P/E 的分母必须是可持续 EPS，不能是周期高点或一次性收益驱动的报表 EPS**。

| 项目 | 数值 | 计算/说明 |
|---|---:|---|
| 收盘价 | 1,697,000 韩元 | 2026-09-14 收盘 |
| FY2025 基本 EPS | 62,044 韩元 | 公司中期财报列示的 FY2025 基本 EPS |
| **FY2025 trailing P/E（本人复算）** | **27.4x** | 1,697,000 ÷ 62,044；这是最干净的已实现 P/E 口径 |
| 2026 H1 报表基本 EPS | 189,546 韩元 | 含大额金融工具公允价值变动收益 |
| H1 EPS 机械年化的 P/E（本人复算） | 4.5x | 1,697,000 ÷（189,546 × 2）；**没有经济意义，不可作为 forward P/E** |
| 2026E 一致预期 EPS（第三方） | 349,281 韩元 | 聚合预测 |

这是非常极端的上行：既有 2025 H1 的低基数，又有 DRAM/NAND ASP 大幅上行、HBM/服务器 DRAM/eSSD 结构改善。它不能被当成常态增长率。若仅把 H1 年化，2026 年化营收约 263.8（比 FY2025 高 171.5%），年化营业利润约 196.3（比 FY2025 高 315.8%）；但 Q3/Q4 的价格、出货、产品组合和一次性项目均可显著改变全年结果。

### 7.2 “明年维持这个增长”会怎样：用 EPS × P/E 直接回答

不能把 2026 H1 的营收同比 +230.8%、营业利润同比 +489.4%原样再套一年：H1 报表 EPS 已含 63.179 万亿韩元的金融工具估值收益，无法从公开资料直接得到“纯经营、可持续”的 2026 EPS。作为市场基准，聚合预测的 2027E EPS 为 47.95 万韩元，较 2026E +37.3%；2028E 仍进一步到 51.98 万。这不是“明年再翻几倍”，但也意味着市场仍假设高盈利可至少延续至 2028。下面把真正需要下注的两个变量摊开：**明年正常化 EPS** 与 **市场愿意给的 forward P/E**。

| 前瞻 EPS（韩元/股） | 3.5x P/E | 4.0x P/E | 5.0x P/E | 6.0x P/E |
|---:|---:|---:|---:|---:|
| 350,000 | 123 万韩元 | 140 万韩元 | 175 万韩元 | 210 万韩元 |
| 400,000 | 140 万韩元 | 160 万韩元 | 200 万韩元 | 240 万韩元 |
| 450,000 | 158 万韩元 | 180 万韩元 | 225 万韩元 | 270 万韩元 |
| **479,499（2027E 一致预期）** | **168 万韩元** | **192 万韩元** | **240 万韩元** | **288 万韩元** |
| **519,784（2028E 一致预期）** | **182 万韩元** | **208 万韩元** | **260 万韩元** | **312 万韩元** |

表中股价为本人按 **股价 = EPS × P/E** 复算的敏感性分析，非目标价。反过来看，当前 169.7 万韩元相对于 2027 一致预期 EPS 47.95 万，隐含的就是约 **3.5x P/E**；相对于 2028 一致预期 EPS 51.98 万，也只有约 **3.3x**。

所以，“明年全年保持增长”不等于股价会按利润同比等比例上涨。用一致预期的 47.95 万 EPS 举例：若 P/E 仍是约 3.5x，股价就是现在的 **168 万**；即使盈利如预期增长，股价也基本已反映。只有市场把它重估到 5x / 6x，才对应约 **240 万 / 288 万**（约 +41% / +69%）；若周期担忧令 P/E 压到 3.0x，则约 **144 万**（约 -15%）。存储周期的典型风险正是：盈利继续改善，但市场因 ASP 见顶、HBM 份额变化或新增产能而继续压低 P/E。

**正确的估值顺序**：先判断 2027–2028 年正常化 EPS 能否达到市场预期的约 48 万 / 52 万韩元，再判断 HBM 的持续性和 NAND/DRAM 供需是否足以使 P/E 从目前隐含的约 3–4x 重估至 5x、6x，还是会压到 3.0x。EV/营业利润只应作为净现金较高时的交叉核对，不应盖过 P/E。

## 8. 核心矛盾、情景与跟踪清单

### 核心矛盾

**公司最强的业务期与最激进的行业供给准备，正在同时发生。**

HBM 的客户认证和先进封装能力令其产品结构显著好于普通存储厂；但当产业相信 AI 内存短缺是永久性的时，所有龙头都会试图增加未来产能。资本开支的最终回报要在 2028–2030 年才见分晓，而不是看 2026 Q2 的利润率。

### 三种情景（推演，非概率预测）

| 情景 | 需要看到什么 | 对经营的含义 |
|---|---|---|
| 乐观 | HBM4 高良率放量、份额稳定；AI 服务器量继续升；普通 DRAM 供给仍紧 | 高端组合延续，营业利润率可高于历史中枢更久 |
| 基准 | HBM 增长持续但份额逐步归一；DRAM/NAND ASP 在高位趋稳；CapEx 分阶段执行 | 收入仍增长，但利润率从异常高点回落；回报取决于投资纪律 |
| 悲观 | GPU/云 CapEx 放缓或客户转换；HBM4 良率/认证延迟；NAND 2027 先转松、DRAM 随后供给增加 | 高固定成本与扩产支出放大利润下行，市场会重估“正常化利润” |

### 错峰需求下行压力测试：NAND 在 T+6 月、DRAM 在 T+12 月开始下降

以下是用户设定的**假设推演**：从 2026-09 为 T0，NAND bit 需求在 2027-03（T+6）开始同比下降，DRAM/HBM 需求在 2027-09（T+12）开始同比下降。这里的“下降”指绝对 bit 需求同比收缩，而非同比增速仍为正、只是变慢；后者的后果会温和很多。

| 时间 | 供需变化 | 对 SK 海力士经营 | 股价/估值通常先反映什么 |
|---|---|---|---|
| T0–T+6 | 两类需求仍强；DRAM 继续受 HBM wafer 挤占，NAND 仍处在供给恢复前夕 | 高 ASP 与高营利率大体延续，市场容易继续上调近端 EPS | 市场会先交易“高点可持续多久”，而不是当季利润 |
| T+6–T+12 | NAND 需求先降；同期正逢 NAND 高层数迁移、既有厂填充及新线逐步爬坡 | eSSD/消费 NAND 出货、ASP 或两者至少一项承压；库存先升、合约价随后下修。DRAM/HBM 仍可部分对冲，使合并营收未必立刻下滑 | 海力士的 NAND 利润率与 Solidigm 去库存会先被下调；即使 DRAM 业绩仍好，股票也可能因 2028 EPS 被砍而先跌 |
| T+12 以后 | DRAM/HBM 需求也转弱，而 2027 年 DRAM bit 供给原本仍预计增长约 24% | 现货/通用 DRAM 先转弱；HBM 因客户认证、长约与供给限制滞后，但新增议价和后续合约也会承压。两条业务同时下行后，固定成本与折旧会使营业利润下降快于营收 | 此时不会因为 trailing P/E 变低就安全：分母（未来 EPS）会被连续下修，市场往往给更低的周期 P/E |

这会使原本“2027 H2 NAND 供需才转松”的基准情景明显提前。TrendForce 的基准是 NAND 在 2027 H2 才逐渐平衡、DRAM 仍紧；因此上述假设的本质是**需求端比行业基准提前约两个季度转弱**，不是普通的价格涨幅放缓。[NAND 基准](https://www.trendforce.com/presscenter/news/20260721-13148.html) [DRAM 供给基准](https://www.trendforce.com/research/download/RP260728GY)

用 2026 H1 实际收入结构作机械敏感性（DRAM 74.0%、NAND 25.4%，其他不变；**不是盈利预测**）：

| 业务收入变化 | 对合并营收的直接影响 |
|---|---:|
| NAND -30% | 约 **-7.6%** |
| NAND -50% | 约 **-12.7%** |
| DRAM -30% | 约 **-22.2%** |
| DRAM -50% | 约 **-37.0%** |

实际利润冲击通常比这张营收表更大：存储有高固定成本，且公司没有披露 2026 年按 DRAM/NAND 的营业利润，不能把营收跌幅直接等同于利润跌幅。这个压力测试的关键结论是：**T+6 的 NAND 下行本身不足以摧毁海力士，但会先终结“全业务同时上行”的叙事；T+12 的 DRAM/HBM 下行才是决定估值是否发生周期性重置的拐点。**

### 延后下行压力测试：NAND 在 T+12 月、DRAM/HBM 在 T+18 月开始下降

这是比上一情景温和、也更贴近“2027 年利润能否兑现”的假设：NAND 到 2027-09 才开始同比下降，DRAM/HBM 到 2028-03 才下降。它允许 2027 年的大部分时间继续享受高 ASP 与供给偏紧，因此与当前 2027E EPS 47.95 万韩元的市场预期**基本相容**；但它与市场仍预期 2028E EPS 再增至 51.98 万韩元的假设并不完全相容，因为 DRAM/HBM 的需求下行会影响 2028 年九个月。

| 时点 | 经营后果 | 对“贵不贵”的含义 |
|---|---|---|
| T0–T+12（至 2027-09） | DRAM/HBM 高景气仍在，NAND 也尚未实际下行；2027 全年盈利大概率接近或超过现有共识 | 现价相对 2027E EPS 约 **3.5x P/E**，并不贵；但这不是无条件低估，而是市场已预先折价 2028 以后周期回落 |
| T+12–T+18（2027-09 至 2028-03） | NAND 先跌，海力士合并盈利仍有 DRAM/HBM 托底；但分析师会先下调 2028 EPS | 股价通常不会等 DRAM 实际下跌才反应；forward P/E 看似更低，实则分母在被下修 |
| T+18 以后（2028-03 起） | DRAM/HBM 需求下降与 2027 年供给扩张叠加；通用 DRAM 先承压，HBM 的价格和收入通常滞后 1–2 个季度 | 若 2028 EPS 只能落在 30–40 万而非市场预期的约 52 万，按 3.5x–4x P/E 对应股价约 **105–160 万韩元**；这是风险区间，不是目标价 |

| 2028E 正常化 EPS 假设 | 3.5x P/E | 4.0x P/E | 5.0x P/E |
|---:|---:|---:|---:|
| 300,000（明显周期回落） | 105 万韩元 | 120 万韩元 | 150 万韩元 |
| 400,000（温和回落） | 140 万韩元 | 160 万韩元 | 200 万韩元 |
| 519,784（当前市场共识） | 182 万韩元 | 208 万韩元 | 260 万韩元 |

**基于这个延后下行假设的研究结论**：海力士在 169.7 万韩元不是“贵股”——它以 2027E 约 3.5x、2028E 约 3.3x 的前瞻 P/E 交易；但也不是可以因为低 P/E 而忽略周期的深度价值股。若投资者确信 NAND 下行不会早于 2027-09、DRAM/HBM 不会早于 2028-03，则当前估值有安全垫，收益主要来自盈利兑现和 P/E 从 3–4x 回到 5x；若这两个时点提前，尤其 DRAM/HBM 在 2027 年内转弱，市场共识 EPS 与低 P/E 会一起失效。这里的“值得买”只能成立为**看好上述时间表的周期性仓位**，不应建立在“HBM 让存储永远脱离周期”的假设上。

### 后续季度最该跟踪的八项

1. HBM4 的收入占比、出货与良率，而非仅“完成开发”或“送样”；
2. HBM 市占能否守住约 50% 的第三方观察值；
3. HBM4 ASP 与 HBM3E 的替换节奏；
4. 普通 DRAM 的 bit 出货、ASP 和服务器产品占比；
5. NAND/eSSD 的价格、321 层 QLC 认证及 M17 装机节奏；
6. 长约是锁定数量、价格还是仅框架合作；
7. 2026 CapEx 最终值、M15X/Y1 实际投产及 P&T7 封装能力；
8. 将净利润拆回经常性口径，并跟踪自由现金流而非只看会计利润。

## 9. 当前判断与研究边界

### 当前判断

1. **基本面强度：✅ 已验证。** FY2025 与 2026 H1 的营收、营业利润和净现金均由公司披露支持；高端 AI 内存并非概念。
2. **HBM 龙头：✅ 已验证，但份额有下行压力。** 公司已实际开始 HBM4 量产出货；第三方追踪仍列第一，但份额由高位下降，不能假定其永久占优。
3. **“存储已脱离周期”：❌ 不成立。** HBM 改善产品结构，不会消除 DRAM/NAND 的供需、价格和 CapEx 周期。
4. **“当季低估值”：⚠️ 不可直接下结论。** H1 营业利润年化会夸大可持续盈利；Q2 净利还含显著非经营性项目。
