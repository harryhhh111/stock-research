# 1GW AI Factory 价值量测算

> 整理/核对日期：2026-08-25。核对状态：Morgan Stanley BOM 表已逐项反推单柜口径核实（✅）；JLL/Bernstein/NVIDIA 锚已核原文；口径警示见 §3 注、§5 注、§10 注。

好。现在开始“算钱”时，我建议先别急着给 Vertiv、Eaton、Micron 分收入，而是先回答最基础的：

> **建成 1 GW AI Factory，钱到底花到哪里去了？**

这一次我们已经有一个很好的条件：Morgan Stanley 对 **GB300 NVL72 和 Vera Rubin NVL72** 都做了同口径单柜 BOM 估算，而我们前面已经推导出了每 GW 对应多少个计算柜。因此可以直接相乘。

## 1. 先算最确定的一块：GPU 计算柜

沿用我们前面的 1 GW 模型：

* GB300：约 **6,400 个 NVL72 compute rack / GW**
* Rubin 完整 Factory：约 **3,200 个 NVL72 compute rack / GW**

Morgan Stanley 的 2026 年估算是：

* GB300 NVL72：约 **$3.995M/柜**
* Vera Rubin NVL72：约 **$7.803M/柜**

也就是说 Rubin 单柜几乎正好是 GB300 的 **2 倍**。这个估计也被 Tom's Hardware 等媒体交叉报道；Rubin 单柜约 $7.8M、GB300 约 $4M。([新浪财经][1])

于是：

### GB300

6,400 × $3.995M

≈

# **$25.6B / GW**

### Rubin

3,200 × $7.803M

≈

# **$25.0B / GW**

这出现了第一个非常漂亮的结果：

> **Rubin 的 GPU 数少了一半，机柜也少了一半，但单柜价格接近翻倍，所以每 GW 的核心计算机柜投资基本没下降。**

GB300：

**~$25.6B**

Rubin：

**~$25.0B**

几乎一样。

---

# 2. 更有意思的是：这 $25B 内部的钱完全重新分配了

直接把 Morgan Stanley 单柜 BOM × 我们的机柜数量：

| 计算柜内部               | GB300 / 1GW | Rubin / 1GW |   Rubin变化 |
| ------------------- | ----------: | ----------: | --------: |
| GPU                 | **$16.13B** | **$12.67B** |  **-21%** |
| CPU                 |      $1.15B |      $0.58B |      -50% |
| NVLink Switch芯片     |      $0.41B |      $0.46B |      +11% |
| 其他网络芯片              |      $1.67B |      $1.84B |      +10% |
| Memory              |  **$2.39B** |  **$6.41B** | **+168%** |
| Rack liquid cooling |      $0.41B |      $0.23B |      -44% |
| Rack power supply   |      $0.37B |      $0.24B |      -34% |
| PCB                 |      $0.22B |  **$0.37B** |      +66% |
| ABF + MLCC          |     ~$0.08B |     ~$0.08B |      大致持平 |
| 其他+组装               |     ~$2.72B |     ~$2.09B |      -23% |
| **合计**              | **$25.57B** | **$24.97B** |  **约-2%** |

BOM来源仍然是 Morgan Stanley 的估算，不是 NVIDIA 官方报价；但它最大的价值就在于两代产品采用了**同一套拆分方法**，因此非常适合做代际比较。([新浪财经·大摩研报转载][1]；原转引页 log.eurekapu.com 已 404，2026-08-25 起改挂此源)

---

# 3. 这个结果特别值得注意：Rubin 少买 GPU，但疯狂买 Memory

GB300：

> **GPU：$16.1B/GW**

Rubin：

> **GPU：$12.7B/GW**

所以按照我们目前的 Rubin 完整 Factory 模型：

# NVIDIA GPU silicon 的美元需求/GW反而下降约21%。

但 Memory：

GB300：

> **$2.4B**

Rubin：

> **$6.4B**

直接增长：

# **约2.7倍。**

这就是非常大的价值转移。

不过这里千万不要把：

> $6.4B = HBM4市场

这样算。

**不对。**

Morgan Stanley 的“Memory”里面至少包含：

* GPU HBM4
* Vera CPU 的大量 LPDDR5X / SOCAMM2
* 3D NAND

Rubin 的一个 NVL72 就有约54TB CPU-side LPDDR5X，而且报道估计仅 3D NAND 就可能达到约 **$1M/rack**；所以 Rubin 的 $2M/rack memory BOM 并不是单纯 HBM。([Tom's Hardware][3])

> **⚠️ 存储口径警示（2026-08-25 核对加入）**：Bernstein 的 GB200 口径里存储仅占 capex ~1–1.5%（~2PB/柜 ≈ $2 万硬件），与 Morgan Stanley 的 VR200 单柜 3D NAND ~$1M 相差约 50 倍——本质分歧是**是否计入 CMX/大容量配置**。这与 `存储与NAND/NAND需求测算.md` 的"CMX 是最大摇摆项"互为印证：拿 $1M/柜 × 机柜数直接外推 NAND 需求会显著高估基准情形。另外 Tom's Hardware 同文标题写 +485%、正文写 +435%，以正文（与 $374k→$2.0M 自洽）为准。

因此后面我们研究：

**SK hynix / Micron / Samsung / NAND**

一定还要继续拆。

但大方向已经很明显：

> **Rubin 时代 Memory 在系统中的价值量明显提高。**

# 4. NVIDIA 自己能拿走多少？

Rubin这里我们甚至有一个比较好的数字。

Morgan Stanley估计 NVIDIA 大客户批量销售：

* Rubin GPU：约 **$55,000**
* Vera CPU：约 **$5,000**

所以一个 NVL72：

72 × $55,000

*

36 × $5,000

=

# **$4.14M**

仅仅：

> Rubin GPU + Vera CPU

就已经 $4.14M/rack。([Tom's Hardware][3])

1GW：

3,200 rack

×

$4.14M

=

# **$13.25B / GW**

而这还没包括 NVIDIA 卖的：

* NVSwitch
* ConnectX-9
* BlueField
* Spectrum-X / Spectrum-6
* 软件

所以：

> **1GW Rubin AI Factory，NVIDIA直接硬件收入池大概率至少是 $13B+，完整 NVIDIA content 很可能进一步向 $15B甚至更高走。**

这也和 Bernstein 对上一代 AI Factory 的估算很接近：他们估计 GPU 就占一个 $35B/GW AI 数据中心总 CapEx 的约39%，也就是约 $13.7B。([Investing.com][4])

# 5. 但 $25B 只是计算柜，还没盖数据中心

这时候才轮到：

> Vertiv / Schneider / Eaton / Siemens / Trane

这些公司。

JLL 对2026年全球数据中心的平均建设成本估计：

> **$11.3M / MW**

而且这个数字：

* 不包括土地
* 不包括 active IT equipment
* 液冷设施大约再有 **10% premium**

所以简单换算：

$11.3M/MW × 1,000MW

=

$11.3B

液冷：

×1.10

≈

# **$12.4B / GW**

这是一个很好的数据中心**房地产+机电基础设施成本基准**。([仲量联行][5])

> **⚠️ JLL 口径注（2026-08-25 核对加入）**：$11.3M/MW 的原始定义是**单租户 50MW 风冷数据中心的 shell-and-core**（建筑外壳+机电主干，2020 年 $7.7M → 2025 $10.7M → 2026E $11.3M）；液冷溢价 7–10% 来自 Turner & Townsend 而非 JLL。严格讲它低估了 1GW 液冷 AI Factory 的完整机电成本；本模型最终没跑偏是因为有全口径锚托底——Bernstein GB200 全口径 **$35B/GW**、Epoch AI 1GW AI 园区 **~$38B**，与 §6 小计一致。([Investing.com][4])

注意：

这 $12.4B 和刚才 $25B 的计算柜基本不重合。

一个是：

> 建筑、供电、制冷等 facility

另一个是：

> GPU计算设备。

这可以拿来做最重要的 top-down validation。

NVIDIA 在给投资者的材料里讨论 OpenAI 多GW基础设施时直接写：

> **Every 1GW build-out will require $50–60 billion in total spend.**

而第一GW使用的就是：

> **Vera Rubin platform。**

([英伟达][6])

> 出处注（2026-08-25 核对加入）：除 NDR deck 外，Bernstein 报告（经 Investing.com 转述）称同一 $50–60B/GW 数字出自 **NVIDIA FY26 Q2 财报电话会**——两处可能都讲过，双标注。Bernstein 自己 $35B/GW 的估算明显低于 NVIDIA 口径，并认为 NVIDIA 是"按未来更高单柜成本的前瞻口径"在说。([Investing.com][4])

这就非常有意思了。

我们的bottom-up：

> 已经能明确找到大约 **$40B+**

然后 NVIDIA 从真正的项目总投资角度说：

> **$50–60B/GW**

两者之间还有：

# **约$10–20B/GW**

没有被我们当前简单BOM完全分配。

> ✅ **悬案已解（2026-09-02）**：NVIDIA Q2 FY27 电话会官方口径 Rubin 每 GW 收入机会 **$40B**（vs Blackwell $25B）——缺口的主要去向是 NVIDIA 自己的非 GPU 内容扩张：**内存转售（SOCAMM 70% 毛利转售已确认，HBM4 口径待定）、POD 非 GPU 柜型（Groq LPX / Vera CPU / BlueField-4 STX）、三层网络内收（CPO）、软件**。逐项拆解见 [`NVIDIA每GW收入拆解.md`](../NVDA/财务与资本分配/NVIDIA每GW收入拆解.md)。

而这恰恰就是接下来值得研究的地方。

不是说我们算错了。

而是：

> **这10–20B到底去了哪里？**

# 12. 现在出现一个我认为非常重要的结论

前面你问：

> Rubin GPU少了一半，但效率提高多少？

现在和钱合起来看，就非常漂亮。

### GB300

约：

> **46万GPU**

Compute rack：

> **$25.6B**

### Rubin

约：

> **23万GPU**

Compute rack：

> **$25.0B**

也就是说：

# 同样1GW，NVIDIA生态并没有因为GPU数量减半而让客户少花一半钱。

反而：

> GPU少50%

↓

每颗GPU/每柜价值大涨

↓

Memory、network、PCB、storage价值大涨

↓

**核心IT投资仍然约$25B/GW。**

而我们上一轮算出来：

> Rubin FP4 inference peak / GW
>
> 约比GB300高 **25%**

在这个保守的 full-factory 口径下。

那么：

GB300：

> $25.6B / 1.00单位算力

Rubin：

> $25.0B / 1.25单位算力

所以：

Rubin每单位peak FP4 inference的**计算设备CapEx**：

约下降：

# **22%**

这就是Rubin真正的经济意义之一。

---

# 13. 而真正 Token/$ 的提升可能比22%大

因为刚才只是比较：

> theoretical FP4 peak。

没有把：

* HBM4带宽
* NVLink 6
* 1.6T networking
* KV Cache reuse
* CMX
* Agentic inference optimizations

这些提高**实际利用率**的东西全部算进去。

所以：

> **峰值FLOPS/$：至少明显改善**
>
> **Token/$：很可能改善得更多。**

但在没有GB300 vs Rubin同模型、同QoS的真实benchmark以前，我不会随便给一个“提高3倍”之类的数字。
