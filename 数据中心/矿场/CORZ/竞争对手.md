# 竞争对手与行业位置

> 核对：2026-09-21。CORZ 事实来自 Q、D；同业模式依据本工作区已有 IREN/HIVE/BTDR 研究及 9 月 17 日台账，不将其中旧数据冒充今日更新。[来源](来源.md)

| 对照组 | 与 CORZ 的关系 | 应比较什么 |
|---|---|---|
| TeraWulf、Cipher、Riot、Galaxy、Applied Digital、Hut 8 | 争夺大租户、可用电力、工程资源和融资的机房开发商 | IT MW、交付时间、净租金、完整 CapEx、承租人信用 |
| IREN | GPU Cloud 模式与机房开发重叠，但收入多含设备与算力价值 | 将机房层和 GPU 层分开后再比较 |
| HIVE | 自有站点改造与租用第三方机房运行 GPU 并存 | 确认每一合同的房东、设备所有人及电力来源 |
| Bitdeer | ASIC/挖矿、AI Cloud、AI colo 多条业务 | 只把 Tydal 等 colo 项目与 CORZ 租金直接比较 |
| CoreWeave | 当前最重要客户，也能自行开发/控制机房资源 | 客户采购量与自建选择，不仅是租约长度 |

【研究判断】供电、土地和建设交付的稀缺性有利于已具备资源的运营商，但公司新签长期合同仅证明当前需求，不能单独证明多年后的续租价格。大客户既带来规模，也有议价权；预付款、建设责任和信用支持可能比名义租金差异更重要。

CORZ 当前优势证据是已经发生的计费容量爬坡和第二组客户签约，而不是“矿企有电所以都能改”。未来供给增加、租户自建、建设成本上升或电网流程变化，都可能削弱先发优势。

不做未经同口径调整的 EV/MW 排名：总电力储备、可出租 IT、已签、已计费容量对应不同风险；新建方和客户出资改造方的剩余投资责任也不同。
