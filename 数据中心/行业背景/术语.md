# 术语表（数据中心项目专用）

> 规范（AGENTS.md §5）：本文件收数据中心/AI Factory 工程专用术语；跨项目通用术语（财务、NAND 行业）见根目录 `../../术语.md`。

## 内存 / 算力

HBM
高带宽内存（High Bandwidth Memory）：与 GPU 封装在一起的堆叠式 DRAM（如 HBM3E/HBM4，GB300/Rubin 均 288GB/GPU）。单价约为 NAND 的 100 倍量级；研究时要区分 bit demand 与 revenue demand。

LPDDR5X
低功耗 DRAM：Grace/Vera CPU 的板载内存（Grace 480GB、Vera 1.5TB/CPU），在 AI Factory 中充当 GPU 旁边的"大货架"（KV cache 二级池、data staging）。

KV Cache
键值缓存：Transformer 推理时缓存历史 token 的 Key/Value 中间结果，避免逐 token 重算。是可重算的临时状态，不是模型参数或用户数据；长上下文/多轮 Agent 场景下体积膨胀，催生 CMX 卸载需求。

CMX
Context Memory Storage：NVIDIA Rubin 代引入的 KV cache 卸载存储层（BlueField-4 STX/CMX rack），把推理上下文从 HBM 卸载到 NAND，是 AI 数据中心 NAND 需求最大的弹性变量。

FLOPS 口径
dense（稠密）与 sparse（稀疏）算力相差 2 倍；NVFP4/FP8/FP16 精度口径也不同。跨代际对比 GPU 算力必须统一口径，因此数据中心研究优先用 GW 而非 FLOPS。

## 机柜架构

BOM
物料清单（Bill of Materials）：一台设备拆解后的完整零部件清单。"BOM 自下而上估算"= 单台设备含量 × 出货量，只对 BOM 公开可查的品类（如 GPU 机柜）有效。

Compute Rack
计算机柜：装 GPU/CPU 的机柜（如 NVL72，GB300 142kW、Rubin 227kW）。GB300 Factory 中占 IT 功率 ~90–91%，Rubin 完整 Factory 降至 ~73%。

Support Rack
支持机柜：Compute Rack 之外的网络/存储/管理机柜。Reference Design 中约 1:1 配置，但大型园区会合并设备，实际数量未必等比。

Compute Tray / NVSwitch Tray
NVL72 内部单元：每柜 18 个 Compute Tray（各 4 GPU + 2 Grace + 4 ConnectX-8 + 1 BlueField）+ 9 个 NVSwitch Tray（柜内 NVLink 交换）。

POD
标准化、可复制的集群单元（一组预先设计好、作为整体工作的机架）。层级：GPU → Tray → Rack → POD → Cluster → Data Center。非固定 GPU 数标准。

LPX（Groq 3 LPX 柜）
Rubin POD 五种柜型之一：推理加速柜，256 颗 LPU/柜。LPU 来自 Groq（2026 年被 NVIDIA 收编），用 SRAM（128GB/柜、40PB/s 带宽）而非 HBM，专攻大模型推理的 decode 阶段（逐 token 生成、延迟敏感）；与 NVL144 分工——GPU 管 prefill+训练，LPU 管 decode。官方宣称 NVL72+LPX 组合对万亿参数模型 tokens +35×。

STX（BlueField-4 STX 柜）
Rubin POD 五种柜型之一：AI-native 存储柜，围绕 BlueField-4 DPU 建造，承载 CMX 平台——把 KV cache 从 HBM 卸载到 NAND SSD，跨 POD 共享复用（宣称 tokens/s +5×）。是 AI 数据中心 NAND 需求增量（CMX 摇摆项）的物理载体。

挂载比（自定义工作术语）
真实部署中每 1 个 GPU 计算柜搭配采购的非 GPU 柜（LPX/Vera CPU/STX/SPX）数量。NVIDIA 参考 POD 为 16 GPU 柜 + 24 非 GPU 柜（比值 1.5），但客户按负载选配：训练型挂载比趋低，agentic 推理型趋高。是 $40B/GW 拆解中 POD 非 GPU 柜收入（$4–13B/GW）的核心变量。

SU
可扩展单元（Scalable Unit）：Supermicro DCBBS 蓝图的基本复制单元，1 SU = 1,152 GPU = 5MW power envelope，可从 5MW 复制到 1GW。

DCBBS
数据中心构建块解决方案（Data Center Building Block Solutions）：Supermicro 的整柜级交付蓝图，含 compute/network/storage/power/cooling 端到端方案。

Scale-up / Scale-out
Scale-up = 柜内/超节点内的高速互连（NVLink，TB/s 级）；Scale-out = 柜间/集群间网络（Ethernet/InfiniBand，800G–1.6T/端口）。

Optical Scale-up
跨柜光互连 scale-up：Rubin Ultra NVL576 起，NVLink 域从"单柜 72 GPU"扩展到"8 柜 576 GPU"，柜间改用直接光互连。2026 GTC 修正后 NVL576 不再是单柜 600kW（2025 旧路线图），而是 8 × NVL72 物理机柜组成的计算单元；Kyber 单柜只做 NVL144。

NVLink / NVSwitch
NVIDIA 的 GPU 间高速互连技术及配套交换芯片：GB300 1.8TB/s/GPU（Gen5）→ Rubin 3.6TB/s（Gen6）。

ConnectX / BlueField（DPU）
NVIDIA 网络芯片线：ConnectX 是网卡（800Gb/s→1.6Tb/s/GPU），BlueField 是 DPU（数据处理器，卸载网络/存储/安全任务；BlueField-4 板载 512GB SSD 服务 KV cache）。

E1.S / E3.S / U.2 / M.2
SSD 物理外形规格。E1.S/E3.S 为服务器热插拔长条规格（GPU 机柜本地盘主流），U.2 为 2.5 寸服务器盘，M.2 多用于启动盘。

Nearline HDD（NL HDD）
近线硬盘：数据中心大容量机械硬盘（20TB+ 级），用于温/冷数据；Seagate、WD 双寡头。其 EB 出货增速与 AI 存储需求增速之差 = QLC eSSD 的替代缺口。

## 供电 / 电气

IT Load
IT 负载：进入 IT 设备（GPU/CPU/存储/网络）的功率。本工作区口径：1GW 数据中心 = 1GW IT Load，不是电网入口功率。

PUE
电能利用效率（Power Usage Effectiveness）= 总设施耗电 ÷ IT 耗电。现代高密度液冷 AI Factory 取 1.10–1.15；电网侧负荷 = IT Load × PUE。

GVA / MVA
视在功率单位（1 GVA = 10 亿伏安）。电气设备（变压器/UPS/PDU）按视在功率标称；与有功功率 GW 的换算差一个功率因数（PF≈0.95）。"installed GVA / IT GW"是研究电气设备商的正确指标。

UPS
不间断电源（Uninterruptible Power Supply）：市电中断时由电池撑住负载直到柴油机启动。GB300 Tier III 型设计约 1.6GVA installed/GW IT（含冗余）。

PDU / RPP / Busway
配电单元链：PDU（Power Distribution Unit，机房级配电，GB300 同样 ~1.6GVA/GW）→ RPP（远程配电盘）→ Busway/母线槽 → Rack PDU（柜内插排）。

N+1 / 4-to-make-3
冗余架构：N+1 = 多配一台备用；4-to-make-3 = 4 台设备承担 3 台的负载（冗余度 4/3）。冗余使 installed 容量显著大于实际负载。

Tier III
数据中心可用性等级（Uptime Institute）：可并行维护（concurrently maintainable），年停机 ~1.6 小时；AI Factory 主流设计等级。

MV / LV
中压 / 低压配电。链条：345/230/138kV 电网 → 主变（Main Transformer）→ 34.5kV MV → MV/LV 变压器 → 415/480V → UPS/PDU。主变 GVA 与机房配电变压器 GVA 必须分开统计。

Behind-the-meter
表后供电：数据中心自建电源（燃气轮机/光伏+储能）直连，不经过公用电网计量点。1GW IT ≈ 一座 1.3GW 级联合循环电厂（GE 7HA / Siemens HL 尺度）。

BESS
电池储能系统（Battery Energy Storage System）：园区级储能，用于削峰/备用/配合可再生能源。

Contracted / Connected Power
签约电力 / 已接入电力：neocloud 披露产能的口径。Contracted = 已签协议锁定的电力（Nebius 2026 年底目标 5GW）；Connected = 数据中心实际接入的电力（年底 800MW–1GW）。Connected → 收入还要经 commissioning、集群部署、客户 onboarding，滞后数月。均不等于 IT Load 或上电投产量。

## 电价 / 电力市场

LMP
节点边际电价（Locational Marginal Price）= 边际发电成本 + 输电损耗 + 拥堵成本。ISO（PJM/ERCOT/MISO）批发市场按节点实时出清，同一州不同节点价格不同。

Demand Charge
需量电费（$/kW-month）：按月度峰值功率收费，哪怕只冲到一次。数据中心电费 ≠ 电价×kWh，而是 energy + demand + capacity + transmission + riders 的总和。

Capacity Charge
容量电费：为确保极端天气下仍有足够发电能力而支付的费用，与电能量分开计价。

Data Center Tariff
数据中心专属电价：500MW–1GW 级项目超出传统 Large Industrial 分类后的专门费率。标杆 AEP Ohio（2025-07 起，≥25MW）：minimum demand 保底 ~85% 合同容量、4 年爬坡 + 8 年正式期、退出赔偿建设成本、50% 最低收费担保——实质 take-or-pay 化，监管目的是防止搁浅电网资产摊给居民。

Delivered Price / All-in Power Cost
电价三口径（详见 `美国电价结构.md` §7）：① PPA 发电侧价（~$30/MWh）≠ ② 送到变电站的 delivered 价（~$55–70/MWh）≠ ③ 含需量/容量/备用/自建变电站摊销的 all-in 全成本（~$60–90/MWh）。研究数据中心成本统一用 ③。

## 发电设备（GEV / 电力系统）

联合循环（CC / CCGT）
Combined Cycle：燃气轮机发电后，排气余热经余热锅炉（HRSG）再驱动蒸汽轮机二次发电。效率从简单循环 ~44% 提到 64%+，是新建大型气电的主流配置。单机 MW 数（如 9HA.02 571MW）指简单循环口径，电厂口径（1×1 CC ~838MW）大得多，比较数字时必须先确认口径。

H 级 / F 级 / E 级燃机
重型燃气轮机技术代际：H 级（最新旗舰，GE 9HA/7HA、西门子 HL、三菱 JAC，CC 效率 >64%）> F 级（全球主力存量）> E 级（老机型）。代际差距靠十几年研发 + 全速全载测试台验证，后进者极难跨越。

LTSA
长期服务协议（Long-Term Service Agreement）：燃机 OEM 对装机提供的多年期检修/换件/升级合同，是"卖机之后收几十年租"的载体；GEV 整体 backlog 超 55% 为服务业务。

Slot Reservation
产能预留位：燃机紧缺周期中，客户付不可退定金锁定未来交付机位（区别于正式合同）。GEV 口径：100 GW 已签合同 + 16 GW slot reservation = 116 GW。

Power Block
电厂动力岛成套设备：一台燃机 + 蒸汽轮机 + 发电机 + 余热锅炉 + 控制系统的组合（如越南 Nhon Trach 的 800MW block）。GEV 卖的是 block 而非单台燃机。

GSU
发电升压变压器（Generator Step-Up transformer）：把发电机出口电压升到输电电压的大型变压器，电厂/表后发电并网的必经设备。当前供应链最紧的品类之一：交期 ~144 周，需求 5 年 +274%（WoodMac Q2'25）。

HVDC
高压直流输电（High-Voltage Direct Current）：远距离/跨海输电和新能源并网的主流方案，换流站是价值核心；主要玩家 Hitachi Energy、Siemens Energy、GE Vernova。相对概念是 HVAC（交流）。

GIS / AIS
气体绝缘 / 空气绝缘开关设备（Gas/Air Insulated Switchgear）：变电站内控制和保护电路的开关柜；GIS 占地小、贵，AIS 占地大、便宜。

FACTS / STATCOM
柔性交流输电系统 / 静止同步补偿器：用于稳定电网电压、提升输电能力的电力电子设备，数据中心并网和新能源消纳都需要。

Book-to-bill
订单出货比 = 当期新签订单 ÷ 当期确认收入。>1 表示 backlog 在积累（如 GEV Electrification Q2'26 ≈1.7），是 2B 设备商最关键的先行指标。

## 散热

DLC
直接液冷（Direct Liquid Cooling）：冷却液通过冷板直接接触芯片。GB300 参考 ~78% 液冷负载；Rubin/200kW+ 时代 94–100%。

CDU
冷量分配单元（Coolant Distribution Unit）：把设施侧水与 IT 侧冷却回路隔离换热的关键设备（如 Vertiv XDU2300 ~2.3MW/台）。CDU 台数由单台容量+冗余架构决定，不可按小设计机械放大。

Cold Plate / Manifold
冷板（贴芯片的换热部件）/ 歧管（机柜级分液器）。液冷价值量拆解的基本单元。

Facility Cooling
设施侧散热：Chiller（冷水机组）、Cooling Tower（冷却塔）、Dry Cooler（干冷器）、CRAH/Fan Wall（机房空调/风墙）——处理风冷部分和液冷回水的最终排热。

## 网络 / 光通信

Transceiver BOM-equivalent
光模块 BOM 等效位：NVIDIA reference 口径 GB300 为 6.12 个/GPU。注意它含 twin-port OSFP、2×400G breakout、铜连接等，不等于 800G 光模块颗数，不能直接 × ASP。

OSFP / Breakout
OSFP = 800G/1.6T 光模块封装；Breakout = 一个高速端口拆成多个低速端口（如 800G→2×400G），使"端口数"与"模块数"口径分离。

AEC / DAC
有源电缆 / 直连铜缆：短距柜内互连的铜方案，替代部分光模块。

CPO / Silicon Photonics
共封装光学 / 硅光：把光引擎与交换芯片封装在一起（Rubin 代 Spectrum-6 开始引入），价值量从可插拔光模块迁往 CPO，算光模块需求时必须区分。

East-West / North-South
东西向流量 = 集群内部 GPU↔GPU 流量（AI 训练极大）；南北向 = 数据中心与外部用户的流量。AI Factory 网络设计由东西向主导。

## 设施 / 商业模式

### 容量披露口径（2026-09-21 补充）

- **Gross power**：园区总电力容量，包含 IT 设备之外的制冷、配电等用电；须另核对是规划、已取得供电权还是已送电。
- **Leasable / Leased capacity**：可出租容量 / 已签约出租容量；均不自动等于建成或起租容量。
- **Billable capacity**：已满足合同计费条件的容量；用于观察租约兑现，比合同总额更接近当前收入阶段，但不等于客户 GPU 实际满负荷用电。
- **HDC**：Core Scientific 披露中的 High-Density Colocation（高密度托管），主要提供可容纳高功率设备的机房及配套服务。

以上按 [CORZ 2026Q2 季报](https://investors.corescientific.com/sec-filings/all-sec-filings/content/0001839341-26-000014/core-20260630.htm) 的业务与容量披露整理；跨公司比较时应重新核对各自定义。

Colocation（Colo）
租用第三方数据中心运营商（Equinix、Digital Realty 等）已建成的机房空间、电力容量、制冷与配电，把自己的 GPU/服务器放进去运营。与自建的权衡：**成本更高**（多一层房东：场地+电力容量+制冷+UPS/配电+运维+房东利润，约 +$2–4M/MW/年），但**上线更快**（自建 100MW 需 2–3 年走完土地/电网/变电站/建筑/冷却/commissioning，colo 现成容量几个月即可装机）。算力紧俏时"早一年上线"往往比省房租值钱——这是 Nebius/HIVE 采用 colo 混合模式的原因。反例：IREN 自持土地/电网/变电站，现金成本仅 ~$1.5M/MW/年。
