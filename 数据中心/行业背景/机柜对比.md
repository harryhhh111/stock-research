# GB300 NVL72 vs Vera Rubin NVL72 机柜对比

> 整理/核对日期：2026-08-21（2026-09-02 补充 §5.2 NVL576 架构修正、§5.3 代际生命周期）。Rubin 规格 NVIDIA 仍标 preliminary，后续可能调整。
> 状态：截至 2026 年 8 月，GB300 已出货；Vera Rubin 已全面投产，按计划 2026 下半年出货。([英伟达][1])

**一句话结论**：两代都是"72 GPU + 36 CPU"的 NVL72 外形，GPU 数量不变，但单 GPU 算力、HBM 带宽、NVLink、scale-out 网络、CPU 内存和整柜功率密度全部大幅升级——Rubin 的升级是系统级的，不是芯片级的。

## 1. 规格对比表

|               | **GB300 NVL72** | **Vera Rubin NVL72** |        变化 |
| ------------- | --------------: | -------------------: | --------: |
| GPU           |       72 × B300 |           72 × Rubin |      数量不变 |
| CPU           |      36 × Grace |        36 × **Vera** |     CPU换代（72核→88核/CPU） |
| 晶体管/GPU       |            208B |             **336B** |      +62% |
| dense NVFP4/GPU |        ~15 PFLOPS |         **50 PFLOPS** |   **~3.3×** |
| HBM/GPU       |     288GB HBM3E |       **288GB HBM4** |    容量不变、代际升级 |
| HBM带宽/GPU     |      **8 TB/s** |          **22 TB/s** | **2.75×** |
| 整柜GPU HBM     |    20.7TB / 576TB/s |     20.7TB / **1,580TB/s** |  容量不变、带宽2.75× |
| CPU内存/CPU       |   480GB LPDDR5X |     **1.5TB LPDDR5X** |   **~3.1×** |
| 整柜CPU内存       |     ~17.3TB |              **54TB** |   **~3.1×** |
| 整柜内存合计(HBM+CPU) |        ~38TB |            **~74.7TB** |      **~2×** |
| 柜内本地SSD（不含CMX）   | **~311TB**（参考配置） |        E1.S Gen6，容量未公开 |      见注 |
| NVLink        |    Gen5，1.8TB/s/GPU |   **Gen6，3.6TB/s/GPU** |    **2×** |
| 整柜NVLink      |         130TB/s |          **260TB/s** |    **2×** |
| Scale-out NIC |  ConnectX-8，800Gb/s/GPU | **ConnectX-9，1.6Tb/s/GPU** |    ~2× |
| 整柜scale-out   |        57.6Tb/s |         **115.2Tb/s** |       2× |
| DPU           |     BlueField-3 |      **BlueField-4** |        换代 |
| Rack功率        |         ≤约142kW |          **约227kW级** |     ~60%↑ |
| 每GPU摊机柜功率    |        ~1.97kW |           **~3.15kW** |     +60% |
| Rack冷却        |        液冷（~90%热量） |      **全液冷、45°C进水** |     热密度大增 |

**表注**：

- GB300 数据来自 NVIDIA 当前 Reference Architecture；Rubin 规格为 preliminary。([NVIDIA Docs][2])
- CPU 内存为官方规格：Grace 480GB LPDDR5X/CPU，Vera 1.5TB LPDDR5X/CPU。([英伟达][6])
- 柜内 SSD：GB300 按 Lenovo 官方产品指南，每 compute tray 参考配置 4×3.84TB E1.S 数据盘 + 1×1.92TB M.2 启动盘，整柜 18 tray ≈ 277TB 数据 + 35TB 启动；盘位满配 8×7.68TB/tray 即 ~1.1PB（Supermicro "144 E1.S bays" 口径一致）。Rubin 确认有 E1.S PCIe Gen6 + M.2，但盘位/容量未公开；BlueField-4 板载 512GB SSD（整柜 ~9.2TB）本质服务 KV cache，按 CMX 口径未计入。([Lenovo][10])

## 2. 算力：单 GPU 约 3.3 倍

- NVIDIA 官方口径（Rubin vs 基础 Blackwell）：inference ~5×、training ~3.5×、HBM 带宽 ~2.8×、NVLink ~2×。([NVIDIA Developer][3])
- 注意基准差异：5× 是相对 B200（10 PFLOPS NVFP4）；相对 B300（~15 PFLOPS）只有 **3.3×**。真实 token 吞吐还受模型、batch、网络、KV cache 影响，不等于参数比。
- NVIDIA 宣称 Rubin 相对 Grace Blackwell 大规模部署 **10× agent throughput**、1/10 cost per token；与 Groq 3 LPX 组合宣称 35× inference per watt——均为特定 workload 口径，不能当通用基准。([NVIDIA Developer][5])

## 3. 内存：HBM 容量冻结，带宽和 CPU 内存暴增

- **HBM 容量不动**（288GB/GPU、20.7TB/柜不变），带宽 8→22TB/s（2.75×）：Rubin 靠"喂数据更快"而非"堆更多容量"。对 SK hynix / Micron / Samsung 而言，要区分 **bit demand**（不涨）和 **revenue demand**（HBM4 单价、堆叠、技术难度全变）。
- **CPU 内存 ~3.1×**（17.3TB → 54TB LPDDR5X）：Rubin 针对 Agentic AI（sandbox、tool execution、RL environment、KV/context 处理、CPU 编排），CPU 侧内存成为主要增量。([英伟达][6])

## 4. 网络：柜内柜外同时翻倍，CPO 登场

- NVLink 5→6：1.8→3.6TB/s/GPU，整柜 130→260TB/s。([英伟达][4])
- Scale-out：ConnectX-8 800Gb/s → ConnectX-9 1.6Tb/s/GPU；整柜 endpoint 57.6→115.2Tb/s，单柜进入 100Tbps 级。([英伟达][1])
- **CPO**：Spectrum-6 的 102.4Tb/s 交换机可采用 silicon photonics/CPO，减少可插拔光模块。([NVIDIA Developer][5]) 投资含义：GB300 可按 pluggable transceiver BOM 算光模块需求；Rubin 带宽更大但**可插拔光模块/GPU 未必同比增长**，部分价值从 pluggable 迁往 CPO/硅光。

## 5. 架构：Rack-scale → POD-scale

Rubin POD 包含五种 rack-scale system，组成 **40-rack POD / 1,152 GPU / 60 exaflops / 10PB/s scale-up 带宽**([NVIDIA Developer][5])：

1. Vera Rubin NVL72（GPU）
2. Vera CPU rack
3. Groq 3 LPX（推理加速）
4. BlueField-4 STX / CMX（KV Cache 卸载到 AI-native 存储）
5. Spectrum-6 SPX（网络）

**含义**：Rubin 完整 AI Factory 不能用 `1GW ÷ 227kW × 72` 直接算 GPU 数——非 GPU 基础设施占比更大，会明显高估。

### 5.2 Rubin Ultra 与 NVL576：2026 路线图修正（2026-09-02 补充）

**NVIDIA 自己改过路线图，网上资料互相矛盾，以 2026 最新定义为准：**

- **2025 GTC 旧版**：Rubin Ultra = Kyber NVL576 = **单柜 576 GPU / ~600kW**，2027 H2。([NVIDIA GTC2025][11])
- **2026 GTC 修正后**：Rubin Ultra 拆成**两种部署形态**——Kyber 单柜只做 **NVL144**；**NVL576 = 8 个物理 NVL72 机柜 × 72 GPU**，柜内铜互连 + **柜间直接光互连**组成一个 NVLink scale-up 域。GTC 2026 已展示内部运行的 NVL576 原型。([NVIDIA Developer][1]；[GTC26 Keynote][12])

| 产品 | 物理结构 | NVLink 域 |
|---|---:|---:|
| GB200/GB300/Rubin NVL72 | 1 rack | 72 GPU |
| Rubin Ultra Kyber NVL144 | 1 rack | 144 GPU |
| **Rubin Ultra NVL576** | **8 × NVL72 racks** | **576 GPU** |
| Feynman / Kyber NVL1152 | 8 × NVL144 racks | 1,152 GPU |

#### Rubin Ultra 两种形态对比（2026-09 状态）

| | **Kyber NVL144**（单柜） | **NVL576**（8 柜） |
|---|---|---|
| 物理形态 | 1 个 Kyber 机柜：竖插刀片 + 正交背板 + 800VDC | 8 个 MGX NVL72 级机柜 |
| NVLink 域 | 144 GPU/柜 | 576 GPU（8×72）一个域 |
| 柜间互连 | 不需要（柜内铜 + NVLink 7 交换） | **柜间直接光互连（optical scale-up）** |
| 功率 | 原设计 ~600kW；降规后（2-die/1800W）实际更低 | 官方未给可靠总数（8×~200–250kW ≈ 1.6–2MW/域） |
| 时间 | **据报道推迟到 2028** ⚠️ | **H2 2027 主力路径**（原型已在 NVIDIA 内部运行） |
| 主要风险 | 正交背板（midplane PCB）层数/线宽良率造不出来 | 光互连供应链（Coherent/Lumentum 产能） |

#### Rubin Ultra 降规连续剧（SemiAnalysis 披露，2026-07/08，Tom's Hardware 等转述）

1. GPU 封装 **4 die → 2 die**（CoWoS-L 翘曲/良率），单 GPU 功耗 2300W → 1800W（Max-Q 主流版）；
2. HBM4e **1TB（16-Hi）→ 768GB（12-Hi）**，并评估 8-Hi 兜底组合——DRAM/HBM 供给紧张是直接原因 ([TrendForce][13])；
3. **Kyber NVL144 推迟到 2028**；NVL72x2 过渡方案被客户否决后放弃。([Tom's Hardware/SemiAnalysis 转述][17])

NVIDIA 官方口径："Our roadmap is intact"，坚持 Rubin Ultra H2 2027，降规定性为"优化计算/网络/内存配置以建造更多 GPU"——**即 2027 年真正放量的 Rubin Ultra 是 8 柜光互连 NVL576，Kyber 单柜是 2028 年的事**。市场已定价：SK 海力士单日跌近 19%（Rubin Ultra 原预计占 2027 全球 HBM 需求 ~20%）。

**三个推论**：
1. **"单柜 600kW"不要再用于模型计算**——那是 2025 版路线图；8 柜 NVL576 的整套功耗 NVIDIA 未给可靠数字，2027 模型按"放大型 NVL72"（~200–250kW/柜 × 8）处理更稳妥。
2. **NVLink 首次从柜内 scale-up 跨到柜间 scale-up**：以前柜间只有 InfiniBand/Spectrum-X scale-out，现在 GPU scale-up 本身开始跨柜用光——Coherent/Lumentum 类光通信、NVLink switch、液冷、800VDC 的权重进一步提高。([NVIDIA Blog][16])
3. **Rubin Ultra ≈ Rubin 的中期增强版**（类似 GB300 之于 GB200），但规格连续降规、最终 GPU/HBM 配置**不要锁死，等量产规格**；对 HBM 需求测算的影响直接且巨大（-25% 容量/封装）。

### 5.3 代际生命周期：谁还在生产（截至 2026-09）

| 年代 | GPU | 主流系统形态 | 状态 |
|---|---|---|---|
| 2022–23 | H100 | HGX/DGX 8-GPU server（非 NVL72 形态） | 基本退出 hyperscale 新建；AI Enterprise 仍支持，OEM 库存/替换件仍在 |
| 2023–24 | H200 | HGX/DGX | **仍在生产**——2026-03 为中国订单+出口许可重启产线；但 Q2 FY27 对华 Hopper 销售 <1% DC 收入，属特殊尾部产品 ([Reuters][14]) |
| 2024–25 | GB200 | NVL72（第一代"整柜即计算机"） | 仍在出货但明显降量，2026 年内完成已有订单+成本敏感客户 ([TrendForce][15]) |
| 2025–26 | GB300 | NVL72 | **2026 主力** |
| 2026–27 | Rubin | NVL72/144 | **2026-08 开始量产出货**；Q3 FY27 即贡献 ~20% DC 收入；已拿到所有主要 hyperscaler/AI 云/OEM 订单 |
| 2027 | Rubin Ultra | NVL576（8 柜光互连）为主力；Kyber NVL144 据报道推迟 2028 | 下一代，规格连续降规未锁死（§5.2） |

**切换节奏是斜坡不是开关**（量级示意）：

```
2025:    GB200 ██████████  GB300 ██
2026 H1: GB200 ███  GB300 ██████████  Rubin ▏
2026 H2: GB200 █  GB300 ████████  Rubin █████
2027:    GB300 ███  Rubin ██████████  Rubin Ultra ██
```

**对 1GW 模型的含义**：2027 起"1GW = X 个 NVL72"要拆成三种单元——Rubin NVL72（1 柜/72 GPU）、Rubin Ultra NVL144（1 柜/144 GPU）、Rubin Ultra NVL576（**8 柜/576 GPU/一个 NVLink 域**，应理解为"8 柜组成的基本计算单元"而非超级机柜）。

## 6. 功率与供电：142→227kW，800VDC 还没到

- 整柜功率 +60% 而 GPU 数不变：**每颗 GPU 的基础设施功率需求显著增加**（1.97→3.15kW/GPU，含 CPU/NVSwitch/NIC/电源，非 GPU TDP）。
- **Vera Rubin 本代不是 800VDC**：Schneider RD113 明确仍为 facility 480VAC 供电，rack 内由 110kW 三相 AC power shelf 整流。([Schneider Electric Blog][7])
- 800VDC（sidecar/in-row power rack，乃至 MV→固态变压器→800VDC）要等 250kW→500kW→1MW rack，即 **Rubin Ultra / Kyber 以后**。([英伟达][8])
- 代际定位：**GB300 = 传统 AC 架构的高密度极致化；Vera Rubin = 过渡世代（重构 rack power）；Kyber 以后 = 800VDC 大规模进入**。对 Eaton/Vertiv/Schneider 的 BOM 预测很关键。

## 7. 液冷：同 GPU 热 +60%，同 1GW 热不变

- 相同 GPU 数量下 Rubin 单柜热负载高 ~60%，且绝大部分必须直接液冷。
- 相同 1GW 数据中心下总热量仍 ~1GW（1GW 电→1GW 热），变的是**热量集中到更少的柜**。
- 因此研究"每 10 万 GPU 多少 CDU"时 Rubin 需求明显增加；研究"每新增 1GW 多少液冷"时总量不变。Rubin 给液冷行业的真正挑战是 **MW/rack 和 flow density**，不是全球总 MW。

## 8. 对 1GW 模型的含义

纯 compute rack 上限：`1GW ÷ 单柜功率 × 72`

| | GB300 | Rubin |
|---|---:|---:|
| 理论 GPU/GW 上限 | **~507,000** | **~317,000** |
| dense NVFP4 算力/GW（粗略峰值模型） | ~7.6 ZFLOPS | **~15.9 ZFLOPS** |

- 同样 1GW，**GPU 数量上限下降约 37%，算力反而约翻倍**——未来固定的资源是 GW，不是 GPU 颗数。
- 真实 Rubin Factory 扣除网络/存储/CPU rack/CMX 后 GPU/GW 会进一步低于 31.7 万（详见 `../数据中心1GW.md`：完整 Agentic 型 ~23 万/GW）。

## 9. 投资语言总结

- **GB300 时代核心瓶颈**：GPU + HBM3E + 800G 网络 + 100kW 级液冷 + 大规模低压供电
- **Rubin 时代**：更强 GPU + HBM4 + 1.6T 网络/CPO + 200kW+ 液冷 + 更强 rack power + AI-native context storage
- **再下一代**：500kW–1MW rack + 800VDC

Rubin 不是"GB300 快 3 倍"，而是 NVIDIA 为了让每 MW 电产生更多 token，把整个 AI Factory 从芯片重新设计到电源、液冷、网络和存储。同样 1GW 电，GPU 颗数下降，但 HBM 代际、网络带宽、功率密度、CPO、液冷和电气系统的**价值量完全重新分配**——这是 GB300 1GW vs Rubin 1GW BOM 研究的价值所在。
