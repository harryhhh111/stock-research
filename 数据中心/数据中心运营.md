# 1GW AI Factory 运营经济账：成本 × 收入

> 整理/核对日期：2026-08-25（由同主题两段问答整合；成本侧 + 收入侧 + 单位经济）。
> 2026-08-25 二次更新：收入侧整合逐单合同锚（IREN×Microsoft、HIVE/Buzz 两单、Core Scientific/Applied Digital 纯机房租金）。
> 2026-08-25 三次更新：新增 §三.8 IREN vs Nebius 价差归因（整合对话附录，补 IREN×NVIDIA $3.4B 合同锚）。
> 口径：1GW = 1GW IT Load（同 `数据中心1GW.md`）。上游 CapEx：`价值量测算.md`（~$50–60B/GW）。

**一句话结论**：1GW AI Factory 每年现金 Opex 约 **$1.0–1.6B**、折旧约 **$6–7B**，会计总成本 **$7–9B**；收入侧分层定价：超级长约 **$6.7B/GW/年**（OpenAI×Oracle，2025）、当前 1–3 年中期合同市场价 **$20–25M/MW/年**（Nebius 2026Q2 实测）；逐单合同反推的 GB300 批发价 **$2.9–4.0/GPU·h** → **1GW 合理收入能力 $12–16B/年（Revenue/CapEx 20–32%）**。**现金 EBITDA 很漂亮（IREN 项目级 margin 85%），但折旧≈电费的 10 倍**，整门生意的 ROIC 取决于三个变量：GPU 采购价、GPU 寿命、合同价与期限。

## 一、成本侧：现金 Opex ~$1.0–1.6B/年

### 1. 电费（最确定的一项）

假设：IT 1GW × 平均负载率 85% = 850MW；PUE 1.12 → 平均取电 952MW；全年 **8.34TWh**。
（PUE 参照：Google fleet-wide ~1.09，Microsoft FY25 ~1.17。([Google][1])）

| 电价 | 年电费 |
|---:|---:|
| $0.05/kWh | $417M |
| $0.06/kWh | $500M |
| $0.07/kWh | $584M |
| $0.0883/kWh（美国 2026 前 5 个月工业均价，[EIA][2]） | $736M |
| $0.10/kWh | $834M |

大型 AI 园区通常签低价长协 PPA，投资模型用 **5–7¢/kWh** 低成本情景 → **Base Case 电费 ~$500–600M/年/GW**。

### 2. 交叉验证：Uptime Institute 成本结构

Uptime 调查：Power 占 facility 年度成本 42–44%、Maintenance ~17%、Labor ~16%、Connectivity ~9%（非 AI 专属，只作比例校验）。([Uptime][3])
反推：$500M ÷ 42% ≈ **$1.19B 总现金 Opex**——与自下而上估算吻合。

### 3. Cash Opex 拆分（美国低电价地区、自持机房）

| 项目 | Base Case / 年 |
|---|---:|
| 电力 | $500–600M |
| 设备维护/备件/service | $180–250M |
| 人员、安保、现场运维 | $120–200M |
| 网络/外部 Connectivity | $70–120M |
| 地产税、保险、行政 | $100–180M |
| 水/化学品/滤芯 | $5–20M |
| 其他 | $30–80M |
| **合计** | **~$1.0–1.4B** |

含昂贵的 IT warranty、GPU/网络备件池的保守口径：**~$1.2–1.6B/GW/年**。

### 4. 水费几乎可忽略

Microsoft FY25 WUE ~0.27 L/kWh IT → 7.45TWh IT 用电 × 0.27 ≈ 200 万 m³/年，即使 $2/m³ 也仅 **~$4M/年**。新一代 direct-to-chip closed-loop 设计已近零蒸发。([Microsoft][4])
**水是选址/环境问题，不是财务问题。**

## 二、成本侧真正的大头：折旧 ~$6–7B/年

CapEx 结构（`价值量测算.md`）：Compute Rack ~$25B、Network/Storage ~$5B+、Facility ~$10–13B。

科技巨头服务器会计寿命：Meta 5–5.5 年、Microsoft ~6 年、Alphabet ~6 年。([SEC][6])

| 资产 | 年限 | 年折旧 |
|---|---:|---:|
| Compute hardware $25B | 5.5 年直线 | ~$4.55B |
| Network/Storage $5B | ~5–6 年 | ~$0.8–1.0B |
| Facility $12B | ~25 年 | ~$0.48B |
| 加其他可折旧资产 | — | **合计 ~$6–7B/年** |

**经济学含义：折旧 ≈ 电费的 ~10 倍。** 所以现阶段 **Token/$ 比 Token/W 更重要**——关键问题不是"电费 5 亿还是 6 亿"，而是 **$25–30B 的 AI 硬件在 ~5 年寿命里能产生多少收入**。

## 三、收入侧：GPU 租赁市场分三层

### 1. 公开零售价（2026 中）

| GPU | 价格 | 备注 |
|---|---:|---|
| H100 | $2.23/GPU·h 起 | CoreWeave 2 年 reserved；on-demand ~$4–6 |
| H200 | ~$4–6.3/GPU·h | on-demand |
| B200 | ~$6.7–8.9/GPU·h | Lambda/CoreWeave |
| GB200 | ~$10.5/GPU·h | CoreWeave on-demand（4-GPU 实例 $42/h） |
| GB300 | 无统一公开报价 | Contact Sales |

（CoreWeave 8-GPU 实例：H100 $49.24/h、H200 $50.44/h、B200 $68.80/h([CoreWeave][7])；Lambda B200 单机 $6.69、256+ 集群 $8.87([Lambda][8])——集群价高于单机因含互联与拓扑保证。）

### 2. 合同价实测锚（2026-08-25 修正：以 Nebius Q2 电话会为准）

Nebius 把合同分三类（NBIS Q2 2026 财报电话会，2026-08-12，[Motley Fool 转录][12]）。大单普遍是 reserved / **take-or-pay**：云厂商备好整套集群+电力，客户承诺固定容量费，合同可用于资产级债务融资（CoreWeave 加权平均合同期 ~5 年，[SEC·CRWV][9]）。

| 层 | 价格锚 | 隐含 $/GPU·h* | 特征 |
|---|---:|---:|---|
| 超级长约（5 年、GW 级、投资级客户） | **$6.7B/GW/年**（OpenAI×Oracle：4.5GW ≈ $30B/年，2025 签，[FT][10]） | ~$1.66 | 最深折扣，用于支撑融资 |
| **中期合同（1–3 年）——当前市场价代表** | **$20–25M/MW/年（= $20–25B/GW/年）** | ~$5.6 | Q2 新签 4 单均 >$1B（Reflection、Cohere 等）；预付款覆盖 50–60% associated CapEx；CEO："可以按这些条款今天就卖光 2027 全部产能" |
| 短期紧急算力（≤6 个月） | $40–50M/MW 年化 | ~$10–12 | 模型发布前训练/RL 冲刺；不能当稳定年收入 |
| 零售 on-demand | 见上表 | $7–10+ | 散客 |

\* 按 1GW ≈ 46 万 GB300 GPU = 40.3 亿 GPU·h/年满负载换算。

**两个修正**：

1. 之前把 OpenAI 超级长约 $6.7B/GW 当作 frontier 合同尺度的代表——它其实是**最深折扣的批发底层**。当前中期合同市场价是 $20–25M/MW，且在**上行**：Nebius 首次容量拍卖成交价比历史最高价 +15%、比 Blackwell pipeline +20%；产能全部售罄。
2. OpenAI 官方称 4.5GW 扩张对应五年 **>$300B** 总规模（[OpenAI][11]）——含容量爬坡期和更广合作范围，不能当纯租金。

### 3. 逐单合同反推（最干净的真实批发价，2026-08-25 整合）

| 合同 | GPU | 数量 | 期限 | 合同额 | 反推 $/GPU·h（已复算 ✅） |
|---|---|---:|---:|---:|---:|
| **IREN → Microsoft**（[IREN 公告][13]、[电话会][14]） | GB300 | ~76,000（4 × 50MW Horizon） | 5 年 | $9.7B | **$2.91** |
| **HIVE/Buzz → Bell/Cohere** | GB200 | 2,304 | 3 年 | $220M | **$3.63** |
| **HIVE/Buzz → 企业客户**（2026-08-17，[HIVE 附件][15]） | GB300 | 2,016 | 5 年 | $350M | **$3.96** |

- 规律：**量越大、期越长，单价越低**——Microsoft 7.6 万颗超级单 $2.91；2,016 颗企业单 $3.96（还含 Quantum-X800 + VAST 存储）；Cohere 的 $3.63 是 HIVE 收到的 compute 价（Cohere 经 Bell 的 all-in 价可能更高）
- **建模基准（替换原 $2–5 随意区间）**：GB300 大客户 3–5 年批发价 = **$3.0–3.5/GPU·h**；几千颗用 $4，5–10 万颗用 $3
- IREN 合同附带披露：GPU+网络+软件 CapEx ~$5.8B、20% 预付款、**项目 EBITDA margin ~85%**（已扣电费/维保/机房运营）→ 反推现金运营成本 ~$291M/年/200MW = **$1.46M/MW**，与本文 §一自持模型（$1.2–1.6M/MW）吻合 ✅

### 4. Facility 租金 vs GPU Cloud 全栈价（价格结构分解）

| 层级 | 锚 | 单价 |
|---|---|---:|
| 纯机房（带电、不含 GPU，租户自付电费） | Core Scientific→CoreWeave：590MW/12 年/~$850M/年；Applied Digital：1,410MW/15 年/$36.2B（[SEC·APLD][16]） | **$1.4–1.7M/MW/年** |
| GPU Cloud 全栈（GB300+InfiniBand+软件） | IREN×Microsoft | **$9.7M/MW/年** |
| **差额 = GPU 折旧/回报 + 网络 + 软件 + 运营商利润** | — | **~$8M/MW/年** |

### 5. 交叉验证与不可算项

- **Nebius × Microsoft**：$17.4B/5 年，Vineland 园区规划 ≤300MW（[Nebius][17]）→ 隐含 **≥$11.6M/MW/年**（未披露 Microsoft 实际占多少 MW，只作下限 cross-check，不当基准）
- **OpenAI × CoreWeave**：累计合同 ~$22.4B，但未披露 GPU 数/SKU/MW——**算不出** $/GPU·h；CoreWeave 整体 RPO $60.7B、>98% 收入来自 committed contracts（[SEC·CRWV][9]），证实 OpenAI 买的就是 3–5 年 take-or-pay
- **Nebius × Meta**：**$12B/5 年 Vera Rubin** dedicated capacity（2027 初起量）+ 最多 $15B 剩余容量 backstop，合计最高 $27B（[Nebius][18]）——Rubin 的五年百亿级需求已锁定，但 GPU 数/MW 未披露，暂不能换算单价

### 6. CapEx 口径对照（为什么 Nebius 22 个月回本 ≠ 推翻 $50B/GW）

- Nebius CFO：>$20M/MW 的合同 **payback < 2 年**。22 个月 × $22.5M/MW/年 ≈ $41M/MW 需覆盖 CapEx+运营 → 其 "associated CapEx" ≈ **$20–30B/GW**
- 与 `价值量测算.md` 的 $50–60B/GW **不矛盾**：后者是**全口径绿地**（IT+建筑+机电+土地+电网/变电站+可选电厂）；Nebius 模式是 **colo 租赁 + asset-light 合作伙伴代建 + Bloom 表后燃料电池**，资产负债表上只背 GPU + fit-out
- 佐证：FY26 CapEx 指引 $20–25B 对应年底 800MW–1GW connected power（含提前采购次年 GPU），量级吻合
- 推论：neocloud 的现金成本含 colo 租金（Nebius 50% EBITDA margin → 现金成本 ~$11M/MW/年），**不能套自持模型的 $1.2–1.6M/MW**

### 7. 收入能力结论（GB300 1GW）

46 万 GPU × 8,760h 满容量：

| 单价 | 收入/GW/年 |
|---:|---:|
| $2.91（Microsoft 级超级批发） | **$11.7B** |
| $3.50（Base Case 上限） | $14.1B |
| $4.00（几千颗中型单） | $16.1B |

→ **GB300 1GW 合理收入能力收窄至 $12–16B/年；对 $50–60B CapEx 即 Revenue/CapEx ≈ 20–32%/年**——这是判断"AI 基建有没有经济账"的核心比率。

### 8. IREN vs Nebius：$10M vs $20–25M/MW 的价差归因（2026-08-25 整合）

统一换算成 $/MW/年 后对齐比较（[IREN Q3 FY26 更新][19]、[IREN 8-K][20]、Nebius 来源见 §三.2/§三.5）：

| 合同 | 类型 | 期限 | 签约 | $/MW/年 |
|---|---|---|---|---:|
| IREN → Microsoft | GB300 dedicated | 5 年 | 2025-11 | **$9.7M** |
| IREN → NVIDIA | 风冷 Blackwell managed cloud（含 Mirantis 编排软件） | 5 年 | 2026-05 | **$11.3M**（$3.4B÷5÷60MW ✅ 已复算） |
| Nebius → Microsoft | dedicated（Vineland ≤300MW） | 5 年 | 2025 | **≥$11.6M**（下限） |
| Nebius 中期新签（Reflection/Cohere 等 4 单） | AI Cloud | 1–3 年 | 2026Q2 | **$20–25M** |
| Nebius 短期紧急算力 | — | ≤6 个月 | 2026Q2–Q3 | $40–50M 年化 |

**核心发现：所有 5 年长约（无论谁家）都落在 $9.7–11.6M/MW 区间；$20–25M 是"中短约 + 涨价周期"的价格，不是 Nebius 的公司定价能力。** 三个归因按贡献排序：

1. **期限与客户结构（贡献最大）**：IREN 卖 5 年 200MW 大宗批发（大客户+大批量+长约三重折扣），换取投资级 take-or-pay 现金流作**融资锚**；Nebius 自己也把合同分三档——5 年 investment-grade 长约"主要用来融资"、1–3 年核心 AI Cloud $20–25M、短期 $40–50M（[Motley Fool][12]）。反向证据：IREN×NVIDIA 到 2026-05 签仍只有 $11.3M——涨价周期中长约依旧便宜。
2. **签约时点**：IREN×Microsoft 2025-11 锁价五年；Nebius 新单签在 2026Q2 涨价周期（价格曲线：2026 base ~$12M → Q2 新签 $20–25M → 短期 $40–50M 年化；老一代 GPU Q2 环比 Q1 也 +30%；首次 capacity auction 比 Blackwell 历史最高价 +15%）。
3. **产品层级**：Microsoft 自带 Azure/存储/软件栈，买的是 GPU+IB+机房+电+运维；Nebius 的 AI-native 客户买的是 contiguous cluster + 扩容承诺 + cloud platform + white-glove 工程支持。IREN 收购 Mirantis（2026-05 宣布，约 $625M 股票对价·媒体报道）正是在补这一层，其 NVIDIA 单已含编排软件。

**MW 口径警示（分母不一样）**：IREN 的 200MW 是 **critical IT load**，2026 年底 480MW 是 **gross AI Cloud capacity**——两个 MW 不是一个概念（$3.7B ARR ÷ 480MW = $7.7M/MW 只能看数量级）；Nebius 的 $20–25M/MW 是 deal yield 指标，分母定义没有 IREN 细。口径差异解释不了 2 倍差距，主因仍是上面三条。

**商业模式对照（不要只比 Revenue/MW）**：

| | IREN | Nebius |
|---|---|---|
| 模式 | 自持土地/电网/变电站 + GPU 批发（AI Factory landlord；比特币矿场出身） | asset-light：租 colo + 合作伙伴代建 + 全栈 AI Cloud |
| 长约收入 | $9.7–11.3M/MW | ≥$11.6M/MW（Microsoft 单） |
| 现金成本 | ~$1.5M/MW（无第三方 colo 租金，[IREN 8-K][20]） | ~$11M/MW（含 colo 租金） |
| 项目 EBITDA margin | **~85%**（扣电费/维保/机房运营；未扣 corporate/融资/D&A） | ~50%（AI Cloud adj. EBITDA） |
| 200MW 项目 CapEx | GPU $5.8B + 数据中心 $14–16M/MW × 200MW ≈ **$8.6–9.0B**（[IREN 8-K][20]） | associated CapEx $20–30B/GW，客户预付 50–60%，回本 22 个月 |
| 资产逻辑 | 数据中心 5 年后仍在，可装下一代 GPU | 高价短约快速回本 → 下一代重新定价 |

**结论**：两家正互相靠近（IREN 买 Mirantis 上软件，Nebius 自建大机房下基础设施）。比较这两家公司的正确框架不是 Revenue/MW，而是 **CapEx/MW → Revenue/MW → EBITDA/MW → 回本年限/ROIC** 全链条。


## 四、成本 × 收入：单位经济

- **每天必须赚的**：$8B/年 ÷ 365 ≈ **$22M/天**，仅覆盖 电+运维+折旧，未含资本回报
- 若要求 $50–60B CapEx 有 10% 回报 → 再加 $5–6B/年 → 需 **$13–15B+ 年度毛利贡献**才算像样的项目
- 对照收入侧分层：**这门生意既诱人又危险**——按超级长约 $6.7B/GW 签，折旧 $6–7B 下会计利润极薄；按逐单合同批发价 $2.9–4.0/GPU·h（→ $12–16B/GW/年），覆盖 $7–9B 会计成本后剩 $3–9B；IREN×Microsoft 项目 EBITDA margin 85% 是当前最干净的实证（其现金成本 $1.46M/MW 与 §一模型吻合）。Nebius 中期合同价 $20–25M/MW 更高，但其成本含 colo 租金，口径不同
- **ROIC 三变量**：① GPU 买得多便宜 ② GPU 能用几年 ③ 客户按多少 $/GW-year 签长约——差一点，ROIC 完全不同

## 五、待办：敏感性表

用 GB300 1GW（46 万 GPU、CapEx $50–60B、Cash Opex $1.2–1.6B）跑矩阵：租赁价按 §三.3 合同锚 **$2.9 / $3.5 / $4.0 per GPU·h**（替换原 $2–5 随意区间）× 利用率 80/90/100% × GPU 寿命 4/5/6 年 → Revenue / EBITDA / FCF / ROIC / 回收期。回答：**Microsoft 给 IREN 的 $2.91/GPU·h 到底够不够赚，以及 IREN 为什么敢给 85% 项目 EBITDA margin。**
