# HBM 术语

> 整理日期：2026-09-11。仅收录本 HBM 专题常用术语；若在更多项目中复用，再迁移至根目录 `术语.md`。

**HBM（High Bandwidth Memory）**  
高带宽内存：将多层 DRAM 垂直堆叠，并用极宽、极短的接口与 GPU/ASIC 相连的高性能工作内存。断电不保存数据。

**HBM Stack / Cube（堆栈）**  
一个由多层 DRAM die 堆叠而成的 HBM 封装单元。报告带宽和容量时必须区分“每堆栈”与“每 GPU”。

**HBM4 / HBM3E**  
HBM 的第四代 / 第三代增强版。HBM4 的核心标准化变化是将单堆栈 I/O 宽度提升至 2,048 bit。

**HBM4E**  
业界对 HBM4 高性能延展产品的命名，通常指在 HBM4 宽接口基础上，通过更高 pin speed、DRAM/逻辑底座、封装和散热优化继续提高性能、容量和能效的产品路线。具体规格和商业阶段取决于供应商与客户平台，不能把名称视为单一统一产品规格。

**TSV（Through-Silicon Via，硅通孔）**  
贯穿硅片的垂直导通结构，用来连接堆叠的 DRAM die。

**2.5D 封装 / Silicon Interposer（硅中介层）**  
让 GPU/ASIC 与多颗 HBM 在同一先进封装内以大量短连接互连的技术路径。2.5D 指芯片并排放在中介层上，而非把计算 die 和内存 die 直接逐层堆在一起。

**I/O Width（I/O 宽度）**  
可并行传输的数据位数量。HBM4 为 2,048 bit；理论峰值带宽约等于每 pin 速率 × I/O 宽度 ÷ 8。

**Pin Speed（每 pin 速率）**  
单个 I/O 引脚的数据传输速率，常以 Gb/s 表示。它不能单独代表一个 HBM 堆栈或整颗 GPU 的总带宽。

**12H / 16H**  
12-high / 16-high，分别指 12 层和 16 层 DRAM 堆叠。层数增加通常有助于提高单堆栈容量，但也提高制造、散热和良率挑战。

**逻辑底座（Logic Base Die）**  
HBM 堆栈底部用于接口、控制和电源相关功能的逻辑芯片。HBM4 时代其制程、定制化和与 GPU 的协同成为竞争维度之一。

**Advanced MR-MUF**  
先进批量回流模制底部填充（Mass Reflow Molded Underfill）：在堆叠芯片间填充并固化保护材料的封装工艺，用于提高多层 HBM 堆叠的机械稳定性和散热表现。

**KV Cache**  
大语言模型推理时保留已处理 token 的 Key/Value 张量缓存。上下文变长、并发提高时会大量占用加速器内存容量与带宽。
