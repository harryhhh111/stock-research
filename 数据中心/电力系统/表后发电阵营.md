# 表后发电（Behind-the-Meter）阵营：谁在数据中心旁边建电厂

> 整理日期：2026-09-02。对应 `1GW数据中心电力链路.md` 的 A 级情景：自建电厂直供，绕过 B（升压并网）和 C（高压输电）。
> 术语"Behind-the-meter"见 `行业背景/术语.md`。

## 1. 为什么绕过电网

两个数字说明动机：

- **并网排队 5 年+**：截至 2026-03，仅 ERCOT（德州）就收到 ~**356 GW** 数据中心并网申请，远超实际供电能力；北弗吉尼亚和德州的新并网实际已到容量上限。([RBC][1];[Introl][2])
- **变压器 128–144 周交期**：就算排到并网，设备也跟不上。

表后发电 = 电厂建在数据中心旁边，电从燃机直接进园区，**不碰公用电网**：不等并网队列、不要长距离输电、不推高居民电价（政治上也更安全）。代价是自己搞定燃料、许可、运维。

**总盘子**（RBC 统计，2026-05）：美国已宣布的数据中心表后天然气发电约 **101 GW**；其中 **57 GW+ 已披露设备订单**，**~7 GW 已开工**；德州占 ~38 GW。([RBC][1])

### ④ 设备商/工程商直接下场

- **Caterpillar**：油服公司 ProPetro 的 PROPWR 部门一次签了**最高 2.1 GW** 的 Cat 发电设备——中小型燃机/发电机组在"过渡期供电"市场放量。([Stocks Tracker][8])
- **GEV 的角色**：不卖电、不拥有电厂，但**几乎每个阵营背后都有它**——Chevron 联盟的 7HA slot、NRG 联盟的整机、xAI 之外的多数项目用 HA/航改机。表后浪潮是 GEV 116 GW backlog 的直接构成部分（数据中心直采 ~20 GW）。

## 3. 绕过 B/C，绕不开什么

表后发电省掉了并网队列和输电，但**换来了四道新门槛**，这也是很多项目跳票的原因：

1. **燃气管道许可**：Stargate 新墨西哥项目被州政府否决输气管道——电厂有了，气进不来。
2. **空气许可**：xAI 走了 7 个月监管审查；Nebius 新泽西 400MW 还在卡许可。
3. **燃机 slot**：本身就要抢（GEV 排期 2030 后）——Chevron/NRG 的模式本质是"用联盟锁定设备产能"。
4. **核电表后的监管天花板**：FERC 否决 Talen/AWS 方案，核电直供目前走不通，只能表前 PPA。

Cleanview 的情景测算：若许可问题延续，2027 年底累计表后投运可能只有 **~5 GW**（乐观情形 13 GW）。([Cleanview][3])

## 4. 研究视角小结【我的推演】

1. 表后发电是**对"电网排队 5 年"的市场化绕行**，101 GW 宣布量里真正能落地的受限于许可而非资金——跟踪时**只数"已获许可 + 已锁燃机 slot"的项目**（~57 GW 有设备订单是更实的口径）。
2. 投资映射：**GEV 是最大卖铲人**（几乎每个阵营都是它客户）；Caterpillar 吃过渡期中小机组；油气公司（Chevron）是新增量玩家；Quanta 这类电网承包商在表后场景**反而被绕开**——这是 PWR 故事的一个对冲项。
3. Talen 案说明监管是模式级风险：表后燃机走得通，表后核电（目前）走不通。

## 5. 附：自建电厂的账怎么算（"直接买气自己发电"的可行性）

以 1 GW IT 数据中心配 1.3 GW 联合循环为例（气价取 Henry Hub 现价 ~$2.9/MMBtu，2026-09-01）：

| 项目 | 测算 | 结果 |
|---|---|---|
| 燃料成本 | 联合循环热耗 ~5,300–5,500 Btu/kWh × ~$3/MMBtu | **~$16–18/MWh** |
| + 管道运输 | ~$0.5–1/MMBtu 管输费 | +$3–6/MWh |
| + 运维（VOM） | 行业惯例 | +$3–5/MWh |
| + 资本成本 | 电厂 ~$1,000–1,300/kW（含燃机涨价）→ 1.3GW ≈ $15 亿；按 ~12% 年摊销、90% 容量因子 | ~$19/MWh |
| **自发电全成本** | | **~$40–50/MWh** |
| 对照：买电 | 数据中心零售长协（NRG 目标价 $80+/MWh） | **$80–100+/MWh** |

**中间 ~$40/MWh 的价差就是表后发电的经济动机**——1GW 全年跑满 ≈ 9.5 TWh，每年省 ~$4 亿。

口径交叉验证：「买电 $80–100+/MWh」是稀缺区零售长协口径；数据中心 all-in 电力全成本的市场中枢是 **~$60–90/MWh**（含 demand/capacity/自建变电站摊销，见 `../行业背景/美国电价结构.md` §7 三口径）。注意数据中心账单 ≠ 电价×kWh，还有 demand charge（$/kW-月）、capacity charge 等——且 AEP Ohio 等已把数据中心 tariff 做成 ~85% 保底消费 + ~12 年 take-or-pay 长约，**买电网的电本身也在变贵变刚性**，这是表后发电经济性的另一面支撑。

但"直接买气"意味着要自己凑齐五件事（这正是 Chevron×Engine No.1×GEV×Kiewit 组团的原因——没有一家能单独快速凑齐）：

1. **气源**：长期供气合同（firm supply）；
2. **管道容量**：firm transport 运力，甚至自费建支管（xAI 自费接 8 英寸支管到 16 英寸主管；Stargate 新墨西哥就死在管道许可上）；
3. **燃机 slot**：重型机排期 2030 后，中小机型快但热耗高（简单循环 8,500–10,000 Btu/kWh，燃料成本翻倍）；
4. **空气许可**：xAI 走了 7 个月，Nebius 还在卡；
5. **EPC + 运维队伍**：电厂是 30 年资产，建设（Kiewit 这类）和运维都不能外包给"没人干过"的人。

气量口径：1.3GW 联合循环满载 ≈ 0.16–0.18 Bcf/天，约为美国日产量的 **0.16%**——单项目可行，但 101GW 宣布量若全落地 ≈ 美国产量的 ~13%，气价本身会成为下一个瓶颈。

→ 3 年维度「新增数据中心 GW → 气耗 → 五道门槛」的完整测算见 `factcheck/数据中心气电需求测算.md`（可复算脚本同目录）：中枢 ~53GW/5.2 Bcf/d，瓶颈排序 **燃机 slot ❌ > 管道区域错配 🟡 > 空气许可 🟡 > 气源总量 🟡 > EPC 🟡**。
