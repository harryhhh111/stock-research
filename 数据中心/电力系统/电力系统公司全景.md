# 电力系统公司全景：上市与未上市普查

> 整理日期：2026-09-02。口径：围绕数据中心电力链路（`1GW数据中心电力链路.md` A–G 七级）+ 发电侧 + 上游材料；**"家数"按独立法人口径**，母子公司只算一次（上市子公司单列、母公司备注），综合集团跨环节重复出现、总数行已去重。上市状态截至 2026-09；并购信息以已公告交割为准。

## 0. 总览

| 环节 | 上市（家） | 未上市（家） | 格局一句话 |
|---|---:|---:|---|
| 1. 发电主机（重型燃机/汽机/HRSG） | ~10 | ~5 | **三巨头 85% 寡头**，2028 前售罄 |
| 2. 中小燃机/内燃机/分布式设备 | ~8 | ~4 | CAT/Cummins 系 + 欧洲专业厂 |
| 3. 备用柴发 | ~4 | ~2 | 与 2 高度重叠 |
| 4. 燃料电池 | ~6 | 0 | 全部上市但体量小 |
| 5. SMR/核电新势力 | ~5 | ~7 | 上市的炒概念，干活的多未上市 |
| 6. 变压器 | ~15 | ~6 | 最分散，全部满产，韩/中厂商关键 |
| 7. 开关/GIS/HVDC/电网设备 | ~12 | ~6 | 与主机厂高度重叠（三巨头全卖） |
| 8. 机房电气（UPS/PDU/母线） | ~11 | ~4 | Vertiv/Eaton/Schneider 三巨头 |
| 9. 上游：电工钢 GOES + 电缆 | ~13 | ~1 | GOES 是真正卡脖子层 |
| 10. EPC/施工 | ~8 | ~10 | Quanta 独大 + 一堆私营巨头 |
| 11. 发电运营（IPP/公用事业） | ~50（美国公用事业 ~45） | 数家 | 正在并购集中 |
| 12. 表后发电/能源新势力 | ~2 | ~10 | 几乎全是未上市新钱 |
| **合计（去重）** | **~95–105** | **~35–45** | **总共约 130–150 家** |

**结构性观察**：
1. **真正卡脖子的环节公司数最少**：重型燃机全球就 3 家（GEV/SE/MHI）+ 二线 3–4 家；GOES 电工钢也就 6–7 家。越上游越寡头。
2. **公用事业家数最多（~45 家上市）但同质化**，研究价值在区域暴露（VA/TX/GA/OH 数据中心州）而非个股差异。
3. **表后发电阵营几乎全未上市**（Chevron×Engine No.1 JV、Crusoe、Lancium、VoltaGrid 等）——股市买不到直接敞口，只能通过设备商（GEV/CAT）和 EPC（Quanta/Kiewit 私营）间接买。
4. **2025–26 发电侧大并购潮**：Constellation 收 Calpine（$26.6B，2026-01 交割）、NRG 收 LS Power（$12B）、Vistra 收 Cogentrix（$4B）、Talen 收 Freedom/Guernsey——可交易的独立气电资产快速减少。

## 13. 公司级研究进度与缺口：按对 2027 新增 GW 验证的重要性排序

“被列入全景”不等于“已完成公司研究”。目前已具备独立研究笔记的核心公司/项目是 **GEV、Quanta、Doosan Enerbility、IREN**，以及 xAI/Stateline 等项目级核对；其余多数仍是名单级覆盖。

| 优先级 | 尚未完成公司级研究的对象 | 所在链路 | 为什么优先 | 要拿到的可用于模型的数据 |
|---|---|---|---|---|
| **P0** | **[Hitachi Energy / Hitachi](../../电力产业链公司/HITACHI/Hitachi%20Energy.md)**（首轮已建档） | GSU、大型主变、HVDC、变电站 | 高压主变的直接瓶颈；已有 hyperscale 项目交付案例 | 北美工厂/进口来源、MVA 产能、数据中心专用订单、交期、项目供应商点名 |
| **P0** | **[Siemens Energy](../../电力产业链公司/ENR/Siemens%20Energy.md)**（首轮已建档） | 燃机、GSU/主变、变电站 | 同时覆盖表后发电和高压接入；已披露 22GW data-center-related commitments，仍须严分 reservation/订单/投运 | 数据中心订单/slot、变压器 MVA、燃机与电网设备是否服务同一园区 |
| **P0** | **[HD Hyundai Electric](../../电力产业链公司/267260/HD%20Hyundai%20Electric.md)**、**[Hyosung Heavy](../../电力产业链公司/298040/Hyosung%20Heavy%20Industries.md)**（均已首轮建档） | 大型变压器 | 韩国是美国大型变压器进口的关键补充；Hyosung 已披露两家美国科技公司数据中心 765/345kV 订单，但无项目 MVA/投运期 | 北美销售/工厂、LPT 交期和订单、美国项目客户/电压等级 |
| **P0** | **[Dominion](../../电力产业链公司/D/Dominion%20Energy.md)**、**[AEP](../../电力产业链公司/AEP/AEP.md)**（均已首轮建档）、Entergy、Southern/Georgia Power、Sempra/Oncor | utility 接电与变电站 | 真正决定 2027 能否接电；也是“主变是否由 utility 采购”的证据源 | interconnection agreement、POI、变电站/线路工程、firm MW、投运日期、客户去重 |
| **P1** | **Eaton、Schneider Electric、Vertiv** | MV/LV 开关柜、UPS/PDU、母线、液冷 | 把“变电站已接电”变成“数据厅可运行”的共同门槛 | 数据中心订单/backlog、模块化 pod MW、制造交期、commissioning 证据 |
| **P1** | **Powell Industries** | 中压开关柜 | 少数相对纯粹的美股 MV 开关柜标的；比综合集团更适合追踪订单 | data-center exposure、book-to-bill、产能与交期、客户/项目披露 |
| **P1** | **Caterpillar/Solar Turbines、Cummins、Wärtsilä、Bloom Energy** | 临时/表后/备用电源 | 决定电网接入不及时的园区能否提前运行 | 已签机组 MW、交付与 SAT 日期、可持续运行还是短期桥接 |
| **P2** | **Mitsubishi Electric、LS Electric、Iljin、WEG、Hammond、SPX** | 变压器/开关设备补充供给 | 用于验证高压/MV 设备供给并非仅三家垄断 | 北美销售、产品电压等级、产能与数据中心订单 |
| **P2** | **Cleveland-Cliffs、Nippon Steel、JFE、POSCO** | GOES 电工钢 | 验证变压器供给的更上游瓶颈；不直接换算 GW | GOES 产能、等级、供货对象、扩产投产日 |
| **P2** | **Prysmian、Nexans、LS Cable、Southwire** | 高压电缆/导线 | 线路、园区接入和变电站改造的第二瓶颈 | 高压电缆订单、工厂 slot、项目交付节点 |

**先后关系**：先研究 P0 的设备商与 utility，才能为项目台账填入“谁建了多少 MVA、何时投运”；P1 验证接电后的 data-hall commissioning；P2 是供给合理性校验，不能替代项目级 MW。
