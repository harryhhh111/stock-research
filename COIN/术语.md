# Coinbase专用术语

整理日期：2026-10-01。

| 词 | 本项目含义与注意事项 |
|---|---|
| Net revenue | 交易与订阅服务收入之和；不是净利润。 |
| Coinbase Prime | 面向机构的交易、托管及相关服务体系。 |
| Deribit | Coinbase收购的专业加密衍生品交易平台。名义成交量不能直接对比现货手续费变现。 |
| USDC合作收入 | 根据与Circle的协议分享相关储备净收益，受余额、利率和合同步骤影响。 |
| Assets on Platform | 平台资产的美元价值，受资产价格影响；不等于公司自有资产。 |
| Base | Coinbase发起的以太坊L2生态；使用量不等于公司独立利润。 |
| Coinbase One | 订阅服务产品；不能把所有订阅服务收入均视为该产品收入。 |
| Blockchain rewards | 质押奖励相关收入，含与客户奖励有关的会计列报；不等于全部由公司保留的净手续费。 |

跨项目通用财务术语遵循根目录《术语.md》。
