# 三星电子项目术语

> 整理日期：2026-09-16。仅收录本项目的三星内存业务口径；DRAM、NAND、HBM 等通用定义优先参见根目录《术语.md》及《数据中心/存储与NAND/HBM/术语.md》。

| 术语 | 含义 | 本项目中的使用边界 |
|---|---|---|
| Memory Business | 三星 DS 中负责 DRAM、NAND Flash 等存储产品的业务。 | 这是本阶段的研究主体；三星公开财务并不完整单列其收入与营业利润。 |
| DS（Device Solutions） | 三星电子半导体分部，涵盖 Memory、Foundry、System LSI 等。 | **不是** Memory 的同义词；DS 财务不可直接当作内存财务。 |
| HBM | 将多层 DRAM 堆叠的高带宽内存产品。 | 属于 DRAM 研究线，而不是独立于 DRAM 的第四个业务分部。 |
| HBM Base Die | HBM 堆栈中承担接口、控制和电源等功能的逻辑底座。 | 三星可由 Foundry 制造；仅在影响 HBM 的成本、良率或交付时纳入。 |
| V-NAND | 三星对其垂直堆叠 NAND Flash 技术的品牌/产品路线名称。 | 层数或架构发布不等于已经形成量产收入，需分开记录。 |
| BV-NAND | Bonding V-NAND，三星 V10 NAND 使用的晶圆键合架构。 | 2026-08 为技术展示/路线信息；后续需验证量产、良率与成本。 |
| eSSD | Enterprise SSD，面向服务器、云和数据中心的企业级固态硬盘。 | 是 NAND die、控制器、固件、封装与认证共同形成的产品收入，不能等同于裸 NAND bit。 |
| PM1763 | 三星于 2026-07 宣布量产的 PCIe 6.0 eSSD。 | 可确认其量产状态和产品规格；收入、客户与毛利率未单列披露。 |
| 1c DRAM | 三星对第六代 10nm 级 DRAM 工艺的命名。 | 在 HBM4/HBM4E 资料中出现；制程名称本身不自动证明产品收入或良率领先。 |
