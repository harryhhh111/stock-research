# 三星 Memory：2026 年 DRAM 与 NAND 产能增加线索

> 整理日期：2026-09-16  
> 数据截止：2026-09-16。本文区分“已实现的出货增长”“已披露的 CapEx/技术迁移”“媒体报道的物理产能计划”，不把三者混为同一件事。

## 先给结论

**有扩产线索，而且 DRAM/HBM 远强于 NAND。**但三星没有公布 DRAM 或 NAND 的月投片、每座厂的稼动率或年度新增 wafer 数，因此不能把“创纪录 bit 出货”写成“新增了多少产能”。

- **DRAM/HBM：**公司已确认扩充 HBM 供给能力、提升 1z-nano 产能及良率；外部媒体还报道平泽 P4 新建 1c DRAM 线，目标在 **2027Q1** 前投运、规模约 **10–12 万片/月**。这构成 2026 年最具体的物理扩产线索，但在数据截止日尚无三星确认“该线已量产”的公告。
- **NAND：**公司证实需求很强、Q2 bit 出货创新高，且通过 V9 QLC/高容量 eSSD 提升产品组合；但第三方数据反而显示三星把资源优先投向 DRAM 后，NAND 出货份额从 32% 降至 25%。目前没有同等级、已证实的新 NAND wafer 产线投产数据。
- **投资含义：**今年的利润和供给改善更多来自 ASP、先进节点/良率、HBM 与 eSSD/QLC 的产品结构，而不是一座全新大厂已经在 2026 年贡献大量通用 DRAM/NAND wafer。新增 cleanroom 和 P4/P5 的影响主要应放在 2027 年以后观察。

## 1. 先分清四种“供给增加”

| 类型 | 含义 | 2026 年三星的证据 | 能否直接证明 wafer 产能增加 |
|---|---|---|---|
| 出货 bit 增长 | 已卖出的 DRAM/NAND bit 变多 | Q2 DRAM/NAND bit 出货均创新高；DRAM 环比低十几%、NAND 环比低个位数 | 否；也可能来自良率、库存、产品组合或产品密度。 |
| 先进制程/良率 | 同一设备投入可产出更多合格/高价值 die 或 bit | 1z-nano 产能扩充与良率提升；V9 QLC、高层 V-NAND 路线 | 部分反映“有效供给”增加，但不等于新 wafer start。 |
| HBM 供给能力 | DRAM die、base die、堆叠/封测的可交付组合 | 公司称持续扩充 HBM supply capacity | 不可直接换算为通用 DRAM 产能；HBM 会占用更多 DRAM die/封装资源。 |
| 新厂/新 cleanroom | 新增物理空间与设备投片能力 | P4 1c DRAM 线与 P5 加速建设为媒体报道 | 是最直接证据，但需等待设备搬入、良率爬坡和量产确认。 |

## 2. DRAM：有实质扩产动作，但大量增量偏后置

### 2.1 已确认的 2026 供给改善

三星在 Q2 电话会中称，DRAM bit 出货环比增长低十几%，高于此前指引；公司将这一表现归于 AI 服务器需求下的产品供给。管理层还表示，HBM4 客户认证逐步完成，客户项目在下半年爬坡；**1z-nano 工艺产能扩张与良率改善正按计划推进**，公司继续提升 HBM 供给能力。该信息证明先进 DRAM/HBM 的有效供给在增加，但没有披露月投片或新增晶圆数。[Q2 电话会记录](https://new.alphaspread.com/security/krx/005930/investor-relations/earnings-call/q2-2026)

Q2 正式业绩材料亦确认：尽管公司努力增产，供应约束仍将持续；下半年需求增长主要来自服务器 DRAM、eSSD 与 HBM。这意味着“产量正在加”与“供需缺口正在收窄”不是同一结论。[2026Q2 业绩材料](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_2Q_conference_eng.pdf)

### 2.2 P4 1c DRAM：最具体的物理产能线索，但属于第三方报道/未来计划

| 项目 | 已报道信息 | 如何使用 |
|---|---|---|
| 位置与产品 | 平泽 P4 拟配置 1c DRAM 线，面向 HBM4 所需的先进 DRAM die | 说明三星将物理扩张优先投向高价值 DRAM/HBM，而非平均扩张所有内存。 |
| 规模 | 约 **10–12 万片/月** wafer capacity；报道同时称三星既有 DRAM 产能约 66 万片/月 | 这是行业媒体口径，不是三星法定披露；不能当成已实现产能。 |
| 时间 | 2026-02 报道的目标为 **2027Q1 前**建成/投运 | 对 2026 收入的影响有限；应把主要新增供给放入 2027 验证。 |
| 进度旁证 | 2026-04 媒体称 P4 尚处半负荷、部分区域拟在 7 月和 11 月以临时使用许可先行启用 | 可佐证建设加速，不能替代设备安装、良率或量产数据。 |

来源：[韩联社 2026-02-05 报道](https://www.yna.co.kr/amp/view/AKR20260205183600003)、[Seoul Economic Daily 2026-04-22 报道](https://en.sedaily.com/finance/2026/04/22/samsung-accelerates-p4-fab-advances-full-production-by-six)。

**判定：🟡 基本属实（扩产规划/建设推进），但“2026 年已经新增 10–12 万片/月 DRAM 产能”不成立。**公开材料指向的是设备与厂房准备在加快、目标投运期在 2027Q1 左右，而非当前产能已完全释放。

### 2.3 HBM 既可能增加收入，也可能挤占通用 DRAM bit

HBM4 需多颗先进 DRAM die 以及逻辑底座和先进封装。三星在 Q2 称 HBM4 销售将继续扩大，Foundry 也将扩大 memory base-die 的销售。因而 P4/1c 的新增能力不应简单按“全部变成 DDR5/LPDDR bit”处理；它首先服务于 HBM4/HBM4E 的供货和客户认证。[2026Q2 业绩材料](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_2Q_conference_eng.pdf)

研究上应同时追踪：

1. HBM4 的出货与客户认证是否兑现；
2. HBM wafer/封装占用对 DDR5、LPDDR 和 GDDR 的可售 bit 有何影响；
3. 1c/1z 良率提升是否足以抵消产品向 HBM 倾斜造成的通用 DRAM 供给收紧。

## 3. NAND：当前更像“密度、QLC 与 eSSD 的有效 bit 增长”，不是明确新厂扩张

### 3.1 已确认的出货与产品线索

- Q2 NAND bit 出货环比为低个位数增长，仍创公司单季新高；管理层对 Q3 的指引为环比高个位数增长。该增长是出货结果，不能单独证明 wafer 产能增加。[Q2 电话会记录](https://new.alphaspread.com/security/krx/005930/investor-relations/earnings-call/q2-2026)
- 公司在电话会中表示，V9 2Tb QLC 于 3 月完成开发，并预期 **H2 的 QLC bit 出货将较 H1 超过翻倍**；这表示高密度 QLC/eSSD 产品能显著增加可销售 NAND bit，但并不说明总 wafer input 同比例扩张。该段为媒体转述的管理层口径，尚待后续财报验证。[Asiae Business Daily 对 Q2 电话会的转述](https://view.asiae.co.kr/en/article/2026073012180322044)
- 三星在 2026-08 展示 V10 BV-NAND（400+ 层、公司称密度比 V9 提升约 58%）。官方公告属于技术路线披露，**不是量产/出货量披露**；不能把 58% 当作 2026 年实际 NAND 总产能增幅。[三星 FMS 2026 公告](https://news.samsung.com/global/samsung-unveils-next-gen-3d-memory-vision-at-fms-2026-charting-the-future-of-ai-infrastructure)

### 3.2 反向线索：三星可能优先把稀缺资源给 DRAM

Counterpoint 的 2026Q2 Memory & Storage Tracker 显示，三星 NAND bit 出货份额为 **25%**，较此前 **32%**下降；其解释是三星在产能受限下优先生产利润较高的 DRAM。该数据为第三方市场跟踪，不能与三星的财报直接相加，但它是判断“2026 年三星是否大幅新增 NAND wafer 供给”的重要反证：至少截至 Q2，公开市场数据没有显示三星为 NAND 激进扩产。[Counterpoint 2026Q2 NAND 跟踪](https://korea.counterpointresearch.com/enterprise-ssd-nand-shipments/)

**判定：**

- **✅** NAND 的高价值有效供给在增加：QLC bit、PCIe Gen6 eSSD、高容量产品均在推进；
- **⚠️** 总 NAND wafer 产能是否增加、增加多少：无法复算；
- **🟡** 2026 年资源向 DRAM/HBM 倾斜：有第三方出货份额支持，也与公司“服务器优先、供给受限”的表述一致。

## 4. FY2026H1：资本开支到底是多少

**官方已披露的 FY2026 上半年 CapEx 是 27.9864 万亿韩元（约 28.0 万亿韩元）。**其中 DS（Device Solutions）为 **25.6030 万亿韩元**，SDC 为 **1.3346 万亿韩元**，其他业务为 **1.0488 万亿韩元**。金额来自三星半年报告的逐项表格（原表单位为亿韩元），不是媒体估计。

| 期间 | 总 CapEx | DS | SDC | 其他 | 口径/来源 |
|---|---:|---:|---:|---:|---|
| FY2026 Q1 | 11.2332 | 10.1927 | 0.5881 | 0.4524 | 公司季度报告原表 |
| FY2026 Q2 | **16.7532** | **15.4103** | **0.7465** | **0.5964** | **自行复算**：官方 H1 减官方 Q1；与当季电话会披露的约 16.8 / 15.4 相符 |
| FY2026 H1 | **27.9864** | **25.6030** | **1.3346** | **1.0488** | 公司半年报告原表 |
| FY2025 全年 | 52.7 | 47.5 | 2.8 | 2.4 | 公司全年披露，作同比参照 |

单位：**万亿韩元**；四舍五入差异可能使各项相加与报道中的“约数”略有不同。

**可直接用于模型的读法：**

- FY2026H1 总 CapEx 已达到 FY2025 全年的约 **53.1%**（`27.9864 ÷ 52.7`）；DS CapEx 已达到 FY2025 DS 全年的约 **53.9%**（`25.6030 ÷ 47.5`）。这只能说明上半年支出强，**不能**据此线性外推全年 CapEx。
- Q2 总 CapEx 较 Q1 多 **5.5200 万亿韩元**；DS 多 **5.2176 万亿韩元**。这是今年设备/基建投入明显加速的硬数据。
- 半年报的用途说明为：DS 和 SDC 的产能扩张、先进节点/制程迁移及基础设施；还特别提到下一代存储技术与中长期需求的投资，同时也包括系统半导体先进节点。因此，DS 的 **25.6030 万亿韩元并不等于 Memory CapEx**。

> **最关键的限制：**三星没有在公开财报中把 DS CapEx 再拆为 DRAM、NAND、HBM、Foundry、System LSI。因此目前能严谨写出的最大粒度是 **DS 25.6030 万亿韩元**；“DRAM CapEx X 万亿”或“NAND CapEx Y 万亿”均属未披露，不能编造分摊比例。Q2 投资同时包含平泽 Memory 基建和 Taylor Foundry 扩建的报道，也印证不能把 DS 全部归给内存。

来源：[三星 FY2026 半年 interim report，第 21 页 CapEx 表](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_Half_Interim_Report.pdf)、[三星 FY2026 Q1 interim report](https://images.samsung.com/is/content/samsung/assets/global/ir/docs/2026_1Q_Interim_Report.pdf)、[FY2025 CapEx 公告](https://www.samsung.com/global/ir/reports-disclosures/public-disclosure-view.84547/)。Q2 电话会的约数及用途报道见 [Seoul Economic Daily，2026-07-30](https://en.sedaily.com/finance/2026/07/30/samsung-q2-capex-hits-168-trillion-won-as-taylor-fab)。

### 4.1 把 DS 25.6030 万亿韩元换算成产能：只能得到“资金规模等值”

三星没有披露每一笔 DS CapEx 所购设备的类型、设备单价、开始安装时间和对应产品；**因此不能将 25.6030 万亿韩元直接除成“新增 X 万片/月”。**这笔钱覆盖 Memory、Foundry、System LSI、制程转换、良率改善、厂务和基础设施，且一条新线的投资跨多个年度确认。

为给模型一个量级参照，可使用 P4 的**机械等值**（不是实际产能预测）：媒体估计 P4 单座 fab 的全周期投资约 **50 万亿韩元**；已报道的 P4 1c DRAM 线目标为约 **10–12 万片/月**。若作一个明知不成立的极端假设——H1 的 DS CapEx 全部用于建设同类 P4 DRAM 产能——则：

| 机械计算 | 结果 | 正确解读 |
|---|---:|---|
| `25.6030 ÷ 50` | **51.2%** | H1 DS 支出约相当于一座 P4 全周期投资的一半。 |
| `10 万片/月 × 51.2%` | **约 5.12 万片/月** | 仅为资金规模等值的下限端。 |
| `12 万片/月 × 51.2%` | **约 6.14 万片/月** | 仅为资金规模等值的上限端。 |

**结论：5.1–6.1 万片/月不是三星 2026 年已经新增的 DRAM 产能，甚至不是可靠预测；它只是“若全花在一条 P4 型新 DRAM 线，资金量大约够到什么量级”的上限式参照。**实际可归因于新增 Memory wafer 的比例必然低于 100%，且部分项目尚未投片，故不可将此数纳入当年供给。

比这个机械值更可靠的，是直接追踪 P4 的投片爬坡、产品结构和良率。完整 P4 投资额为媒体估计，且 P4 和 P5 均含多阶段建设，故仅作资本强度锚点。[Seoul Economic Daily，2026-04-23](https://en.sedaily.com/finance/2026/04/23/samsung-accelerates-p4-full-operation-by-six-months-to)

### 4.2 FY2027 产能增加：官方未给总目标，第三方口径显示“总量小增、P4 爬坡明显”

截至数据截止日，三星的公开财报、业绩材料和董事会投资事项**均未披露** FY2027 的公司级 DRAM/NAND 月投片目标、Memory-only CapEx 或全年 DS CapEx 目标。官方材料仅确认将增产、推进先进制程与 HBM；不能把这种方向性表述填成明确的 2027 wafer 数。[三星 FY2026Q2 业绩公告](https://news.samsung.com/global/samsung-electronics-announces-second-quarter-2026-results)

| 指标 | FY2026 | FY2027 | 变化 | 证据等级与应有用法 |
|---|---:|---:|---:|---|
| 三星 **总 DRAM** 年化 wafer capacity | 817.5 万片/年 | 828.0 万片/年 | **+10.5 万片/年，+1.28%**；折合平均月产能约 **+0.875 万片/月** | Omdia 数据的第三方预测；这是最适合用于公司总量模型的口径。 |
| 三星 **P4L DRAM 单线** 年末 wafer input | 约 6.5 万片/月（2026 年末） | 约 12–13 万片/月（接近满载） | **+5.5–6.5 万片/月** | LS Securities 的第三方线体爬坡预测；适合跟踪 P4 进度，不等于公司总量净增。 |
| 三星 **总 NAND** wafer capacity | 未披露 | 未披露 | 无法量化 | 无公司级可靠数字；已知重点仍是制程迁移、密度与产品组合。 |
| P5 对 2027 供给 | — | 年末竣工后仍需搬设备 | **不计入 2027 的实质 wafer 增量** | LS Securities 判断；若进度变化，需等设备搬入/投片确认。 |

**为什么两组 DRAM 数不能相加：**Omdia 是三星总 DRAM 年化产能（817.5→828.0 万片/年）；LS 是 P4 单线在年末由 ramp-up 走向接近满载的输入能力。P4 的提升可能已被总量预测部分反映，也可能同时伴随旧线转换/关停、HBM 占用和良率爬坡。将“总量 +0.875 万片/月”再加上“P4 +5.5–6.5 万片/月”会双重计算。

Omdia 总量数据及其“以 1c 转换和良率为先”的背景见 [ChosunBiz，2026-08-24](https://biz.chosun.com/en/en-it/2026/08/24/E4XCMURJTREG7GDXVGQZZNPM3Y/?outputType=amp)。P4L 的 2026 年末/2027 接近满载 input 与 P5 对 2026–2027 不贡献的判断见 [LS Securities Research，2026 年研究报告，第 33–34 页](https://consensus.hankyung.com/analysis/downpdf?report_idx=647122)。

## 5. 当前可以写进模型的结论

| 问题 | 当前最稳妥的输入 | 不应采用的输入 |
|---|---|---|
| 2026 DRAM/HBM 有无扩产 | 有：1z 产能/良率提升、HBM 供给扩张；P4 1c 新线是 2027 前后物理扩产线索 | 把 P4 报道的 10–12 万片/月直接计为 2026 已投产。 |
| 2026 NAND 有无扩产 | 有效 bit 供给通过 V9 QLC、高容量 eSSD 增加；总 wafer capex 未披露 | 将 V10 的 58% 密度提升当作公司已实现总 NAND 产能增长。 |
| 供给是否会很快松动 | 不能据此推断；公司仍称即使增产也受限，客户需求超出供给 | 用建厂新闻直接预测 ASP 回落。 |
| 如何量化 | 先用产品状态、季度 bit 指引、CapEx、P4 设备/量产确认建立情景 | 伪造 DRAM/NAND 单独厂级产能与毛利。 |

## 6. 可直接放进模型的数值表

### 6.1 DRAM：总 wafer capacity 与新增产线不能相加

| 指标 | 数值 | 计算/含义 | 证据等级 |
|---|---:|---|---|
| 三星 DRAM 2025 年化产能 | **769.5 万片 300mm wafer/年** | 即月均约 **64.13 万片** | 第三方：Omdia 数据由 ChosunBiz 报道。 |
| 三星 DRAM 2026 年化产能估计 | **817.5 万片/年** | 即月均约 **68.13 万片**；较 2025 年增加 **48 万片/年**，即平均每月约 **4 万片**，增幅 **6.24%**。 | 第三方：Omdia 预测/估计，不是公司实际投片披露。 |
| 三星 DRAM 2027 年化产能估计 | **828.0 万片/年** | 即月均约 **69.00 万片**；较 2026 年仅增加约 **0.88 万片/月**（+1.28%）。 | 第三方：Omdia 预测，不能当作已承诺 CapEx。 |
| P4 1c DRAM 新线目标 | **10–12 万片/月** | 报道中的目标投运期为 **2027Q1 前**；相当于 2026 年化总产能估计的约 **14.7%–17.6%**。 | 第三方媒体/行业消息；不是三星确认的已投产产能。 |
| 2026Q2 DRAM bit 出货 | 环比 **低十几%** 增长 | 不是月投片；是产出、良率、库存和产品组合共同作用后的销售结果。 | 公司电话会表述。 |
| 2026Q2 DRAM ASP | 环比 **中 40% 区间** 上涨 | 解释收入增长的价格因素；不能视为产能增长。 | 公司电话会表述。 |

**复算：**

- 2025 平均月产能：`7,695,000 ÷ 12 = 641,250` 片/月；2026：`8,175,000 ÷ 12 = 681,250` 片/月；差额 `40,000` 片/月。
- 2026 同比：`(8,175,000 ÷ 7,695,000 - 1) = 6.24%`。
- P4 相对 2026 总量的名义比例：`100,000 ÷ 681,250 = 14.7%`，`120,000 ÷ 681,250 = 17.6%`。

**关键限制：P4 的 10–12 万片/月不能与 817.5 万片/年相加。**Omdia 的 2026 总产能估计可能已反映部分现有线改造或扩充；P4 也可能替代旧线、服务 HBM 或在 2027 才达到稳定投片。正确用法是建立“保守/中性/积极”情景，而非得到一个虚假的 2027 月产能总数。

Omdia 数字及其“以 1c 转换和良率优先、而非激进扩 wafer”为背景见 [ChosunBiz 2026-08-24 报道](https://biz.chosun.com/en/en-it/2026/08/24/E4XCMURJTREG7GDXVGQZZNPM3Y/?outputType=amp)。P4 的月产能与时间目标见 [韩联社报道](https://www.yna.co.kr/amp/view/AKR20260205183600003)。Q2 bit/ASP 数据见 [三星 Q2 电话会记录](https://new.alphaspread.com/security/krx/005930/investor-relations/earnings-call/q2-2026)。

### 6.2 NAND：可量化的是西安单厂的短期回落，非三星总 NAND 产能

| 指标 | 数值 | 正确解释 | 证据等级 |
|---|---:|---|---|
| 西安 NAND 厂此前月产出 | 约 **15 万片/月** | 仅为三星西安厂的行业估计，不代表三星全球 NAND 总产能。 | 第三方行业消息。 |
| 西安厂 2026 年产出变化 | 约 **-5% 至 -6%** | 估计当前为约 **14.10–14.25 万片/月**；主因是设备更换、制程升级和良率重爬。 | 第三方行业消息。 |
| Q2 NAND bit 出货 | 环比 **低个位数** 增长 | 公司总 NAND 销售结果；不能用来验证西安厂或总投片。 | 公司电话会表述。 |
| Q3 NAND bit 指引 | 环比 **高个位数** 增长 | 管理层前瞻，不是已实现事实。 | 公司电话会表述。 |
| Q2 NAND ASP | 环比 **高 60% 区间** 上涨 | 价格弹性远大于 Q2 bit 增长，是 NAND 收入/利润改善的重要原因。 | 公司电话会表述。 |
| QLC bit 出货（2026H2 指引） | 较 H1 **超过 2 倍** | 是公司管理层的产品组合/bit 出货预期，不等同于 wafer input 翻倍。 | 媒体转述公司电话会。 |

**复算：**西安厂若以 15 万片/月为基准，`150,000 × (1 - 5%) = 142,500`，`150,000 × (1 - 6%) = 141,000`，即约 **14.10–14.25 万片/月**。这反映的是升级期的短期产出损失，不代表全公司 NAND 产能变化。

西安厂数据来自 [ChosunBiz 2026-04-22 报道](https://biz.chosun.com/en/en-it/2026/04/22/5BDWL5XKBNCFDGEZEYC3CC7BUU/?outputType=amp)。三星没有披露全球 NAND wafer input；TrendForce 也明确指出，2026 年 NAND 供给主要靠工艺迁移和既有 cleanroom 填充，而不是大规模绿地新厂，因此不应以一个未经验证的“全球三星 NAND 月产能”代替空白。[TrendForce 2026-07 行业更新](https://www.trendforce.com/presscenter/news/20260721-13148.html)

### 6.3 用这些数字得出的供给判断

| 判断 | 量化依据 | 判定 |
|---|---|---|
| 三星 DRAM wafer 供给在 2026 年增加，但增幅不大 | Omdia 估计从 769.5 万片/年升至 817.5 万片/年，+6.24% | 🟡 基本属实：为第三方估计，尚非公司实际投片。 |
| 2026 年 HBM 会立即带来充裕通用 DRAM 供给 | P4 10–12 万片/月目标在 2027Q1 前；HBM 优先占用先进 DRAM 与封装资源 | ❌ 不符：方向相反，HBM 扩张短期还可能压缩 DDR/LPDDR 的可用资源。 |
| 三星正在大幅扩充 NAND wafer 产能 | 西安厂估计从约 15 万片/月降至 14.10–14.25 万片/月；行业整体主要靠迁移增加 bit | ❌ 缺乏支持：目前是升级与有效 bit 增加，不是明确的大规模 wafer 扩张。 |
| NAND 销售可以快速增加 | Q2 bit +低个位数但 ASP +高 60% 区间；H2 QLC bit 预期 >2× H1 | ✅ 可以：收入/高价值 bit 可大幅增长，但这不等于物理 wafer 供给同比例增加。 |

### 6.4 过去两年新增 DRAM 供给能否满足数据中心需求？不能；且不能用“新增 wafer”单独计算

公开资料没有提供一套可审计的“2025–2026 全球新增 DRAM bit”与“数据中心新增 DRAM bit”绝对数，因此无法诚实地给出一个覆盖率百分比。但从可观测的行业供需结果判断，答案是 **❌ 不能完全满足**：TrendForce 估计 2026 年全球 DRAM sufficiency ratio（供给相对需求的充足率）约为 **-1% 至 -2%**，且预计 2027 年需求增速继续高于供给、缺口进一步扩大。

| 观察层次 | 过去两年的真实变化 | 对“能否满足数据中心需求”的含义 |
|---|---|---|
| 新增 wafer starts | 主要仍是既有厂房利用、设备改造和 P4 等分阶段 ramp-up；大规模新厂要到 2027H2 后才开始有意义的爬坡，显著产出多在 2028。 | 物理新增慢，不能跟上 CSP 的短期 AI 建设速度。 |
| 新增 DRAM bit | 制程迁移、密度与良率提升可让 bit 增长快于 wafer starts。 | 是供给的主要缓冲，但不足以消除总缺口。 |
| HBM 的资源占用 | HBM 单位 bit 需要显著更多 wafer input 和先进封装；扩 HBM 并不等于同比增加通用 DDR/LPDDR bit。 | 数据中心拿到更多 HBM 的同时，会进一步挤压普通 DRAM 的可用供给。 |
| 数据中心需求 | 北美 CSP 持续扩 CapEx，新 CPU 平台、Agentic AI、每台服务器更高的 HBM/DRAM 内容量共同拉动需求。 | 需求不仅增加服务器台数，也增加单台内存含量；所以“产能小增”不够。 |

三星自身的 Q2 表述与此相符：尽管努力增产，Memory 仍以有限产能优先供给服务器，预计服务器 DRAM、eSSD、HBM 的需求增长将保持市场供不应求。由此可推导，三星新增供给会优先流向 HBM、服务器 DDR 和 eSSD；这能改善其数据中心客户的**配额**，但不代表行业已经能充分满足所有数据中心需求。[三星 2026Q2 业绩公告](https://news.samsung.com/global/samsung-electronics-announces-second-quarter-2026-results)

**模型结论：**不要把 2025–2027 的新增 wafer/bit 当成“足以平衡数据中心需求”的供给情景。基准情景应为：DRAM 仍偏紧、服务器/HBM 优先获得新增供给、普通 DRAM 的有效供给更紧；只有当 CSP CapEx 或单机内存配置明显下修，或新厂的设备搬入和良率爬坡早于预期时，该判断才需要下调。TrendForce 的 2026–2027 供需判断见 [2026-07-30 行业更新](https://www.trendforce.com/presscenter/news/20260730-13158.html)。

## 7. 下一步核对清单

1. 三星 2026Q3 业绩材料：DRAM/NAND bit 增速是否实现 Q2 指引的中个位数/高个位数；
2. P4 1c 线：设备搬入、开始投片、良率、客户认证和量产的公司确认；
3. HBM4/HBM4E：HBM 供给能力增加是否转化为收入，而非仅停留在样品/产能预留；
4. NAND：V9 2Tb QLC 与 PM1763 的实际销量，以及 V10 是否有正式量产声明；
5. DS CapEx：2026 年后续季度是否将支出明确拆向 Memory、Foundry 或新 cleanroom。
