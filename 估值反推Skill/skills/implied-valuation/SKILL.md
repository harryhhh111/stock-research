# 估值条件反推

使用Python 3.10或更新版本，无第三方运行依赖。资源均相对本Skill目录，安装到任何位置都能使用。

## 执行

1. 明确主体/股类和价格日期。向用户集中取得价格、完整年度归属普通股股东利润、当前/目标股数、目标财年末、必要回报率和PE；字段与例子见 [输入约定](references/input.md)。不自动联网或刷新公司数据。缺来源则询问或如实标用户输入，不能编来源。
2. 检查同币种、股价和股数同一证券单位（尤其ADS/普通股）、正且可比的年度利润。先确认目标股数、回报率、PE及敏感性范围；目标股数可建议不变，但用户未确认不得默设。利润不可比、重大资本结构变化、特殊行业及亏损不强套本模型。
3. 按约定创建本次输入JSON。事实与假设分开：真实来源未核对用`user_input`，实际查过才用`verified`；示意值一律`synthetic`。完整年度利润必须在价格日已经公开，不能用未来资料解释历史股价。不得将`assumptions_confirmed`替用户设为true。
4. 运行本目录的脚本，使用绝对路径指向脚本与输入，输出放当前研究主体/主题目录。路径应正确引用；不要复制下面的占位路径作为实参：

   `python3 <skill目录>/scripts/valuation.py --input <本次输入.json> --output <项目目录>/估值反推-日期.html`

   演示时可直接使用`assets/example-input.json`，这是作者已设定的纯示意假设；输出必须明确为演示。脚本同时写同名JSON结果，拒绝覆盖已有文件。遇到输入错误先修正来源/口径，不能绕过验证或改写公式凑结果。
5. 检查同源HTML/JSON的数值与来源状态，验证离线、窄屏和打印可读；需要修版时使用新文件名。向用户返回可打开的HTML链接，简述条件答案、假设与限制。不要输出另一份Markdown研究报告。

## 必须说明

- 仅反推满足指定必要回报率的条件，不能声称这是市场唯一预期，也不能把估值残差归给“AGI CPU”等概念。
- 回报年数从价格日算起，利润增长年数从年度利润期末算起；二者可不同。程序按周年计时，具体公式及限制在HTML常驻展示。
- 延迟一年/两年仍固定回报率、PE和目标股数，比较需要多大终点利润；不冒充收入、费用、竞争变化的经营预测。
- 期间现金分红未建模，回购/稀释只通过目标股数假设反映。当前股数用于展示基准与确认单位，求解使用目标股数。程序只检查结构/算式，不能代替财报事实核验。
- 不主动发起购买、发布、收款、交易或把用户数据上传外部。只完成本次条件计算和报告。
